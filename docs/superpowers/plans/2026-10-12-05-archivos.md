# MC Server Manager — Plan 5: Archivos y transferencias

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pestaña *Archivos* del servidor: navegar `/data`, editar texto con CodeMirror 6, subir, descargar, renombrar, borrar y crear carpetas, con el agente confinado al directorio de datos y un mecanismo genérico de transferencias HTTP en streaming (`/agent/transfer/:id`) que reutilizarán backups y migración en la oleada B.

**Architecture:** El agente añade el paquete `internal/files` (validación léxica + `filepath.EvalSymlinks` con prefijo + E/S a través de `os.Root`, escrituras atómicas) y atiende los mensajes `Files*` del WebSocket; los ficheros grandes viajan por HTTP saliente del agente con su token (`conn.TransferClient`). El panel crea transferencias de un solo uso ligadas al nodo (`TransferService`), las sirve en `GET/PUT /agent/transfer/:id` y enlaza en streaming el cuerpo del navegador con el del agente, sin cargar nada en memoria ni pasar por disco; el staging (`<DATA_DIR>/staging`) queda listo para la oleada B. La web añade la pestaña con un navegador de ficheros y un editor CodeMirror cargado bajo demanda.

**Tech Stack:** Go 1.27.2 (`os.Root`, `net/http`), protobuf con buf 1.73; Node 26, Fastify 5 (parser `application/octet-stream` como stream), `node:stream`, zod 4; React 19, TanStack Query, CodeMirror 6 (`codemirror` 6.0.2, `@codemirror/state` 6.7, `@codemirror/view` 6.43, `@codemirror/language` 6.13, `@codemirror/lang-json` 6.0, `@codemirror/legacy-modes` 6.5, `@codemirror/theme-one-dark` 6.1; versiones comprobadas con `npm view` el 2026-10-12).

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` (§5.1 transferencias HTTP y staging, §5.3 `Files*`, §6.6 archivos, §8 pestaña Archivos, §9 seguridad, §10 errores). Hoja de ruta: `docs/superpowers/plans/README.md` (Plan 5). Coordinación de la oleada A: `docs/superpowers/plans/COORDINATION.md`.

- Confinamiento en tres barreras: validación léxica, `filepath.EvalSymlinks` + comprobación de prefijo **con separador** sobre la raíz real, y E/S con `os.Root` (un enlace cambiado entre comprobación y uso no escapa).

- Escrituras atómicas: temporal `.mcsm-tmp-<hex>` en la misma carpeta + `fsync` + `rename`; conserva permisos y uid/gid del fichero reemplazado; lo nuevo hereda uid/gid de su carpeta (el servidor itzg corre como uid 1000 y el agente como root).
- Transferencias (spec §5.1): `GET /agent/transfer/:id` (panel → agente) y `PUT /agent/transfer/:id` (agente → panel) con `Authorization: Bearer <token del nodo>`, fuera del guard de sesión. `transferId` = 32 bytes aleatorios en base64url (43 caracteres, `randomToken()`), **un solo uso**, ligado al nodo, caduca si no se reclama en 60 s (barrido cada 10 s). El panel genera el `transferId` y lo envía en `FilesDownload`/`FilesUpload` (la spec decía que `Download` lo devolvía el agente; lo genera quien autoriza la petición HTTP).
- Staging: `<DATA_DIR>/staging`, se vacía al arrancar, se barre cada hora (> 24 h). Los flujos del navegador de este plan **no** pasan por disco.
- API del navegador (todas con sesión): `GET /api/servers/:id/files?path=`, `GET …/files/stat?path=`, `GET …/files/content?path=`, `POST …/files/content {path, content}`, `POST …/files/mkdir {path}`, `POST …/files/rename {from, to}`, `DELETE …/files?path=`, `GET …/files/download?path=`, `PUT …/files/upload?path=` (cuerpo `application/octet-stream`).
- Códigos de error del agente → HTTP: `invalid_path`/`path_outside`/`root`/`is_dir`/`not_dir` → 400, `unknown_server`/`not_found` → 404, `exists`/`disconnected` → 409, `too_large` → 413, `timeout` → 504, `transfer_failed`/`io_error`/otros → 502 con el texto del agente (spec §10).
- Respuestas del agente: toda respuesta con datos se llama `*Result`; el hub las reconoce con `isResponseCase` (ack, error y `*Result`).
- Descargas: `content-type: application/octet-stream`, `x-content-type-options: nosniff`, `content-disposition` RFC 6266/5987; nunca se sirve un fichero del servidor "inline".

## Review Focus

1. **Rutas que salen de `/data`** — `../../etc/passwd` → 400 en el panel (zod) y `invalid_path` en el agente; un enlace creado dentro de `/data` por un plugin (absoluto, relativo, o hacia la carpeta hermana `data2` que comparte prefijo) → `path_outside`, también cuando el componente final no existe; un enlace cambiado entre la comprobación y el uso (TOCTOU) no escapa gracias a `os.Root`. Tests: Task 2 (`TestTraversalRejected`, `TestSymlinksOutsideAreRejected`, `TestTOCTOUSwapToSymlinkIsRefused`), Task 3 (`TestWriteErrors`, `TestRename`, `TestDelete`), Task 6, Task 9 (400 con el nodo desconectado), Task 13.
2. **Escrituras que dejan el fichero a medias o con otro dueño** — un guardado o subida cortados no tocan el original ni dejan temporales; se conservan permisos y uid/gid para que itzg (uid 1000) pueda reescribir `server.properties`. Tests: Task 3 (`TestWriteFailureKeepsOriginal`, `TestWriteTruncatedTransferKeepsOriginal`, `TestWriteReplacesAtomicallyKeepingMode`), Task 5 (`TestFilesUploadTruncatedDoesNotReplace`), Task 13 (`stat` del fichero subido).
3. **Límite inline de 2 MiB** — leer o guardar más de 2 MiB da 413 con un mensaje que manda descargar; una FIFO dentro de `/data` no bloquea al agente. Tests: Task 2 (`TestReadLimits`), Task 3, Task 9 (413 sin llegar al agente), Task 11 (`canEdit`).
4. **Subida de 50 MB sin cargar en memoria** — el panel no acumula el cuerpo (el agente recibe datos antes de que el navegador termine de enviar), el agente escribe con memoria constante y un corte del agente devuelve al navegador su error en JSON, no un corte de red. Tests: Task 3 (`TestWriteFromStreamsWithoutBuffering`), Task 5 (`TestFilesUploadStreamsFromPanel`), Task 10 (subida de 50 MiB con compuerta y corte del agente), Task 13 (RSS del panel).
5. **`transferId` reutilizado, ajeno o abandonado** — segundo uso → 404; el token de otro nodo → 404 sin quemarlo; sin reclamar en 60 s → caduca y la subida del navegador recibe 504; `HEAD` no lo consume; el staging se vacía al arrancar y se barre. Tests: Task 7, Task 8 y Task 10 (subida con el agente que nunca hace el GET).
6. **Nombres de descarga y tipo de contenido** — `mundo ñ.dat`, comillas o `\r\n` en el nombre no rompen ni inyectan cabeceras; un `.html` subido nunca se renderiza en el origen del panel (`octet-stream` + `nosniff`). Tests: Task 10 (`contentDisposition`, cabeceras de la descarga).

```proto
// ── plan-5 ──
// Archivos de un servidor (spec §5.3, §6.6). Las rutas son relativas a /data del
// servidor, con "/" como separador ("/" es la raíz); el agente rechaza ".." y
// caracteres de control. Respuestas: los *Result, Ack o Error{code, message} con
// code ∈ invalid_path|path_outside|unknown_server|not_found|exists|is_dir|not_dir|
// too_large|root|transfer_failed|io_error.

message FileEntry {
  string name = 1;
  bool dir = 2;
  bool symlink = 3;
  uint64 size = 4;
  int64 mod_time_unix_ms = 5;
  uint32 mode = 6; // bits de permisos (0o755…)
}

message FilesList {
  string server_id = 1;
  string path = 2;
}

message FilesListResult {
  repeated FileEntry entries = 1; // carpetas primero, luego por nombre
  bool truncated = 2; // la carpeta tiene más entradas de las devueltas
}

message FilesStat {
  string server_id = 1;
  string path = 2;
}

message FilesStatResult {
  FileEntry entry = 1;
}

// Lectura inline: como máximo 2 MiB (o max_bytes si es menor); si no, too_large.
message FilesRead {
  string server_id = 1;
  string path = 2;
  uint32 max_bytes = 3;
}

message FilesReadResult {
  bytes content = 1;
  uint64 size = 2;
}

// Escritura inline atómica (temporal + rename), como máximo 2 MiB. Respuesta: Ack.
message FilesWrite {
  string server_id = 1;
  string path = 2;
  bytes content = 3;
}

message FilesMkdir {
  string server_id = 1;
  string path = 2;
}

// No sobrescribe: si `to` existe responde exists.
message FilesRename {
  string server_id = 1;
  string from = 2;
  string to = 3;
}

// Una carpeta se borra con todo su contenido; un enlace se borra a sí mismo.
message FilesDelete {
  string server_id = 1;
  string path = 2;
}

// El agente sube el fichero con PUT /agent/transfer/{transfer_id} y responde Ack
// cuando el panel lo ha recibido entero.
message FilesDownload {
  string server_id = 1;
  string path = 2;
  string transfer_id = 3;
}

// El agente descarga el contenido con GET /agent/transfer/{transfer_id}, lo escribe
// de forma atómica y responde Ack. size = -1 si el panel no conoce el tamaño.
message FilesUpload {
  string server_id = 1;
  string path = 2;
  string transfer_id = 3;
  int64 size = 4;
}
```

```go
// layout crea <tmp>/srv/alpha/data (la raíz), un secreto fuera de ella y una carpeta hermana
// data2 cuyo nombre comparte prefijo con la raíz.
func layout(t *testing.T) (fsys *FS, root, outside string) {
	t.Helper()
	base := t.TempDir()
	root = filepath.Join(base, "srv", "alpha", "data")
	outside = filepath.Join(base, "outside")
	for _, d := range []string{root, outside, filepath.Join(root, "mods"), filepath.Join(root, "config"), filepath.Join(base, "srv", "alpha", "data2")} {
		if err := os.MkdirAll(d, 0o755); err != nil {
			t.Fatal(err)
		}
	}
	write(t, filepath.Join(outside, "secret.txt"), "SECRETO")
	write(t, filepath.Join(base, "srv", "alpha", "data2", "secret.txt"), "SECRETO2")
	write(t, filepath.Join(root, "server.properties"), "motd=hola\n")
	write(t, filepath.Join(root, "config", "a.yml"), "a: 1\n")
	return New(root), root, outside
}

func write(t *testing.T, p, s string) {
	t.Helper()
	if err := os.WriteFile(p, []byte(s), 0o644); err != nil {
		t.Fatal(err)
	}
}

func TestClean(t *testing.T) {
	ok := map[string]string{"": ".", "/": ".", ".": ".", "mods": "mods", "/mods/a.jar": "mods/a.jar", "mods//a.jar/": "mods/a.jar", "./config/./a.yml": "config/a.yml", "con espacios/ñ.txt": "con espacios/ñ.txt"}

func TestTraversalRejected(t *testing.T) {
	fsys, _, _ := layout(t)
	if _, _, err := fsys.Read("../../etc/passwd", 0); !errors.Is(err, ErrInvalidPath) || Code(err) != "invalid_path" {
```

```go
// Package files implementa las operaciones de archivos de un servidor confinadas a
// su directorio de datos (spec §6.6).
//
// Cada ruta pasa por tres barreras:
//  1. Clean: validación léxica; ".." y caracteres de control se rechazan, nunca se "arreglan".
//  2. resolve: filepath.EvalSymlinks + comprobación de prefijo con separador sobre la raíz real.
//  3. La E/S se hace con os.Root (openat sin seguir enlaces que salgan de la raíz): si un enlace
//     se cambia entre la comprobación y el uso (TOCTOU), la operación falla en vez de escapar.
package files

import (
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"
	"syscall"
	"time"

	"mcsm/agent/internal/spec"
)

// InlineMax es el máximo de lectura/escritura inline por el WebSocket (spec §6.6).
const InlineMax = 2 << 20

// maxEntries limita un listado; el resto se marca como truncado. Variable para los tests.
var maxEntries = 5000

// tmpPrefix marca los temporales de las escrituras atómicas (se ocultan en los listados).
const tmpPrefix = ".mcsm-tmp-"

var (
	ErrInvalidPath   = errors.New("ruta inválida")
	ErrOutside       = errors.New("la ruta sale del directorio del servidor")
	ErrUnknownServer = errors.New("servidor desconocido en este nodo")
	ErrNotFound      = errors.New("no existe")
	ErrExists        = errors.New("ya existe")
	ErrIsDir         = errors.New("es una carpeta")
	ErrNotDir        = errors.New("no es una carpeta")
	ErrTooLarge      = errors.New("demasiado grande para abrirlo en línea (máx. 2 MiB): descárgalo")
	ErrRoot          = errors.New("no se puede modificar la carpeta raíz del servidor")
	ErrTransfer      = errors.New("transferencia fallida")
)

// Code traduce un error a su código de protocolo (Error.code).
func Code(err error) string {
	switch {
	case errors.Is(err, ErrInvalidPath):
		return "invalid_path"
	case errors.Is(err, ErrOutside):
		return "path_outside"
	case errors.Is(err, ErrUnknownServer):
		return "unknown_server"
	case errors.Is(err, ErrNotFound):
		return "not_found"
	case errors.Is(err, ErrExists):
		return "exists"
	case errors.Is(err, ErrIsDir):
		return "is_dir"
	case errors.Is(err, ErrNotDir):
		return "not_dir"
	case errors.Is(err, ErrTooLarge):
		return "too_large"
	case errors.Is(err, ErrRoot):
		return "root"
	case errors.Is(err, ErrTransfer):
		return "transfer_failed"
	default:
		return "io_error"
	}
}

// Entry describe un fichero o carpeta.
type Entry struct {
	Name    string
	Dir     bool
	Symlink bool
	Size    int64
	ModTime time.Time
	Mode    fs.FileMode // solo bits de permisos
}

// Root devuelve el directorio de datos de un servidor: <dataRoot>/<slug>/data.
func Root(dataRoot, slug string) (string, error) {
	if !spec.ValidSlug(slug) {
		return "", fmt.Errorf("%w: slug %q", ErrInvalidPath, slug)
	}
	return filepath.Join(filepath.Clean(dataRoot), slug, "data"), nil
}

// FS opera dentro de una raíz.
type FS struct {
	root string
	// afterCheck se invoca entre la comprobación de una ruta y su uso. Solo para tests (TOCTOU).
	afterCheck func()
}

// New crea un FS confinado a root (normalmente el resultado de Root).
func New(root string) *FS { return &FS{root: filepath.Clean(root)} }

// Clean valida una ruta del panel ("/", "mods/a.jar", "/config/x.yml") y la devuelve relativa
// a la raíz, con "/" como separador ("." es la raíz).
func Clean(p string) (string, error) {
	if len(p) > 4096 {
		return "", fmt.Errorf("%w: demasiado larga", ErrInvalidPath)
	}
	parts := make([]string, 0, 8)
	for _, seg := range strings.Split(p, "/") {
		switch seg {
		case "", ".":
			continue
		case "..":
			return "", fmt.Errorf("%w: no se permite «..»", ErrInvalidPath)
		}
		for _, r := range seg {
			if r < 0x20 || r == 0x7f {
				return "", fmt.Errorf("%w: contiene caracteres de control", ErrInvalidPath)
			}
		}
		parts = append(parts, seg)
	}
	if len(parts) == 0 {
		return ".", nil
	}
	return strings.Join(parts, "/"), nil
}

// display es la ruta tal y como la ve el usuario ("/" + relativa).
func display(rel string) string {
	if rel == "." {
		return "/"
	}
	return "/" + rel
}

// within comprueba que p es root o cuelga de root. El separador evita que /x/data2
// pase por estar "dentro" de /x/data.
func within(root, p string) bool {
	return p == root || strings.HasPrefix(p, root+string(filepath.Separator))
}

// realRoot resuelve los enlaces de la propia raíz (DATA_ROOT puede ser un enlace).
func (f *FS) realRoot() (string, error) {
	r, err := filepath.EvalSymlinks(f.root)
	if errors.Is(err, fs.ErrNotExist) {
		return "", fmt.Errorf("%w: la carpeta de datos del servidor aún no existe (arráncalo una vez)", ErrNotFound)
	}
	if err != nil {
		return "", fmt.Errorf("error de E/S en la carpeta de datos: %v", errors.Unwrap(err))
	}
	return r, nil
}

// resolve aplica la spec §6.6 a una ruta limpia: EvalSymlinks y prefijo. Devuelve la ruta real
// relativa a la raíz real (siguiendo los enlaces que quedan dentro).
func (f *FS) resolve(rel string) (string, error) {
	root, err := f.realRoot()
	if err != nil {
		return "", err
	}
	real, err := filepath.EvalSymlinks(filepath.Join(root, filepath.FromSlash(rel)))
	if err != nil {
		if errors.Is(err, fs.ErrNotExist) || errors.Is(err, syscall.ENOTDIR) {
			// Si un componente intermedio sale de la raíz se informa como tal, no como
			// "no existe": no se revela qué hay fuera.
			if rel != "." {
				if _, perr := f.resolve(path.Dir(rel)); errors.Is(perr, ErrOutside) {
					return "", perr
				}
			}
			return "", fmt.Errorf("%w: %s", ErrNotFound, display(rel))
		}
		return "", fmt.Errorf("%w: %s", ErrInvalidPath, display(rel))
	}
	if !within(root, real) {
		return "", fmt.Errorf("%w: %s", ErrOutside, display(rel))
	}
	out, err := filepath.Rel(root, real)
	if err != nil {
		return "", fmt.Errorf("%w: %s", ErrOutside, display(rel))
	}
	return filepath.ToSlash(out), nil
}

// resolveEntry resuelve la carpeta padre (siguiendo enlaces) y conserva el último componente
// sin seguirlo: borrar o renombrar un enlace actúa sobre el enlace, nunca sobre su destino.
func (f *FS) resolveEntry(rel string) (string, error) {
	if rel == "." {
		return "", ErrRoot
	}
	parent, err := f.resolve(path.Dir(rel))
	if err != nil {
		return "", err
	}
	return path.Join(parent, path.Base(rel)), nil
}

// open abre la raíz real como os.Root. Se abre en cada operación: una restauración de backup
// renombra la carpeta y un descriptor guardado apuntaría a la antigua.
func (f *FS) open() (*os.Root, error) {
	if f.afterCheck != nil {
		f.afterCheck()
	}
	root, err := f.realRoot()
	if err != nil {
		return nil, err
	}
	r, err := os.OpenRoot(root)
	if err != nil {
		return nil, fmt.Errorf("error de E/S en la carpeta de datos: %v", errors.Unwrap(err))
	}
	return r, nil
}

// isEscape detecta el error de os.Root cuando una ruta sale de la raíz.
func isEscape(err error) bool {
	var pe *fs.PathError
	if errors.As(err, &pe) && pe.Err != nil && pe.Err.Error() == "path escapes from parent" {
		return true
	}
	var le *os.LinkError
	return errors.As(err, &le) && le.Err != nil && le.Err.Error() == "path escapes from parent"
}

// mapErr traduce errores de os.Root a los errores del paquete, sin rutas absolutas del host.
func mapErr(err error, rel string) error {
	if err == nil {
		return nil
	}
	d := display(rel)
	switch {
	case isEscape(err):
		return fmt.Errorf("%w: %s", ErrOutside, d)
	case errors.Is(err, fs.ErrNotExist):
		return fmt.Errorf("%w: %s", ErrNotFound, d)
	case errors.Is(err, fs.ErrExist):
		return fmt.Errorf("%w: %s", ErrExists, d)
	case errors.Is(err, syscall.ENOTDIR):
		return fmt.Errorf("%w: %s", ErrNotDir, d)
	case errors.Is(err, syscall.EISDIR):
		return fmt.Errorf("%w: %s", ErrIsDir, d)
	case errors.Is(err, syscall.EINVAL):
		return fmt.Errorf("%w: %s", ErrInvalidPath, d)
	}
	cause := err
	var pe *fs.PathError
	var le *os.LinkError
	if errors.As(err, &pe) {
		cause = pe.Err
	} else if errors.As(err, &le) {
		cause = le.Err
	}
	return fmt.Errorf("error de E/S en %s: %v", d, cause)
}

func entryOf(name string, info fs.FileInfo) Entry {
	return Entry{
		Name: name, Dir: info.IsDir(), Symlink: info.Mode()&fs.ModeSymlink != 0,
		Size: info.Size(), ModTime: info.ModTime(), Mode: info.Mode().Perm(),
	}
}

// List devuelve el contenido de una carpeta: carpetas primero y luego por nombre. Los enlaces
// que apuntan dentro de la raíz se describen por su destino; los que salen, como enlaces.
func (f *FS) List(p string) ([]Entry, bool, error) {
	rel, err := Clean(p)
	if err != nil {
		return nil, false, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, false, err
	}
	r, err := f.open()
	if err != nil {
		return nil, false, err
	}
	defer r.Close()
	d, err := r.Open(real)
	if err != nil {
		return nil, false, mapErr(err, rel)
	}
	defer d.Close()
	st, err := d.Stat()
	if err != nil {
		return nil, false, mapErr(err, rel)
	}
	if !st.IsDir() {
		return nil, false, fmt.Errorf("%w: %s", ErrNotDir, display(rel))
	}
	des, err := d.ReadDir(maxEntries + 1)
	if err != nil && !errors.Is(err, io.EOF) {
		return nil, false, mapErr(err, rel)
	}
	truncated := len(des) > maxEntries
	if truncated {
		des = des[:maxEntries]
	}
	out := make([]Entry, 0, len(des))
	for _, de := range des {
		if strings.HasPrefix(de.Name(), tmpPrefix) {
			continue
		}
		info, err := de.Info()
		if err != nil {
			continue // borrado entre ReadDir e Info
		}
		e := entryOf(de.Name(), info)
		if e.Symlink {
			if target, err := r.Stat(path.Join(real, de.Name())); err == nil {
				e.Dir, e.Size, e.ModTime = target.IsDir(), target.Size(), target.ModTime()
			}
		}
		out = append(out, e)
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].Dir != out[j].Dir {
			return out[i].Dir
		}
		return strings.ToLower(out[i].Name) < strings.ToLower(out[j].Name)
	})
	return out, truncated, nil
}

// Stat describe una ruta siguiendo los enlaces que quedan dentro de la raíz.
func (f *FS) Stat(p string) (Entry, error) {
	rel, err := Clean(p)
	if err != nil {
		return Entry{}, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return Entry{}, err
	}
	r, err := f.open()
	if err != nil {
		return Entry{}, err
	}
	defer r.Close()
	info, err := r.Stat(real)
	if err != nil {
		return Entry{}, mapErr(err, rel)
	}
	return entryOf(path.Base(display(rel)), info), nil
}

// openRegular abre solo ficheros regulares. O_NONBLOCK evita quedarse bloqueado al abrir una
// FIFO que alguien haya creado dentro de /data; en un fichero regular no tiene efecto.
func openRegular(r *os.Root, real, rel string) (*os.File, fs.FileInfo, error) {
	fh, err := r.OpenFile(real, os.O_RDONLY|syscall.O_NONBLOCK, 0)
	if err != nil {
		return nil, nil, mapErr(err, rel)
	}
	info, err := fh.Stat()
	if err != nil {
		fh.Close()
		return nil, nil, mapErr(err, rel)
	}
	if info.IsDir() {
		fh.Close()
		return nil, nil, fmt.Errorf("%w: %s", ErrIsDir, display(rel))
	}
	if !info.Mode().IsRegular() {
		fh.Close()
		return nil, nil, fmt.Errorf("%w: %s no es un fichero normal", ErrInvalidPath, display(rel))
	}
	return fh, info, nil
}

// Read lee un fichero entero si no supera max (o InlineMax si max <= 0 o es mayor).
func (f *FS) Read(p string, max int64) ([]byte, int64, error) {
	if max <= 0 || max > InlineMax {
		max = InlineMax
	}
	rel, err := Clean(p)
	if err != nil {
		return nil, 0, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, 0, err
	}
	r, err := f.open()
	if err != nil {
		return nil, 0, err
	}
	defer r.Close()
	fh, info, err := openRegular(r, real, rel)
	if err != nil {
		return nil, 0, err
	}
	defer fh.Close()
	if info.Size() > max {
		return nil, info.Size(), fmt.Errorf("%w: %s ocupa %d bytes", ErrTooLarge, display(rel), info.Size())
	}
	data, err := io.ReadAll(io.LimitReader(fh, max+1))
	if err != nil {
		return nil, 0, mapErr(err, rel)
	}
	if int64(len(data)) > max { // creció mientras se leía
		return nil, int64(len(data)), fmt.Errorf("%w: %s", ErrTooLarge, display(rel))
	}
	return data, info.Size(), nil
}

// Open abre un fichero regular para descargarlo en streaming. El llamante lo cierra.
func (f *FS) Open(p string) (*os.File, Entry, error) {
	rel, err := Clean(p)
	if err != nil {
		return nil, Entry{}, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, Entry{}, err
	}
	r, err := f.open()
	if err != nil {
		return nil, Entry{}, err
	}
	defer r.Close() // el fichero abierto sigue siendo válido tras cerrar la raíz
	fh, info, err := openRegular(r, real, rel)
	if err != nil {
		return nil, Entry{}, err
	}
	return fh, entryOf(path.Base(rel), info), nil
}
```

```go
package files

import (
	"bytes"
	"crypto/rand"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"syscall"
)

// writeTarget es el destino ya validado de una escritura.
type writeTarget struct {
	real  string      // ruta real relativa a la raíz
	mode  fs.FileMode // permisos a conservar (0o644 si es nuevo)
	owner fs.FileInfo // de quién copiar uid/gid: el fichero reemplazado o su carpeta
}

// prepareWrite valida el destino de una escritura: la carpeta existe y está dentro, el destino
// no es una carpeta y, si es un enlace que queda dentro, se escribe en su destino real.
func (f *FS) prepareWrite(r *os.Root, rel string) (writeTarget, error) {
	target, err := f.resolveEntry(rel)
	if err != nil {
		return writeTarget{}, err
	}
	li, err := r.Lstat(target)
	switch {
	case err == nil:
		if li.Mode()&fs.ModeSymlink != 0 {
			if target, err = f.resolve(target); err != nil {
				return writeTarget{}, err
			}
			if li, err = r.Stat(target); err != nil {
				return writeTarget{}, mapErr(err, rel)
			}
		}
		if li.IsDir() {
			return writeTarget{}, fmt.Errorf("%w: %s", ErrIsDir, display(rel))
		}
		if !li.Mode().IsRegular() {
			return writeTarget{}, fmt.Errorf("%w: %s no es un fichero normal", ErrInvalidPath, display(rel))
		}
		return writeTarget{real: target, mode: li.Mode().Perm(), owner: li}, nil
	case errors.Is(err, fs.ErrNotExist):
		pi, err := r.Stat(path.Dir(target))
		if err != nil {
			return writeTarget{}, mapErr(err, path.Dir(rel))
		}
		if !pi.IsDir() {
			return writeTarget{}, fmt.Errorf("%w: %s", ErrNotDir, display(path.Dir(rel)))
		}
		return writeTarget{real: target, mode: 0o644, owner: pi}, nil
	default:
		return writeTarget{}, mapErr(err, rel)
	}
}

// CheckWrite valida que p se puede escribir sin tocar nada. Sirve para fallar antes de
// empezar una transferencia; WriteFrom vuelve a validar al escribir.
func (f *FS) CheckWrite(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	_, err = f.prepareWrite(r, rel)
	return err
}

// readErr marca los errores que vienen del origen (la transferencia), no del disco.
type readErr struct{ error }

func (e readErr) Unwrap() error { return e.error }

type tagReader struct{ r io.Reader }

func (t tagReader) Read(p []byte) (int, error) {
	n, err := t.r.Read(p)
	if err != nil && err != io.EOF {
		err = readErr{err}
	}
	return n, err
}

func randHex() string {
	b := make([]byte, 8)
	_, _ = rand.Read(b)
	return hex.EncodeToString(b)
}

// WriteFrom escribe src en p de forma atómica: temporal en la misma carpeta, fsync y rename.
// Si algo falla, el fichero anterior queda intacto y el temporal se borra. expected >= 0 exige
// ese número exacto de bytes (una transferencia truncada nunca reemplaza el fichero). Conserva
// permisos y dueño del fichero reemplazado; uno nuevo hereda el dueño de su carpeta, para que
// el servidor (uid 1000 en itzg) pueda seguir reescribiéndolo aunque el agente sea root.
// Copia en streaming: la memoria usada no depende del tamaño.
func (f *FS) WriteFrom(p string, src io.Reader, expected int64) (int64, error) {
	rel, err := Clean(p)
	if err != nil {
		return 0, err
	}
	r, err := f.open()
	if err != nil {
		return 0, err
	}
	defer r.Close()
	wt, err := f.prepareWrite(r, rel)
	if err != nil {
		return 0, err
	}
	tmp := path.Join(path.Dir(wt.real), tmpPrefix+randHex())
	fh, err := r.OpenFile(tmp, os.O_WRONLY|os.O_CREATE|os.O_EXCL, wt.mode)
	if err != nil {
		return 0, mapErr(err, rel)
	}
	closed, renamed := false, false
	defer func() {
		if !closed {
			fh.Close()
		}
		if !renamed {
			_ = r.Remove(tmp)
		}
	}()
	n, err := io.Copy(fh, tagReader{src})
	if err != nil {
		var re readErr
		if errors.As(err, &re) {
			return n, fmt.Errorf("%w: %v", ErrTransfer, re.error)
		}
		return n, mapErr(err, rel)
	}
	if expected >= 0 && n != expected {
		return n, fmt.Errorf("%w: recibidos %d de %d bytes", ErrTransfer, n, expected)
	}
	if err := fh.Chmod(wt.mode); err != nil { // el umask pudo recortar los permisos al crear
		return n, mapErr(err, rel)
	}
	chownLike(fh, wt.owner)
	if err := fh.Sync(); err != nil {
		return n, mapErr(err, rel)
	}
	closed = true
	if err := fh.Close(); err != nil {
		return n, mapErr(err, rel)
	}
	if err := r.Rename(tmp, wt.real); err != nil {
		return n, mapErr(err, rel)
	}
	renamed = true
	if d, err := r.Open(path.Dir(wt.real)); err == nil { // que el rename sobreviva a un corte de luz
		_ = d.Sync()
		d.Close()
	}
	return n, nil
}

// Write es la escritura inline (editor): como máximo InlineMax bytes.
func (f *FS) Write(p string, data []byte) error {
	if len(data) > InlineMax {
		return fmt.Errorf("%w: %d bytes", ErrTooLarge, len(data))
	}
	_, err := f.WriteFrom(p, bytes.NewReader(data), int64(len(data)))
	return err
}

// chownLike copia uid/gid de ref. Sin privilegios falla con EPERM y se ignora: el fichero
// queda del usuario del agente, que es el mismo que el de la carpeta en ese caso.
func chownLike(fh *os.File, ref fs.FileInfo) {
	if st, ok := ref.Sys().(*syscall.Stat_t); ok {
		_ = fh.Chown(int(st.Uid), int(st.Gid))
	}
}

// Mkdir crea una carpeta (su padre debe existir) con el dueño de la carpeta padre.
func (f *FS) Mkdir(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	target, err := f.resolveEntry(rel)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	pi, err := r.Stat(path.Dir(target))
	if err != nil {
		return mapErr(err, path.Dir(rel))
	}
	if err := r.Mkdir(target, 0o755); err != nil {
		return mapErr(err, rel)
	}
	if st, ok := pi.Sys().(*syscall.Stat_t); ok {
		_ = r.Lchown(target, int(st.Uid), int(st.Gid))
	}
	return nil
}

// Rename mueve o renombra sin sobrescribir: si el destino existe devuelve ErrExists.
// Renombrar un enlace mueve el enlace, no su destino.
func (f *FS) Rename(from, to string) error {
	src, err := Clean(from)
	if err != nil {
		return err
	}
	dst, err := Clean(to)
	if err != nil {
		return err
	}
	s, err := f.resolveEntry(src)
	if err != nil {
		return err
	}
	d, err := f.resolveEntry(dst)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	if _, err := r.Lstat(s); err != nil {
		return mapErr(err, src)
	}
	if _, err := r.Lstat(d); err == nil {
		return fmt.Errorf("%w: %s", ErrExists, display(dst))
	} else if !errors.Is(err, fs.ErrNotExist) {
		return mapErr(err, dst)
	}
	if err := r.Rename(s, d); err != nil {
		return mapErr(err, dst)
	}
	return nil
}

// Delete borra un fichero, un enlace (no su destino) o una carpeta con todo su contenido.
func (f *FS) Delete(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	target, err := f.resolveEntry(rel)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	li, err := r.Lstat(target)
	if err != nil {
		return mapErr(err, rel)
	}
	if li.IsDir() {
		return mapErr(r.RemoveAll(target), rel)
	}
	return mapErr(r.Remove(target), rel)
}
```

```go
// ErrTransferNotFound: el panel no conoce el transfer_id (caducado, ya usado o de otro nodo).
var ErrTransferNotFound = errors.New("el panel no reconoce la transferencia (caducada o ya usada)")

// transferIDRe: 32 bytes aleatorios en base64url, como los genera el panel.
var transferIDRe = regexp.MustCompile(`^[A-Za-z0-9_-]{43}$`)

// transferHTTP se comparte para reutilizar conexiones. Sin Timeout global: los cuerpos van en
// streaming y los corta el context; solo se acota el diálogo y la espera de cabeceras.
var transferHTTP = &http.Client{Transport: &http.Transport{
	Proxy:                 http.ProxyFromEnvironment,
	DialContext:           (&net.Dialer{Timeout: dialTimeout, KeepAlive: 30 * time.Second}).DialContext,
	ResponseHeaderTimeout: 60 * time.Second,
	IdleConnTimeout:       90 * time.Second,
	MaxIdleConnsPerHost:   4,
}}

// TransferClient hace las transferencias HTTP salientes del agente (spec §5.1):
// GET y PUT /agent/transfer/{id} con el token del nodo.
type TransferClient struct {
	base  string
	token string
	http  *http.Client
}

// NewTransferClient crea un cliente para el panel en panelURL con el token del nodo.
func NewTransferClient(panelURL, token string) *TransferClient {
	return &TransferClient{base: strings.TrimRight(panelURL, "/"), token: token, http: transferHTTP}
}

func (c *TransferClient) newRequest(ctx context.Context, method, id string, body io.Reader) (*http.Request, error) {
	if !transferIDRe.MatchString(id) {
		return nil, fmt.Errorf("transfer_id inválido %q", id)
	}
	req, err := http.NewRequestWithContext(ctx, method, c.base+"/agent/transfer/"+id, body)
	if err != nil {
		return nil, err
	}
	req.Header.Set("Authorization", "Bearer "+c.token)
	return req, nil
}

func statusErr(resp *http.Response) error {
	if resp.StatusCode >= 200 && resp.StatusCode < 300 {
		return nil
	}
	if resp.StatusCode == http.StatusNotFound {
		return ErrTransferNotFound
	}
	msg, _ := io.ReadAll(io.LimitReader(resp.Body, 4096))
	return fmt.Errorf("el panel respondió %d: %s", resp.StatusCode, strings.TrimSpace(string(msg)))
}

// Get abre una transferencia panel → agente. Devuelve el cuerpo en streaming (el llamante lo
// cierra) y su tamaño, o -1 si el panel no lo indicó.
func (c *TransferClient) Get(ctx context.Context, id string) (io.ReadCloser, int64, error) {
	req, err := c.newRequest(ctx, http.MethodGet, id, nil)
	if err != nil {
		return nil, 0, err
	}
	resp, err := c.http.Do(req)
	if err != nil {
		return nil, 0, err
	}
	if err := statusErr(resp); err != nil {
		resp.Body.Close()
		return nil, 0, err
	}
	return resp.Body, resp.ContentLength, nil
}

// Put envía body en una transferencia agente → panel. size >= 0 fija Content-Length (si el
// cuerpo tiene otro tamaño la petición falla); -1 usa chunked. Termina cuando el panel ha
// recibido y reenviado todo (responde 204).
func (c *TransferClient) Put(ctx context.Context, id string, body io.Reader, size int64) error {
	if size == 0 {
		body = http.NoBody // con ContentLength 0 y cuerpo no nulo Go usaría chunked
	}
	req, err := c.newRequest(ctx, http.MethodPut, id, body)
	if err != nil {
		return err
	}
	req.ContentLength = size
	req.Header.Set("Content-Type", "application/octet-stream")
	resp, err := c.http.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()
	if err := statusErr(resp); err != nil {
		return err
	}
	_, _ = io.Copy(io.Discard, io.LimitReader(resp.Body, 4096))
	return nil
}
```

```go
	n := copy(b, patternBlock[p.off%251:])
```

```go
func (a *App) handleFiles(ctx context.Context, env *mcsmv1.Envelope, send func(*mcsmv1.Envelope) error) {
	resp, err := a.filesOp(ctx, env)
	if err != nil {
		_ = send(errMsg(env.Id, files.Code(err), err))
		return
	}
	resp.Id = env.Id
	_ = send(resp)
}

func (a *App) filesOp(ctx context.Context, env *mcsmv1.Envelope) (*mcsmv1.Envelope, error) {
	req := filesRequest(env)
	if req == nil {
		return nil, fmt.Errorf("mensaje de archivos no soportado: %T", env.Body)
	}
	fsys, err := a.serverFS(req.GetServerId())
	if err != nil {
		return nil, err
	}
	switch b := env.Body.(type) {
	case *mcsmv1.Envelope_FilesList:
		entries, truncated, err := fsys.List(b.FilesList.Path)
		if err != nil {
			return nil, err
		}
		out := make([]*mcsmv1.FileEntry, 0, len(entries))
		for _, e := range entries {
			out = append(out, entryToProto(e))
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesListResult{FilesListResult: &mcsmv1.FilesListResult{Entries: out, Truncated: truncated}}}, nil

	case *mcsmv1.Envelope_FilesStat:
		e, err := fsys.Stat(b.FilesStat.Path)
		if err != nil {
			return nil, err
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesStatResult{FilesStatResult: &mcsmv1.FilesStatResult{Entry: entryToProto(e)}}}, nil

	case *mcsmv1.Envelope_FilesRead:
		data, size, err := fsys.Read(b.FilesRead.Path, int64(b.FilesRead.MaxBytes))
		if err != nil {
			return nil, err
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesReadResult{FilesReadResult: &mcsmv1.FilesReadResult{Content: data, Size: uint64(size)}}}, nil

	case *mcsmv1.Envelope_FilesWrite:
		err = fsys.Write(b.FilesWrite.Path, b.FilesWrite.Content)
	case *mcsmv1.Envelope_FilesMkdir:
		err = fsys.Mkdir(b.FilesMkdir.Path)
	case *mcsmv1.Envelope_FilesRename:
		err = fsys.Rename(b.FilesRename.From, b.FilesRename.To)
	case *mcsmv1.Envelope_FilesDelete:
		err = fsys.Delete(b.FilesDelete.Path)
	case *mcsmv1.Envelope_FilesDownload:
		err = a.filesDownload(ctx, fsys, b.FilesDownload)
	case *mcsmv1.Envelope_FilesUpload:
		err = a.filesUpload(ctx, fsys, b.FilesUpload)
	default:
		return nil, fmt.Errorf("mensaje de archivos no soportado: %T", env.Body)
	}
	if err != nil {
		return nil, err
	}
	return ack(0), nil
}

// filesDownload sube el fichero al panel por PUT /agent/transfer/{id} y confirma al terminar.
func (a *App) filesDownload(ctx context.Context, fsys *files.FS, m *mcsmv1.FilesDownload) error {
	f, e, err := fsys.Open(m.Path)
	if err != nil {
		return err
	}
	defer f.Close()
	xfer, err := a.transfers()
	if err != nil {
		return err
	}
	// LimitReader: si el fichero crece mientras se envía, se manda lo que medía al abrirlo.
	if err := xfer.Put(ctx, m.TransferId, io.LimitReader(f, e.Size), e.Size); err != nil {
		return fmt.Errorf("%w: %v", files.ErrTransfer, err)
	}
	return nil
}

// filesUpload valida el destino, descarga del panel por GET /agent/transfer/{id} y escribe de
// forma atómica en streaming. Un cuerpo truncado nunca reemplaza el fichero.
func (a *App) filesUpload(ctx context.Context, fsys *files.FS, m *mcsmv1.FilesUpload) error {
	if err := fsys.CheckWrite(m.Path); err != nil { // fallar antes de consumir la transferencia
		return err
	}
	xfer, err := a.transfers()
	if err != nil {
		return err
	}
	body, size, err := xfer.Get(ctx, m.TransferId)
	if err != nil {
		return fmt.Errorf("%w: %v", files.ErrTransfer, err)
	}
	defer body.Close()
	expected := m.Size
	if expected < 0 {
		expected = size
	}
	if size >= 0 && expected != size {
		return fmt.Errorf("%w: el panel anuncia %d bytes y envía %d", files.ErrTransfer, m.Size, size)
	}
	_, err = fsys.WriteFrom(m.Path, body, expected)
	return err
}
```

```ts
import { z } from "zod";

/** Límite de lectura/escritura inline (spec §6.6); lo más grande va por transferencia. */
export const INLINE_MAX_BYTES = 2 * 1024 * 1024;

/** Entrada de un listado de archivos tal y como la sirve la API. */
export interface FileEntryDto {
  name: string;
  dir: boolean;
  symlink: boolean;
  size: number;
  /** epoch en milisegundos */
  modifiedAt: number;
  /** bits de permisos (0o644…) */
  mode: number;
}

const CONTROL = /[\u0000-\u001f\u007f]/;

/**
 * Normaliza una ruta dentro de /data del servidor ("mods//a.jar/" → "/mods/a.jar", "" → "/").
 * Devuelve null si es insegura: ".." o caracteres de control se rechazan, nunca se arreglan.
 */
export function normalizePath(p: string): string | null {
  if (CONTROL.test(p)) return null;
  const parts: string[] = [];
  for (const seg of p.split("/")) {
    if (seg === "" || seg === ".") continue;
    if (seg === "..") return null;
    parts.push(seg);
  }
  return "/" + parts.join("/");
}

/** Ruta de archivo validada y normalizada (empieza por "/"). */
export const filePathSchema = z
  .string({ error: "Falta la ruta" })
  .max(4096, "Ruta demasiado larga")
  .transform((p, ctx) => {
    const n = normalizePath(p);
    if (n === null) {
      ctx.addIssue({ code: "custom", message: "Ruta inválida: no se permite «..» ni caracteres de control" });
      return z.NEVER;
    }
    return n;
  });

/** Nombre de un fichero o carpeta nuevo (crear carpeta, renombrar). */
export const fileNameSchema = z
  .string()
  .trim()
  .min(1, "El nombre no puede estar vacío")
  .max(255, "Nombre demasiado largo")
  .refine((n) => n !== "." && n !== ".." && !n.includes("/") && !CONTROL.test(n), "Nombre inválido: sin «/», «..» ni caracteres de control");

export function joinPath(dir: string, name: string): string {
  return dir === "/" ? `/${name}` : `${dir}/${name}`;
}

export function parentPath(p: string): string {
  const i = p.lastIndexOf("/");
  return i <= 0 ? "/" : p.slice(0, i);
}

export function baseName(p: string): string {
  return p.slice(p.lastIndexOf("/") + 1);
}

export type EditorLanguage = "properties" | "yaml" | "json" | "toml" | "text";

const LANGUAGES: Record<string, EditorLanguage> = {
  properties: "properties", ini: "properties",
  yml: "yaml", yaml: "yaml",
  json: "json", mcmeta: "json",
  toml: "toml",
  txt: "text", cfg: "text", conf: "text", log: "text", md: "text",
};

/** Lenguaje del editor según la extensión; null si el fichero no se abre en el editor. */
export function editorLanguage(name: string): EditorLanguage | null {
  const i = name.lastIndexOf(".");
  if (i < 0) return null;
  return LANGUAGES[name.slice(i + 1).toLowerCase()] ?? null;
}
```

```ts
import { randomToken } from "../lib/tokens.js";

/** Cuerpo de una transferencia: stream y tamaño (null si se desconoce). */
export interface TransferPayload { stream: Readable; size: number | null }
/** Fuente perezosa de una transferencia panel → agente: se invoca cuando el agente hace GET. */
export type TransferSource = () => Promise<TransferPayload>;

export type TransferErrorCode = "expired" | "cancelled" | "aborted";

export class TransferError extends Error {
  constructor(public code: TransferErrorCode, message: string) { super(message); this.name = "TransferError"; }
}

/** Panel → agente: el agente hace GET /agent/transfer/:id. */
export interface OutboundTransfer {
  id: string;
  /** Se resuelve cuando el agente ha recibido todo el cuerpo; se rechaza si caduca, se cancela o se corta. */
  done: Promise<void>;
  cancel(reason?: string): void;
}

/** Agente → panel: el agente hace PUT /agent/transfer/:id. */
export interface InboundTransfer {
  id: string;
  /** Se resuelve cuando llega el PUT del agente, con su cuerpo en streaming. */
  incoming: Promise<TransferPayload>;
  cancel(reason?: string): void;
}

/** Lo que obtiene la ruta HTTP al reclamar un transferId. */
export type ClaimedTransfer =
  | { kind: "outbound"; source: TransferSource; complete(): void; fail(err: Error): void }
  | { kind: "inbound"; deliver(payload: TransferPayload): void };

interface Deferred<T> { promise: Promise<T>; resolve(v: T): void; reject(e: Error): void }

function deferred<T>(): Deferred<T> {
  let resolve!: (v: T) => void;
  let reject!: (e: Error) => void;
  const promise = new Promise<T>((res, rej) => { resolve = res; reject = rej; });
  promise.catch(() => {}); // quien no la espere no provoca un unhandledRejection
  return { promise, resolve, reject };
}

type Entry =
  | { kind: "outbound"; nodeId: string; createdAt: number; source: TransferSource; done: Deferred<void> }
  | { kind: "inbound"; nodeId: string; createdAt: number; incoming: Deferred<TransferPayload> };

export interface TransferServiceOptions {
  /** Reloj inyectable (ms). */
  now?: () => number;
  /** Tiempo que tiene el agente para reclamar la transferencia. */
  claimTtlMs?: number;
}

/**
 * Transferencias HTTP entre panel y agentes (spec §5.1). Cada transferId es aleatorio
 * (32 bytes), de un solo uso, ligado al nodo que debe reclamarlo y caduca si nadie lo
 * reclama a tiempo. El cuerpo nunca se carga en memoria: se pasan streams.
 */
export class TransferService {
  private pending = new Map<string, Entry>();
  private now: () => number;
  private ttl: number;

  constructor(opts: TransferServiceOptions = {}) {
    this.now = opts.now ?? (() => Date.now()); // se lee al llamar: los tests pueden falsear Date
    this.ttl = opts.claimTtlMs ?? 60_000;
  }

  /** Transferencias aún sin reclamar. */
  get pendingCount(): number { return this.pending.size; }

  outbound(nodeId: string, source: TransferSource): OutboundTransfer {
    const id = randomToken();
    const done = deferred<void>();
    this.pending.set(id, { kind: "outbound", nodeId, createdAt: this.now(), source, done });
    return { id, done: done.promise, cancel: (reason = "cancelada") => this.cancel(id, reason) };
  }

  inbound(nodeId: string): InboundTransfer {
    const id = randomToken();
    const incoming = deferred<TransferPayload>();
    this.pending.set(id, { kind: "inbound", nodeId, createdAt: this.now(), incoming });
    return { id, incoming: incoming.promise, cancel: (reason = "cancelada") => this.cancel(id, reason) };
  }

  /**
   * Reclama un transferId (un solo uso). Devuelve null sin consumirlo si es de otro nodo o del
   * otro sentido (un nodo no puede quemar transferencias ajenas), y null consumiéndolo si caducó.
   */
  claim(id: string, nodeId: string, method: "GET" | "PUT"): ClaimedTransfer | null {
    const e = this.pending.get(id);
    if (!e || e.nodeId !== nodeId) return null;
    if ((method === "GET") !== (e.kind === "outbound")) return null;
    this.pending.delete(id);
    if (this.now() - e.createdAt > this.ttl) {
      this.reject(e, new TransferError("expired", "El agente no inició la transferencia a tiempo"));
      return null;
    }
    if (e.kind === "outbound") {
      return { kind: "outbound", source: e.source, complete: () => e.done.resolve(), fail: (err) => e.done.reject(err) };
    }
    return { kind: "inbound", deliver: (p) => e.incoming.resolve(p) };
  }

  /** Caduca las transferencias no reclamadas a tiempo. Devuelve cuántas. */
  sweep(): number {
    let n = 0;
    for (const [id, e] of this.pending) {
      if (this.now() - e.createdAt <= this.ttl) continue;
      this.pending.delete(id);
      this.reject(e, new TransferError("expired", "El agente no inició la transferencia a tiempo"));
      n++;
    }
    return n;
  }

  /** Cancela todo lo pendiente (cierre del panel). */
  closeAll(): void {
    for (const id of [...this.pending.keys()]) this.cancel(id, "el panel se está cerrando");
  }

  private cancel(id: string, reason: string) {
    const e = this.pending.get(id);
    if (!e) return; // ya reclamada: su ruta HTTP gestiona el corte
    this.pending.delete(id);
    this.reject(e, new TransferError("cancelled", `Transferencia cancelada: ${reason}`));
  }

  private reject(e: Entry, err: TransferError) {
    if (e.kind === "outbound") e.done.reject(err);
    else e.incoming.reject(err);
  }
}
```

```ts
import { createReadStream, createWriteStream } from "node:fs";
import { mkdir, readdir, rename, rm, stat } from "node:fs/promises";
import { join } from "node:path";
import type { Readable } from "node:stream";
import { pipeline } from "node:stream/promises";
import type { TransferSource } from "./service.js";

export interface StagedFile { id: string; path: string; size: number }

const ID_RE = /^[A-Za-z0-9_-]{1,64}$/;

/**
 * Directorio de staging del panel (spec §5.1) para transferencias que no pueden ir en
 * streaming directo (p. ej. migración con el destino aún no listo, oleada B). Los flujos del
 * navegador del Plan 5 no lo usan: van en streaming sin tocar disco. Se vacía al arrancar,
 * cada fichero se borra al consumirse y `sweep` elimina lo abandonado.
 */
export class Staging {
  private removing = new Set<Promise<void>>();

  constructor(readonly dir: string, private now: () => number = Date.now) {}

  /** Borra los restos de una ejecución anterior. No crea el directorio. */
  async init(): Promise<number> {
    let names: string[];
    try {
      names = await readdir(this.dir);
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code === "ENOENT") return 0;
      throw e;
    }
    await Promise.all(names.map((n) => rm(join(this.dir, n), { recursive: true, force: true })));
    return names.length;
  }

  /** Guarda un stream (escribe `<id>.part` y lo renombra a `<id>.bin` al terminar). */
  async save(id: string, stream: Readable): Promise<StagedFile> {
    if (!ID_RE.test(id)) throw new Error("Identificador de staging inválido");
    await mkdir(this.dir, { recursive: true });
    const part = join(this.dir, `${id}.part`);
    const path = join(this.dir, `${id}.bin`);
    try {
      await pipeline(stream, createWriteStream(part, { flags: "wx" }));
      await rename(part, path);
    } catch (e) {
      await rm(part, { force: true });
      throw e;
    }
    return { id, path, size: (await stat(path)).size };
  }

  /** Fuente para TransferService.outbound; por defecto borra el fichero al cerrarse el stream. */
  source(file: StagedFile, opts: { removeAfter?: boolean } = {}): TransferSource {
    const removeAfter = opts.removeAfter ?? true;
    return async () => {
      const stream = createReadStream(file.path);
      if (removeAfter) stream.once("close", () => { this.track(rm(file.path, { force: true })); });
      return { stream, size: file.size };
    };
  }

  async remove(file: StagedFile): Promise<void> {
    await rm(file.path, { force: true });
  }

  /** Espera a que terminen los borrados lanzados al cerrarse las fuentes (cierre del panel, tests). */
  async settled(): Promise<void> {
    await Promise.all([...this.removing]);
  }

  private track(p: Promise<void>) {
    const t = p.catch(() => {}).finally(() => this.removing.delete(t));
    this.removing.add(t);
  }

  /** Borra lo que lleve más de maxAgeMs sin modificarse. Devuelve cuántos ficheros. */
  async sweep(maxAgeMs: number): Promise<number> {
    let names: string[];
    try {
      names = await readdir(this.dir);
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code === "ENOENT") return 0;
      throw e;
    }
    let n = 0;
    for (const name of names) {
      const p = join(this.dir, name);
      const st = await stat(p).catch(() => null);
      if (st && this.now() - st.mtimeMs > maxAgeMs) {
        await rm(p, { recursive: true, force: true });
        n++;
      }
    }
    return n;
  }
}
```

```ts
import type { Readable } from "node:stream";
import { finished } from "node:stream/promises";
import type { FastifyInstance, FastifyRequest } from "fastify";
import { hashToken } from "../lib/tokens.js";
import { TransferError, type TransferPayload } from "./service.js";

/** Nodo dueño del token Bearer, o null. Mismo criterio que /agent/ws. */
function nodeFromAuth(app: FastifyInstance, req: FastifyRequest) {
  const header = req.headers.authorization ?? "";
  const token = header.startsWith("Bearer ") ? header.slice(7) : "";
  return token ? app.nodes.findByTokenHash(hashToken(token)) : null;
}

const NOT_FOUND = { error: "Transferencia desconocida, caducada o ya usada" };

/** Content-Length de la petición, o null si no viene (cuerpo chunked). */
export function contentLength(req: FastifyRequest): number | null {
  const v = req.headers["content-length"];
  return v !== undefined && /^\d+$/.test(v) ? Number(v) : null;
}

/**
 * Transferencias HTTP de los agentes (spec §5.1), fuera del guard de sesión y con el token
 * del nodo. El cuerpo nunca se carga en memoria: se pasa el stream tal cual.
 */
export async function transferRoutes(app: FastifyInstance) {
  // El cuerpo llega como stream (req.body) sin límite de tamaño ni parseo.
  app.addContentTypeParser("application/octet-stream", (_req, payload, done) => done(null, payload));

  // Panel → agente. Sin ruta HEAD automática: un HEAD consumiría la transferencia.
  app.get<{ Params: { id: string } }>("/agent/transfer/:id", { exposeHeadRoute: false }, async (req, reply) => {
    const node = nodeFromAuth(app, req);
    if (!node) return reply.code(401).send({ error: "token inválido" });
    const claimed = app.transfers.claim(req.params.id, node.id, "GET");
    if (claimed?.kind !== "outbound") return reply.code(404).send(NOT_FOUND);
    let payload: TransferPayload;
    try {
      payload = await claimed.source();
    } catch (e) {
      claimed.fail(e instanceof Error ? e : new Error(String(e)));
      req.log.warn({ err: e }, "origen de transferencia no disponible");
      return reply.code(500).send({ error: "Error interno" });
    }
    reply.raw.once("close", () => {
      if (reply.raw.writableFinished) claimed.complete();
      else claimed.fail(new TransferError("aborted", "La transferencia se cortó antes de terminar"));
    });
    reply.header("content-type", "application/octet-stream");
    if (payload.size !== null) reply.header("content-length", String(payload.size));
    return reply.send(payload.stream);
  });

  // Agente → panel: se entrega el cuerpo a quien espera y se responde cuando lo ha leído entero.
  app.put<{ Params: { id: string } }>("/agent/transfer/:id", async (req, reply) => {
    const node = nodeFromAuth(app, req);
    if (!node) return reply.code(401).send({ error: "token inválido" });
    const claimed = app.transfers.claim(req.params.id, node.id, "PUT");
    if (claimed?.kind !== "inbound") return reply.code(404).send(NOT_FOUND);
    const body = req.body as Readable | undefined;
    if (!body || typeof body.pipe !== "function") return reply.code(415).send({ error: "Envía el cuerpo como application/octet-stream" });
    claimed.deliver({ stream: body, size: contentLength(req) });
    try {
      await finished(body);
    } catch {
      return reply.code(400).send({ error: "La transferencia se cortó antes de terminar" });
    }
    return reply.code(204).send();
  });
}
```

```ts
import { join } from "node:path";
import fp from "fastify-plugin";
import type { FastifyInstance } from "fastify";
import { TransferService } from "./service.js";
import { Staging } from "./staging.js";
import { transferRoutes } from "./routes.js";

const SWEEP_EVERY_MS = 10_000;
const STAGING_SWEEP_EVERY_MS = 3600_000;
const STAGING_MAX_AGE_MS = 24 * 3600_000;

/**
 * Transferencias y staging (spec §5.1). Decora `app.transfers` y `app.staging` en la raíz
 * (fastify-plugin) y registra las rutas de los agentes en un contexto propio.
 */
export const transfersPlugin = fp(async function transfersPlugin(app: FastifyInstance) {
  app.decorate("transfers", new TransferService());
  app.decorate("staging", new Staging(join(app.config.dataDir, "staging")));
  await app.register(transferRoutes);

  const transferSweep = setInterval(() => app.transfers.sweep(), SWEEP_EVERY_MS);
  transferSweep.unref();
  const stagingSweep = setInterval(() => {
    app.staging.sweep(STAGING_MAX_AGE_MS).catch((e) => app.log.warn({ err: e }, "limpieza de staging fallida"));
  }, STAGING_SWEEP_EVERY_MS);
  stagingSweep.unref();

  app.addHook("onReady", async () => {
    const n = await app.staging.init();
    if (n) app.log.info({ n }, "staging: borrados restos de una ejecución anterior");
  });
  app.addHook("onClose", async () => {
    clearInterval(transferSweep);
    clearInterval(stagingSweep);
    app.transfers.closeAll();
    await app.staging.settled();
  });
}, { name: "transfers" });

declare module "fastify" {
  interface FastifyInstance { transfers: TransferService; staging: Staging }
```

```ts
import type { FastifyInstance } from "fastify";
import type { FileEntry } from "@mcsm/proto";
import { INLINE_MAX_BYTES, type FileEntryDto } from "@mcsm/shared";
import { AgentError, type Body } from "../agents/hub.js";
import { HttpError } from "../servers/service.js";
import { TransferError } from "../transfers/service.js";

/** Código de error del agente (files.Code en Go) → estado HTTP. */
const STATUS_BY_CODE: Record<string, number> = {
  invalid_path: 400, path_outside: 400, root: 400, is_dir: 400, not_dir: 400,
  unknown_server: 404, not_found: 404,
  exists: 409, disconnected: 409,
  too_large: 413,
  timeout: 504,
};

/** Traduce un fallo del agente o de una transferencia a HttpError conservando el texto del agente (spec §10). */
export function toHttpError(e: unknown, fallback: string): HttpError {
  if (e instanceof HttpError) return e;
  if (e instanceof AgentError) return new HttpError(STATUS_BY_CODE[e.code] ?? 502, e.message);
  if (e instanceof TransferError) return new HttpError(e.code === "expired" ? 504 : 502, e.message);
  return new HttpError(502, fallback);
}

export const toEntryDto = (e: FileEntry): FileEntryDto => ({
  name: e.name, dir: e.dir, symlink: e.symlink, size: Number(e.size), modifiedAt: Number(e.modTimeUnixMs), mode: e.mode,
});

const REQUEST_TIMEOUT_MS = 30_000;

export class FilesService {
  constructor(protected app: FastifyInstance) {}

  /** Servidor y conexión de su nodo: 404/409 antes de molestar al agente. */
  protected target(serverId: string) {
    const row = this.app.servers.get(serverId);
    if (!row) throw new HttpError(404, "Servidor no encontrado");
    const conn = this.app.agents.get(row.node_id);
    if (!conn) throw new HttpError(409, "El nodo está desconectado");
    return { row, conn };
  }

  private async call(serverId: string, body: Body, fallback: string) {
    const { conn } = this.target(serverId);
    try {
      return await conn.request(body, REQUEST_TIMEOUT_MS);
    } catch (e) {
      throw toHttpError(e, fallback);
    }
  }

  async list(serverId: string, path: string): Promise<{ path: string; entries: FileEntryDto[]; truncated: boolean }> {
    const res = await this.call(serverId, { case: "filesList", value: { serverId, path } }, "No se pudo listar la carpeta");
    if (res.body.case !== "filesListResult") throw new HttpError(502, "Respuesta inesperada del agente");
    return { path, entries: res.body.value.entries.map(toEntryDto), truncated: res.body.value.truncated };
  }

  async stat(serverId: string, path: string): Promise<FileEntryDto> {
    const res = await this.call(serverId, { case: "filesStat", value: { serverId, path } }, "No se pudo consultar el fichero");
    if (res.body.case !== "filesStatResult" || !res.body.value.entry) throw new HttpError(502, "Respuesta inesperada del agente");
    return toEntryDto(res.body.value.entry);
  }

  async read(serverId: string, path: string): Promise<{ path: string; content: string; size: number }> {
    const res = await this.call(serverId, { case: "filesRead", value: { serverId, path, maxBytes: INLINE_MAX_BYTES } }, "No se pudo leer el fichero");
    if (res.body.case !== "filesReadResult") throw new HttpError(502, "Respuesta inesperada del agente");
    let content: string;
    try {
      content = new TextDecoder("utf-8", { fatal: true }).decode(res.body.value.content);
    } catch {
      throw new HttpError(415, "El fichero no es texto UTF-8: descárgalo para abrirlo");
    }
    if (content.includes("\u0000")) throw new HttpError(415, "El fichero parece binario: descárgalo para abrirlo");
    return { path, content, size: Number(res.body.value.size) };
  }

  async write(serverId: string, path: string, content: string): Promise<void> {
    const bytes = new TextEncoder().encode(content);
    if (bytes.byteLength > INLINE_MAX_BYTES) throw new HttpError(413, "El contenido supera 2 MiB: súbelo como fichero");
    await this.call(serverId, { case: "filesWrite", value: { serverId, path, content: bytes } }, "No se pudo guardar el fichero");
  }

  async mkdir(serverId: string, path: string): Promise<void> {
    await this.call(serverId, { case: "filesMkdir", value: { serverId, path } }, "No se pudo crear la carpeta");
  }

  async rename(serverId: string, from: string, to: string): Promise<void> {
    if (from === "/" || to === "/") throw new HttpError(400, "No se puede renombrar la carpeta raíz");
    await this.call(serverId, { case: "filesRename", value: { serverId, from, to } }, "No se pudo renombrar");
  }

  async remove(serverId: string, path: string): Promise<void> {
    if (path === "/") throw new HttpError(400, "No se puede borrar la carpeta raíz");
    await this.call(serverId, { case: "filesDelete", value: { serverId, path } }, "No se pudo borrar");
  }
}
```

```ts
/**
 * Cabecera Content-Disposition para descargar `filename` (RFC 6266 + RFC 5987): un nombre ASCII
 * de reserva entre comillas y el nombre real en UTF-8 percent-encoded. Comillas, barras
 * invertidas, % y caracteres de control nunca llegan crudos a la cabecera.
 */
export function contentDisposition(filename: string): string {
  const name = filename || "descarga";
  const fallback = name.replace(/[^\x20-\x7e]|["\\%]/g, "_");
  const encoded = encodeURIComponent(name).replace(/['()*]/g, (c) => "%" + c.charCodeAt(0).toString(16).toUpperCase());
  return `attachment; filename="${fallback}"; filename*=UTF-8''${encoded}`;
}
```

```ts
import { PassThrough, type Readable } from "node:stream";
import { finished } from "node:stream/promises";

/**
 * Envuelve el cuerpo de una subida del navegador para dárselo al agente. Si el agente corta,
 * el cuerpo original no se destruye (se desengancha y se sigue leyendo), para que el navegador
 * termine de enviar y reciba la respuesta de error en vez de un corte de red. Si es el
 * navegador el que corta, la copia se destruye y el agente ve la transferencia truncada.
 */
export function detachable(src: Readable): Readable {
  const out = new PassThrough();
  src.on("error", (e) => out.destroy(e));
  src.on("close", () => { if (!src.readableEnded) out.destroy(new Error("La subida se interrumpió")); });
  out.on("close", () => {
    if (!src.readableEnded) {
      src.unpipe(out);
      src.resume();
    }
  });
  src.pipe(out);
  return out;
}

/** Lee y descarta lo que quede de un cuerpo para poder responder con un error limpio. */
export async function drain(body: Readable): Promise<void> {
  if (body.readableEnded || body.destroyed) return;
  body.resume();
  await finished(body).catch(() => {});
}
```

```ts
const STATUS_BY_CODE: Record<string, number> = {
  invalid_path: 400, path_outside: 400, root: 400, is_dir: 400, not_dir: 400,
  unknown_server: 404, not_found: 404,
  exists: 409, disconnected: 409,
  too_large: 413,
  timeout: 504,
};

/** Traduce un fallo del agente o de una transferencia a HttpError conservando el texto del agente (spec §10). */
export function toHttpError(e: unknown, fallback: string): HttpError {
  if (e instanceof HttpError) return e;
  if (e instanceof AgentError) return new HttpError(STATUS_BY_CODE[e.code] ?? 502, e.message);
  if (e instanceof TransferError) return new HttpError(e.code === "expired" ? 504 : 502, e.message);
  return new HttpError(502, fallback);
}

export const toEntryDto = (e: FileEntry): FileEntryDto => ({
  name: e.name, dir: e.dir, symlink: e.symlink, size: Number(e.size), modifiedAt: Number(e.modTimeUnixMs), mode: e.mode,
});

const REQUEST_TIMEOUT_MS = 30_000;
/** Tope de una subida o descarga completa a través del panel; la caducidad de 60 s cubre al agente que no arranca. */
export const TRANSFER_TIMEOUT_MS = 60 * 60_000;

/** Rechaza solo si la transferencia caduca sin que el agente la reclame; si no, nunca se resuelve. */
function failOnExpiry(done: Promise<void>): Promise<never> {
  return new Promise((_, reject) => {
    done.catch((e) => { if (e instanceof TransferError && e.code === "expired") reject(e); });
  });
}

export class FilesService {
  constructor(protected app: FastifyInstance) {}

  /** Servidor y conexión de su nodo: 404/409 antes de molestar al agente. */
  protected target(serverId: string) {
    const row = this.app.servers.get(serverId);
    if (!row) throw new HttpError(404, "Servidor no encontrado");
    const conn = this.app.agents.get(row.node_id);
    if (!conn) throw new HttpError(409, "El nodo está desconectado");
    return { row, conn };
  }

  private async call(serverId: string, body: Body, fallback: string) {
    const { conn } = this.target(serverId);
    try {
      return await conn.request(body, REQUEST_TIMEOUT_MS);
    } catch (e) {
      throw toHttpError(e, fallback);
    }
  }

  async list(serverId: string, path: string): Promise<{ path: string; entries: FileEntryDto[]; truncated: boolean }> {
    const res = await this.call(serverId, { case: "filesList", value: { serverId, path } }, "No se pudo listar la carpeta");
    if (res.body.case !== "filesListResult") throw new HttpError(502, "Respuesta inesperada del agente");
    return { path, entries: res.body.value.entries.map(toEntryDto), truncated: res.body.value.truncated };
  }

  async stat(serverId: string, path: string): Promise<FileEntryDto> {
    const res = await this.call(serverId, { case: "filesStat", value: { serverId, path } }, "No se pudo consultar el fichero");
    if (res.body.case !== "filesStatResult" || !res.body.value.entry) throw new HttpError(502, "Respuesta inesperada del agente");
    return toEntryDto(res.body.value.entry);
  }

  async read(serverId: string, path: string): Promise<{ path: string; content: string; size: number }> {
    const res = await this.call(serverId, { case: "filesRead", value: { serverId, path, maxBytes: INLINE_MAX_BYTES } }, "No se pudo leer el fichero");
    if (res.body.case !== "filesReadResult") throw new HttpError(502, "Respuesta inesperada del agente");
    let content: string;
    try {
      content = new TextDecoder("utf-8", { fatal: true }).decode(res.body.value.content);
    } catch {
      throw new HttpError(415, "El fichero no es texto UTF-8: descárgalo para abrirlo");
    }
    if (content.includes("\u0000")) throw new HttpError(415, "El fichero parece binario: descárgalo para abrirlo");
    return { path, content, size: Number(res.body.value.size) };
  }

  async write(serverId: string, path: string, content: string): Promise<void> {
    const bytes = new TextEncoder().encode(content);
    if (bytes.byteLength > INLINE_MAX_BYTES) throw new HttpError(413, "El contenido supera 2 MiB: súbelo como fichero");
    await this.call(serverId, { case: "filesWrite", value: { serverId, path, content: bytes } }, "No se pudo guardar el fichero");
  }

  async mkdir(serverId: string, path: string): Promise<void> {
    await this.call(serverId, { case: "filesMkdir", value: { serverId, path } }, "No se pudo crear la carpeta");
  }

  async rename(serverId: string, from: string, to: string): Promise<void> {
    if (from === "/" || to === "/") throw new HttpError(400, "No se puede renombrar la carpeta raíz");
    await this.call(serverId, { case: "filesRename", value: { serverId, from, to } }, "No se pudo renombrar");
  }

  async remove(serverId: string, path: string): Promise<void> {
    if (path === "/") throw new HttpError(400, "No se puede borrar la carpeta raíz");
    await this.call(serverId, { case: "filesDelete", value: { serverId, path } }, "No se pudo borrar");
  }

  /**
   * Descarga: el agente sube el fichero por PUT /agent/transfer/:id y el stream se reenvía tal
   * cual al navegador. `done` es el resultado final del agente (solo para registrarlo).
   */
  async download(serverId: string, path: string): Promise<{ stream: Readable; size: number | null; done: Promise<void> }> {
    const { row, conn } = this.target(serverId);
    const t = this.app.transfers.inbound(row.node_id);
    const req = conn.request({ case: "filesDownload", value: { serverId, path, transferId: t.id } }, TRANSFER_TIMEOUT_MS);
    const done = req.then(() => undefined);
    done.catch(() => {});
    try {
      const incoming = await Promise.race([
        t.incoming,
        req.then((): never => { throw new HttpError(502, "El agente terminó sin enviar el fichero"); }),
      ]);
      return { stream: incoming.stream, size: incoming.size, done };
    } catch (e) {
      t.cancel("descarga fallida");
      throw toHttpError(e, "No se pudo descargar el fichero");
    }
  }

  /**
   * Subida: el agente descarga el cuerpo del navegador por GET /agent/transfer/:id, sin pasar
   * por disco. Si falla, se drena lo que quede del cuerpo para responder con el error del agente.
   */
  async upload(serverId: string, path: string, body: Readable, size: number | null): Promise<void> {
    let t: OutboundTransfer | undefined;
    try {
      const { row, conn } = this.target(serverId);
      t = this.app.transfers.outbound(row.node_id, async () => ({ stream: detachable(body), size }));
      const req = conn.request({ case: "filesUpload", value: { serverId, path, transferId: t.id, size: BigInt(size ?? -1) } }, TRANSFER_TIMEOUT_MS);
      await Promise.race([req, failOnExpiry(t.done)]);
    } catch (e) {
      t?.cancel("subida fallida");
      await drain(body);
      throw toHttpError(e, "No se pudo subir el fichero");
    }
  }
}
```

```ts
    await svc.write(req.params.id, path, content);
    return reply.code(204).send();
  });

  app.post<P>("/api/servers/:id/files/mkdir", async (req, reply) => {
    await svc.mkdir(req.params.id, pathQuery.parse(req.body).path);
    return reply.code(204).send();
  });

  app.post<P>("/api/servers/:id/files/rename", async (req, reply) => {
    const { from, to } = renameBody.parse(req.body);
    await svc.rename(req.params.id, from, to);
    return reply.code(204).send();
  });

  app.delete<P>("/api/servers/:id/files", async (req, reply) => {
    await svc.remove(req.params.id, pathQuery.parse(req.query).path);
    return reply.code(204).send();
  });

  // ── transferencias con el navegador (sin pasar por disco del panel) ──
  app.addContentTypeParser("application/octet-stream", (_req, payload, done) => done(null, payload));

  // Sin HEAD automático: un HEAD pediría al agente subir el fichero entero.
  app.get<P>("/api/servers/:id/files/download", { exposeHeadRoute: false }, async (req, reply) => {
    const { path } = pathQuery.parse(req.query);
    const dl = await svc.download(req.params.id, path);
    dl.done.catch((e) => req.log.warn({ err: e, path }, "descarga terminada con error"));
    reply.header("content-type", "application/octet-stream");
    reply.header("x-content-type-options", "nosniff");
    reply.header("cache-control", "no-store");
    reply.header("content-disposition", contentDisposition(baseName(path)));
    if (dl.size !== null) reply.header("content-length", String(dl.size));
    return reply.send(dl.stream);
  });

  app.put<P>("/api/servers/:id/files/upload", async (req, reply) => {
    const body = req.body as Readable | undefined;
    if (!body || typeof body.pipe !== "function") throw new HttpError(415, "Envía el fichero como application/octet-stream");
    const { path } = pathQuery.parse(req.query);
    if (path === "/") throw new HttpError(400, "Indica la ruta del fichero de destino");
    await svc.upload(req.params.id, path, body, contentLength(req));
    return reply.code(204).send();
  });
}
```

```ts
import { INLINE_MAX_BYTES, editorLanguage, fileNameSchema, type FileEntryDto } from "@mcsm/shared";
import { ApiError, api, errorMessage, reportStatus } from "./api";

export interface FileListDto { path: string; entries: FileEntryDto[]; truncated: boolean }
export interface FileContentDto { path: string; content: string; size: number }

const base = (serverId: string) => `/api/servers/${encodeURIComponent(serverId)}/files`;
const q = (path: string) => `path=${encodeURIComponent(path)}`;

export const filesApi = {
  list: (serverId: string, path: string) => api.get<FileListDto>(`${base(serverId)}?${q(path)}`),
  read: (serverId: string, path: string) => api.get<FileContentDto>(`${base(serverId)}/content?${q(path)}`),
  write: (serverId: string, path: string, content: string) => api.post<void>(`${base(serverId)}/content`, { path, content }),
  mkdir: (serverId: string, path: string) => api.post<void>(`${base(serverId)}/mkdir`, { path }),
  rename: (serverId: string, from: string, to: string) => api.post<void>(`${base(serverId)}/rename`, { from, to }),
  remove: (serverId: string, path: string) => api.del<void>(`${base(serverId)}?${q(path)}`),
  downloadUrl: (serverId: string, path: string) => `${base(serverId)}/download?${q(path)}`,
};

/**
 * Sube un fichero con progreso (fetch no informa del progreso de subida). El cuerpo va como
 * application/octet-stream y el panel lo reenvía al agente en streaming.
 */
export function uploadFile(serverId: string, path: string, file: Blob, onProgress?: (sent: number, total: number) => void, signal?: AbortSignal): Promise<void> {
  const url = `${base(serverId)}/upload?${q(path)}`;
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open("PUT", url);
    xhr.setRequestHeader("content-type", "application/octet-stream");
    xhr.upload.onprogress = (e) => onProgress?.(e.loaded, e.lengthComputable ? e.total : file.size);
    xhr.onload = () => {
      if (xhr.status >= 200 && xhr.status < 300) return resolve();
      reportStatus(xhr.status, url);
      let data: unknown = null;
      try { data = JSON.parse(xhr.responseText); } catch { /* cuerpo no JSON */ }
      reject(new ApiError(xhr.status, errorMessage(xhr.status, xhr.statusText, data)));
    };
    xhr.onerror = () => reject(new ApiError(0, "Error de red: la subida se cortó"));
    xhr.onabort = () => reject(new ApiError(0, "Subida cancelada"));
    signal?.addEventListener("abort", () => xhr.abort(), { once: true });
    xhr.send(file);
  });
}

/** Migas de pan de una ruta: la raíz se llama "data" como en el contenedor. */
export function breadcrumbs(path: string): { name: string; path: string }[] {
  const out = [{ name: "data", path: "/" }];
  let acc = "";
  for (const seg of path.split("/").filter(Boolean)) {
    acc += `/${seg}`;
    out.push({ name: seg, path: acc });
  }
  return out;
}

/** Se abre en el editor si es texto conocido y cabe en el límite inline. */
export function canEdit(e: Pick<FileEntryDto, "name" | "dir" | "size">): boolean {
  return !e.dir && editorLanguage(e.name) !== null && e.size <= INLINE_MAX_BYTES;
}

/** Valida un nombre nuevo (carpeta o renombrado): mensaje de error o null. */
export function validateNewName(name: string, existing: readonly string[], current?: string): string | null {
  const parsed = fileNameSchema.safeParse(name);
  if (!parsed.success) return parsed.error.issues[0]?.message ?? "Nombre inválido";
  if (parsed.data !== current && existing.includes(parsed.data)) return `Ya existe «${parsed.data}» en esta carpeta`;
  return null;
}

/** Porcentaje entero de una subida (0 si el total es 0). */
export const progressPct = (sent: number, total: number): number => (total > 0 ? Math.min(100, Math.floor((sent / total) * 100)) : 0);
```

```tsx
      if (nameAction?.kind === "rename") return filesApi.rename(serverId, joinPath(path, nameAction.entry.name), joinPath(path, name));
    },
    onSuccess: () => { setNameAction(null); void refresh(); },
  });
  const del = useMutation({
    mutationFn: (e: FileEntryDto) => filesApi.remove(serverId, joinPath(path, e.name)),
    onSettled: () => void refresh(),
  });

  const upload = async (picked: FileList | null) => {
    if (!picked?.length) return;
    const files = [...picked];
    const clash = files.filter((f) => names.includes(f.name)).map((f) => f.name);
    if (clash.length && !confirm(`Ya existe ${clash.join(", ")} en esta carpeta. ¿Reemplazar?`)) return;
    setUploads(files.map((f) => ({ name: f.name, sent: 0, total: f.size })));
    for (const [i, f] of files.entries()) {
      const update = (patch: Partial<UploadItem>) => setUploads((u) => u.map((x, j) => (j === i ? { ...x, ...patch } : x)));
      try {
        await uploadFile(serverId, joinPath(path, f.name), f, (sent, total) => update({ sent, total }));
        update({ sent: f.size });
      } catch (e) {
        update({ error: errText(e) });
      }
    }
    void refresh();
    setUploads((u) => u.filter((x) => x.error)); // las correctas desaparecen; los errores se quedan a la vista
  };

  const open = (e: FileEntryDto) => {
    if (e.dir) return setPath(joinPath(path, e.name));
    if (canEdit(e)) return setEditing(joinPath(path, e.name));
  };

  if (editing) {
    return (
      <Suspense fallback={<div className="flex items-center gap-2 p-4 text-muted-foreground"><Loader2 className="size-4 animate-spin" /> Cargando editor…</div>}>
        <FileEditor serverId={serverId} path={editing} onClose={() => { setEditing(null); void refresh(); }} />
      </Suspense>
    );
  }

  return (
    <div
      className="flex flex-col gap-3"
      onDragOver={(e) => { if (!offline) e.preventDefault(); }}
      onDrop={(e) => { e.preventDefault(); if (!offline) void upload(e.dataTransfer.files); }}
    >
      <div className="flex flex-wrap items-center justify-between gap-2">
        <nav aria-label="Ruta" className="flex flex-wrap items-center gap-1 font-mono text-sm">
          {breadcrumbs(path).map((b, i, all) => (
            <span key={b.path} className="flex items-center gap-1">
              {i > 0 && <span className="text-muted-foreground">/</span>}
              {i === all.length - 1 ? <span>{b.name}</span> : <button type="button" className="text-sky-400 hover:underline" onClick={() => setPath(b.path)}>{b.name}</button>}
            </span>
          ))}
        </nav>
        <div className="flex items-center gap-2">
          <input ref={fileInput} type="file" multiple hidden onChange={(e) => { void upload(e.target.files); e.target.value = ""; }} />
          <Button size="sm" variant="secondary" disabled={offline} onClick={() => fileInput.current?.click()}><Upload /> Subir</Button>
          <Button size="sm" variant="secondary" disabled={offline} onClick={() => { nameMut.reset(); setNameAction({ kind: "mkdir" }); }}><FolderPlus /> Nueva carpeta</Button>
          <Button size="icon-sm" variant="ghost" aria-label="Refrescar" disabled={offline} onClick={() => void refresh()}><RefreshCw /></Button>
        </div>
      </div>

      {offline && <p className="text-sm text-amber-400">El nodo está desconectado: los archivos no están disponibles.</p>}
      {uploads.map((u) => (
        <div key={u.name} className="flex items-center gap-3 text-sm">
          <span className="w-64 truncate font-mono">{u.name}</span>
          {u.error ? <span role="alert" className="text-red-400">{u.error}</span> : (
            <>
              <div className="h-2 w-48 overflow-hidden rounded bg-muted"><div className="h-full bg-primary" style={{ width: `${progressPct(u.sent, u.total)}%` }} /></div>
              <span className="text-muted-foreground">{progressPct(u.sent, u.total)} % de {formatBytes(u.total)}</span>
            </>
          )}
        </div>
      ))}
      {del.error && <p role="alert" className="text-sm text-red-400">{errText(del.error)}</p>}
      {list.isError && <p role="alert" className="text-sm text-red-400">{errText(list.error)}</p>}

      <Table>
        <TableHeader>
          <TableRow><TableHead>Nombre</TableHead><TableHead className="w-28 text-right">Tamaño</TableHead><TableHead className="w-44">Modificado</TableHead><TableHead className="w-32" /></TableRow>
        </TableHeader>
        <TableBody>
          {path !== "/" && (
            <TableRow className="cursor-pointer" onClick={() => setPath(parentPath(path))}>
              <TableCell colSpan={4} className="font-mono text-muted-foreground">..</TableCell>
            </TableRow>
          )}
          {list.isPending && !offline && <TableRow><TableCell colSpan={4} className="text-muted-foreground"><Loader2 className="inline size-4 animate-spin" /> Cargando…</TableCell></TableRow>}
          {list.data?.entries.length === 0 && <TableRow><TableCell colSpan={4} className="text-muted-foreground">Carpeta vacía. Arrastra ficheros aquí para subirlos.</TableCell></TableRow>}
          {list.data?.entries.map((e) => {
            const Icon = e.dir ? Folder : e.symlink ? Link2 : canEdit(e) ? FileText : File;
            const clickable = e.dir || canEdit(e);
            return (
              <TableRow key={e.name}>
                <TableCell>
                  <button type="button" disabled={!clickable} className="flex items-center gap-2 font-mono text-sm enabled:hover:underline disabled:cursor-default" onClick={() => open(e)} title={clickable ? undefined : "No se puede abrir en el editor: descárgalo"}>
                    <Icon className={`size-4 ${e.dir ? "text-sky-400" : "text-muted-foreground"}`} />{e.name}
                  </button>
                </TableCell>
                <TableCell className="text-right text-muted-foreground">{e.dir ? "—" : formatBytes(e.size)}</TableCell>
                <TableCell className="text-muted-foreground">{new Date(e.modifiedAt).toLocaleString()}</TableCell>
                <TableCell>
                  <div className="flex justify-end gap-1">
                    {!e.dir && <Button asChild size="icon-xs" variant="ghost" aria-label={`Descargar ${e.name}`}><a href={filesApi.downloadUrl(serverId, joinPath(path, e.name))} download={e.name}><Download /></a></Button>}
                    <Button size="icon-xs" variant="ghost" aria-label={`Renombrar ${e.name}`} onClick={() => { nameMut.reset(); setNameAction({ kind: "rename", entry: e }); }}><Pencil /></Button>
                    <Button size="icon-xs" variant="ghost" aria-label={`Borrar ${e.name}`} disabled={del.isPending} onClick={() => {
                      if (confirm(e.dir ? `¿Borrar la carpeta «${e.name}» y todo su contenido?` : `¿Borrar «${e.name}»?`)) del.mutate(e);
                    }}><Trash2 /></Button>
                  </div>
                </TableCell>
              </TableRow>
            );
          })}
        </TableBody>
      </Table>
      {list.data?.truncated && <p className="text-sm text-amber-400">La carpeta tiene demasiadas entradas: solo se muestran las primeras 5000.</p>}

      <NameDialog
        open={nameAction !== null}
        title={nameAction?.kind === "rename" ? `Renombrar «${nameAction.entry.name}»` : "Nueva carpeta"}
        confirmLabel={nameAction?.kind === "rename" ? "Renombrar" : "Crear"}
        initial={nameAction?.kind === "rename" ? nameAction.entry.name : ""}
        existing={names}
        pending={nameMut.isPending}
        error={nameMut.error ? errText(nameMut.error) : null}
        onConfirm={(n) => nameMut.mutate(n)}
        onOpenChange={(o) => { if (!o) setNameAction(null); }}
      />
    </div>
  );
}
```
