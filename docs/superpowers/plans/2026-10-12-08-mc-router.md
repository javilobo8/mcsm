# MC Server Manager — Plan 8: mc-router

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que los jugadores entren a cada servidor por su hostname (`survival.lan`, `creativo.lan`) a través de un único puerto del nodo: el agente despliega y reconcilia un contenedor `itzg/mc-router` por nodo (activable, con puerto y autoscale configurables desde Nodos) y los servidores con la sección `router` llevan las etiquetas `mc-router.host` que el router descubre por Docker.

**Architecture:** El panel guarda la configuración de cada nodo en `router_deployments` y se la envía al agente (`RouterApply{spec}` / `RouterRemove{}`, Ack inmediato) al cambiarla y tras cada handshake; el agente la persiste en bbolt y un `router.Manager` reconcilia el contenedor `mcsm-router` (crear, recrear por hash, arrancar, borrar) en segundo plano —al recibirla, al arrancar, cada 30 s y con los eventos de Docker del contenedor— y publica `RouterObserved` (id = 0), que el panel guarda y reenvía a la web por el WS. La spec del servidor gana `router: {enabled, hostname}`: `BuildContainer` añade `mc-router.host`/`mc-router.network` (dentro del hash, sin cambiarlo cuando falta o está desactivada). Con el autoscale del router, los servidores con hostname quedan «bajo demanda»: el reconciliador deja de arrancarlos/pararlos por su cuenta (mc-router lo hace).

**Tech Stack:** Go 1.27.2 (agente: `router` nuevo, `reconcile`, `app`, `store`, `spec`); protobuf con buf 1.73 (`pnpm gen`); `itzg/mc-router:1.47.1`; Node 26, pnpm 12, Fastify 5, `node:sqlite`, zod 4; React 19, TanStack Query, shadcn/ui (Radix), Vitest 4 en node (sin jsdom); E2E con Docker real y un sondeo SLP propio en Node.

## Decisiones resueltas con el código real

- **Una sección `router: {enabled, hostname}` por servidor.** La spec (§4.1) dibuja `hostnames: [...]` y un `autoscale` por servidor; se sigue el encargo: **un** hostname por servidor (único por nodo entre los que tienen el router activo; un hostname en otro nodo es otro DNS) y el autoscale **por nodo** en `router_deployments.spec`. Motivo comprobado en el código de mc-router (`server/docker.go`): en modo Docker solo conserva los contenedores parados en su tabla si el flag **global** `-auto-scale-up` está activo; las etiquetas `mc-router.auto-scale-*` solo afinan sobre él. Hostname: minúsculas, RFC 1123 (etiquetas de 1–63 `[a-z0-9-]` sin guion al principio ni al final, separadas por puntos, máx. 253), misma regex en Go y zod con fixture compartida. `enabled` sin hostname es inválido; desactivado conserva el hostname.
- **Etiquetas y hash.** Con `router.enabled`, `BuildContainer` añade `mc-router.host=<hostname>` y `mc-router.network=<red>` (mc-router exige la red si el contenedor está en varias). Entran en `hashInput.Labels` como el resto: activar, desactivar o cambiar el hostname recrea el contenedor (reinicio del servidor); sin sección o desactivada no se añade nada y el golden no cambia.
- **Puertos.** Cada servidor **sigue publicando su puerto propio** (acceso directo por IP:puerto y respaldo si el router cae; los servidores sin router no cambian). mc-router alcanza a los servidores por la **IP del contenedor en la red `mcsm`** y el puerto 25565 interno (no por el alias `mcsm-<slug>`), así que el router se crea en esa misma red. El puerto del host del router activo queda reservado en el nodo: `allocatePort` no lo reparte y `checkPorts` lo rechaza (también para la importación del Plan 6, que usa `checkPorts`); activar el router en un puerto que publica un servidor es 409. Sin backend por defecto: un hostname desconocido ve la conexión cerrada.
- **Importados (Plan 6).** Un contenedor adoptado no tiene etiquetas `mc-router.*` hasta que se recrea. Activar el router en un importado es un cambio de spec con versión mayor que la de la adopción, así que el Plan 6 lo recrea ya como gestionado y con etiquetas (el servidor se reinicia). Se documenta; no hay código específico.
- **«Bajo demanda».** Con el autoscale del router, para un servidor con `router.enabled` el reconciliador crea y recrea el contenedor pero no arranca uno parado ni para uno en marcha (`Reconciler.SetOnDemand`, consultado con el lock del servidor: solo lee un atómico del router). Un contenedor recién creado sí sigue el estado deseado y `Power` sigue mandando. Al activar o quitar el autoscale, el agente reconcilia todos los servidores (vuelve a imponerse el deseado). Consecuencia aceptada: tras una restauración o una recreación, un servidor bajo demanda puede quedar dormido hasta que entre alguien.
- **Contenedor del router.** `itzg/mc-router:1.47.1` con `-in-docker -port 25565` (y, con autoscale, `-auto-scale-up -auto-scale-down -auto-scale-down-after <N>m` y MOTD «Servidor dormido…»/«Arrancando el servidor…»), puerto del host configurable (25565 por defecto), red de los servidores, `restart unless-stopped`, etiquetas `mcsm.managed=true` (para recibir sus eventos por el filtro existente; el muestreador y la importación ya ignoran contenedores sin `mcsm.server_id`/gestionados), `mcsm.router=true` y `mcsm.router_hash` (hash canónico propio: cambiar `router.Tag` recrea el router al actualizar el agente). Endurecido: `User 65532:65532` + `GroupAdd <gid del socket>` (el agente lee el grupo de `/var/run/docker.sock`, montado con la misma ruta), `CapDrop ALL`, `no-new-privileges`, `ReadonlyRootfs`, 256 MiB, 256 procesos, solo el socket montado (`:ro`, que **no** limita la API: se documenta en el paquete). Probado con el mc-router real.
- **Reconciliación del router** (`router.Manager`): idempotente; con spec, un contenedor igual a `BuildContainer` y en marcha; sin spec, ninguno (también limpia un router huérfano de un alta anterior). Lo encuentra por etiqueta **y** nombre; un contenedor ajeno llamado igual no se toca (error de nombre en uso). Si el arranque falla (puerto ocupado), **borra el contenedor**: Docker 29.7 arranca sin publicar puertos un contenedor cuyo arranque anterior falló por el puerto (comprobado con `docker start` dos veces), así que reintentar con el mismo dejaría el router «en marcha» e inalcanzable. Tras un fallo, con la misma spec no vuelve a tocar Docker hasta pasados 25 s (los eventos del intento fallido no hacen bucle; el tick de 30 s reintenta); una spec nueva se aplica al momento.
- **Protocolo y flujo.** `RouterApply{spec}`/`RouterRemove{}` guardan (o borran) la spec en bbolt y responden Ack enseguida; el contenedor se ajusta en segundo plano y el resultado llega por `RouterObserved` (no solicitado, `id = 0`). No hay job `deploy_router` (spec §4): el estado observado basta y no bloquea la UI mientras se descarga la imagen. `RouterSpec` va en el proto con `host_port`, `autoscale` y `autoscale_down_after_minutes`; el panel guarda además `enabled`.
- **El panel es la verdad.** `RouterService` reenvía la configuración tras el handshake de un nodo **con fila** (`conn.ready`, sin tocar el handshake) y al guardar; los envíos de un nodo van en cadena y cada uno lee la fila al salir, así que el último en llegar es siempre el vigente. Sin fila no se envía nada (los tests existentes con el agente falso no ven mensajes nuevos). Un `RouterObserved` con router configurado en un nodo sin fila activa (BD del panel restaurada) provoca un `RouterRemove`. Los fallos transitorios al guardar (`disconnected`, `syncing`, `timeout`) no impiden guardar; un agente sin soporte (`unsupported`) es 409.
- **Rutas.** `GET`/`PUT /api/nodes/:id/router`. PUT y no POST: la guarda del Plan 7 bloquea los `POST /api/nodes/:id/…` de un nodo con una migración en curso, y configurar el router no debe quedar bloqueado. Borrar un nodo con el router activo es 409 (su contenedor quedaría huérfano en esa máquina); desactivado, la fila cae en cascada.
- **Plantillas.** El hostname es de un servidor concreto: `specToTemplate` quita `router`, el editor de plantillas no lo envía (`TEMPLATE_KEYS`) y la pestaña Red (donde vive la sección) no existe en plantillas.
- **Web.** Nodos gana la columna «Router» (insignia de estado; al pulsarla, un diálogo con activar, puerto, autoscale y minutos, el error del agente y la nota del socket). El estado llega en vivo por el topic `nodes` (evento `router`). En el servidor, la sección «Router (mc-router)» va al final de la pestaña Red del `SpecForm` (hostname en minúsculas mientras se escribe; desactivado y vacío vuelve a «sin sección» y no versiona).
- **DNS.** Resolver `*.lan` hacia la IP del nodo es cosa del usuario (router de casa, Pi-hole, `/etc/hosts`). La E2E no depende de DNS: envía el handshake de Minecraft con el hostname contra `127.0.0.1:<puerto>`.

```go
package spec

import (
	"fmt"
	"regexp"

// Etiquetas de descubrimiento de mc-router en modo -in-docker (itzg/mc-router). El router enruta
// por el hostname del handshake a la IP del contenedor en la red indicada, puerto 25565.
const (
	LabelRouterHost    = "mc-router.host"
	LabelRouterNetwork = "mc-router.network"
	// MaxHostnameLen es la longitud máxima de un nombre DNS (RFC 1123).
	MaxHostnameLen = 253
)

// hostnameRe: nombre DNS en minúsculas (RFC 1123): etiquetas de 1 a 63 caracteres [a-z0-9-] que no
// empiezan ni acaban por guion, separadas por puntos, sin punto final. Misma regex que el panel
// (HOSTNAME_RE en panel/packages/shared/src/router.ts; fixture proto/fixtures/router-hostname-cases.json).
var hostnameRe = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$`)

// Router es la entrada de jugadores por hostname con el mc-router del nodo (plan-8). nil = ausente:
// sin etiquetas, el contenedor y el hash no cambian.
type Router struct {
	Enabled  bool   `json:"enabled"`
	Hostname string `json:"hostname"`
}

// ValidHostname indica si h es un hostname válido para mc-router (minúsculas, RFC 1123, ≤ 253).
func ValidHostname(h string) bool { return len(h) <= MaxHostnameLen && hostnameRe.MatchString(h) }

// Validate: activado exige hostname; un hostname presente siempre debe ser válido.
func (r *Router) Validate() error {
	if r == nil {
		return nil
	}
	if r.Enabled && r.Hostname == "" {
		return fmt.Errorf("spec: router.hostname es obligatorio con el router activado")
	}
	if r.Hostname != "" && !ValidHostname(r.Hostname) {
		return fmt.Errorf("spec: router.hostname inválido %q (minúsculas, números, guiones y puntos; máx. 253)", r.Hostname)
	}
	return nil
}

// Active indica si el servidor entra por el router (sección presente y activada).
func (r *Router) Active() bool { return r != nil && r.Enabled }

// addLabels añade las etiquetas de mc-router si el router está activo. mc-router.network fija la
// red por la que el router alcanza el contenedor aunque alguien lo conecte a otra.
func (r *Router) addLabels(labels map[string]string, networkName string) {
	if !r.Active() {
		return
	}
	labels[LabelRouterHost] = r.Hostname
	labels[LabelRouterNetwork] = networkName
}
```

```go
// descubrimiento por Docker (-in-docker) en la red de los servidores, que publica un puerto del host
// y enruta cada conexión por el hostname del handshake al contenedor con esa etiqueta mc-router.host.
//
// Riesgo del socket de Docker: mc-router lo necesita para descubrir los servidores (y, con autoscale,
// para arrancarlos y pararlos). Quien controla ese socket controla el host, igual que el agente. Se
// reduce lo que el contenedor puede hacer por sí mismo: imagen fijada (Tag), usuario no root
// (65532) con solo el grupo del socket, CapDrop ALL, no-new-privileges, raíz de solo lectura,
// límites de memoria y procesos, sin API HTTP de mc-router y sin más montajes. El «:ro» del
// montaje NO limita la API de Docker (connect() sobre un socket no comprueba el montaje): solo
// documenta la intención. Aislarlo de verdad exigiría un proxy del socket (no incluido).
package router

import (
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"sort"

	"github.com/moby/moby/api/types/container"

	"mcsm/agent/internal/spec"
)

const (
	// ContainerName es el nombre del contenedor del router en un nodo (los tests usan mcsm-test-…).
	ContainerName = "mcsm-router"
	Image         = "itzg/mc-router"
	// Tag fija la versión de mc-router. Cambiarla cambia el hash: al actualizar el agente, el router
	// se recrea con la imagen nueva.
	Tag = "1.47.1"
	// LabelRouter marca el contenedor del router (además de mcsm.managed, para recibir sus eventos).
	LabelRouter = "mcsm.router"
	// LabelHash guarda el hash de la configuración para detectar cambios sin comparar campo a campo.
	LabelHash = "mcsm.router_hash"
	// ListenPort es el puerto de mc-router dentro del contenedor.
	ListenPort = 25565
	// HostSocket es el socket de Docker del host: el agente lo tiene montado en la misma ruta.
	HostSocket = "/var/run/docker.sock"
	// User es el usuario no root de la imagen (chainguard static).
	User = "65532:65532"

	DefaultDownAfterMinutes = 10
	MaxDownAfterMinutes     = 1440

	memoryLimit = 256 << 20
	pidsLimit   = 256
	hashSchema  = 1

	asleepMOTD  = "Servidor dormido: conéctate para arrancarlo"
	loadingMOTD = "Arrancando el servidor…"
)

// ImageRef es la imagen del router con su etiqueta fijada.
func ImageRef() string { return Image + ":" + Tag }

// Build es la configuración del contenedor del router.
type Build struct {
	Name       string
	Config     *container.Config
	HostConfig *container.HostConfig
	Networking *network.NetworkingConfig
	Hash       string
}

// Validate comprueba una spec de router del panel.
func Validate(sp *mcsmv1.RouterSpec) error {
	if sp == nil {
		return errors.New("router: falta la spec")
	}
	if sp.HostPort < 1 || sp.HostPort > 65535 {
		return fmt.Errorf("router: puerto del host fuera de rango: %d", sp.HostPort)
	}
	if sp.AutoscaleDownAfterMinutes > MaxDownAfterMinutes {
		return fmt.Errorf("router: minutos sin jugadores fuera de rango: %d (máx. %d)", sp.AutoscaleDownAfterMinutes, MaxDownAfterMinutes)
	}
	return nil
}

// args son los argumentos de mc-router. Sin autoscale, mc-router solo enruta a contenedores en
// marcha; con autoscale arranca el servidor al entrar un jugador y lo para tras N minutos sin nadie.
func args(sp *mcsmv1.RouterSpec) []string {
	a := []string{"-in-docker", "-port", strconv.Itoa(ListenPort)}
	if sp.Autoscale {
		mins := sp.AutoscaleDownAfterMinutes
		if mins == 0 {
			mins = DefaultDownAfterMinutes
		}
		a = append(a, "-auto-scale-up", "-auto-scale-down", "-auto-scale-down-after", fmt.Sprintf("%dm", mins),
			"-auto-scale-asleep-motd", asleepMOTD, "-auto-scale-loading-motd", loadingMOTD)
	}
	return a
}

// BuildContainer traduce la spec a la configuración del contenedor. Pura: misma entrada, mismo Hash.
// socketGID es el grupo propietario del socket de Docker del host (GroupAdd).
func BuildContainer(sp *mcsmv1.RouterSpec, name, networkName string, socketGID uint32) (*Build, error) {
	if err := Validate(sp); err != nil {
		return nil, err
	}
	port := network.MustParsePort(fmt.Sprintf("%d/tcp", ListenPort))
	cfg := &container.Config{
		Image:        ImageRef(),
		Cmd:          args(sp),
		User:         User,
		ExposedPorts: network.PortSet{port: {}},
		Labels:       map[string]string{spec.LabelManaged: "true", LabelRouter: "true"},
	}
	host := &container.HostConfig{
		Binds:          []string{HostSocket + ":" + HostSocket + ":ro"},
		PortBindings:   network.PortMap{port: {{HostPort: strconv.FormatUint(uint64(sp.HostPort), 10)}}},
		RestartPolicy:  container.RestartPolicy{Name: container.RestartPolicyUnlessStopped},
		SecurityOpt:    []string{"no-new-privileges:true"},
		CapDrop:        []string{"ALL"},
		GroupAdd:       []string{strconv.FormatUint(uint64(socketGID), 10)},
		ReadonlyRootfs: true,
	}
	host.Resources.Memory = memoryLimit
	pids := int64(pidsLimit)
	host.Resources.PidsLimit = &pids
	net := &network.NetworkingConfig{EndpointsConfig: map[string]*network.EndpointSettings{networkName: {}}}
	hash, err := hashOf(name, networkName, cfg, host)
	if err != nil {
		return nil, err
	}
	cfg.Labels[LabelHash] = hash
	return &Build{Name: name, Config: cfg, HostConfig: host, Networking: net, Hash: hash}, nil
}

// hashInput es la forma canónica de lo que define el contenedor del router (no el JSON de moby, que
// cambia entre versiones de la librería). Todo lo que BuildContainer ponga debe estar aquí.
type hashInput struct {
	Schema         int               `json:"schema"`
	Name           string            `json:"name"`
	Image          string            `json:"image"`
	Cmd            []string          `json:"cmd"`
	User           string            `json:"user"`
	Labels         map[string]string `json:"labels"`
	Ports          []string          `json:"ports"`
	Binds          []string          `json:"binds"`
	Network        string            `json:"network"`
	Restart        string            `json:"restart"`
	Memory         int64             `json:"memory"`
	PidsLimit      int64             `json:"pidsLimit"`
	SecurityOpt    []string          `json:"securityOpt"`
	CapDrop        []string          `json:"capDrop"`
	GroupAdd       []string          `json:"groupAdd"`
	ReadonlyRootfs bool              `json:"readonlyRootfs"`
}

func hashOf(name, networkName string, cfg *container.Config, host *container.HostConfig) (string, error) {
	in := hashInput{
		Schema: hashSchema, Name: name, Image: cfg.Image, Cmd: append([]string{}, cfg.Cmd...), User: cfg.User,
		Labels: map[string]string{}, Binds: sorted(host.Binds), Network: networkName, Restart: string(host.RestartPolicy.Name),
		Memory: host.Resources.Memory, SecurityOpt: sorted(host.SecurityOpt), CapDrop: sorted(host.CapDrop),
		GroupAdd: sorted(host.GroupAdd), ReadonlyRootfs: host.ReadonlyRootfs,
	}
	for k, v := range cfg.Labels {
		if k != LabelHash {
			in.Labels[k] = v
		}
	}
	for p, binds := range host.PortBindings {
		for _, b := range binds {
			in.Ports = append(in.Ports, p.String()+"->:"+b.HostPort)
		}
	}
	sort.Strings(in.Ports)
	if host.Resources.PidsLimit != nil {
		in.PidsLimit = *host.Resources.PidsLimit
	}
	b, err := json.Marshal(in)
	if err != nil {
		return "", fmt.Errorf("router: calcular el hash: %w", err)
	}
	sum := sha256.Sum256(b)
	return hex.EncodeToString(sum[:])[:16], nil
}

func sorted(in []string) []string {
	out := append([]string{}, in...)
	sort.Strings(out)
	return out
}
```

```go
package store

import (
	"errors"

	"go.etcd.io/bbolt"
	"google.golang.org/protobuf/proto"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
)

// bRouter guarda la spec del mc-router del nodo (plan-8) bajo la clave "spec". Sin clave = el nodo
// no tiene router. El bucket se crea al primer uso para no tocar la lista de buckets de Open.
var (
	bRouter     = []byte("router")
	kRouterSpec = []byte("spec")
)

// RouterSpec devuelve la spec del router guardada, o nil si no hay.
func (s *Store) RouterSpec() (*mcsmv1.RouterSpec, error) {
	var out *mcsmv1.RouterSpec
	err := s.db.View(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bRouter)
		if b == nil {
			return nil
		}
		raw := b.Get(kRouterSpec)
		if raw == nil {
			return nil
		}
		sp := &mcsmv1.RouterSpec{}
		if err := proto.Unmarshal(raw, sp); err != nil {
			return err
		}
		out = sp
		return nil
	})
	return out, err
}

// PutRouterSpec guarda (o sustituye) la spec del router.
func (s *Store) PutRouterSpec(sp *mcsmv1.RouterSpec) error {
	if sp == nil {
		return errors.New("store: spec de router vacía")
	}
	raw, err := proto.Marshal(sp)
	if err != nil {
		return err
	}
	return s.db.Update(func(tx *bbolt.Tx) error {
		b, err := tx.CreateBucketIfNotExists(bRouter)
		if err != nil {
			return err
		}
		return b.Put(kRouterSpec, raw)
	})
}

// DeleteRouterSpec borra la spec del router (idempotente).
func (s *Store) DeleteRouterSpec() error {
	return s.db.Update(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bRouter)
		if b == nil {
			return nil
		}
		return b.Delete(kRouterSpec)
	})
}
```

```go
package router

import (
	"context"
	"errors"
	"fmt"
	"os"
	"sync"
	"sync/atomic"
	"syscall"
	"time"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/docker"
)

const (
	// stopTimeout es la espera de una parada limpia del router antes de matarlo.
	stopTimeout = 10 * time.Second
	// RetryAfter es la espera tras un fallo antes de volver a tocar Docker con la misma spec (los
	// eventos del propio intento fallido no deben convertirse en un bucle de crear y borrar).
	RetryAfter = 25 * time.Second // menos que el tick de 30 s del agente: cada tick reintenta
)

// Store es lo que el router usa del store del agente (store.Store lo cumple).
type Store interface {
	RouterSpec() (*mcsmv1.RouterSpec, error)
	PutRouterSpec(*mcsmv1.RouterSpec) error
	DeleteRouterSpec() error
}

// Options configura un Manager. Name y SocketGID tienen valores por defecto.
type Options struct {
	// Name del contenedor: ContainerName si está vacío (los tests con Docker real usan mcsm-test-…).
	Name    string
	Network string
	// SocketGID devuelve el grupo propietario del socket de Docker del host; por defecto, el de
	// HostSocket (montado con la misma ruta en el agente).
	SocketGID func() (uint32, error)
	Now       func() time.Time
}

// Manager reconcilia el contenedor del router con la spec guardada: con spec, un contenedor igual a
// BuildContainer y en marcha; sin spec, ningún contenedor del router. Reconcile y las demás
// operaciones sobre Docker se serializan con mu.
type Manager struct {
	eng  docker.Engine
	st   Store
	opts Options

	mu        sync.Mutex
	lastErr   string    // error de la última reconciliación (bajo mu)
	failedAt  time.Time // cuándo falló (bajo mu)
	failedFor string    // specKey de la spec con la que falló (bajo mu)
	// autoscale refleja la spec guardada sin tomar mu: la lee el reconciliador de servidores con su
	// propio lock tomado mientras Reconcile puede estar esperando a Docker.
	autoscale atomic.Bool
}

// New crea el gestor y carga el autoscale de la spec guardada (reinicio del agente).
func New(eng docker.Engine, st Store, opts Options) *Manager {
	if opts.Name == "" {
		opts.Name = ContainerName
	}
	if opts.SocketGID == nil {
		opts.SocketGID = hostSocketGID
	}
	if opts.Now == nil {
		opts.Now = time.Now
	}
	m := &Manager{eng: eng, st: st, opts: opts}
	if sp, err := st.RouterSpec(); err == nil && sp != nil {
		m.autoscale.Store(sp.Autoscale)
	}
	return m
}

// hostSocketGID lee el grupo propietario del socket de Docker.
func hostSocketGID() (uint32, error) {
	fi, err := os.Stat(HostSocket)
	if err != nil {
		return 0, err
	}
	st, ok := fi.Sys().(*syscall.Stat_t)
	if !ok {
		return 0, errors.New("no se puede leer el propietario del socket")
	}
	return st.Gid, nil
}

// Apply valida y guarda la spec sin tocar Docker (el contenedor lo ajusta Reconcile).
func (m *Manager) Apply(sp *mcsmv1.RouterSpec) error {
	if err := Validate(sp); err != nil {
		return err
	}
	if err := m.st.PutRouterSpec(sp); err != nil {
		return err
	}
	m.autoscale.Store(sp.Autoscale)
	return nil
}

// Clear borra la spec guardada sin tocar Docker (Reconcile retira el contenedor).
func (m *Manager) Clear() error {
	if err := m.st.DeleteRouterSpec(); err != nil {
		return err
	}
	m.autoscale.Store(false)
	return nil
}

// Autoscale indica si el router guardado arranca y para los servidores con hostname. No bloquea.
func (m *Manager) Autoscale() bool { return m.autoscale.Load() }

// specKey identifica una spec para la espera tras un fallo ("" = sin spec).
func specKey(sp *mcsmv1.RouterSpec) string {
	if sp == nil {
		return ""
	}
	return fmt.Sprintf("%d/%t/%d", sp.HostPort, sp.Autoscale, sp.AutoscaleDownAfterMinutes)
}

// Reconcile deja Docker igual que la spec guardada y devuelve el estado observado. Idempotente:
// recrea el contenedor si falta (borrado a mano) o si su hash no coincide (spec o imagen nuevas),
// lo arranca si está parado y, sin spec, lo borra. Un fallo (p. ej. el puerto del host ocupado)
// queda en RouterObserved.Error; con la misma spec no se reintenta hasta pasados RetryAfter (una
// spec nueva sí se aplica al momento).
func (m *Manager) Reconcile(ctx context.Context) *mcsmv1.RouterObserved {
	m.mu.Lock()
	defer m.mu.Unlock()
	sp, err := m.st.RouterSpec()
	if err != nil {
		m.lastErr = fmt.Sprintf("leer la spec del router: %v", err)
		return m.observeLocked(ctx)
	}
	key := specKey(sp)
	if m.lastErr != "" && key == m.failedFor && m.opts.Now().Before(m.failedAt.Add(RetryAfter)) {
		return m.observeLocked(ctx)
	}
	m.lastErr = ""
	if err := m.reconcileLocked(ctx, sp); err != nil {
		m.lastErr, m.failedAt, m.failedFor = err.Error(), m.opts.Now(), key
	}
	return m.observeLocked(ctx)
}

func (m *Manager) reconcileLocked(ctx context.Context, sp *mcsmv1.RouterSpec) error {
	existing, err := m.find(ctx)
	if err != nil {
		return err
	}
	if sp == nil {
		if existing == nil {
			return nil
		}
		return m.remove(ctx, existing)
	}
	gid, err := m.opts.SocketGID()
	if err != nil {
		return fmt.Errorf("leer el grupo del socket de Docker %s (el router lo necesita): %w", HostSocket, err)
	}
	b, err := BuildContainer(sp, m.opts.Name, m.opts.Network, gid)
	if err != nil {
		return err
	}
	if existing != nil && existing.Labels[LabelHash] != b.Hash {
		if err := m.remove(ctx, existing); err != nil {
			return err
		}
		existing = nil
	}
	if existing == nil {
		if err := m.eng.EnsureImage(ctx, b.Config.Image); err != nil {
			return fmt.Errorf("descargar %s: %w", b.Config.Image, err)
		}
		id, err := m.eng.Create(ctx, b.Name, b.Config, b.HostConfig, b.Networking)
		if err != nil {
			return fmt.Errorf("crear el contenedor %s: %w", b.Name, err)
		}
		existing = &docker.Container{ID: id, Name: b.Name, State: "created"}
	}
	if existing.State != "running" && existing.State != "restarting" {
		if err := m.eng.Start(ctx, existing.ID); err != nil {
			// Docker (29.x) arranca SIN publicar puertos un contenedor cuyo arranque anterior falló por
			// el puerto del host: se borra para que el reintento lo cree de nuevo y vuelva a fallar
			// mientras el puerto siga ocupado, en vez de quedar «en marcha» e inalcanzable.
			if rerr := m.eng.Remove(ctx, existing.ID); rerr != nil && !errors.Is(rerr, docker.ErrNotFound) {
				return fmt.Errorf("arrancar el router en el puerto %d del host: %w (y no se pudo borrar: %v)", sp.HostPort, err, rerr)
			}
			return fmt.Errorf("arrancar el router en el puerto %d del host: %w", sp.HostPort, err)
		}
	}
	return nil
}

// remove para y borra el contenedor del router.
func (m *Manager) remove(ctx context.Context, c *docker.Container) error {
	if err := m.eng.Stop(ctx, c.ID, stopTimeout); err != nil && !errors.Is(err, docker.ErrNotFound) {
		return fmt.Errorf("parar el router: %w", err)
	}
	if err := m.eng.Remove(ctx, c.ID); err != nil && !errors.Is(err, docker.ErrNotFound) {
		return fmt.Errorf("borrar el router: %w", err)
	}
	return nil
}

func (m *Manager) observeLocked(ctx context.Context) *mcsmv1.RouterObserved {
	obs := &mcsmv1.RouterObserved{State: "missing", Error: m.lastErr, TsUnixMs: m.opts.Now().UnixMilli()}
	sp, err := m.st.RouterSpec()
	if err != nil && obs.Error == "" {
		obs.Error = err.Error()
	}
	if sp != nil {
		obs.Configured, obs.HostPort, obs.Autoscale, obs.Image = true, sp.HostPort, sp.Autoscale, ImageRef()
	}
	c, err := m.find(ctx)
	if err != nil {
		if obs.Error == "" {
			obs.Error = err.Error()
		}
		return obs
	}
	if c == nil {
		return obs
	}
	ins, err := m.eng.Inspect(ctx, c.ID)
	if err != nil {
		if !errors.Is(err, docker.ErrNotFound) && obs.Error == "" {
			obs.Error = err.Error()
		}
		return obs
	}
	obs.ContainerId, obs.State = ins.ID, ins.State
	return obs
}

// find busca el contenedor del router por su etiqueta y su nombre (nil si no existe).
func (m *Manager) find(ctx context.Context) (*docker.Container, error) {
	list, err := m.eng.ListManaged(ctx)
	if err != nil {
		return nil, fmt.Errorf("listar contenedores: %w", err)
	}
	for i := range list {
		if list[i].Labels[LabelRouter] == "true" && list[i].Name == m.opts.Name {
			return &list[i], nil
		}
	}
	return nil, nil
}
```

```go
// cliente: mc-router lo lee para elegir el servidor por addr.
func handshake(addr string, port uint16) []byte {
	varint := func(b *bytes.Buffer, v int) {
		for {
			c := byte(v & 0x7f)
			v >>= 7
			if v != 0 {
				c |= 0x80
			}
			b.WriteByte(c)
			if v == 0 {
				return
			}
		}
	}

	body.WriteString(addr)
	_ = binary.Write(&body, binary.BigEndian, port)
	varint(&body, 1) // siguiente estado: status
	var pkt bytes.Buffer
	varint(&pkt, body.Len())
	pkt.Write(body.Bytes())
	return pkt.Bytes()
}
```

```go
func (a *App) onDemand(s spec.Spec) bool { return s.Router.Active() && a.router.Autoscale() }

func (a *App) handleRouterApply(id uint64, req *mcsmv1.RouterApply, send func(*mcsmv1.Envelope) error) {
	before := a.router.Autoscale()
	if err := a.router.Apply(req.GetSpec()); err != nil {
		_ = send(errMsg(id, errcode.InvalidRequest, err))
		return
	}
	_ = send(ack(id))

	if a.router.Autoscale() != before {
		a.reconcileAll(a.life) // cambia qué servidores están bajo demanda

func (a *App) handleRouterRemove(id uint64, send func(*mcsmv1.Envelope) error) {
	before := a.router.Autoscale()
	if err := a.router.Clear(); err != nil {
		_ = send(errMsg(id, errcode.IOError, err))
		return
	}
	_ = send(ack(id))
	a.routerAsync(a.life)
	if before {
		a.reconcileAll(a.life) // los servidores bajo demanda vuelven a su estado deseado
	}
}

func (a *App) routerAsync(ctx context.Context) {
	a.dispatch(ctx, "router", func() {
		obs := a.router.Reconcile(ctx)
		_ = a.send(&mcsmv1.Envelope{Body: &mcsmv1.Envelope_RouterObserved{RouterObserved: obs}})
	})
}

// routerLoop reconcilia el router al arrancar (reinicio del agente: lo recrea si falta) y cada
// reconcileEvery (borrado a mano, puerto liberado).
func (a *App) routerLoop(ctx context.Context) {
	a.routerAsync(ctx)
	t := time.NewTicker(reconcileEvery)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			a.routerAsync(ctx)
		}
	}
}

// routerEvent reacciona a un evento de Docker del contenedor del router.
func (a *App) routerEvent(ctx context.Context, action string) {
	switch action {
	case "start", "die", "stop", "kill", "destroy", "oom", "restart":
		a.routerAsync(ctx)
	}
}

func isRouterEvent(labels map[string]string) bool { return labels[router.LabelRouter] == "true" }
```

```ts
import { z } from "zod";

/**
 * Hostname de un servidor en el mc-router de su nodo: nombre DNS en minúsculas (RFC 1123), etiquetas
 * de 1 a 63 caracteres [a-z0-9-] que no empiezan ni acaban por guion, separadas por puntos, sin punto
 * final, máx. 253. Misma regex que el agente (hostnameRe en agent/internal/spec/router.go; fixture
 * proto/fixtures/router-hostname-cases.json).
 */
export const HOSTNAME_RE = /^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$/;
export const MAX_HOSTNAME_LEN = 253;

export function validHostname(h: string): boolean {
  return h.length <= MAX_HOSTNAME_LEN && HOSTNAME_RE.test(h);
}

/** Mensaje para un hostname inválido; null si vale (vacío = sin hostname, lo decide el esquema). */
export function hostnameError(h: string): string | null {
  if (h === "" || validHostname(h)) return null;
  if (h !== h.toLowerCase()) return "El hostname va en minúsculas";
  if (h.length > MAX_HOSTNAME_LEN) return `El hostname no puede pasar de ${MAX_HOSTNAME_LEN} caracteres`;
  return "Hostname inválido: letras minúsculas, números, guiones y puntos (p. ej. survival.lan)";
}

/**
 * Sección `router` de la spec de un servidor (plan-8): entrar por `hostname` a través del mc-router del
 * nodo. Activada exige hostname. El agente añade las etiquetas `mc-router.host`/`mc-router.network`
 * al contenedor (activarla, desactivarla o cambiar el hostname recrea el contenedor).
 */
export const serverRouterSchema = z
```

```ts
export function toRouterDto(nodeId: string, r: RouterRow | null): RouterDto {
  return {
    nodeId, spec: rowSpec(r),
    observed: r?.observed ? (JSON.parse(r.observed) as RouterObservedDto) : null,
    observedAt: r?.observed_at ?? null, updatedAt: r?.updated_at ?? null,

export class RouterRepo {
  constructor(private db: Db) {}

  get(nodeId: string): RouterRow | null {
    return (this.db.prepare("SELECT * FROM router_deployments WHERE node_id = ?").get(nodeId) as RouterRow | undefined) ?? null;
```

```ts
import type { FastifyInstance } from "fastify";
import type { RouterObserved } from "@mcsm/proto";
import { formatZodError, routerDeploymentSpecSchema, type RouterDto, type RouterObservedDto, type Spec } from "@mcsm/shared";
import { AgentError, type Body } from "../agents/hub.js";
import { AgentErrorCode } from "../agents/error-codes.js";
import { HttpError, agentErrorToHttp } from "../lib/http.js";
import { hostnameOwner, portOwner } from "./checks.js";
import { RouterRepo, rowSpec, toRouterDto } from "./repo.js";

/** Fallos de envío que no impiden guardar: la configuración llega en el próximo handshake. */
const TRANSIENT = new Set<string>([AgentErrorCode.Disconnected, AgentErrorCode.Syncing, AgentErrorCode.Timeout]);

export function observedToDto(o: RouterObserved): RouterObservedDto {
  return {
    configured: o.configured, state: o.state || "missing", containerId: o.containerId, image: o.image,
    hostPort: o.hostPort, autoscale: o.autoscale, error: o.error,
  };
}

/**
 * mc-router de cada nodo (spec §7 RouterService). La fila de `router_deployments` es la verdad: tras el
 * handshake de un nodo con fila se le reenvía (RouterApply si está activo, RouterRemove si no) y cada
 * cambio del usuario se envía al momento si el nodo está conectado. Los envíos de un nodo van en
 * cadena y cada uno lee la fila al salir, así que el último en llegar al agente es siempre el vigente.
 */
export class RouterService {
  private chains = new Map<string, Promise<void>>();

  constructor(private app: FastifyInstance, private repo: RouterRepo) {}

  start() {
    this.app.agents.on("attached", (nodeId: string) => {
      const conn = this.app.agents.get(nodeId);
      // Tras el Ack de SyncSpecs (conn.ready): nada sale al agente antes.
      conn?.ready.then(() => {
        if (this.repo.get(nodeId)) this.push(nodeId).catch((e) => this.app.log.warn({ nodeId, err: e }, "no se pudo enviar el router al agente"));
      }, () => { /* desconectado antes de sincronizar: el próximo handshake lo reenvía */ });
    });
  }

  private requireNode(nodeId: string) {
    if (!this.app.nodes.get(nodeId)) throw new HttpError(404, "Nodo no encontrado");
  }

  get(nodeId: string): RouterDto {
    this.requireNode(nodeId);
    return toRouterDto(nodeId, this.repo.get(nodeId));
  }

  /** ¿Está activo el router del nodo? */
  isEnabled(nodeId: string): boolean {
    return rowSpec(this.repo.get(nodeId)).enabled;
  }

  /** Puerto del host que ocupa el router activo del nodo; null si no está activo. */
  reservedPort(nodeId: string): number | null {
    const spec = rowSpec(this.repo.get(nodeId));
    return spec.enabled ? spec.port : null;
  }

  /** 409 si el hostname del router de `spec` ya lo usa otro servidor del nodo (con el router activo). */
  checkHostname(nodeId: string, spec: Spec, selfId?: string) {
    if (!spec.router?.enabled) return;
    const owner = hostnameOwner(this.app.servers.list(nodeId), spec.router.hostname, selfId);
    if (owner) throw new HttpError(409, `El hostname «${spec.router.hostname}» ya lo usa el servidor «${owner.name}» de este nodo`);
  }

  async put(nodeId: string, input: unknown): Promise<RouterDto> {
    this.requireNode(nodeId);
    const parsed = routerDeploymentSpecSchema.safeParse(input ?? {});
    if (!parsed.success) throw new HttpError(400, formatZodError(parsed.error));
    const spec = parsed.data;
    if (spec.enabled) {
      const owner = portOwner(this.app.servers.list(nodeId), spec.port);
      if (owner) {
        throw new HttpError(409, `El puerto ${spec.port} lo usa el servidor «${owner.name}» de este nodo: elige otro puerto para el router o cambia el del servidor`);
      }
    }
    const row = this.repo.upsertSpec(nodeId, spec);
    this.app.events.emit("router", nodeId, toRouterDto(nodeId, row));
    try {
      await this.push(nodeId);
    } catch (e) {
      if (!(e instanceof AgentError && TRANSIENT.has(e.code))) throw agentErrorToHttp(e, "El agente no pudo aplicar el router");
    }
    return toRouterDto(nodeId, this.repo.get(nodeId));
  }

  /** Envía al agente la configuración vigente del nodo (si está conectado). Serializado por nodo. */
  push(nodeId: string): Promise<void> {
    const prev = this.chains.get(nodeId) ?? Promise.resolve();
    const next = prev.catch(() => {}).then(async () => {
      const conn = this.app.agents.get(nodeId);
      if (!conn) return;
      const spec = rowSpec(this.repo.get(nodeId));
      const body: Body = spec.enabled
        ? { case: "routerApply", value: { spec: { hostPort: spec.port, autoscale: spec.autoscale, autoscaleDownAfterMinutes: spec.autoscaleDownAfterMinutes } } }
        : { case: "routerRemove", value: {} };
      await conn.request(body, 30_000);
    });
    this.chains.set(nodeId, next);
    next.then(() => this.release(nodeId, next), () => this.release(nodeId, next));
    return next;
  }

  private release(nodeId: string, p: Promise<void>) {
    if (this.chains.get(nodeId) === p) this.chains.delete(nodeId);
  }

  /** RouterObserved del agente (no solicitado). */
  onObserved(nodeId: string, o: RouterObserved) {
    if (!this.app.nodes.get(nodeId)) return;
    const dto = observedToDto(o);
    const before = this.repo.get(nodeId);
    if (!before && !dto.configured) return; // nodo sin router: nada que guardar
    const row = this.repo.setObserved(nodeId, dto);
    // Un router que el panel no quiere (p. ej. tras restaurar la BD del panel) se retira.
    if (dto.configured && !rowSpec(row).enabled) {
      this.push(nodeId).catch((e) => this.app.log.warn({ nodeId, err: e }, "no se pudo retirar el router del agente"));
    }
    if (before?.observed !== row.observed) this.app.events.emit("router", nodeId, toRouterDto(nodeId, row));
  }
}
```

```ts
import type { QueryClient } from "@tanstack/react-query";
import { ROUTER_DEFAULT_DOWN_AFTER_MINUTES, ROUTER_MAX_DOWN_AFTER_MINUTES, type RouterDeploymentSpec, type RouterDto } from "@mcsm/shared";
import type { ServerMessage } from "./api";
import { mergeIntoCached } from "./live";

export const routerKey = (nodeId: string) => ["router", nodeId] as const;

export type RouterTone = "ok" | "warn" | "bad" | "muted";
export interface RouterStatus { label: string; tone: RouterTone; detail: string | null }

/** Estado legible del router de un nodo a partir de lo guardado y lo último que informó el agente. Pura. */
export function routerStatus(r: RouterDto, nodeOnline: boolean): RouterStatus {
  const o = r.observed;
  if (!r.spec.enabled) {
    if (o?.configured && o.state !== "missing" && nodeOnline) return { label: "Retirando…", tone: "warn", detail: null };
    return { label: "Desactivado", tone: "muted", detail: null };
  }
  if (!nodeOnline) return { label: "Nodo desconectado", tone: "warn", detail: "Se aplicará cuando el nodo vuelva a conectar" };
  if (o?.error) return { label: "Error", tone: "bad", detail: o.error };
  if (!o || !o.configured || o.hostPort !== r.spec.port || o.autoscale !== r.spec.autoscale) return { label: "Aplicando…", tone: "warn", detail: null };
  if (o.state === "running") return { label: `Activo en :${r.spec.port}`, tone: "ok", detail: null };
  return { label: `Estado: ${o.state}`, tone: "warn", detail: null };
}

/** Estado del formulario del router (los números como texto, tal y como se escriben). */
export interface RouterForm { enabled: boolean; port: string; autoscale: boolean; minutes: string }

export function routerFormFrom(spec: RouterDeploymentSpec): RouterForm {
  return { enabled: spec.enabled, port: String(spec.port), autoscale: spec.autoscale, minutes: String(spec.autoscaleDownAfterMinutes) };
}

const intIn = (text: string, min: number, max: number): number | null => {
  const t = text.trim();
  if (!/^[0-9]+$/.test(t)) return null;
  const n = Number(t);
  return n >= min && n <= max ? n : null;
};

/** Errores de campo del formulario (mismas reglas que la API). Vacío = se puede guardar. */
export function routerFormErrors(f: RouterForm): { port?: string; minutes?: string } {
  const out: { port?: string; minutes?: string } = {};
  if (intIn(f.port, 1, 65535) === null) out.port = "Puerto: un número entre 1 y 65535";
  if (f.autoscale && intIn(f.minutes, 1, ROUTER_MAX_DOWN_AFTER_MINUTES) === null) out.minutes = `Minutos: un número entre 1 y ${ROUTER_MAX_DOWN_AFTER_MINUTES}`;
  return out;
}

/** Cuerpo del PUT. Sin autoscale, unos minutos inválidos vuelven al valor por defecto. */
export function routerFormBody(f: RouterForm): RouterDeploymentSpec {
  return {
    enabled: f.enabled, port: intIn(f.port, 1, 65535) ?? 0, autoscale: f.autoscale,
    autoscaleDownAfterMinutes: intIn(f.minutes, 1, ROUTER_MAX_DOWN_AFTER_MINUTES) ?? ROUTER_DEFAULT_DOWN_AFTER_MINUTES,
  };
}

type RouterMsg = Extract<ServerMessage, { type: "router" }>;

export function applyRouterEvent(qc: QueryClient, msg: RouterMsg): void {
  mergeIntoCached<RouterDto>(qc, routerKey(msg.nodeId), () => msg.router);
}

/** Subconjunto de `Realtime` que se usa aquí (facilita los tests). */
export interface RouterLiveSource {
  subscribe(topic: string, handler: (msg: ServerMessage) => void): () => void;
  onReconnect(cb: () => void): () => void;
}

/** Mantiene ["router", nodeId] al día con el topic `nodes`. Devuelve la función de limpieza. */
export function bindRouterLive(qc: QueryClient, live: RouterLiveSource, nodeId: string): () => void {
  const offs = [
    live.subscribe("nodes", (m) => { if (m.type === "router" && m.nodeId === nodeId) applyRouterEvent(qc, m); }),
    live.onReconnect(() => { void qc.invalidateQueries({ queryKey: routerKey(nodeId) }); }),
  ];
  return () => offs.forEach((off) => off());
}
```

```js
    let b = n & 0x7f;
    n >>>= 7;
    if (n) b |= 0x80;
    out.push(b);
  } while (n);
  return Buffer.from(out);
};
const str = (s) => {
  const b = Buffer.from(s, "utf8");
  return Buffer.concat([varint(b.length), b]);
};
const packet = (...parts) => {
  const body = Buffer.concat(parts);
  return Buffer.concat([varint(body.length), body]);
};
const u16 = Buffer.alloc(2);
u16.writeUInt16BE(port);
const handshake = packet(varint(0x00), varint(769), str(host), u16, varint(login ? 2 : 1));
// Login Start (1.21.4): nombre + UUID (16 bytes).
const second = login ? packet(varint(0x00), str("e2e"), Buffer.alloc(16)) : packet(varint(0x00));

function readVarint(buf, off) {
  let n = 0;
  for (let shift = 0; shift <= 28; shift += 7) {
    if (off >= buf.length) return null;
    const b = buf[off++];
    n |= (b & 0x7f) << shift;
    if (!(b & 0x80)) return [n, off];
  }
  throw new Error("varint demasiado largo");
}

const sock = net.connect({ host: ip, port });
sock.setTimeout(10_000, () => {
  // Al despertar un servidor, mc-router retiene la conexión hasta que arranca: el intento ya cuenta.
  if (login) { console.log(JSON.stringify({ login: true, bytes: acc.length })); process.exit(0); }
  console.error("sin respuesta en 10 s");
  process.exit(2);
});
let acc = Buffer.alloc(0);
sock.on("connect", () => sock.write(Buffer.concat([handshake, second])));
sock.on("data", (d) => {
  acc = Buffer.concat([acc, d]);
  if (login) return; // cualquier respuesta vale: se imprime al cerrar
  const head = readVarint(acc, 0);
  if (!head || acc.length < head[1] + head[0]) return;
  const body = acc.subarray(head[1], head[1] + head[0]);
  const [, afterId] = readVarint(body, 0);
  const [len, start] = readVarint(body, afterId);
  const json = JSON.parse(body.subarray(start, start + len).toString("utf8"));
  const desc = json.description;
  const motd = typeof desc === "string" ? desc : (desc?.text ?? "") + (desc?.extra ?? []).map((e) => e?.text ?? "").join("");
  console.log(JSON.stringify({ motd, version: json.version?.name ?? "", players: json.players?.online ?? 0 }));
  sock.end();
  process.exit(0);
});
sock.on("error", (e) => { console.error(e.message); process.exit(1); });
sock.on("close", () => {
  if (login) { console.log(JSON.stringify({ login: true, bytes: acc.length })); process.exit(0); }
  console.error("conexión cerrada sin respuesta de estado");
  process.exit(1);
});
```
