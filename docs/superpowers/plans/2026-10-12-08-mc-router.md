# MC Server Manager — Plan 8: mc-router

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let players reach each server by its hostname (`survival.lan`, `creativo.lan`) through a single port on the node: the agent deploys and reconciles one `itzg/mc-router` container per node (enableable, with port and autoscale configurable from Nodes), and servers with the `router` section carry the `mc-router.host` labels that the router discovers through Docker.

**Architecture:** The panel stores each node's configuration in `router_deployments` and sends it to the agent (`RouterApply{spec}` / `RouterRemove{}`, immediate Ack) when it changes and after each handshake; the agent persists it in bbolt and a `router.Manager` reconciles the `mcsm-router` container (create, recreate on hash change, start, delete) in the background —on receipt, at startup, every 30 s and on the container's Docker events— and publishes `RouterObserved` (id = 0), which the panel stores and forwards to the web over the WS. The server spec gains `router: {enabled, hostname}`: `BuildContainer` adds `mc-router.host`/`mc-router.network` (inside the hash, without changing it when missing or disabled). With the router's autoscale, servers with a hostname become “on-demand”: the reconciler stops starting/stopping them on its own (mc-router does it).

**Tech Stack:** Go 1.27.2 (agent: new `router`, `reconcile`, `app`, `store`, `spec`); protobuf with buf 1.73 (`pnpm gen`); `itzg/mc-router:1.47.1`; Node 26, pnpm 12, Fastify 5, `node:sqlite`, zod 4; React 19, TanStack Query, shadcn/ui (Radix), Vitest 4 on node (no jsdom); E2E with real Docker and a custom SLP probe in Node.

## Decisions resolved against the real code

- **One `router: {enabled, hostname}` section per server.** The spec (§4.1) sketches `hostnames: [...]` and an `autoscale` per server; the brief is followed: **one** hostname per server (unique per node among those with the router enabled; a hostname on another node is another DNS name) and autoscale **per node** in `router_deployments.spec`. Reason verified in mc-router's code (`server/docker.go`): in Docker mode it only keeps stopped containers in its table if the **global** flag `-auto-scale-up` is active; the `mc-router.auto-scale-*` labels only fine-tune on top of it. Hostname: lowercase, RFC 1123 (labels of 1–63 `[a-z0-9-]` with no hyphen at the start or end, separated by dots, max. 253), same regex in Go and zod with a shared fixture. `enabled` without a hostname is invalid; disabled keeps the hostname.
- **Labels and hash.** With `router.enabled`, `BuildContainer` adds `mc-router.host=<hostname>` and `mc-router.network=<network>` (mc-router requires the network if the container is on several). They go into `hashInput.Labels` like the rest: enabling, disabling or changing the hostname recreates the container (server restart); without a section or disabled, nothing is added and the golden does not change.
- **Ports.** Each server **still publishes its own port** (direct access by IP:port and fallback if the router goes down; servers without a router do not change). mc-router reaches the servers by **the container's IP on the `mcsm` network** and the internal port 25565 (not by the `mcsm-<slug>` alias), so the router is created on that same network. The active router's host port is reserved on the node: `allocatePort` does not hand it out and `checkPorts` rejects it (also for the Plan 6 import, which uses `checkPorts`); enabling the router on a port a server publishes is 409. No default backend: an unknown hostname sees the connection closed.
- **Imported (Plan 6).** An adopted container has no `mc-router.*` labels until it is recreated. Enabling the router on an imported one is a spec change with a version higher than the adoption's, so Plan 6 recreates it already as managed and with labels (the server restarts). Documented; no specific code.
- **“On-demand”.** With the router's autoscale, for a server with `router.enabled` the reconciler creates and recreates the container but neither starts a stopped one nor stops a running one (`Reconciler.SetOnDemand`, checked under the server lock: it only reads an atomic from the router). A newly created container does follow the desired state and `Power` still takes precedence. When autoscale is enabled or removed, the agent reconciles all servers (the desired state is enforced again). Accepted consequence: after a restore or a recreation, an on-demand server may stay asleep until someone joins.
- **Router container.** `itzg/mc-router:1.47.1` with `-in-docker -port 25565` (and, with autoscale, `-auto-scale-up -auto-scale-down -auto-scale-down-after <N>m` and MOTD “Server asleep…”/“Starting the server…”), configurable host port (25565 by default), the servers' network, `restart unless-stopped`, labels `mcsm.managed=true` (to receive its events through the existing filter; the sampler and the import already ignore containers without `mcsm.server_id`/managed), `mcsm.router=true` and `mcsm.router_hash` (its own canonical hash: changing `router.Tag` recreates the router when the agent is updated). Hardened: `User 65532:65532` + `GroupAdd <socket gid>` (the agent reads the group of `/var/run/docker.sock`, mounted at the same path), `CapDrop ALL`, `no-new-privileges`, `ReadonlyRootfs`, 256 MiB, 256 processes, only the socket mounted (`:ro`, which does **not** limit the API: documented in the package). Tested with the real mc-router.
- **Router reconciliation** (`router.Manager`): idempotent; with a spec, one container equal to `BuildContainer` and running; without a spec, none (it also cleans up a router left over from an earlier enrollment). It finds it by label **and** name; a foreign container with the same name is not touched (name-in-use error). If the start fails (port busy), it **deletes the container**: Docker 29.7 starts a container without publishing ports when its previous start failed because of the port (checked with `docker start` twice), so retrying with the same one would leave the router “running” and unreachable. After a failure, with the same spec it does not touch Docker again for 25 s (the events from the failed attempt do not loop; the 30 s tick retries); a new spec is applied at once.
- **Protocol and flow.** `RouterApply{spec}`/`RouterRemove{}` save (or delete) the spec in bbolt and reply Ack right away; the container is adjusted in the background and the result arrives through `RouterObserved` (unsolicited, `id = 0`). There is no `deploy_router` job (spec §4): the observed state is enough and does not block the UI while the image downloads. `RouterSpec` goes in the proto with `host_port`, `autoscale` and `autoscale_down_after_minutes`; the panel also stores `enabled`.
- **The panel is the source of truth.** `RouterService` resends the configuration after the handshake of a node **with a row** (`conn.ready`, without touching the handshake) and on save; a node's sends are chained and each one reads the row when it leaves, so the last to arrive is always the current one. Without a row nothing is sent (the existing tests with the fake agent see no new messages). A `RouterObserved` with a router configured on a node with no active row (panel DB restored) causes a `RouterRemove`. Transient failures on save (`disconnected`, `syncing`, `timeout`) do not prevent saving; an agent without support (`unsupported`) is 409.
- **Routes.** `GET`/`PUT /api/nodes/:id/router`. PUT and not POST: the Plan 7 guard blocks `POST /api/nodes/:id/…` on a node with a migration in progress, and configuring the router must not get blocked. Deleting a node with the router enabled is 409 (its container would be left orphaned on that machine); disabled, the row cascades away.
- **Templates.** The hostname belongs to one specific server: `specToTemplate` removes `router`, the template editor does not send it (`TEMPLATE_KEYS`), and the Network tab (where the section lives) does not exist in templates.
- **Web.** Nodes gains the “Router” column (status badge; clicking it opens a dialog with enable, port, autoscale and minutes, the agent error and the socket note). The state arrives live through the `nodes` topic (`router` event). On the server, the “Router (mc-router)” section goes at the end of the Network tab of `SpecForm` (hostname in lowercase as it is typed; disabled and empty goes back to “no section” and does not version).
- **DNS.** Resolving `*.lan` to the node's IP is up to the user (home router, Pi-hole, `/etc/hosts`). The E2E does not depend on DNS: it sends the Minecraft handshake with the hostname against `127.0.0.1:<port>`.

// mc-router per node (spec §4 router_deployments, §5.3 RouterApply/RouterRemove). The agent keeps
// a `mcsm-router` container (itzg/mc-router with -in-docker) on the servers' network, which routes
// by the handshake's hostname to the containers with the mc-router.host label. The panel is the
// source of truth: after each SyncSpecs it resends RouterApply or RouterRemove if it has the node's configuration.

// Router configuration of a node.
message RouterSpec {
  uint32 host_port = 1; // TCP port on the host (1-65535); inside the container it is always 25565
  bool autoscale = 2; // mc-router starts when a player joins and stops after autoscale_down_after_minutes without players
  uint32 autoscale_down_after_minutes = 3; // 1-1440; 0 = 10
}

// Panel → agent. Saves the spec (survives agent restarts) and reconciles the container in
// the background. Reply: Ack (saved; the result arrives via RouterObserved) or Error
// (invalid_request: spec missing or out of range).
message RouterApply {
  RouterSpec spec = 1;
}

// Panel → agent. Deletes the saved spec and, in the background, the router container. Idempotent.
// Reply: Ack, or Error (io_error) if it could not be deleted from the agent's store.
message RouterRemove {}

// Agent → panel, unsolicited (id = 0): router state after each reconciliation (on receiving
// RouterApply/RouterRemove, every 30 s and on its container's Docker events).
message RouterObserved {
  bool configured = 1; // the agent has a saved router spec
  string state = 2; // missing|created|running|restarting|exited|dead|paused
  string container_id = 3;
  string image = 4; // image of the container, e.g. itzg/mc-router:1.47.1
  uint32 host_port = 5; // port of the applied spec (0 without a spec)
  bool autoscale = 6;
  string error = 7; // error of the last reconciliation ("" if it succeeded)
  int64 ts_unix_ms = 8;
}
```

package spec

import (
	"fmt"
	"regexp"
)

// mc-router discovery labels in -in-docker mode (itzg/mc-router). The router routes by the
// handshake hostname to the container IP on the given network, port 25565.
const (
	LabelRouterHost    = "mc-router.host"
	LabelRouterNetwork = "mc-router.network"
	// MaxHostnameLen is the maximum length of a DNS name (RFC 1123).
	MaxHostnameLen = 253
)

// hostnameRe: lowercase DNS name (RFC 1123): labels of 1 to 63 characters [a-z0-9-] that neither
// start nor end with a hyphen, separated by dots, no trailing dot. Same regex as the panel
// (HOSTNAME_RE in panel/packages/shared/src/router.ts; fixture proto/fixtures/router-hostname-cases.json).
var hostnameRe = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$`)

// Router is the player entry by hostname through the node's mc-router (plan-8). nil = absent:
// without labels, the container and the hash do not change.
type Router struct {
	Enabled  bool   `json:"enabled"`
	Hostname string `json:"hostname"`
}

// ValidHostname reports whether h is a valid hostname for mc-router (lowercase, RFC 1123, ≤ 253).
func ValidHostname(h string) bool { return len(h) <= MaxHostnameLen && hostnameRe.MatchString(h) }

// Validate: enabled requires a hostname; a hostname that is present must always be valid.
func (r *Router) Validate() error {
	if r == nil {
		return nil
	}
	if r.Enabled && r.Hostname == "" {
		return fmt.Errorf("spec: router.hostname is required with the router enabled")
	}
	if r.Hostname != "" && !ValidHostname(r.Hostname) {
		return fmt.Errorf("spec: invalid router.hostname %q (lowercase letters, digits, hyphens and dots; max. 253)", r.Hostname)
	}
	return nil
}

// Active reports whether the server is reached through the router (section present and enabled).
func (r *Router) Active() bool { return r != nil && r.Enabled }

// addLabels adds the mc-router labels if the router is active. mc-router.network fixes the network
// through which the router reaches the container, even if someone connects it to another one.
func (r *Router) addLabels(labels map[string]string, networkName string) {
	if !r.Active() {
		return
	}
	labels[LabelRouterHost] = r.Hostname
	labels[LabelRouterNetwork] = networkName
}

// Package router maintains a node's mc-router (plan-8): an itzg/mc-router container with Docker
// discovery (-in-docker) on the servers' network, which publishes a host port and routes each
// connection by the handshake hostname to the container with that mc-router.host label.
//
// Docker socket risk: mc-router needs it to discover the servers (and, with autoscale, to start
// and stop them). Whoever controls that socket controls the host, just like the agent does. What
// the container can do on its own is reduced: pinned image (Tag), non-root user (65532) with only
// the socket's group, CapDrop ALL, no-new-privileges, read-only root filesystem, memory and process
// limits, no mc-router HTTP API and no other mounts. The «:ro» on the mount does NOT limit the Docker
// API (connect() on a socket does not check the mount): it only documents the intent. Truly
// isolating it would require a socket proxy (not included).
package router

import (
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"sort"
	"strconv"

	"github.com/moby/moby/api/types/container"
	"github.com/moby/moby/api/types/network"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/spec"
)

const (
	// ContainerName is the router container's name on a node (the tests use mcsm-test-…).
	ContainerName = "mcsm-router"
	Image         = "itzg/mc-router"
	// Tag pins the mc-router version. Changing it changes the hash: when the agent is updated, the
	// router is recreated with the new image.
	Tag = "1.47.1"
	// LabelRouter marks the router container (in addition to mcsm.managed, so it receives its events).
	LabelRouter = "mcsm.router"
	// LabelHash stores the configuration hash to detect changes without comparing field by field.
	LabelHash = "mcsm.router_hash"
	// ListenPort is mc-router's port inside the container.
	ListenPort = 25565
	// HostSocket is the host's Docker socket: the agent has it mounted at the same path.
	HostSocket = "/var/run/docker.sock"
	// User is the image's non-root user (chainguard static).
	User = "65532:65532"

	DefaultDownAfterMinutes = 10
	MaxDownAfterMinutes     = 1440

	memoryLimit = 256 << 20
	pidsLimit   = 256
	hashSchema  = 1

	asleepMOTD  = "Server asleep: connect to start it"
	loadingMOTD = "Starting the server…"
)

// ImageRef is the router image with its pinned tag.
func ImageRef() string { return Image + ":" + Tag }

// Build is the router container's configuration.
type Build struct {
	Name       string
	Config     *container.Config
	HostConfig *container.HostConfig
	Networking *network.NetworkingConfig
	Hash       string
}

// Validate checks a router spec from the panel.
func Validate(sp *mcsmv1.RouterSpec) error {
	if sp == nil {
		return errors.New("router: missing spec")
	}
	if sp.HostPort < 1 || sp.HostPort > 65535 {
		return fmt.Errorf("router: host port out of range: %d", sp.HostPort)
	}
	if sp.AutoscaleDownAfterMinutes > MaxDownAfterMinutes {
		return fmt.Errorf("router: minutes without players out of range: %d (max. %d)", sp.AutoscaleDownAfterMinutes, MaxDownAfterMinutes)
	}
	return nil
}

// args are mc-router's arguments. Without autoscale, mc-router only routes to containers that are
// running; with autoscale it starts the server when a player joins and stops it after N minutes
// with nobody on it.
func args(sp *mcsmv1.RouterSpec) []string {
	a := []string{"-in-docker", "-port", strconv.Itoa(ListenPort)}
	if sp.Autoscale {
		mins := sp.AutoscaleDownAfterMinutes
		if mins == 0 {
			mins = DefaultDownAfterMinutes
		}
		a = append(a, "-auto-scale-up", "-auto-scale-down", "-auto-scale-down-after", fmt.Sprintf("%dm", mins),
			"-auto-scale-asleep-motd", asleepMOTD, "-auto-scale-loading-motd", loadingMOTD)
	}
	return a
}

// BuildContainer translates the spec into the container's configuration. Pure: same input, same Hash.
// socketGID is the group owning the host's Docker socket (GroupAdd).
func BuildContainer(sp *mcsmv1.RouterSpec, name, networkName string, socketGID uint32) (*Build, error) {
	if err := Validate(sp); err != nil {
		return nil, err
	}
	port := network.MustParsePort(fmt.Sprintf("%d/tcp", ListenPort))
	cfg := &container.Config{
		Image:        ImageRef(),
		Cmd:          args(sp),
		User:         User,
		ExposedPorts: network.PortSet{port: {}},
		Labels:       map[string]string{spec.LabelManaged: "true", LabelRouter: "true"},
	}
	host := &container.HostConfig{
		Binds:          []string{HostSocket + ":" + HostSocket + ":ro"},
		PortBindings:   network.PortMap{port: {{HostPort: strconv.FormatUint(uint64(sp.HostPort), 10)}}},
		RestartPolicy:  container.RestartPolicy{Name: container.RestartPolicyUnlessStopped},
		SecurityOpt:    []string{"no-new-privileges:true"},
		CapDrop:        []string{"ALL"},
		GroupAdd:       []string{strconv.FormatUint(uint64(socketGID), 10)},
		ReadonlyRootfs: true,
	}
	host.Resources.Memory = memoryLimit
	pids := int64(pidsLimit)
	host.Resources.PidsLimit = &pids
	net := &network.NetworkingConfig{EndpointsConfig: map[string]*network.EndpointSettings{networkName: {}}}
	hash, err := hashOf(name, networkName, cfg, host)
	if err != nil {
		return nil, err
	}
	cfg.Labels[LabelHash] = hash
	return &Build{Name: name, Config: cfg, HostConfig: host, Networking: net, Hash: hash}, nil
}

// hashInput is the canonical form of what defines the router container (not moby's JSON, which
// changes between library versions). Everything BuildContainer sets must be here.
type hashInput struct {
	Schema         int               `json:"schema"`
	Name           string            `json:"name"`
	Image          string            `json:"image"`
	Cmd            []string          `json:"cmd"`
	User           string            `json:"user"`
	Labels         map[string]string `json:"labels"`
	Ports          []string          `json:"ports"`
	Binds          []string          `json:"binds"`
	Network        string            `json:"network"`
	Restart        string            `json:"restart"`
	Memory         int64             `json:"memory"`
	PidsLimit      int64             `json:"pidsLimit"`
	SecurityOpt    []string          `json:"securityOpt"`
	CapDrop        []string          `json:"capDrop"`
	GroupAdd       []string          `json:"groupAdd"`
	ReadonlyRootfs bool              `json:"readonlyRootfs"`
}

func hashOf(name, networkName string, cfg *container.Config, host *container.HostConfig) (string, error) {
	in := hashInput{
		Schema: hashSchema, Name: name, Image: cfg.Image, Cmd: append([]string{}, cfg.Cmd...), User: cfg.User,
		Labels: map[string]string{}, Binds: sorted(host.Binds), Network: networkName, Restart: string(host.RestartPolicy.Name),
		Memory: host.Resources.Memory, SecurityOpt: sorted(host.SecurityOpt), CapDrop: sorted(host.CapDrop),
		GroupAdd: sorted(host.GroupAdd), ReadonlyRootfs: host.ReadonlyRootfs,
	}
	for k, v := range cfg.Labels {
		if k != LabelHash {
			in.Labels[k] = v
		}
	}
	for p, binds := range host.PortBindings {
		for _, b := range binds {
			in.Ports = append(in.Ports, p.String()+"->:"+b.HostPort)
		}
	}
	sort.Strings(in.Ports)
	if host.Resources.PidsLimit != nil {
		in.PidsLimit = *host.Resources.PidsLimit
	}
	b, err := json.Marshal(in)
	if err != nil {
		return "", fmt.Errorf("router: compute the hash: %w", err)
	}
	sum := sha256.Sum256(b)
	return hex.EncodeToString(sum[:])[:16], nil
}

func sorted(in []string) []string {
	out := append([]string{}, in...)
	sort.Strings(out)
	return out
}

var (
	bRouter     = []byte("router")
	kRouterSpec = []byte("spec")
)

// RouterSpec returns the stored router spec, or nil if there is none.
func (s *Store) RouterSpec() (*mcsmv1.RouterSpec, error) {
	var out *mcsmv1.RouterSpec
	err := s.db.View(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bRouter)
		if b == nil {
			return nil
		}
		raw := b.Get(kRouterSpec)
		if raw == nil {
			return nil
		}
		sp := &mcsmv1.RouterSpec{}
		if err := proto.Unmarshal(raw, sp); err != nil {
			return err
		}
		out = sp
		return nil
	})
	return out, err
}

// PutRouterSpec stores (or replaces) the router spec.
func (s *Store) PutRouterSpec(sp *mcsmv1.RouterSpec) error {
	if sp == nil {
		return errors.New("store: empty router spec")
	}
	raw, err := proto.Marshal(sp)
	if err != nil {
		return err
	}
	return s.db.Update(func(tx *bbolt.Tx) error {
		b, err := tx.CreateBucketIfNotExists(bRouter)
		if err != nil {
			return err
		}
		return b.Put(kRouterSpec, raw)
	})
}

// DeleteRouterSpec deletes the router spec (idempotent).
func (s *Store) DeleteRouterSpec() error {
	return s.db.Update(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bRouter)
		if b == nil {
			return nil
		}
		return b.Delete(kRouterSpec)
	})
}

package router

import (
	"context"
	"errors"
	"fmt"
	"os"
	"sync"
	"sync/atomic"
	"syscall"
	"time"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/docker"
)

const (
	// stopTimeout is the wait for a clean stop of the router before killing it.
	stopTimeout = 10 * time.Second
	// RetryAfter is the wait after a failure before touching Docker again with the same spec (the
	// events of the failed attempt itself must not turn into a loop of creating and removing).
	RetryAfter = 25 * time.Second // less than the agent's 30 s tick: every tick retries
)

// Store is what the router uses from the agent's store (store.Store satisfies it).
type Store interface {
	RouterSpec() (*mcsmv1.RouterSpec, error)
	PutRouterSpec(*mcsmv1.RouterSpec) error
	DeleteRouterSpec() error
}

// Options configures a Manager. Name and SocketGID have default values.
type Options struct {
	// Name of the container: ContainerName if empty (the tests with real Docker use mcsm-test-…).
	Name    string
	Network string
	// SocketGID returns the group owning the host's Docker socket; by default, that of
	// HostSocket (mounted at the same path in the agent).
	SocketGID func() (uint32, error)
	Now       func() time.Time
}

// Manager reconciles the router container with the stored spec: with a spec, a container equal to
// BuildContainer and running; without a spec, no router container. Reconcile and the other
// operations on Docker are serialized with mu.
type Manager struct {
	eng  docker.Engine
	st   Store
	opts Options

	mu        sync.Mutex
	lastErr   string    // error of the last reconciliation (under mu)
	failedAt  time.Time // when it failed (under mu)
	failedFor string    // specKey of the spec it failed with (under mu)
	// autoscale mirrors the stored spec without taking mu: the server reconciler reads it with its
	// own lock held while Reconcile may be waiting on Docker.
	autoscale atomic.Bool
}

// New creates the manager and loads the autoscale setting from the stored spec (agent restart).
func New(eng docker.Engine, st Store, opts Options) *Manager {
	if opts.Name == "" {
		opts.Name = ContainerName
	}
	if opts.SocketGID == nil {
		opts.SocketGID = hostSocketGID
	}
	if opts.Now == nil {
		opts.Now = time.Now
	}
	m := &Manager{eng: eng, st: st, opts: opts}
	if sp, err := st.RouterSpec(); err == nil && sp != nil {
		m.autoscale.Store(sp.Autoscale)
	}
	return m
}

// hostSocketGID reads the group owning the Docker socket.
func hostSocketGID() (uint32, error) {
	fi, err := os.Stat(HostSocket)
	if err != nil {
		return 0, err
	}
	st, ok := fi.Sys().(*syscall.Stat_t)
	if !ok {
		return 0, errors.New("cannot read the socket owner")
	}
	return st.Gid, nil
}

// Apply validates and stores the spec without touching Docker (Reconcile adjusts the container).
func (m *Manager) Apply(sp *mcsmv1.RouterSpec) error {
	if err := Validate(sp); err != nil {
		return err
	}
	if err := m.st.PutRouterSpec(sp); err != nil {
		return err
	}
	m.autoscale.Store(sp.Autoscale)
	return nil
}

// Clear deletes the stored spec without touching Docker (Reconcile removes the container).
func (m *Manager) Clear() error {
	if err := m.st.DeleteRouterSpec(); err != nil {
		return err
	}
	m.autoscale.Store(false)
	return nil
}

// Autoscale reports whether the stored router starts and stops the servers with a hostname. Does not block.
func (m *Manager) Autoscale() bool { return m.autoscale.Load() }

// specKey identifies a spec for the wait after a failure ("" = no spec).
func specKey(sp *mcsmv1.RouterSpec) string {
	if sp == nil {
		return ""
	}
	return fmt.Sprintf("%d/%t/%d", sp.HostPort, sp.Autoscale, sp.AutoscaleDownAfterMinutes)
}

// Reconcile leaves Docker equal to the stored spec and returns the observed state. Idempotent:
// it recreates the container if it is missing (deleted by hand) or if its hash does not match
// (new spec or image), starts it if it is stopped and, without a spec, removes it. A failure (e.g.
// the host port is busy) is left in RouterObserved.Error; with the same spec it is not retried
// until RetryAfter has passed (a new spec is applied right away).
func (m *Manager) Reconcile(ctx context.Context) *mcsmv1.RouterObserved {
	m.mu.Lock()
	defer m.mu.Unlock()
	sp, err := m.st.RouterSpec()
	if err != nil {
		m.lastErr = fmt.Sprintf("read the router spec: %v", err)
		return m.observeLocked(ctx)
	}
	key := specKey(sp)
	if m.lastErr != "" && key == m.failedFor && m.opts.Now().Before(m.failedAt.Add(RetryAfter)) {
		return m.observeLocked(ctx)
	}
	m.lastErr = ""
	if err := m.reconcileLocked(ctx, sp); err != nil {
		m.lastErr, m.failedAt, m.failedFor = err.Error(), m.opts.Now(), key
	}
	return m.observeLocked(ctx)
}

func (m *Manager) reconcileLocked(ctx context.Context, sp *mcsmv1.RouterSpec) error {
	existing, err := m.find(ctx)
	if err != nil {
		return err
	}
	if sp == nil {
		if existing == nil {
			return nil
		}
		return m.remove(ctx, existing)
	}
	gid, err := m.opts.SocketGID()
	if err != nil {
		return fmt.Errorf("read the group of the Docker socket %s (the router needs it): %w", HostSocket, err)
	}
	b, err := BuildContainer(sp, m.opts.Name, m.opts.Network, gid)
	if err != nil {
		return err
	}
	if existing != nil && existing.Labels[LabelHash] != b.Hash {
		if err := m.remove(ctx, existing); err != nil {
			return err
		}
		existing = nil
	}
	if existing == nil {
		if err := m.eng.EnsureImage(ctx, b.Config.Image); err != nil {
			return fmt.Errorf("download %s: %w", b.Config.Image, err)
		}
		id, err := m.eng.Create(ctx, b.Name, b.Config, b.HostConfig, b.Networking)
		if err != nil {
			return fmt.Errorf("create the container %s: %w", b.Name, err)
		}
		existing = &docker.Container{ID: id, Name: b.Name, State: "created"}
	}
	if existing.State != "running" && existing.State != "restarting" {
		if err := m.eng.Start(ctx, existing.ID); err != nil {
			// Docker (29.x) starts a container WITHOUT publishing ports when its previous start failed
			// because of the host port: it is removed so the retry creates it again and fails again
			// while the port stays busy, instead of being left "running" and unreachable.
			if rerr := m.eng.Remove(ctx, existing.ID); rerr != nil && !errors.Is(rerr, docker.ErrNotFound) {
				return fmt.Errorf("start the router on host port %d: %w (and it could not be removed: %v)", sp.HostPort, err, rerr)
			}
			return fmt.Errorf("start the router on host port %d: %w", sp.HostPort, err)
		}
	}
	return nil
}

// remove stops and deletes the router container.
func (m *Manager) remove(ctx context.Context, c *docker.Container) error {
	if err := m.eng.Stop(ctx, c.ID, stopTimeout); err != nil && !errors.Is(err, docker.ErrNotFound) {
		return fmt.Errorf("stop the router: %w", err)
	}
	if err := m.eng.Remove(ctx, c.ID); err != nil && !errors.Is(err, docker.ErrNotFound) {
		return fmt.Errorf("remove the router: %w", err)
	}
	return nil
}

// handshake is a Minecraft handshake (state 1, status) toward addr:port, as a client sends it:
// mc-router reads it to choose the server by addr.
func handshake(addr string, port uint16) []byte {
	varint := func(b *bytes.Buffer, v int) {
		for {
			c := byte(v & 0x7f)
			v >>= 7
			if v != 0 {
				c |= 0x80
			}
			b.WriteByte(c)
			if v == 0 {
				return
			}
		}
	}
	var body bytes.Buffer
	varint(&body, 0x00) // packet id
	varint(&body, 769)  // protocol (1.21.4)
	varint(&body, len(addr))
	body.WriteString(addr)
	_ = binary.Write(&body, binary.BigEndian, port)
	varint(&body, 1) // next state: status
	var pkt bytes.Buffer
	varint(&pkt, body.Len())
	pkt.Write(body.Bytes())
	return pkt.Bytes()
}

	"context"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"

	"mcsm/agent/internal/router"

// plan-8: the node's mc-router. The spec lives in the store (it survives restarts) and the container
// is reconciled in the background, with the life context: on RouterApply/RouterRemove, when the agent
// starts, every reconcileEvery and with the Docker events of its container. Each pass sends
// RouterObserved (id = 0) over the current session; without a session it is lost and the next one replaces it.

// onDemand reports whether a server is started and stopped by mc-router (the router's autoscale and a hostname).
// The reconciler calls it with the server's lock held: it only reads an atomic value from the router.
func (a *App) onDemand(s spec.Spec) bool { return s.Router.Active() && a.router.Autoscale() }

// handleRouterApply stores the router spec and replies; the container is adjusted in the background.
func (a *App) handleRouterApply(id uint64, req *mcsmv1.RouterApply, send func(*mcsmv1.Envelope) error) {
	before := a.router.Autoscale()
	if err := a.router.Apply(req.GetSpec()); err != nil {
		_ = send(errMsg(id, errcode.InvalidRequest, err))
		return
	}
	_ = send(ack(id))
	a.routerAsync(a.life)
	if a.router.Autoscale() != before {
		a.reconcileAll(a.life) // changes which servers are on-demand
	}
}

// handleRouterRemove deletes the router spec and replies; the container is removed in the background.
func (a *App) handleRouterRemove(id uint64, send func(*mcsmv1.Envelope) error) {
	before := a.router.Autoscale()
	if err := a.router.Clear(); err != nil {
		_ = send(errMsg(id, errcode.IOError, err))
		return
	}
	_ = send(ack(id))
	a.routerAsync(a.life)
	if before {
		a.reconcileAll(a.life) // the on-demand servers go back to their desired state
	}
}

// routerAsync reconciles the router without blocking (coalesced with the dispatcher) and publishes its state.
func (a *App) routerAsync(ctx context.Context) {
	a.dispatch(ctx, "router", func() {
		obs := a.router.Reconcile(ctx)
		_ = a.send(&mcsmv1.Envelope{Body: &mcsmv1.Envelope_RouterObserved{RouterObserved: obs}})
	})
}

// routerLoop reconciles the router when the agent starts (agent restart: it recreates it if missing)
// and every reconcileEvery (removed by hand, port freed).
func (a *App) routerLoop(ctx context.Context) {
	a.routerAsync(ctx)
	t := time.NewTicker(reconcileEvery)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			a.routerAsync(ctx)
		}
	}
}

// routerEvent reacts to a Docker event of the router's container.
func (a *App) routerEvent(ctx context.Context, action string) {
	switch action {
	case "start", "die", "stop", "kill", "destroy", "oom", "restart":
		a.routerAsync(ctx)
	}
}

// isRouterEvent reports whether the event belongs to the router's container.
func isRouterEvent(labels map[string]string) bool { return labels[router.LabelRouter] == "true" }

import { z } from "zod";

/**
 * Hostname of a server in its node's mc-router: lowercase DNS name (RFC 1123), labels of 1 to 63
 * characters [a-z0-9-] that neither start nor end with a hyphen, separated by dots, no trailing dot,
 * max. 253. Same regex as the agent (hostnameRe in agent/internal/spec/router.go; fixture
 * proto/fixtures/router-hostname-cases.json).
 */
export const HOSTNAME_RE = /^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$/;
export const MAX_HOSTNAME_LEN = 253;

export function validHostname(h: string): boolean {
  return h.length <= MAX_HOSTNAME_LEN && HOSTNAME_RE.test(h);
}

/** Message for an invalid hostname; null if it is valid (empty = no hostname, the schema decides). */
export function hostnameError(h: string): string | null {
  if (h === "" || validHostname(h)) return null;
  if (h !== h.toLowerCase()) return "The hostname must be lowercase";
  if (h.length > MAX_HOSTNAME_LEN) return `The hostname cannot exceed ${MAX_HOSTNAME_LEN} characters`;
  return "Invalid hostname: lowercase letters, digits, hyphens and dots (e.g. survival.lan)";
}

/**
 * `router` section of a server's spec (plan-8): enter through `hostname` via the node's mc-router.
 * Enabled requires a hostname. The agent adds the `mc-router.host`/`mc-router.network` labels
 * to the container (enabling, disabling or changing the hostname recreates the container).
 */
export const serverRouterSchema = z
  .object({
    enabled: z.boolean().default(false),
    hostname: z.string().default("").superRefine((h, ctx) => {
      const msg = hostnameError(h);
      if (msg) ctx.addIssue({ code: "custom", message: msg });
    }),
  })
  .refine((r) => !r.enabled || r.hostname !== "", { message: "Enter the hostname to connect through the router", path: ["hostname"] });
export type ServerRouter = z.infer<typeof serverRouterSchema>;

export const ROUTER_DEFAULT_PORT = 25565;
export const ROUTER_DEFAULT_DOWN_AFTER_MINUTES = 10;
export const ROUTER_MAX_DOWN_AFTER_MINUTES = 1440;

/** Configuration of a node's mc-router (`router_deployments.spec`). */
export const routerDeploymentSpecSchema = z.object({
  enabled: z.boolean().default(false),
  port: z.number().int().min(1).max(65535).default(ROUTER_DEFAULT_PORT),
  autoscale: z.boolean().default(false),
  autoscaleDownAfterMinutes: z.number().int().min(1).max(ROUTER_MAX_DOWN_AFTER_MINUTES).default(ROUTER_DEFAULT_DOWN_AFTER_MINUTES),
});
export type RouterDeploymentSpec = z.infer<typeof routerDeploymentSpecSchema>;

export function defaultRouterDeploymentSpec(): RouterDeploymentSpec {
  return routerDeploymentSpecSchema.parse({});
}

/** Last RouterObserved from the agent (proto `RouterObserved`, without the ts). */
export interface RouterObservedDto {
  configured: boolean; state: string; containerId: string; image: string; hostPort: number; autoscale: boolean; error: string;
}

/** A node's router as served by `GET/PUT /api/nodes/:id/router` and the `router` WS event. */
export interface RouterDto {
  nodeId: string; spec: RouterDeploymentSpec; observed: RouterObservedDto | null; observedAt: string | null; updatedAt: string | null;
}

import { defaultRouterDeploymentSpec, routerDeploymentSpecSchema, type RouterDeploymentSpec, type RouterDto, type RouterObservedDto } from "@mcsm/shared";
import type { Db } from "../db/db.js";
import { nowIso } from "../lib/time.js";

export interface RouterRow {
  node_id: string; spec: string; observed: string | null; observed_at: string | null; updated_at: string | null;
}

/** Spec stored in the row (the default one, disabled, if there is no row). */
export function rowSpec(r: RouterRow | null): RouterDeploymentSpec {
  return r ? routerDeploymentSpecSchema.parse(JSON.parse(r.spec)) : defaultRouterDeploymentSpec();
}

export function toRouterDto(nodeId: string, r: RouterRow | null): RouterDto {
  return {
    nodeId, spec: rowSpec(r),
    observed: r?.observed ? (JSON.parse(r.observed) as RouterObservedDto) : null,
    observedAt: r?.observed_at ?? null, updatedAt: r?.updated_at ?? null,
  };
}

export class RouterRepo {
  constructor(private db: Db) {}

  get(nodeId: string): RouterRow | null {
    return (this.db.prepare("SELECT * FROM router_deployments WHERE node_id = ?").get(nodeId) as RouterRow | undefined) ?? null;
  }

  /** Stores the user's configuration (creates the row if it does not exist). */
  upsertSpec(nodeId: string, spec: RouterDeploymentSpec): RouterRow {
    this.db.prepare(`INSERT INTO router_deployments (node_id, spec, updated_at) VALUES (?, ?, ?)
      ON CONFLICT(node_id) DO UPDATE SET spec = excluded.spec, updated_at = excluded.updated_at`)
      .run(nodeId, JSON.stringify(spec), nowIso());
    return this.get(nodeId)!;
  }

  /** Stores the last observed state (creates the row, disabled, if it does not exist). */
  setObserved(nodeId: string, observed: RouterObservedDto): RouterRow {
    this.db.prepare(`INSERT INTO router_deployments (node_id, spec, observed, observed_at) VALUES (?, ?, ?, ?)
      ON CONFLICT(node_id) DO UPDATE SET observed = excluded.observed, observed_at = excluded.observed_at`)
      .run(nodeId, JSON.stringify(defaultRouterDeploymentSpec()), JSON.stringify(observed), nowIso());
    return this.get(nodeId)!;
  }
}

/** Server in the list that publishes `port` on the host (game or extra port), if any. Pure. */
export function portOwner(rows: readonly ServerRow[], port: number): ServerRow | null {
  for (const r of rows) {
    const s = JSON.parse(r.spec) as Spec;
    if (s.ports.game === port || s.ports.extra.some((e) => e.host === port)) return r;
  }
  return null;
}

/** Server in the list (other than `selfId`) with the router active and that hostname, if any. Pure. */
export function hostnameOwner(rows: readonly ServerRow[], hostname: string, selfId?: string): ServerRow | null {
  for (const r of rows) {
    if (r.id === selfId) continue;
    const router = (JSON.parse(r.spec) as Spec).router;
    if (router?.enabled && router.hostname === hostname) return r;
  }
  return null;
}

import type { FastifyInstance } from "fastify";
import type { RouterObserved } from "@mcsm/proto";
import { formatZodError, routerDeploymentSpecSchema, type RouterDto, type RouterObservedDto, type Spec } from "@mcsm/shared";
import { AgentError, type Body } from "../agents/hub.js";
import { AgentErrorCode } from "../agents/error-codes.js";
import { HttpError, agentErrorToHttp } from "../lib/http.js";
import { hostnameOwner, portOwner } from "./checks.js";
import { RouterRepo, rowSpec, toRouterDto } from "./repo.js";

/** Send failures that do not prevent saving: the configuration arrives in the next handshake. */
const TRANSIENT = new Set<string>([AgentErrorCode.Disconnected, AgentErrorCode.Syncing, AgentErrorCode.Timeout]);

export function observedToDto(o: RouterObserved): RouterObservedDto {
  return {
    configured: o.configured, state: o.state || "missing", containerId: o.containerId, image: o.image,
    hostPort: o.hostPort, autoscale: o.autoscale, error: o.error,
  };
}

/**
 * Each node's mc-router (spec §7 RouterService). The `router_deployments` row is the source of truth:
 * after the handshake of a node with a row, it is sent again (RouterApply if active, RouterRemove if not)
 * and each change by the user is sent right away if the node is connected. A node's sends run in a chain
 * and each one reads the row when it leaves, so the last one to reach the agent is always the current one.
 */
export class RouterService {
  private chains = new Map<string, Promise<void>>();

  constructor(private app: FastifyInstance, private repo: RouterRepo) {}

  start() {
    this.app.agents.on("attached", (nodeId: string) => {
      const conn = this.app.agents.get(nodeId);
      // After the SyncSpecs Ack (conn.ready): nothing goes to the agent before it.
      conn?.ready.then(() => {
        if (this.repo.get(nodeId)) this.push(nodeId).catch((e) => this.app.log.warn({ nodeId, err: e }, "could not send the router to the agent"));
      }, () => { /* disconnected before syncing: the next handshake sends it again */ });
    });
  }

  private requireNode(nodeId: string) {
    if (!this.app.nodes.get(nodeId)) throw new HttpError(404, "Node not found");
  }

  get(nodeId: string): RouterDto {
    this.requireNode(nodeId);
    return toRouterDto(nodeId, this.repo.get(nodeId));
  }

  /** Is the node's router active? */
  isEnabled(nodeId: string): boolean {
    return rowSpec(this.repo.get(nodeId)).enabled;
  }

  /** Host port occupied by the node's active router; null if it is not active. */
  reservedPort(nodeId: string): number | null {
    const spec = rowSpec(this.repo.get(nodeId));
    return spec.enabled ? spec.port : null;
  }

  /** 409 if the hostname of the router in `spec` is already used by another server on the node (with the router active). */
  checkHostname(nodeId: string, spec: Spec, selfId?: string) {
    if (!spec.router?.enabled) return;
    const owner = hostnameOwner(this.app.servers.list(nodeId), spec.router.hostname, selfId);
    if (owner) throw new HttpError(409, `The hostname “${spec.router.hostname}” is already used by server “${owner.name}” on this node`);
  }

  async put(nodeId: string, input: unknown): Promise<RouterDto> {
    this.requireNode(nodeId);
    const parsed = routerDeploymentSpecSchema.safeParse(input ?? {});
    if (!parsed.success) throw new HttpError(400, formatZodError(parsed.error));
    const spec = parsed.data;
    if (spec.enabled) {
      const owner = portOwner(this.app.servers.list(nodeId), spec.port);
      if (owner) {
        throw new HttpError(409, `Port ${spec.port} is used by server “${owner.name}” on this node: choose another port for the router or change the server's port`);
      }
    }
    const row = this.repo.upsertSpec(nodeId, spec);
    this.app.events.emit("router", nodeId, toRouterDto(nodeId, row));
    try {
      await this.push(nodeId);
    } catch (e) {
      if (!(e instanceof AgentError && TRANSIENT.has(e.code))) throw agentErrorToHttp(e, "The agent could not apply the router");
    }
    return toRouterDto(nodeId, this.repo.get(nodeId));
  }

  /** Sends the node's current configuration to the agent (if it is connected). Serialized per node. */
  push(nodeId: string): Promise<void> {
    const prev = this.chains.get(nodeId) ?? Promise.resolve();
    const next = prev.catch(() => {}).then(async () => {
      const conn = this.app.agents.get(nodeId);
      if (!conn) return;
      const spec = rowSpec(this.repo.get(nodeId));
      const body: Body = spec.enabled
        ? { case: "routerApply", value: { spec: { hostPort: spec.port, autoscale: spec.autoscale, autoscaleDownAfterMinutes: spec.autoscaleDownAfterMinutes } } }
        : { case: "routerRemove", value: {} };
      await conn.request(body, 30_000);
    });
    this.chains.set(nodeId, next);
    next.then(() => this.release(nodeId, next), () => this.release(nodeId, next));
    return next;
  }

  private release(nodeId: string, p: Promise<void>) {
    if (this.chains.get(nodeId) === p) this.chains.delete(nodeId);
  }

  /** RouterObserved from the agent (unsolicited). */
  onObserved(nodeId: string, o: RouterObserved) {
    if (!this.app.nodes.get(nodeId)) return;
    const dto = observedToDto(o);
    const before = this.repo.get(nodeId);
    if (!before && !dto.configured) return; // node without a router: nothing to store
    const row = this.repo.setObserved(nodeId, dto);
    // A router the panel does not want (e.g. after restoring the panel's DB) is removed.
    if (dto.configured && !rowSpec(row).enabled) {
      this.push(nodeId).catch((e) => this.app.log.warn({ nodeId, err: e }, "could not remove the router from the agent"));
    }
    if (before?.observed !== row.observed) this.app.events.emit("router", nodeId, toRouterDto(nodeId, row));
  }
}

import type { QueryClient } from "@tanstack/react-query";
import { ROUTER_DEFAULT_DOWN_AFTER_MINUTES, ROUTER_MAX_DOWN_AFTER_MINUTES, type RouterDeploymentSpec, type RouterDto } from "@mcsm/shared";
import type { ServerMessage } from "./api";
import { mergeIntoCached } from "./live";

export const routerKey = (nodeId: string) => ["router", nodeId] as const;

export type RouterTone = "ok" | "warn" | "bad" | "muted";
export interface RouterStatus { label: string; tone: RouterTone; detail: string | null }

/** Readable state of a node's router from what is stored and the last thing the agent reported. Pure. */
export function routerStatus(r: RouterDto, nodeOnline: boolean): RouterStatus {
  const o = r.observed;
  if (!r.spec.enabled) {
    if (o?.configured && o.state !== "missing" && nodeOnline) return { label: "Removing…", tone: "warn", detail: null };
    return { label: "Disabled", tone: "muted", detail: null };
  }
  if (!nodeOnline) return { label: "Node offline", tone: "warn", detail: "It will be applied when the node comes back online" };
  if (o?.error) return { label: "Error", tone: "bad", detail: o.error };
  if (!o || !o.configured || o.hostPort !== r.spec.port || o.autoscale !== r.spec.autoscale) return { label: "Applying…", tone: "warn", detail: null };
  if (o.state === "running") return { label: `Active on :${r.spec.port}`, tone: "ok", detail: null };
  return { label: `State: ${o.state}`, tone: "warn", detail: null };
}

/** State of the router form (numbers as text, as they are typed). */
export interface RouterForm { enabled: boolean; port: string; autoscale: boolean; minutes: string }

export function routerFormFrom(spec: RouterDeploymentSpec): RouterForm {
  return { enabled: spec.enabled, port: String(spec.port), autoscale: spec.autoscale, minutes: String(spec.autoscaleDownAfterMinutes) };
}

const intIn = (text: string, min: number, max: number): number | null => {
  const t = text.trim();
  if (!/^[0-9]+$/.test(t)) return null;
  const n = Number(t);
  return n >= min && n <= max ? n : null;
};

/** Field errors of the form (same rules as the API). Empty = it can be saved. */
export function routerFormErrors(f: RouterForm): { port?: string; minutes?: string } {
  const out: { port?: string; minutes?: string } = {};
  if (intIn(f.port, 1, 65535) === null) out.port = "Port: a number between 1 and 65535";
  if (f.autoscale && intIn(f.minutes, 1, ROUTER_MAX_DOWN_AFTER_MINUTES) === null) out.minutes = `Minutes: a number between 1 and ${ROUTER_MAX_DOWN_AFTER_MINUTES}`;
  return out;
}

/** Body of the PUT. Without autoscale, invalid minutes fall back to the default value. */
export function routerFormBody(f: RouterForm): RouterDeploymentSpec {
  return {
    enabled: f.enabled, port: intIn(f.port, 1, 65535) ?? 0, autoscale: f.autoscale,
    autoscaleDownAfterMinutes: intIn(f.minutes, 1, ROUTER_MAX_DOWN_AFTER_MINUTES) ?? ROUTER_DEFAULT_DOWN_AFTER_MINUTES,
  };
}

type RouterMsg = Extract<ServerMessage, { type: "router" }>;

export function applyRouterEvent(qc: QueryClient, msg: RouterMsg): void {
  mergeIntoCached<RouterDto>(qc, routerKey(msg.nodeId), () => msg.router);
}

/** Subset of `Realtime` used here (makes the tests easier). */
export interface RouterLiveSource {
  subscribe(topic: string, handler: (msg: ServerMessage) => void): () => void;
  onReconnect(cb: () => void): () => void;
}

/** Keeps ["router", nodeId] up to date with the `nodes` topic. Returns the cleanup function. */
export function bindRouterLive(qc: QueryClient, live: RouterLiveSource, nodeId: string): () => void {
  const offs = [
    live.subscribe("nodes", (m) => { if (m.type === "router" && m.nodeId === nodeId) applyRouterEvent(qc, m); }),
    live.onReconnect(() => { void qc.invalidateQueries({ queryKey: routerKey(nodeId) }); }),
  ];
  return () => offs.forEach((off) => off());
}

import { useEffect } from "react";

import type { RouterDeploymentSpec, RouterDto } from "@mcsm/shared";

/** A node's router (mc-router): via REST first, then live over the WS (`router` event). */
export function useNodeRouter(nodeId: string) {
  const qc = useQueryClient();
  useEffect(() => bindRouterLive(qc, realtime, nodeId), [qc, nodeId]);

#!/usr/bin/env node
// Minecraft Server List Ping with whatever hostname is wanted in the handshake (what mc-router reads),
// without depending on DNS. Prints {"motd","version","players"} on one line.
//   node deploy/e2e/mc-status.mjs <ip> <port> <hostname>           status (next state 1)
//   node deploy/e2e/mc-status.mjs <ip> <port> <hostname> --login   login attempt (next
//     state 2 + Login Start): with mc-router's autoscale, it wakes up a sleeping server.
import net from "node:net";

const [ip = "127.0.0.1", portArg = "25565", host = ip, flag] = process.argv.slice(2);
const port = Number(portArg);
const login = flag === "--login";

const varint = (n) => {
  const out = [];
  do {
    let b = n & 0x7f;
    n >>>= 7;
    if (n) b |= 0x80;
    out.push(b);
  } while (n);
  return Buffer.from(out);
};
const str = (s) => {
  const b = Buffer.from(s, "utf8");
  return Buffer.concat([varint(b.length), b]);
};
const packet = (...parts) => {
  const body = Buffer.concat(parts);
  return Buffer.concat([varint(body.length), body]);
};
const u16 = Buffer.alloc(2);
u16.writeUInt16BE(port);
const handshake = packet(varint(0x00), varint(769), str(host), u16, varint(login ? 2 : 1));
// Login Start (1.21.4): name + UUID (16 bytes).
const second = login ? packet(varint(0x00), str("e2e"), Buffer.alloc(16)) : packet(varint(0x00));

function readVarint(buf, off) {
  let n = 0;
  for (let shift = 0; shift <= 28; shift += 7) {
    if (off >= buf.length) return null;
    const b = buf[off++];
    n |= (b & 0x7f) << shift;
    if (!(b & 0x80)) return [n, off];
  }
  throw new Error("varint too long");
}

const sock = net.connect({ host: ip, port });
sock.setTimeout(10_000, () => {
  // When a server wakes up, mc-router holds the connection until it starts: the attempt already counts.
  if (login) { console.log(JSON.stringify({ login: true, bytes: acc.length })); process.exit(0); }
  console.error("no response in 10 s");
  process.exit(2);
});
let acc = Buffer.alloc(0);
sock.on("connect", () => sock.write(Buffer.concat([handshake, second])));
sock.on("data", (d) => {
  acc = Buffer.concat([acc, d]);
  if (login) return; // any response is enough: it is printed on close
  const head = readVarint(acc, 0);
  if (!head || acc.length < head[1] + head[0]) return;
  const body = acc.subarray(head[1], head[1] + head[0]);
  const [, afterId] = readVarint(body, 0);
  const [len, start] = readVarint(body, afterId);
  const json = JSON.parse(body.subarray(start, start + len).toString("utf8"));
  const desc = json.description;
  const motd = typeof desc === "string" ? desc : (desc?.text ?? "") + (desc?.extra ?? []).map((e) => e?.text ?? "").join("");
  console.log(JSON.stringify({ motd, version: json.version?.name ?? "", players: json.players?.online ?? 0 }));
  sock.end();
  process.exit(0);
});
sock.on("error", (e) => { console.error(e.message); process.exit(1); });
sock.on("close", () => {
  if (login) { console.log(JSON.stringify({ login: true, bytes: acc.length })); process.exit(0); }
  console.error("connection closed without a status response");
  process.exit(1);
});
```
