# MC Server Manager — Plan 2: Metrics

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The agent sends a `MetricBatch` every 10 s with the host usage (CPU, RAM, disk of `DATA_ROOT`) and of each running server (CPU, memory, network, players, ping and TPS on Paper/Purpur); the panel stores it for 7 days in `metric_samples`, serves it aggregated on the fly (`GET /api/servers/:id/metrics`, `GET /api/nodes/:id/metrics`), and the web shows 1 h / 24 h / 7 day charts in the server Overview and live usage on the node cards.

**Architecture:** In the agent, a new package `internal/stats` with a `Sampler` that on each tick (second 5 of each 10 s window) reads one-shot `docker stats` of the running containers, computes the CPU % against the previous reading, performs the Server List Ping and, every 30 s, requests `tps` through a persistent RCON session on Paper/Purpur; the host is read with gopsutil. In the panel, `MetricsService` (idempotent transactional ingest keyed by `(scope, scope_id, ts)`, hourly purge to 7 days, aggregation in 10 s / 1 min / 5 min buckets at query time) and a `node_metrics` event that the browser WS forwards on the topic `nodes`. In the web, uPlot for the charts.

**Tech Stack:** Go 1.27.2, `github.com/moby/moby/client` v0.6.2 (`ContainerStats` one-shot), `github.com/shirou/gopsutil/v4` v4.26.9 (already in `go.mod`); Node 26, Fastify 5, `node:sqlite`, zod 4, `@bufbuild/protobuf` 2.16; React 19, TanStack Query 5, **uPlot 1.6.32**; buf 1.73.

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` — §4 `metric_samples`, §6.4, §7 (`MetricsService`, WS), §8 (Overview charts and node cards). Scope and acceptance: `docs/superpowers/plans/README.md` (Plan 2). Merge rules: `docs/superpowers/plans/COORDINATION.md`.

## Review Focus

1. **Size of the table with resends and purge** (agent reconnection that repeats a window, two batches in the same slot, purge that never gets to run) → at most one row per server and 10 s window and never more than 60 480 + 360 rows per server/week (acceptance: ≤ ~70k). Tests: Task 7 (primary key `(scope, scope_id, ts)` with `INSERT OR REPLACE`) and Task 8 (8 simulated days with duplicates and hourly purge).
2. **Node clock out of sync or delayed tick** → a node with the wrong time must not leave its points out of the chart nor collide windows: the agent samples mid-window (second 5) and rounds to 10 s; the panel uses its own time if the agent's `ts` differs by more than 30 s. Tests: Task 4 (`NextTick`/`RoundTS` with delays of up to 3.6 s) and Task 8 (batch with +1 h and with `ts = 0`).
3. **On-the-fly aggregation wrong or slow** → `node:sqlite` binds numbers as REAL and `ts / 60` would stop grouping; buckets without data (server stopped) must be `null`, not 0 nor a line joining two periods; the query must go through the primary key. Tests: Task 7 (`ts` not a multiple of the bucket, filling with `null`, `EXPLAIN QUERY PLAN` with `USING PRIMARY KEY`).
4. **First reading and reset counters** (freshly started agent, restarted container: the accumulated CPU goes back to 0) → never an absurd spike from a `uint64` overflow nor a false 0: that window is skipped. Tests: Task 4 (`ContainerCPUPercent` with counters that go down) and Task 5 (`TestSampleSkipsStoppedUnlabeledAndResetCounters`).
5. **Sampling cost** (`docker stats` without `one-shot` waits 1 s per container; a hung server that does not answer the ping) → `docker stats` with `stream=false&one-shot=true` (< 1 s) and ping/TPS in parallel with a 4 s cap per server: a hung server does not delay the others. Tests: Task 2 (integration: `Stats` in < 900 ms) and Task 5 (`TestHungServerDoesNotBlockOthers`).
6. **TPS over RCON only on Paper/Purpur** → `tps` is never sent to Vanilla/Fabric/Forge (they answer "Unknown command"); it is requested every 30 s over a **persistent RCON session** (each new connection writes "Thread RCON Client … started/shutting down" to the console), it is closed when the server stops or the password changes, it reconnects after an error, and a value older than 45 s is not sent. Tests: Task 3 (one connection for several commands, `ParseTPS` of Paper/Purpur with § codes) and Task 5 (three TPS tests) and Task 13 (real console).

## Decisions (conscious deviations from the spec)

- `metric_samples` has no UUID `id` (§4 says every table has one): the composite primary key `(scope, scope_id, ts)` `WITHOUT ROWID` **is** the index the spec asks for, makes ingestion idempotent and saves ~40 bytes per row across ~600k rows.
- Extra column `disk_total_bytes` (node only) to draw "used / total" without touching `nodes.host_info` or the Plan 1 `Hello`.
- §5.3/§6.4 speak of a grouped `MetricSample{...}`: the message is `MetricBatch` (roadmap name) with `HostMetricSample` and `ServerMetricSample`.
- §7 mentions the topic `node:<id>:metrics`: the existing topic `nodes` is used with the type `node_metrics` (it does not extend the topics regex, which Plan 4 also touches). The server charts are reloaded over REST at the pace of their bucket (10 s / 1 min / 5 min).
- The sampler does its own Server List Ping (cheap and does not show up in the server log) instead of reusing the one from the observation loop: this way it does not touch `onObserved` nor the `App` struct of Plan 1.
- The first reading of each container and of the host is not sent (there is no base for the CPU %): the first point appears 10–20 s after starting.
- Network (`net_rx_bytes`/`net_tx_bytes`): cumulative Docker counters; they are stored and aggregated (bucket maximum) but this plan does not draw them.
- Per bucket: CPU, memory, TPS and ping with average; players with maximum (bucket peak), limits with maximum.
- If the panel is not connected, the batch is discarded: the agent does not accumulate metrics.

// ── plan-2 ──

// MetricBatch groups the metrics of one sampling cycle (every 10 s, spec §6.4).
// Agent → panel, unsolicited (Envelope.id = 0). Only carries servers whose container is running.
message MetricBatch {
  // Epoch in seconds, rounded down to a multiple of 10.
  int64 ts_unix = 1;
  // Absent until there are two host CPU readings.
  HostMetricSample host = 2;
  repeated ServerMetricSample servers = 3;
}

message HostMetricSample {
  // 0–100 across all the host CPUs.
  double cpu_pct = 1;
  // Total minus available.
  uint64 mem_used_bytes = 2;
  uint64 mem_total_bytes = 3;
  // Filesystem containing DATA_ROOT.
  uint64 disk_used_bytes = 4;
  uint64 disk_total_bytes = 5;
}

message ServerMetricSample {
  string server_id = 1;
  // 100 = one full core (same criterion as `docker stats`).
  double cpu_pct = 2;
  // Usage without the inactive page cache.
  uint64 mem_bytes = 3;
  uint64 mem_limit_bytes = 4;
  // Cumulative since the container started (all interfaces).
  uint64 net_rx_bytes = 5;
  uint64 net_tx_bytes = 6;
  // The Server List Ping answered; if false, players_* and ping_ms mean nothing.
  bool mc_online = 7;
  uint32 players_online = 8;
  uint32 players_max = 9;
  uint32 ping_ms = 10;
  // PAPER/PURPUR only: TPS of the last minute, measured in the last 45 s.
  optional double tps = 11;
}
```

	"context"
	"encoding/json"

	"github.com/moby/moby/api/types/container"
	"github.com/moby/moby/client"
)

// Stats requests a single sample (`stream=false&one-shot=true`): it responds immediately,
// without the one-second wait Docker needs to fill precpu_stats.
func (m *Moby) Stats(ctx context.Context, id string) (Stats, error) {
	res, err := m.cli.ContainerStats(ctx, id, client.ContainerStatsOptions{Stream: false, IncludePreviousSample: false})
	if err != nil {
		return Stats{}, notFound(err)
	}
	defer res.Body.Close()
	var s container.StatsResponse
	if err := json.NewDecoder(res.Body).Decode(&s); err != nil {
		return Stats{}, fmt.Errorf("docker: decode stats: %w", err)
	}
	return statsFrom(&s), nil
}

// statsFrom reduces Docker's response to what the sampler uses.
func statsFrom(s *container.StatsResponse) Stats {
	out := Stats{
		Read:        s.Read,
		CPUTotalNs:  s.CPUStats.CPUUsage.TotalUsage,
		SystemCPUNs: s.CPUStats.SystemUsage,
		OnlineCPUs:  s.CPUStats.OnlineCPUs,
		MemBytes:    memWithoutCache(s.MemoryStats),
		MemLimit:    s.MemoryStats.Limit,
	}
	if out.OnlineCPUs == 0 {
		out.OnlineCPUs = uint32(len(s.CPUStats.CPUUsage.PercpuUsage))
	}
	for _, n := range s.Networks {
		out.NetRxBytes += n.RxBytes
		out.NetTxBytes += n.TxBytes
	}
	return out
}

// memWithoutCache replicates the Docker CLI calculation: usage minus the inactive
// page cache (cgroup v1: total_inactive_file; cgroup v2: inactive_file).
func memWithoutCache(m container.MemoryStats) uint64 {
	if v, ok := m.Stats["total_inactive_file"]; ok && v < m.Usage {
		return m.Usage - v
	}
	if v := m.Stats["inactive_file"]; v < m.Usage {
		return m.Usage - v
	}
	return m.Usage
}

package mc

import (
	"context"
	"errors"
	"fmt"
	"net"
	"strconv"
	"time"
)

// Packet types of the Source RCON protocol.
const (
	typeCommandResp = 0
	typeCommand     = 2
	typeAuthResp    = 2
	typeAuth        = 3
)

// RconConn is an authenticated RCON session that supports several commands in a row over
// the same TCP connection. It serves periodic polls (TPS) without opening a connection
// per command: each new connection writes "Thread RCON Client … started/shutting
// down" to the server console.
//
// It is not safe for concurrent use. After any error it is closed and another one must
// be opened with DialRcon.
type RconConn struct {
	conn   net.Conn
	nextID int32
	closed bool
}

// DialRcon opens an RCON connection and authenticates.
func DialRcon(ctx context.Context, host string, port uint16, password string) (*RconConn, error) {
	d := net.Dialer{Timeout: rconTimeout}
	conn, err := d.DialContext(ctx, "tcp", net.JoinHostPort(host, strconv.Itoa(int(port))))
	if err != nil {
		return nil, fmt.Errorf("rcon: connect: %w", err)
	}
	c := &RconConn{conn: conn, nextID: 1}
	if err := c.login(ctx, password); err != nil {
		c.Close()
		return nil, err
	}
	return c, nil
}

// arm sets the deadline of an operation (rconTimeout or the ctx deadline if it is earlier) and
// closes the connection if ctx is cancelled meanwhile. It returns the function that disarms
// that cancellation.
func (c *RconConn) arm(ctx context.Context) func() bool {
	deadline := time.Now().Add(rconTimeout)
	if dl, ok := ctx.Deadline(); ok && dl.Before(deadline) {
		deadline = dl
	}
	_ = c.conn.SetDeadline(deadline)
	return context.AfterFunc(ctx, func() { _ = c.conn.Close() })
}

func (c *RconConn) next() int32 {
	id := c.nextID
	c.nextID++
	if c.nextID <= 0 { // -1 means "wrong password": we never use it as an id
		c.nextID = 1
	}
	return id
}

func (c *RconConn) login(ctx context.Context, password string) error {
	stop := c.arm(ctx)
	defer stop()
	if err := writePacket(c.conn, c.next(), typeAuth, password); err != nil {
		return fmt.Errorf("rcon: login: %w", err)
	}
	for { // the server may first send an empty response packet
		id, typ, _, err := readPacket(c.conn)
		if err != nil {
			return fmt.Errorf("rcon: login: %w", err)
		}
		if typ != typeAuthResp {
			continue
		}
		if id == -1 {
			return errors.New("rcon: login: wrong password")
		}
		return nil
	}
}

// Command runs a command and returns its output. If it fails, the session is closed.
func (c *RconConn) Command(ctx context.Context, command string) (string, error) {
	if c.closed {
		return "", errors.New("rcon: session closed")
	}
	stop := c.arm(ctx)
	defer stop()
	id := c.next()
	if err := writePacket(c.conn, id, typeCommand, command); err != nil {
		c.Close()
		return "", fmt.Errorf("rcon: run: %w", err)
	}
	for {
		rid, typ, body, err := readPacket(c.conn)
		if err != nil {
			c.Close()
			return "", fmt.Errorf("rcon: run: %w", err)
		}
		if typ == typeCommandResp && rid == id {
			return body, nil
		}
	}
}

// Close closes the connection. It is idempotent.
func (c *RconConn) Close() error {
	if c.closed {
		return nil
	}
	c.closed = true
	return c.conn.Close()
}

package mc

import (
	"math"
	"regexp"
	"strconv"
	"strings"

var (
	// colorCode are the legacy formatting codes (§a, §l, §x…) that Paper leaves in the
	// output of the commands over RCON.
	colorCode = regexp.MustCompile(`§[0-9a-fk-orxA-FK-ORX]`)
	tpsLine   = regexp.MustCompile(`(?i)TPS from last ([^:\n]+):([^\n]*)`)
	number    = regexp.MustCompile(`^\*?\s*([0-9]+(?:\.[0-9]+)?)`)
)

// ParseTPS extracts the TPS of the last minute from the output of the `tps` command of Paper
// ("TPS from last 1m, 5m, 15m: 20.0, 20.0, 20.0") or Purpur (which adds "5s" in front).
// It accepts § colour codes and the * prefix with which Paper marks clamped values.
func ParseTPS(out string) (float64, bool) {
	m := tpsLine.FindStringSubmatch(colorCode.ReplaceAllString(out, ""))
	if m == nil {
		return 0, false
	}
	labels := strings.Split(m[1], ",")
	values := strings.Split(m[2], ",")
	idx := 0
	for i, l := range labels {
		if strings.TrimSpace(l) == "1m" {
			idx = i
			break
		}
	}
	if idx >= len(values) {
		return 0, false
	}
	n := number.FindStringSubmatch(strings.TrimSpace(values[idx]))
	if n == nil {
		return 0, false
	}
	v, err := strconv.ParseFloat(n[1], 64)
	if err != nil || math.IsNaN(v) || math.IsInf(v, 0) {
		return 0, false
	}
	return v, true
}

// Package stats samples the host and the running containers every 10 s (spec §6.4)
// and sends them to the panel in a MetricBatch.
package stats

import (
	"math"
	"time"

	"mcsm/agent/internal/docker"
)

// Interval is the sampling period.
const Interval = 10 * time.Second

const intervalSec = int64(Interval / time.Second)

// RoundTS returns t in epoch seconds, rounded down to a multiple of 10.
func RoundTS(t time.Time) int64 {
	s := t.Unix()
	return s - s%intervalSec
}

// NextTick returns the next sampling instant: second 5 of a 10 s window
// (…:05, …:15). Sampling mid-window makes RoundTS give consecutive windows even when
// the timer is delayed by a few milliseconds.
func NextTick(now time.Time) time.Time {
	base := RoundTS(now)
	t := time.Unix(base+intervalSec/2, 0)
	if !t.After(now) {
		t = t.Add(Interval)
	}
	return t
}

// ContainerCPUPercent computes the CPU % between two readings like `docker stats`
// (100 = one full core). ok=false if there is no valid delta: reset counters
// (the container restarted) or the host CPU clock did not advance.
func ContainerCPUPercent(prev, cur docker.Stats) (float64, bool) {
	if cur.CPUTotalNs < prev.CPUTotalNs || cur.SystemCPUNs <= prev.SystemCPUNs {
		return 0, false
	}
	cpus := cur.OnlineCPUs
	if cpus == 0 {
		cpus = 1
	}
	cpu := float64(cur.CPUTotalNs - prev.CPUTotalNs)
	sys := float64(cur.SystemCPUNs - prev.SystemCPUNs)
	return cpu / sys * float64(cpus) * 100, true
}

// CPUTimes are the accumulated CPU counters of the host, in seconds.
type CPUTimes struct{ Busy, Total float64 }

// HostCPUPercent computes the host CPU % (0–100 over all CPUs) between two readings.
// ok=false if the total did not advance or the counters went backwards.
func HostCPUPercent(prev, cur CPUTimes) (float64, bool) {
	dt := cur.Total - prev.Total
	if dt <= 0 || cur.Busy < prev.Busy {
		return 0, false
	}
	return math.Min(100, math.Max(0, (cur.Busy-prev.Busy)/dt*100)), true
}

// round1 rounds to one decimal (what the UI shows).
func round1(v float64) float64 { return math.Round(v*10) / 10 }

package stats

import (
	"context"
	"errors"

	"github.com/shirou/gopsutil/v4/cpu"
	"github.com/shirou/gopsutil/v4/disk"
	"github.com/shirou/gopsutil/v4/mem"
)

// HostReader reads the host usage.
type HostReader interface {
	CPUTimes(ctx context.Context) (CPUTimes, error)
	// Memory returns the RAM used (total - available) and the total.
	Memory(ctx context.Context) (used, total uint64, err error)
	// Disk returns the usage of the filesystem that contains path.
	Disk(ctx context.Context, path string) (used, total uint64, err error)
}

// GopsutilHost implements HostReader with gopsutil. gopsutil reads HOST_PROC, so with
// the host's /proc mounted at /host/proc (spec §6.1) it measures the host and not the container.
type GopsutilHost struct{}

func (GopsutilHost) CPUTimes(ctx context.Context) (CPUTimes, error) {
	ts, err := cpu.TimesWithContext(ctx, false)
	if err != nil {
		return CPUTimes{}, err
	}
	if len(ts) == 0 {
		return CPUTimes{}, errors.New("stats: no CPU times")
	}
	return cpuTimesFrom(ts[0]), nil
}

// cpuTimesFrom replicates gopsutil's calculation: guest and guestNice are already included
// in user and nice, so they are not added again.
func cpuTimesFrom(t cpu.TimesStat) CPUTimes {
	total := t.User + t.System + t.Idle + t.Nice + t.Iowait + t.Irq + t.Softirq + t.Steal
	return CPUTimes{Busy: total - t.Idle - t.Iowait, Total: total}
}

func (GopsutilHost) Memory(ctx context.Context) (uint64, uint64, error) {
	vm, err := mem.VirtualMemoryWithContext(ctx)
	if err != nil {
		return 0, 0, err
	}
	used := vm.Total
	if vm.Available < vm.Total {
		used = vm.Total - vm.Available
	}
	return used, vm.Total, nil
}

func (GopsutilHost) Disk(ctx context.Context, path string) (uint64, uint64, error) {
	u, err := disk.UsageWithContext(ctx, path)
	if err != nil {
		return 0, 0, err
	}
	return u.Used, u.Total, nil
}

package stats

import (
	"context"
	"fmt"
	"log/slog"
	"strings"
	"sync"
	"time"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/docker"
	"mcsm/agent/internal/mc"
	"mcsm/agent/internal/spec"
)

const (
	tpsEvery            = 30 * time.Second // spec §6.4
	tpsMaxAge           = 45 * time.Second // a TPS older than this is not sent
	statsTimeout        = 3 * time.Second
	defaultProbeTimeout = 4 * time.Second // SLP + TPS of one server
)

// Containers is what the sampler uses from Docker (docker.Engine satisfies it).
type Containers interface {
	ListManaged(ctx context.Context) ([]docker.Container, error)
	Stats(ctx context.Context, id string) (docker.Stats, error)
}

// Rcon is a persistent RCON session (*mc.RconConn satisfies it).
type Rcon interface {
	Command(ctx context.Context, command string) (string, error)
	Close() error
}

// DialRcon opens an authenticated RCON session.
type DialRcon func(ctx context.Context, host string, port uint16, password string) (Rcon, error)

// Clock abstracts time so that Run can be tested without real waits.
type Clock interface {
	Now() time.Time
	After(d time.Duration) <-chan time.Time
}

type realClock struct{}

func (realClock) Now() time.Time                         { return time.Now() }
func (realClock) After(d time.Duration) <-chan time.Time { return time.After(d) }

// RealClock is the system clock.
var RealClock Clock = realClock{}

// Options are the sampler's dependencies.
type Options struct {
	Containers   Containers
	Host         HostReader
	DataRoot     string                                  // path whose filesystem is measured
	Status       mc.StatusFunc                           // Server List Ping
	Spec         func(serverID string) (spec.Spec, bool) // saved spec: type and RCON password
	Dial         DialRcon
	Send         func(*mcsmv1.Envelope) error
	Clock        Clock         // defaults to RealClock
	ProbeTimeout time.Duration // SLP + TPS per server; defaults to 4 s
	Log          *slog.Logger
}

// tpsProbe is the TPS polling state of one server. During a Sample only the goroutine
// that polls that server touches it.
type tpsProbe struct {
	password string
	conn     Rcon
	tried    time.Time // last attempt (zero: never)
	value    float64
	at       time.Time // when value was measured (zero: never)
	err      error     // result of the last attempt, to log it from Sample
}

func (p *tpsProbe) close() {
	if p.conn != nil {
		_ = p.conn.Close()
		p.conn = nil
	}
}

// job is a running server whose SLP and TPS are polled in parallel.
type job struct {
	m     *mcsmv1.ServerMetricSample
	host  string
	probe *tpsProbe // nil if its type has no `tps`
}

// Sampler gathers the metrics of the host and of the running servers. It is not safe
// for concurrent use: Run is the only one that calls Sample.
type Sampler struct {
	o        Options
	prevHost *CPUTimes
	prev     map[string]docker.Stats // last reading per container id
	tps      map[string]*tpsProbe    // by server_id
	warned   map[string]string       // last error logged per key
}

// New creates a sampler.
func New(o Options) *Sampler {
	if o.Clock == nil {
		o.Clock = RealClock
	}
	if o.ProbeTimeout <= 0 {
		o.ProbeTimeout = defaultProbeTimeout
	}
	if o.Log == nil {
		o.Log = slog.Default()
	}
	return &Sampler{o: o, prev: map[string]docker.Stats{}, tps: map[string]*tpsProbe{}, warned: map[string]string{}}
}

// Run samples at each NextTick and sends the batch until ctx ends. If the panel is not
// connected the batch is discarded: nothing accumulates in memory.
func (s *Sampler) Run(ctx context.Context) {
	defer s.closeAll()
	for {
		now := s.o.Clock.Now()
		select {
		case <-ctx.Done():
			return
		case t := <-s.o.Clock.After(NextTick(now).Sub(now)):
			b := s.Sample(ctx, t)
			if b == nil {
				continue
			}
			if err := s.o.Send(&mcsmv1.Envelope{Body: &mcsmv1.Envelope_MetricBatch{MetricBatch: b}}); err != nil {
				s.o.Log.Debug("metrics batch discarded", "err", err)
			}
		}
	}
}

// Sample takes a reading at the instant now. It returns nil if there is nothing to send:
// the first reading of each container (and of the host) only sets the CPU baseline.
func (s *Sampler) Sample(ctx context.Context, now time.Time) *mcsmv1.MetricBatch {
	b := &mcsmv1.MetricBatch{TsUnix: RoundTS(now), Host: s.sampleHost(ctx)}
	list, err := s.o.Containers.ListManaged(ctx)
	s.report("list containers", err)
	if err != nil {
		return nonEmpty(b) // transient failure: the state is not touched and sessions are not closed
	}
	var jobs []job
	seen, running := map[string]bool{}, map[string]bool{}
	for _, c := range list {
		id := c.Labels[spec.LabelServerID]
		if id == "" || c.State != "running" {
			continue
		}
		seen[c.ID], running[id] = true, true
		if m := s.readContainer(ctx, c.ID, id); m != nil {
			jobs = append(jobs, job{m: m, host: spec.ContainerName(c.Labels[spec.LabelSlug]), probe: s.probeFor(id)})
		}
	}
	var wg sync.WaitGroup
	for _, j := range jobs {
		wg.Go(func() { s.probe(ctx, now, j) })
	}
	wg.Wait()
	for _, j := range jobs {
		b.Servers = append(b.Servers, j.m)
		if j.probe != nil {
			s.report("tps of "+j.m.ServerId, j.probe.err)
		}
	}
	for cid := range s.prev {
		if !seen[cid] {
			delete(s.prev, cid)
		}
	}
	for id, p := range s.tps {
		if !running[id] {
			p.close()
			delete(s.tps, id)
		}
	}
	return nonEmpty(b)
}

// sampleHost reads the host. nil on the first reading or if the CPU read fails; if memory
// or disk fail they are sent as 0 and the error is logged.
func (s *Sampler) sampleHost(ctx context.Context) *mcsmv1.HostMetricSample {
	cur, err := s.o.Host.CPUTimes(ctx)
	s.report("host cpu", err)
	if err != nil {
		return nil
	}
	prev := s.prevHost
	s.prevHost = &cur
	if prev == nil {
		return nil
	}
	pct, ok := HostCPUPercent(*prev, cur)
	if !ok {
		return nil
	}
	h := &mcsmv1.HostMetricSample{CpuPct: round1(pct)}
	var memErr, diskErr error
	h.MemUsedBytes, h.MemTotalBytes, memErr = s.o.Host.Memory(ctx)
	s.report("host memory", memErr)
	h.DiskUsedBytes, h.DiskTotalBytes, diskErr = s.o.Host.Disk(ctx, s.o.DataRoot)
	s.report("DATA_ROOT disk", diskErr)
	return h
}

// readContainer reads docker stats and computes the CPU relative to the previous reading.
// nil on the container's first reading or if its counters were reset.
func (s *Sampler) readContainer(ctx context.Context, containerID, serverID string) *mcsmv1.ServerMetricSample {
	cctx, cancel := context.WithTimeout(ctx, statsTimeout)
	cur, err := s.o.Containers.Stats(cctx, containerID)
	cancel()
	s.report("stats of "+serverID, err)
	if err != nil {
		return nil
	}
	prev, had := s.prev[containerID]
	s.prev[containerID] = cur
	if !had {
		return nil
	}
	pct, ok := ContainerCPUPercent(prev, cur)
	if !ok {
		return nil
	}
	return &mcsmv1.ServerMetricSample{
		ServerId: serverID, CpuPct: round1(pct), MemBytes: cur.MemBytes, MemLimitBytes: cur.MemLimit,
		NetRxBytes: cur.NetRxBytes, NetTxBytes: cur.NetTxBytes,
	}
}

// probeFor returns the TPS probe if the server's type supports it, closing the RCON
// session if the password changed. nil if it does not apply.
func (s *Sampler) probeFor(serverID string) *tpsProbe {
	sp, ok := s.o.Spec(serverID)
	if !ok || !hasTPS(sp.Type) {
		if p := s.tps[serverID]; p != nil {
			p.close()
			delete(s.tps, serverID)
		}
		return nil
	}
	p := s.tps[serverID]
	if p == nil {
		p = &tpsProbe{}
		s.tps[serverID] = p
	}
	if p.password != sp.RconPassword {
		p.close()
		p.password = sp.RconPassword
	}
	return p
}

// hasTPS: only Paper and Purpur have the `tps` command (spec §6.4).
func hasTPS(serverType string) bool {
	return strings.EqualFold(serverType, "PAPER") || strings.EqualFold(serverType, "PURPUR")
}

// probe does the Server List Ping and, every 30 s, asks for the TPS. It runs in parallel
// with the other servers and only touches j: a hung server delays by no more than ProbeTimeout.
func (s *Sampler) probe(ctx context.Context, now time.Time, j job) {
	ctx, cancel := context.WithTimeout(ctx, s.o.ProbeTimeout)
	defer cancel()
	st := s.o.Status(ctx, j.host, spec.GamePort)
	if st == nil || !st.Online {
		return
	}
	j.m.McOnline = true
	j.m.PlayersOnline, j.m.PlayersMax, j.m.PingMs = st.PlayersOnline, st.PlayersMax, st.LatencyMs
	p := j.probe
	if p == nil {
		return
	}
	if p.tried.IsZero() || now.Sub(p.tried) >= tpsEvery {
		p.tried = now
		p.err = s.measureTPS(ctx, now, p, j.host)
	}
	if !p.at.IsZero() && now.Sub(p.at) <= tpsMaxAge {
		v := p.value
		j.m.Tps = &v
	}
}

// measureTPS reuses the server's RCON session (or opens one) and runs `tps`.
// If the session fails it is closed and reopened on the next attempt.
func (s *Sampler) measureTPS(ctx context.Context, now time.Time, p *tpsProbe, host string) error {
	if p.conn == nil {
		c, err := s.o.Dial(ctx, host, spec.RconPort, p.password)
		if err != nil {
			return err
		}
		p.conn = c
	}
	out, err := p.conn.Command(ctx, "tps")
	if err != nil {
		p.close()
		return err
	}
	v, ok := mc.ParseTPS(out)
	if !ok {
		return fmt.Errorf("unrecognized tps output: %.80q", out)
	}
	p.value, p.at = v, now
	return nil
}

func (s *Sampler) closeAll() {
	for id, p := range s.tps {
		p.close()
		delete(s.tps, id)
	}
}

// report logs err only once while it does not change, so that it is not repeated every 10 s.
func (s *Sampler) report(key string, err error) {
	if err == nil {
		delete(s.warned, key)
		return
	}
	if s.warned[key] == err.Error() {
		return
	}
	s.warned[key] = err.Error()
	s.o.Log.Warn("metrics: failed to read "+key, "err", err)
}

func nonEmpty(b *mcsmv1.MetricBatch) *mcsmv1.MetricBatch {
	if b.Host == nil && len(b.Servers) == 0 {
		return nil
	}
	return b
}

import { z } from "zod";

/** Ranges of the charts and the size of the bucket with which they are aggregated on the fly (spec §4 `metric_samples`). */
export const METRIC_RANGES = {
  "1h": { seconds: 3_600, step: 10 },
  "24h": { seconds: 86_400, step: 60 },
  "7d": { seconds: 604_800, step: 300 },
} as const;

export type MetricRange = keyof typeof METRIC_RANGES;

export const metricRangeSchema = z.enum(["1h", "24h", "7d"], { message: "Invalid range: use 1h, 24h or 7d" });

/** Buckets of a query: `count` buckets of `step` seconds; the last one contains `nowSec`. */
export function metricBuckets(range: MetricRange, nowSec: number): { from: number; step: number; count: number } {
  const { seconds, step } = METRIC_RANGES[range];
  const count = seconds / step;
  const last = Math.floor(nowSec / step) * step;
  return { from: last - (count - 1) * step, step, count };
}

/** Columns of a series, aligned with `t`. */
export const METRIC_COLUMNS = [
  "cpuPct", "memBytes", "memLimitBytes", "netRxBytes", "netTxBytes", "diskBytes", "diskTotalBytes",
  "playersOnline", "playersMax", "tps", "pingMs",
] as const;

export type MetricColumn = (typeof METRIC_COLUMNS)[number];

/**
 * Aggregated series for a chart: `t` are the bucket starts (epoch s) and each column has
 * one value per bucket, `null` if there were no samples (server stopped, node down).
 * Servers: cpuPct with 100 = one core; players*, tps and pingMs only if the ping answered.
 * Nodes: cpuPct 0–100 of the host, memLimitBytes = total RAM, diskBytes/diskTotalBytes of DATA_ROOT.
 */
export type MetricSeries = { range: MetricRange; step: number; t: number[] } & Record<MetricColumn, (number | null)[]>;

/** Latest sample of a node; the browser WS emits it as `{ type: "node_metrics", nodeId, sample }`. */
export interface NodeLiveSample {
  ts: number;
  cpuPct: number;
  memBytes: number;
  memTotalBytes: number;
  diskBytes: number;
  diskTotalBytes: number;
}

import type { StatementSync } from "node:sqlite";
import { METRIC_COLUMNS, metricBuckets, type MetricColumn, type MetricRange, type MetricSeries } from "@mcsm/shared";
import type { Db } from "../db/db.js";

export type MetricScope = "server" | "node";

/** One row of `metric_samples`. `ts` in epoch seconds, a multiple of 10. */
export type MetricRow = { scope: MetricScope; scopeId: string; ts: number } & Record<MetricColumn, number | null>;

/** SQL aggregation per bucket for each column of the series. */
const AGG: Record<MetricColumn, string> = {
  cpuPct: "AVG(cpu_pct)",
  memBytes: "AVG(mem_bytes)",
  memLimitBytes: "MAX(mem_limit_bytes)",
  netRxBytes: "MAX(net_rx_bytes)", // cumulative counters: the last one in the bucket
  netTxBytes: "MAX(net_tx_bytes)",
  diskBytes: "MAX(disk_bytes)",
  diskTotalBytes: "MAX(disk_total_bytes)",
  playersOnline: "MAX(players_online)", // peak of the bucket: a player who joins and leaves does not disappear
  playersMax: "MAX(players_max)",
  tps: "AVG(tps)", // AVG ignores NULLs (servers without TPS or without a reading)
  pingMs: "AVG(ping_ms)",
};

const SQL_COLUMN: Record<MetricColumn, string> = {
  cpuPct: "cpu_pct", memBytes: "mem_bytes", memLimitBytes: "mem_limit_bytes", netRxBytes: "net_rx_bytes",
  netTxBytes: "net_tx_bytes", diskBytes: "disk_bytes", diskTotalBytes: "disk_total_bytes",
  playersOnline: "players_online", playersMax: "players_max", tps: "tps", pingMs: "ping_ms",
};

/** Decimals with which each column is returned (bytes and counters are integers). */
const DECIMALS: Partial<Record<MetricColumn, number>> = { cpuPct: 1, tps: 2, pingMs: 0 };

const round = (v: number, decimals: number) => {
  const f = 10 ** decimals;
  return Math.round(v * f) / f;
};

export class MetricsRepo {
  private insert: StatementSync;
  private aggregate: StatementSync;

  constructor(private db: Db) {
    const cols = METRIC_COLUMNS.map((c) => SQL_COLUMN[c]);
    this.insert = db.prepare(
      `INSERT OR REPLACE INTO metric_samples (scope, scope_id, ts, ${cols.join(", ")}) VALUES (?, ?, ?, ${cols.map(() => "?").join(", ")})`,
    );
    // node:sqlite binds JS numbers as REAL: without CAST, ts / 10 would be a real division
    // and there would be no buckets.
    this.aggregate = db.prepare(
      `SELECT (ts / CAST(? AS INTEGER)) * CAST(? AS INTEGER) AS t, ${METRIC_COLUMNS.map((c) => `${AGG[c]} AS ${c}`).join(", ")}
       FROM metric_samples
       WHERE scope = ? AND scope_id = ? AND ts >= ? AND ts < ?
       GROUP BY t ORDER BY t`,
    );
  }

  /** Inserts (or replaces, if that window already exists) all the rows in one transaction. */
  insertMany(rows: MetricRow[]): void {
    if (rows.length === 0) return;
    this.db.exec("BEGIN");
    try {
      for (const r of rows) this.insert.run(r.scope, r.scopeId, r.ts, ...METRIC_COLUMNS.map((c) => r[c]));
      this.db.exec("COMMIT");
    } catch (e) {
      this.db.exec("ROLLBACK");
      throw e;
    }
  }

  /** Deletes the rows with `ts` before `beforeTs`. Returns how many it deleted. */
  deleteOlderThan(beforeTs: number): number {
    return Number(this.db.prepare("DELETE FROM metric_samples WHERE ts < ?").run(beforeTs).changes);
  }

  count(scope: MetricScope, scopeId: string): number {
    return (this.db.prepare("SELECT COUNT(*) AS n FROM metric_samples WHERE scope = ? AND scope_id = ?").get(scope, scopeId) as { n: number }).n;
  }

  /** Aggregates on the fly by the buckets of the range and fills the buckets without samples with null. */
  series(scope: MetricScope, scopeId: string, range: MetricRange, nowSec: number): MetricSeries {
    const { from, step, count } = metricBuckets(range, nowSec);
    const out = { range, step, t: Array.from({ length: count }, (_, i) => from + i * step) } as MetricSeries;
    for (const c of METRIC_COLUMNS) out[c] = new Array<number | null>(count).fill(null);
    const rows = this.aggregate.all(step, step, scope, scopeId, from, from + count * step) as unknown as ({ t: number } & Record<MetricColumn, number | null>)[];
    for (const row of rows) {
      const i = (row.t - from) / step;
      if (!Number.isInteger(i) || i < 0 || i >= count) continue;
      for (const c of METRIC_COLUMNS) {
        const v = row[c];
        out[c][i] = v === null ? null : round(v, DECIMALS[c] ?? 0);
      }
    }
    return out;
  }
}

import type { EventEmitter } from "node:events";
import type { MetricBatch } from "@mcsm/proto";
import type { MetricRange, MetricSeries, NodeLiveSample } from "@mcsm/shared";
import type { MetricRow, MetricScope, MetricsRepo } from "./repo.js";

/** Retention of the history: 7 days (spec §4). */
export const RETENTION_SECONDS = 7 * 86_400;
/** How often what exceeds the retention is purged. */
export const PURGE_EVERY_MS = 3_600_000;
/** If the node's clock differs from the panel's by more than this, the batch is dated with the panel's time. */
export const MAX_SKEW_SECONDS = 30;

type Cancel = () => void;

export interface MetricsDeps {
  repo: MetricsRepo;
  /** Ids of the node's servers: samples of foreign or deleted servers are discarded. */
  serverIdsOf: (nodeId: string) => Set<string>;
  /** Receives `node_metrics` (nodeId, NodeLiveSample) in each batch with host data. */
  events: EventEmitter;
  /** Clock in ms (injectable in tests). */
  now?: () => number;
  /** Repeats `fn` every `ms` and returns the function that cancels it (injectable in tests). */
  every?: (fn: () => void, ms: number) => Cancel;
  log?: { warn(obj: object, msg: string): void };
}

const defaultEvery = (fn: () => void, ms: number): Cancel => {
  const t = setInterval(fn, ms);
  t.unref();
  return () => clearInterval(t);
};

const finite = (v: number): number => (Number.isFinite(v) ? v : 0);

/** Batch ingestion, hourly purge and query-time aggregation (spec §7 `MetricsService`). */
export class MetricsService {
  private stopPurge: Cancel | null = null;
  private now: () => number;

  constructor(private deps: MetricsDeps) {
    this.now = deps.now ?? Date.now;
  }

  private nowSec(): number {
    return Math.floor(this.now() / 1000);
  }

  /** 10 s window of the batch: the agent's if its clock is reasonable; otherwise the panel's. */
  slotOf(agentTs: number): number {
    const now = this.nowSec();
    const ts = Number.isFinite(agentTs) && Math.abs(agentTs - now) <= MAX_SKEW_SECONDS ? agentTs : now;
    return ts - (ts % 10);
  }

  /** Stores a MetricBatch from the agent. Returns how many rows it wrote. */
  ingest(nodeId: string, batch: MetricBatch): number {
    const ts = this.slotOf(Number(batch.tsUnix));
    const rows: MetricRow[] = [];
    const h = batch.host;
    if (h) {
      rows.push({
        scope: "node", scopeId: nodeId, ts, cpuPct: finite(h.cpuPct),
        memBytes: Number(h.memUsedBytes), memLimitBytes: Number(h.memTotalBytes), netRxBytes: null, netTxBytes: null,
        diskBytes: Number(h.diskUsedBytes), diskTotalBytes: Number(h.diskTotalBytes),
        playersOnline: null, playersMax: null, tps: null, pingMs: null,
      });
    }
    if (batch.servers.length > 0) {
      const mine = this.deps.serverIdsOf(nodeId);
      for (const s of batch.servers) {
        if (!mine.has(s.serverId)) continue;
        const online = s.mcOnline;
        rows.push({
          scope: "server", scopeId: s.serverId, ts, cpuPct: finite(s.cpuPct),
          memBytes: Number(s.memBytes), memLimitBytes: Number(s.memLimitBytes),
          netRxBytes: Number(s.netRxBytes), netTxBytes: Number(s.netTxBytes), diskBytes: null, diskTotalBytes: null,
          playersOnline: online ? s.playersOnline : null, playersMax: online ? s.playersMax : null,
          pingMs: online ? s.pingMs : null,
          tps: online && s.tps !== undefined && Number.isFinite(s.tps) ? s.tps : null,
        });
      }
    }
    this.deps.repo.insertMany(rows);
    if (h) {
      const sample: NodeLiveSample = {
        ts, cpuPct: finite(h.cpuPct), memBytes: Number(h.memUsedBytes), memTotalBytes: Number(h.memTotalBytes),
        diskBytes: Number(h.diskUsedBytes), diskTotalBytes: Number(h.diskTotalBytes),
      };
      this.deps.events.emit("node_metrics", nodeId, sample);
    }
    return rows.length;
  }

  /** Deletes what exceeds the retention. Returns how many rows it deleted. */
  purge(): number {
    return this.deps.repo.deleteOlderThan(this.nowSec() - RETENTION_SECONDS);
  }

  /** Purges now and then every hour. */
  start(): void {
    if (this.stopPurge) return;
    this.safePurge();
    this.stopPurge = (this.deps.every ?? defaultEvery)(() => this.safePurge(), PURGE_EVERY_MS);
  }

  stop(): void {
    this.stopPurge?.();
    this.stopPurge = null;
  }

  series(scope: MetricScope, scopeId: string, range: MetricRange): MetricSeries {
    return this.deps.repo.series(scope, scopeId, range, this.nowSec());
  }

  private safePurge() {
    try {
      this.purge();
    } catch (e) {
      this.deps.log?.warn({ err: e }, "failed to purge old metrics");
    }
  }
}

import WebSocket from "ws";

/** Browser WS client for tests: JSON message queue and wait with timeout. */
export function browserClient(url: string, cookie: string): Promise<{ ws: WebSocket; next: (timeoutMs?: number) => Promise<any> }> {
  return new Promise((resolve, reject) => {
    const ws = new WebSocket(url.replace(/^http/, "ws") + "/ws", { headers: { cookie } });
    const queue: any[] = [];
    const waiters: ((m: any) => void)[] = [];
    ws.on("message", (d) => {
      const m = JSON.parse(d.toString());
      const w = waiters.shift();
      if (w) w(m); else queue.push(m);
    });
    const next = (timeoutMs = 3000) => queue.length
      ? Promise.resolve(queue.shift())
      : new Promise<any>((res, rej) => {
        const t = setTimeout(() => rej(new Error("no message")), timeoutMs);
        waiters.push((m) => { clearTimeout(t); res(m); });
      });
    ws.on("open", () => resolve({ ws, next }));
    ws.on("unexpected-response", (_r, res) => reject(new Error(`HTTP ${res.statusCode}`)));
    ws.on("error", reject);
  });
}

async function metricsRoutes(app: FastifyInstance) {
  app.setErrorHandler((err: FastifyError, _req, reply) => {
    const status = err.statusCode;
    if (status === undefined || status >= 500) {
      app.log.error(err);
      return reply.code(500).send({ error: "Error interno" });
    }
    return reply.code(status).send({ error: err.message });
  });

    if (!app.servers.get(req.params.id)) return reply.code(404).send({ error: "Server not found" });

    if (!q.success) return reply.code(400).send({ error: q.error.issues[0]?.message ?? "Invalid range" });

import type { QueryClient } from "@tanstack/react-query";
import type { MetricColumn, MetricRange, MetricSeries, NodeLiveSample } from "@mcsm/shared";
import type { ServerMessage } from "./api";
import type { LiveSource } from "./live";
import { formatBytes } from "./format";

export const RANGE_OPTIONS: { value: MetricRange; label: string }[] = [
  { value: "1h", label: "1 h" },
  { value: "24h", label: "24 h" },
  { value: "7d", label: "7 days" },
];

/** How often a chart is reloaded: one new bucket of 10 s, 1 min or 5 min. */
export const REFRESH_MS: Record<MetricRange, number> = { "1h": 10_000, "24h": 60_000, "7d": 300_000 };

/** Data for uPlot: [t, series1, series2…] with `null` in the gaps. */
export type Aligned = [number[], ...(number | null)[][]];

export const aligned = (s: MetricSeries, cols: MetricColumn[]): Aligned => [s.t, ...cols.map((c) => s[c])];

export const hasData = (col: (number | null)[]): boolean => col.some((v) => v !== null);

/** Latest sample of a node series (paints the card before the first live event). */
export function latestNodeSample(s: MetricSeries): NodeLiveSample | null {
  for (let i = s.t.length - 1; i >= 0; i--) {
    const cpu = s.cpuPct[i];
    if (cpu === null || cpu === undefined) continue;
    return {
      ts: s.t[i]!, cpuPct: cpu, memBytes: s.memBytes[i] ?? 0, memTotalBytes: s.memLimitBytes[i] ?? 0,
      diskBytes: s.diskBytes[i] ?? 0, diskTotalBytes: s.diskTotalBytes[i] ?? 0,
    };
  }
  return null;
}

/** The agent sends every 10 s: a sample older than 60 s is stale. */
export const isFresh = (s: NodeLiveSample | null | undefined, nowMs: number): s is NodeLiveSample =>
  !!s && nowMs / 1000 - s.ts <= 60;

export const percent = (used: number, total: number): number => (total > 0 ? Math.min(100, Math.max(0, (used / total) * 100)) : 0);

export const usageTone = (pct: number): "ok" | "warn" | "bad" => (pct >= 90 ? "bad" : pct >= 70 ? "warn" : "ok");

export const formatCpu = (v: number): string => `${Math.round(v)} %`;
export const formatCount = (v: number): string => String(Math.round(v));
export const formatTps = (v: number): string => v.toFixed(1);
export const formatMem = (v: number): string => formatBytes(v);

type NodeMetricsMsg = Extract<ServerMessage, { type: "node_metrics" }>;

/** Stores the latest live sample of a node; an older one than the stored one does not overwrite it. */
export function applyNodeMetricsEvent(qc: QueryClient, msg: NodeMetricsMsg): void {
  qc.setQueryData<NodeLiveSample | null>(["node-live", msg.nodeId], (old) => (old && old.ts > msg.sample.ts ? old : msg.sample));
}

/** Connects the WS `node_metrics` to the cache. Returns the cleanup function. */
export function bindNodeMetrics(qc: QueryClient, live: LiveSource): () => void {
  const offs = [
    live.subscribe("nodes", (m) => { if (m.type === "node_metrics") applyNodeMetricsEvent(qc, m); }),
    // Samples are lost during the disconnection: the latest one is reloaded via REST.
    live.onReconnect(() => { void qc.invalidateQueries({ queryKey: ["node-live"] }); }),
  ];
  return () => offs.forEach((off) => off());
}
```

import { useEffect } from "react";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import type { MetricRange, MetricSeries } from "@mcsm/shared";
import { api } from "@/lib/api";
import { realtime } from "@/lib/ws";
import { REFRESH_MS, bindNodeMetrics, latestNodeSample } from "@/lib/metrics";

/** Historical series of a server; reloaded at the pace of the range's bucket. */
export function useServerMetrics(serverId: string, range: MetricRange) {
  return useQuery({
    queryKey: ["metrics", "server", serverId, range],
    queryFn: () => api.get<MetricSeries>(`/api/servers/${serverId}/metrics?range=${range}`),
    refetchInterval: REFRESH_MS[range],
  });
}

/** Latest sample of a node: the first via REST and then live over the WS (`node_metrics`). */
export function useNodeLive(nodeId: string) {
  const qc = useQueryClient();
  useEffect(() => bindNodeMetrics(qc, realtime), [qc]);
  return useQuery({
    queryKey: ["node-live", nodeId],
    queryFn: async () => latestNodeSample(await api.get<MetricSeries>(`/api/nodes/${nodeId}/metrics?range=1h`)),
    staleTime: Infinity,
  });
}

import { useEffect, useRef } from "react";
import uPlot from "uplot";
import "uplot/dist/uPlot.min.css";
import type { Aligned } from "@/lib/metrics";

export interface ChartLine { label: string; color: string; dash?: number[]; fill?: boolean }

interface Props {
  title: string;
  data: Aligned;
  /** Must be stable (module constant): if it changes, the chart is recreated. */
  lines: ChartLine[];
  /** Must be stable: formats the Y axis and the legend. */
  format: (v: number) => string;
  /** Fixed Y-axis range (stable); by default from 0 to the maximum of the data. */
  yRange?: [number, number];
  height?: number;
}

const AXIS: uPlot.Axis = { stroke: "#a1a1aa", grid: { stroke: "#27272a", width: 1 }, ticks: { stroke: "#3f3f46", width: 1 } };
const MIN_WIDTH = 200;

/** Time chart with uPlot. Gaps (null) are drawn as breaks: periods without data are not joined. */
export function TimeSeriesChart({ title, data, lines, format, yRange, height = 160 }: Props) {
  const box = useRef<HTMLDivElement>(null);
  const plot = useRef<uPlot | null>(null);
  const latest = useRef(data);
  latest.current = data;

  useEffect(() => {
    const el = box.current;
    if (!el) return;
    const u = new uPlot({
      width: Math.max(el.clientWidth, MIN_WIDTH),
      height,
      cursor: { drag: { x: false, y: false, setScale: false } },
      scales: { y: { range: (_u, _min, max) => yRange ?? [0, Math.max(max, 1) * 1.1] } },
      axes: [AXIS, { ...AXIS, size: 70, values: (_u, splits) => splits.map((v) => format(v)) }],
      series: [
        { value: (_u, v) => (v == null ? "—" : new Date(v * 1000).toLocaleString()) },
        ...lines.map((l) => ({
          label: l.label, stroke: l.color, width: 1.5, dash: l.dash, fill: l.fill ? `${l.color}26` : undefined,
          value: (_u: uPlot, v: number | null) => (v == null ? "—" : format(v)),
        })),
      ],
    }, latest.current, el);
    plot.current = u;
    const ro = new ResizeObserver(() => u.setSize({ width: Math.max(el.clientWidth, MIN_WIDTH), height }));
    ro.observe(el);
    return () => { ro.disconnect(); u.destroy(); plot.current = null; };
  }, [lines, format, yRange, height]);

  useEffect(() => { plot.current?.setData(data); }, [data]);

  return (
    <figure className="min-w-0">
      <figcaption className="mb-1 text-xs uppercase tracking-wide text-muted-foreground">{title}</figcaption>
      <div ref={box} className="w-full" />
    </figure>
  );
}
