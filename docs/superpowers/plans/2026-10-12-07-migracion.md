# MC Server Manager — Plan 7: Migración entre nodos

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mover un servidor (mundo, spec e identidad) de un nodo a otro desde la web con un job de 7 pasos visibles: si algo falla, el origen queda intacto y, si estaba en marcha, arrancado; si sale bien, el servidor vive en el destino con la spec en versión +1 (y otro puerto si el suyo choca) y el origen se retira (`<slug>.migrated-<ts>` o borrado).

**Architecture:** El panel orquesta (`MigrationService`) y los agentes ejecutan pasos idempotentes. Origen: `PowerAction stop` → `BackupNow{PRE_MIGRATION}` → `BackupPush` (sube el `.tar.zst` a staging del panel por `PUT /agent/transfer`). Destino: `MigrateReceive` (job del agente: descarga desde staging con `GET /agent/transfer`, comprueba tamaño y sha256, restaura en un `<DATA_ROOT>/<slug>` que crea en exclusiva con un marcador) → `ApplySpec` (versión +1, parado) → `PowerAction start` y espera a `healthy`/ping (5 min). El commit es una transacción SQLite que cambia `servers.node_id/slug/spec/spec_version` solo si la versión no cambió; después `MigrateRetire` retira el origen. Mientras la migración está abierta (tabla `migrations`), `SyncSpecs` no retira el servidor de ninguno de los dos nodos y un hook del panel rechaza (409) las acciones del usuario sobre él. Un fallo antes del commit deshace: `MigrateAbort` en el destino (borra solo lo que lleva el marcador de esta migración) y, si el origen estaba en marcha, se rearranca, pero nunca antes de haber retirado una copia del destino que llegó a arrancarse.

**Tech Stack:** Go 1.27.2 (agente: `backup`, `app`, `reconcile`, `jobs`, `conn.TransferClient`); protobuf con buf 1.73 (`pnpm gen`); Node 26, pnpm 12, Fastify 5, `node:sqlite`, zod 4; React 19, TanStack Query, shadcn/ui (Radix), Vitest 4 en node (sin jsdom); E2E con Docker real y Docker-in-Docker para el segundo nodo.

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` (§2 «Migración», §4 `backups.trigger=pre_migration` y `jobs.type=migrate`, §5.1 transferencias, §5.3 `BackupPush`/`BackupPull`, §6.5, §7 `MigrationService`, §10 «Migración fallida» y «Panel reiniciado a mitad de job»). ## Decisiones resueltas con el código real

- **La misma identidad en los dos nodos, con el panel como árbitro.** El servidor conserva su `id` (URL, métricas, historial). Entre el paso 4 y el commit, el destino guarda una spec «fantasma» con ese `id`; la fila de `servers` sigue en el origen. La tabla `migrations` registra cada migración y `AgentService.handshake` no pone en `removed_ids` un servidor con una migración abierta que pasa por ese nodo (`app.migrations.protects`): ni el fantasma del destino ni el origen pendiente de retirar desaparecen por un Hello. El cambio de nodo es **una** transacción (`MigrationsRepo.commit`) que solo se aplica si la fila sigue en el origen con la `spec_version` del inicio; si no, la migración se deshace.
- **Staging en el panel, no streaming directo.** La spec (§7) pide `BackupPush` y `BackupPull` en paralelo; el Plan 5 dejó `Staging.source({removeAfter:false})` + `remove()` precisamente para que la migración pueda **reintentar** el envío al destino sin repetir la copia en el origen. El panel guarda la copia en `staging/mig-<id>.bin` verificando tamaño y sha256 (frente al `BackupCreated` del origen y al `BackupPushResult`), y la sirve al destino; se borra al terminar el paso 4 o al fallar.
- **Restaurar antes de crear la spec en el destino** (pasos 4 y 5 de la spec, invertidos). `MigrateReceive` crea `<DATA_ROOT>/<slug>` con `os.Mkdir` (exclusivo) y un marcador `.mcsm-migration` con el id de la migración, descarga la copia a `<slug>/backups/` y la restaura con `backup.Restore` en un `data` que aún no existe (sin `pre-restore`). Así el reconciliador nunca crea un `data` vacío, un directorio ajeno nunca se pisa (`exists`) y `MigrateAbort` solo borra lo que lleva su marcador.
- **Nombres de mensajes.** `BackupPush{server_id, filename, transfer_id}` responde `BackupPushResult{size_bytes, sha256, data_bytes}` (convención `*Result` de `isResponseCase`). En lugar de `BackupPull`, `MigrateReceive` (descarga + verificación + extracción, como job `migrate_in`). Además `MigrateAbort` (deshacer en el destino) y `MigrateRetire` (retirar el origen).
- **Pasos visibles** (`MIGRATION_STEPS` en shared; el progreso del job cae en el tramo de su paso): 1 parar en el origen (0–5 %), 2 copia `pre_migration` (5–30), 3 copia al panel (30–50), 4 copia al destino y restauración (50–80), 5 crear el servidor en el destino (80–83), 6 arrancar y comprobar (83–95), 7 confirmar y retirar el origen (95–100).
- **Verificación.** Se arranca siempre en el destino y se espera `state=running` con `health=healthy` o ping SLP correcto, como mucho 5 min; `exited`/`dead` falla al instante. Si el servidor estaba parado, se vuelve a parar antes del commit. El estado deseado final es el de antes (`was_running`).
- **Nunca dos servidores vivos.** El paso 1 usa `serversService.power(id,"stop")`, que persiste `stopped` en el agente **y** en la fila: un `SyncSpecs` del origen a mitad no lo rearranca. Al deshacer, si el destino llegó a recibir `start` (`target_started`), el origen solo se rearranca después de que `MigrateAbort` haya borrado ese contenedor; si el destino no responde, el origen queda parado y la migración en `rolling_back` hasta que vuelva.
- **Retirada del origen** (`MigrateRetire`, idempotente): reserva, espera a `fileWrites`, para el contenedor si alguien lo arrancó, aparta el directorio entero del servidor, `<DATA_ROOT>/<slug>` → `<DATA_ROOT>/<slug>.migrated-<ts>` (o, con «borrar origen», lo borra cuando el contenedor ya no existe), `Forget` y libera la reserva (lo que borra el contenedor por su lápida). **Desviación de la spec** (§7 dice `data.migrated-<ts>`): se aparta `<slug>` entero y no solo `data`, para que el slug quede libre en el origen (volver a migrar el servidor a ese nodo, o crear otro con ese slug, no tropieza con un directorio que la web no deja borrar) y las copias del origen se queden junto a sus datos. Las copias del origen ya no se gestionan desde el panel; tras el commit el panel pide el inventario al destino, que da de alta la copia `pre_migration` recibida (mismo servidor, nuevo nodo) y marca borradas las del origen (vía negativa del inventario, `request_id`).
- **Acciones del usuario bloqueadas mientras dura.** Un hook `preHandler` raíz (registrado **antes** de las rutas, porque Fastify fija los hooks de cada contexto al registrarlo) rechaza con 409: cualquier método no GET bajo `/api/servers/:id…` (salvo `/migration`) si la migración está `running` o `rolling_back`; crear servidores en un nodo destino sin confirmar o en un origen con la retirada pendiente (`POST /api/servers`, `/api/templates/:id/servers`, `POST /api/nodes/:id/…` como la importación del Plan 6); borrar un nodo con una migración `running`. Escapatoria: si el nodo destino no va a volver, se puede borrar (las filas de `migrations` caen en cascada y el servidor queda libre, parado en el origen).
- **Plan 6 en paralelo.** Un servidor con `dataPath` se rechaza (409) leyendo `spec.dataPath` de forma genérica (el campo aún no existe en esta rama); el commit pone `imported_from = NULL` si la columna existe (`PRAGMA table_info`) y la spec que recibe el destino se construye con una fila sin `imported_from` (sin `adopt`).
- **Reinicio del panel.** `JobService.interruptStale` falla el job `migrate` («interrumpido»); `MigrationService.recover` (en `onReady`) pasa las migraciones `running` a `rolling_back` con lo pendiente según `target_touched`/`was_running`. Lo pendiente (`rolling_back` y `committed`) se reintenta cada 30 s y tras cada Hello de los nodos implicados. Los sub-jobs de los agentes (`backup` pre_migration y `migrate_in`) siguen su curso: `migrate_in` entra en `AGENT_JOB_TYPES`.
- **E2E con Docker-in-Docker.** Dos agentes sobre el **mismo** Docker se verían los contenedores (el reconciliador busca por la etiqueta `mcsm.server_id`, que es la misma en origen y destino): el del destino recrearía el del origen. El segundo nodo corre dentro de `mcsm-test-nodeb` (`docker:<versión>-dind`, privilegiado) con su propio Docker; su `DATA_ROOT` es un directorio del host montado con la misma ruta (espejo) en el contenedor dind y en el agente.

// Migración entre nodos (spec §7 MigrationService). La orquesta el panel; el agente ejecuta
// pasos idempotentes sobre su disco y su Docker. Origen: BackupPush y MigrateRetire. Destino:
// MigrateReceive y MigrateAbort.

// Panel → agente (origen). Sube una copia .tar.zst de <slug>/backups/ al panel con
// PUT /agent/transfer/{transfer_id}. Respuesta: BackupPushResult cuando el panel la ha recibido
// entera, o Error (unknown_server | invalid_request | not_found | busy | transfer_failed |
// backup_failed: la copia no tiene sha256 en su .json).
message BackupPush {
  string server_id = 1;
  string filename = 2;
  string transfer_id = 3;
}

// Metadatos de la copia enviada, de su .json: el panel compara tamaño y sha256 con lo que ha
// recibido y con el BackupCreated del job.
message BackupPushResult {
  uint64 size_bytes = 1;
  string sha256 = 2;
  uint64 data_bytes = 3; // contenido sin comprimir; 0 si la copia no lo anotó

package backup

import (
	"context"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"regexp"
	"time"
)

// migratedInfix: <slug>.migrated-<ts> es el directorio de un servidor que conserva el nodo origen
// tras una migración confirmada (spec §7, paso 7).
const migratedInfix = ".migrated-"

var sha256Re = regexp.MustCompile(`^[0-9a-f]{64}$`)

// MigratedName es el nombre con que se aparta, junto a él, el directorio de un servidor del nodo
// origen al confirmar una migración: p. ej. survival.migrated-20261012T040000.000Z. Conserva data y
// sus copias y deja libre <slug> (el servidor puede volver, o crearse otro con ese slug).
func MigratedName(serverDir string, t time.Time) string {
	return filepath.Base(serverDir) + migratedInfix + t.UTC().Format(tsLayout)
}

// CheckSpace falla, envolviendo ErrNoSpace, si en dir no caben need bytes más el margen
// max(5 %, 256 MiB) con el que los servidores del nodo siguen pudiendo guardar. Si no se puede
// consultar el espacio libre no falla: lo vigilan después las escrituras. free nil usa statfs.
func CheckSpace(dir string, need int64, what string, free func(dir string) (uint64, error)) error {
	if free == nil {
		free = freeSpace
	}
	got, err := free(dir)
	if err != nil {
		return nil
	}
	n := uint64(max(need, 0))
	if req := requiredSpace(need); got < req {
		return fmt.Errorf("%w para %s: hacen falta %s (%s más un margen de %s para que los servidores del nodo sigan pudiendo guardar) y quedan %s libres en %s; faltan %s",
			ErrNoSpace, what, humanBytes(req), humanBytes(n), humanBytes(req-n), humanBytes(got), dir, humanBytes(req-got))
	}
	return nil
}

// ReceiveRequest describe una copia que llega de otro nodo (migración, spec §7).
type ReceiveRequest struct {
	BackupsDir string
	ServerID   string
	Slug       string
	Filename   string    // <slug>-<ts>-<versión>.tar.zst (ValidName con Slug)
	Body       io.Reader // la copia; se leen como mucho Size+1 bytes
	Size       int64     // bytes exactos que deben llegar
	SHA256     string    // hex en minúsculas del fichero completo
	// ExtractBytes es lo que ocupará extraída (0 = desconocido: se toma Size). Mientras llega se
	// exige que siga cabiendo con el margen: la restauración va justo después.
	ExtractBytes int64
	Now          func() time.Time
	FreeSpace    func(dir string) (uint64, error) // nil: statfs
	Progress     func(done, total int64)
}

// Receive escribe la copia como <Filename>.partial en BackupsDir calculando su sha256 y, solo si
// llegan exactamente Size bytes con ese sha256, escribe su .json (trigger pre_migration) y la
// renombra a su nombre final: Restore la vuelve a verificar con ese .json. Si algo falla, se
// cancela o deja de haber espacio, no deja nada (ni parcial ni .json) y nunca pisa una copia
// existente.
func Receive(ctx context.Context, req ReceiveRequest) (meta Meta, err error) {
	if req.Now == nil {
		req.Now = time.Now
	}
	if req.FreeSpace == nil {
		req.FreeSpace = freeSpace
	}
	if req.Progress == nil {
		req.Progress = func(int64, int64) {}
	}
	if !ValidName(req.Slug, req.Filename) {
		return Meta{}, fmt.Errorf("nombre de copia inválido %q", req.Filename)
	}
	if req.Size <= 0 || !sha256Re.MatchString(req.SHA256) {
		return Meta{}, errors.New("tamaño o sha256 de la copia inválidos")
	}
	started, version, _ := parseName(req.Slug, req.Filename)
	if err := os.MkdirAll(req.BackupsDir, 0o750); err != nil {
		return Meta{}, fmt.Errorf("crear el directorio de copias: %w", err)
	}
	final := filepath.Join(req.BackupsDir, req.Filename)
	if _, serr := os.Lstat(final); serr == nil {
		return Meta{}, fmt.Errorf("la copia %s ya existe", req.Filename)
	}
	extract := req.ExtractBytes
	if extract <= 0 {
		extract = req.Size
	}
	partial := final + partialExt
	f, err := os.OpenFile(partial, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0o640)
	if err != nil {
		return Meta{}, fmt.Errorf("crear la copia: %w", err)
	}
	closed := false
	defer func() {
		if err != nil {
			if !closed {
				_ = f.Close()
			}
			_ = os.Remove(partial)
		}
	}()
	h := sha256.New()
	// Lo que debe seguir libre mientras llega: la extracción que viene después, con su margen.
	guard := &spaceGuard{w: f, free: req.FreeSpace, dir: req.BackupsDir, margin: requiredSpace(extract), since: -1}
	src := &progressReader{r: ctxReader{ctx: ctx, r: io.LimitReader(req.Body, req.Size+1)}, total: req.Size, fn: req.Progress}
	var n int64
	n, err = io.Copy(io.MultiWriter(guard, h), src)
	if err != nil {
		if cerr := ctx.Err(); cerr != nil {
			return Meta{}, fmt.Errorf("recepción cancelada: %w", cerr)
		}
		return Meta{}, fmt.Errorf("recibir la copia: %w", err)
	}
	if n < req.Size {
		return Meta{}, fmt.Errorf("la copia llegó incompleta: %d bytes de %d", n, req.Size)
	}
	if n > req.Size {
		return Meta{}, fmt.Errorf("la copia llegó con bytes de más: se esperaban %d", req.Size)
	}
	sum := hex.EncodeToString(h.Sum(nil))
	if sum != req.SHA256 {
		return Meta{}, fmt.Errorf("la copia llegó dañada: sha256 %s, esperado %s", sum, req.SHA256)
	}
	if err = f.Sync(); err != nil {
		return Meta{}, fmt.Errorf("guardar la copia en disco: %w", err)
	}
	closed = true
	if err = f.Close(); err != nil {
		return Meta{}, fmt.Errorf("guardar la copia en disco: %w", err)
	}
	meta = Meta{
		Filename: req.Filename, ServerID: req.ServerID, Slug: req.Slug, SpecVersion: version, Trigger: TriggerPreMigration,
		SizeBytes: req.Size, SHA256: sum, StartedAt: started.UTC(), FinishedAt: req.Now().UTC(), DataBytes: req.ExtractBytes,
	}
	if err = WriteMeta(req.BackupsDir, meta); err != nil {
		return Meta{}, fmt.Errorf("guardar los metadatos de la copia: %w", err)
	}
	if err = rename(partial, final); err != nil {
		_ = os.Remove(final + MetaExt)
		return Meta{}, fmt.Errorf("guardar la copia: %w", err)
	}
	_ = syncDir(req.BackupsDir)
	return meta, nil
}

// migrateErrCode traduce un fallo de los mensajes de migración al Error.code del protocolo.
func migrateErrCode(err error) string {
	switch {
	case errors.Is(err, reconcile.ErrBusy), errors.Is(err, errTransfersBusy), errors.Is(err, errClosing), errors.Is(err, errFilesClosing):
		return errcode.Busy
	case errors.Is(err, errUnknownServer):
		return errcode.UnknownServer
	case errors.Is(err, errBadRequest):
		return errcode.InvalidRequest
	case errors.Is(err, errMigrateExists):
		return errcode.Exists
	case errors.Is(err, backup.ErrNoSpace):
		return errcode.TooLarge
	case errors.Is(err, files.ErrTransfer):
		return errcode.TransferFailed
	case errors.Is(err, fs.ErrNotExist):
		return errcode.NotFound
	default:
		return errcode.BackupFailed
	}
}

// handleBackupPush sube una copia al panel (PUT /agent/transfer/{id}) y responde con sus
// metadatos cuando el panel la ha recibido entera. Cuenta como Files* en curso para el cierre
// (xfer.enter) y ocupa uno de los huecos de transferencia del nodo. ctx: el de vida del agente.
func (a *App) handleBackupPush(ctx context.Context, id uint64, m *mcsmv1.BackupPush, send func(*mcsmv1.Envelope) error) {
	if !a.xfer.enter() {
		_ = send(errMsg(id, errcode.Busy, errFilesClosing))
		return
	}
	defer a.xfer.leave()
	res, err := a.backupPush(ctx, m)
	if err != nil {
		_ = send(errMsg(id, migrateErrCode(err), err))
		return
	}
	_ = send(&mcsmv1.Envelope{Id: id, Body: &mcsmv1.Envelope_BackupPushResult{BackupPushResult: res}})
}

func (a *App) backupPush(ctx context.Context, m *mcsmv1.BackupPush) (*mcsmv1.BackupPushResult, error) {
	t, err := a.bk.target(m.GetServerId())
	if err != nil {
		return nil, err
	}
	if !backup.ValidName(t.slug, m.GetFilename()) {
		return nil, fmt.Errorf("%w: nombre de copia inválido %q", errBadRequest, m.GetFilename())
	}
	meta, err := backup.ReadMeta(t.backupsDir, m.GetFilename())
	if err != nil || meta.SHA256 == "" {
		return nil, fmt.Errorf("la copia %s no tiene sha256 en su .json: no se envía sin poder comprobarla", m.GetFilename())
	}
	// Abierta antes de reclamar la transferencia: una copia que ya no existe no la consume. El
	// descriptor sigue valiendo aunque la poda la borre mientras se envía.
	f, err := os.Open(filepath.Join(t.backupsDir, m.GetFilename()))
	if err != nil {
		return nil, fmt.Errorf("abrir la copia: %w", err)
	}
	defer f.Close()
	fi, err := f.Stat()
	if err != nil {
		return nil, err
	}
	if !fi.Mode().IsRegular() {
		return nil, fmt.Errorf("%w: la copia no es un fichero normal", errBadRequest)
	}
	xfer, err := a.transfers()
	if err != nil {
		return nil, err
	}
	release, err := a.xfer.acquire()
	if err != nil {
		return nil, err
	}
	defer release()
	size := fi.Size()
	err = a.withIdleGuard(ctx, func(ctx context.Context, track func(io.Reader) io.Reader) error {
		// LimitReader: se manda lo que medía al abrirla; si encoge, Put falla por Content-Length.
		if err := xfer.Put(ctx, m.GetTransferId(), track(io.LimitReader(f, size)), size); err != nil {
			return fmt.Errorf("%w: %v", files.ErrTransfer, err)
		}
		return nil
	})
	if err != nil {
		return nil, err
	}
	return &mcsmv1.BackupPushResult{SizeBytes: uint64(size), Sha256: meta.SHA256, DataBytes: uint64(max(meta.DataBytes, 0))}, nil
}

const (
	// jobTypeMigrateIn es el tipo de job de la recepción (JobProgress.type, inventario).
	jobTypeMigrateIn = "migrate_in"
	// holdMigration es el motivo de la reserva durante los pasos de una migración.
	holdMigration = "migración"
	// migrationMarker se crea en <DATA_ROOT>/<slug> al recibir una migración y contiene su id:
	// MigrateAbort solo borra un directorio con el marcador de esa misma migración.
	migrationMarker = ".mcsm-migration"
	// maxMigrateBytes acota size_bytes y data_bytes (un valor absurdo desbordaría las cuentas).
	maxMigrateBytes = 1 << 50
)

var migrateSHA256 = regexp.MustCompile(`^[0-9a-f]{64}$`)

func (b *backupService) handleMigrateReceive(id uint64, m *mcsmv1.MigrateReceive, send func(*mcsmv1.Envelope) error) {
	if err := b.startReceive(m); err != nil {
		_ = send(errMsg(id, migrateErrCode(err), err))
		return
	}
	_ = send(ack(id))
}

// startReceive valida, registra el job (un job_id ya conocido reenvía su estado, §5.4),
// comprueba que ni el servidor ni su directorio existen en este nodo y que cabe la copia más su
// extracción con el margen, reserva el servidor y lanza la recepción en segundo plano.
func (b *backupService) startReceive(m *mcsmv1.MigrateReceive) error {
	if m.GetJobId() == "" || m.GetServerId() == "" || m.GetMigrationId() == "" {
		return fmt.Errorf("%w: faltan job_id, server_id o migration_id", errBadRequest)
	}
	if !spec.ValidSlug(m.GetSlug()) || !backup.ValidName(m.GetSlug(), m.GetFilename()) {
		return fmt.Errorf("%w: slug o nombre de copia no válidos", errBadRequest)
	}
	if m.GetSizeBytes() == 0 || m.GetSizeBytes() > maxMigrateBytes || m.GetDataBytes() > maxMigrateBytes || !migrateSHA256.MatchString(m.GetSha256()) {
		return fmt.Errorf("%w: tamaño o sha256 de la copia no válidos", errBadRequest)
	}
	j, existing, err := b.jobs.Begin(m.GetJobId(), m.GetServerId(), jobTypeMigrateIn)
	if err != nil {
		return err
	}
	if existing != nil {
		b.jobs.Replay(existing)
		return nil
	}
	fail := func(err error) error {
		b.finish(j, err, "")
		return err
	}
	sp, err := b.a.st.GetSpec(m.GetServerId())
	if err != nil {
		return fail(err)
	}
	if sp != nil {
		return fail(fmt.Errorf("%w: el servidor ya está en este nodo", errMigrateExists))
	}
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	if _, err := os.Lstat(dir); err == nil {
		return fail(fmt.Errorf("%w: %s ya existe en el nodo destino; muévelo o bórralo antes de migrar aquí", errMigrateExists, dir))
	} else if !errors.Is(err, fs.ErrNotExist) {
		return fail(err)
	}
	size, extract := int64(m.GetSizeBytes()), int64(m.GetDataBytes())
	if extract <= 0 {
		extract = size
	}
	if err := backup.CheckSpace(b.a.cfg.DataRoot, size+extract, "recibir la migración", b.freeSpace); err != nil {
		return fail(err)
	}
	// Reserva sin spec: un ApplySpec que llegara durante la recepción solo se guarda; se aplica
	// (y crea el contenedor) al liberar, ya con data restaurado. Ningún Files* puede escribir en este
	// servidor (serverFS responde unknown_server antes de fileWrites.enter): no hay escrituras que esperar.
	release, err := b.a.rec.Hold(m.GetServerId(), holdMigration)
	if err != nil {
		return fail(err)
	}
	if !b.spawn(func() { b.runReceive(m, dir, j, release) }) {
		release(b.a.life)
		return fail(errClosing)
	}
	return nil
}

func (b *backupService) runReceive(m *mcsmv1.MigrateReceive, dir string, j *jobs.Job, release func(context.Context)) {
	ctx := b.a.life
	err := b.withSlot(ctx, j, func() error { return b.receive(ctx, m, dir, j) })
	err = interrupted(ctx, err)
	release(b.a.life) // normalmente sin spec: no hay nada que reconciliar
	b.finish(j, err, "Copia recibida, verificada y restaurada en "+filepath.Join(dir, "data"))
}

// receive crea <DATA_ROOT>/<slug> (exclusivo) con el marcador de la migración, descarga la copia
// a su backups/ comprobando tamaño y sha256, y la restaura como data/ con backup.Restore (que la
// verifica otra vez, comprueba el espacio y acota la extracción). Si algo falla, borra el
// directorio entero: lo ha creado esta recepción.
func (b *backupService) receive(ctx context.Context, m *mcsmv1.MigrateReceive, dir string, j *jobs.Job) (err error) {
	if err := os.Mkdir(dir, 0o755); err != nil {
		if errors.Is(err, fs.ErrExist) {
			return fmt.Errorf("%w: %s ya existe en el nodo destino", errMigrateExists, dir)
		}
		return fmt.Errorf("crear %s: %w", dir, err)
	}
	defer func() {
		if err == nil {
			return
		}
		if rerr := os.RemoveAll(dir); rerr != nil {
			j.Log("aviso: no se pudo borrar " + dir + " (bórralo a mano): " + rerr.Error())
		}
	}()
	if err := os.WriteFile(filepath.Join(dir, migrationMarker), []byte(m.GetMigrationId()+"\n"), 0o644); err != nil {
		return fmt.Errorf("marcar el directorio de la migración: %w", err)
	}
	xfer, err := b.a.transfers()
	if err != nil {
		return err
	}
	releaseSlot, err := b.a.xfer.acquire()
	if err != nil {
		return err
	}
	backupsDir := backup.Dir(b.a.cfg.DataRoot, m.GetSlug())

func (b *backupService) handleMigrateAbort(id uint64, m *mcsmv1.MigrateAbort, send func(*mcsmv1.Envelope) error) {
	b.respondAsync(id, send, func() error { return b.abortMigration(m) })
}

func (b *backupService) handleMigrateRetire(id uint64, m *mcsmv1.MigrateRetire, send func(*mcsmv1.Envelope) error) {
	b.respondAsync(id, send, func() error { return b.retireMigration(m) })
}

// respondAsync ejecuta fn en segundo plano, contada en wg como las copias (el cierre la espera), y
// responde Ack o Error al terminar. Si el agente se está cerrando, busy.
func (b *backupService) respondAsync(id uint64, send func(*mcsmv1.Envelope) error, fn func() error) {
	if !b.spawn(func() {
		if err := fn(); err != nil {
			_ = send(errMsg(id, migrateErrCode(err), err))
			return
		}
		_ = send(ack(id))
	}) {
		_ = send(errMsg(id, errcode.Busy, errClosing))
	}
}

func checkMigrationMsg(serverID, slug, migrationID string) error {
	if serverID == "" || migrationID == "" || !spec.ValidSlug(slug) {
		return fmt.Errorf("%w: faltan server_id o migration_id, o el slug no es válido", errBadRequest)
	}
	return nil
}

// abortMigration deshace en el destino lo que dejó una migración no confirmada: la spec y el
// contenedor (Forget y liberar la reserva, que lo para y lo borra por su lápida) y el directorio,
// solo si lleva el marcador de esta migración. Repetirlo no hace nada.
func (b *backupService) abortMigration(m *mcsmv1.MigrateAbort) error {
	if err := checkMigrationMsg(m.GetServerId(), m.GetSlug(), m.GetMigrationId()); err != nil {
		return err
	}
	id := m.GetServerId()
	sp, err := b.a.st.GetSpec(id)
	if err != nil {
		return err
	}
	switch {
	case sp != nil && sp.Slug != m.GetSlug():
		return fmt.Errorf("%w: el servidor tiene otro slug en este nodo (%s)", errBadRequest, sp.Slug)
	case sp != nil:
		if err := b.forgetHeld(id, nil); err != nil {
			return err
		}
	default:
		if reason := b.a.rec.HeldReason(id); reason != "" {
			return fmt.Errorf("%w: se reintentará al terminar", reconcile.Busy(reason))
		}
	}
	if err := b.removalDone(id); err != nil {
		return err
	}
	b.a.hub.Reset(id)
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	mark, err := os.ReadFile(filepath.Join(dir, migrationMarker))
	switch {
	case errors.Is(err, fs.ErrNotExist):
		return nil // nada de esta migración en el disco (o ya borrado)
	case err != nil:
		return err
	case strings.TrimSpace(string(mark)) != m.GetMigrationId():
		b.a.log.Warn("deshacer migración: el directorio es de otra migración; no se toca", "dir", dir)
		return nil
	}
	if err := os.RemoveAll(dir); err != nil {
		return fmt.Errorf("borrar %s: %w", dir, err)
	}
	return nil
}

// retireMigration retira el servidor del origen tras confirmar la migración: con la reserva
// tomada, para el contenedor si alguien lo arrancó, aparta <DATA_ROOT>/<slug> (datos y copias) a
// <DATA_ROOT>/<slug>.migrated-<ts> (sin delete_data), olvida la spec y libera la reserva (lo que
// borra el contenedor). Con delete_data borra <DATA_ROOT>/<slug> cuando el contenedor ya no existe. Repetirlo (tras
// un corte o una respuesta perdida) no hace nada más.
func (b *backupService) retireMigration(m *mcsmv1.MigrateRetire) error {
	if err := checkMigrationMsg(m.GetServerId(), m.GetSlug(), m.GetMigrationId()); err != nil {
		return err
	}
	id := m.GetServerId()
	sp, err := b.a.st.GetSpec(id)
	if err != nil {
		return err
	}
	if sp != nil && sp.Slug != m.GetSlug() {
		return fmt.Errorf("%w: el servidor tiene otro slug en este nodo (%s)", errBadRequest, sp.Slug)
	}
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	setAside := func() error {
		if m.GetDeleteData() {
			return nil // se borra entero al final, ya sin contenedor
		}
		if _, err := os.Lstat(dir); errors.Is(err, fs.ErrNotExist) {
			return nil
		} else if err != nil {
			return err
		}
		to := filepath.Join(b.a.cfg.DataRoot, backup.MigratedName(dir, b.clock.Now()))
		if err := os.Rename(dir, to); err != nil {
			return fmt.Errorf("apartar %s: %w", dir, err)
		}
		b.a.log.Info("migración confirmada: los datos del origen se conservan", "server", id, "en", to)
		return nil
	}
	if sp != nil {
		if err := b.forgetHeld(id, func() error {
			if err := b.stopForRetire(id); err != nil {
				return err
			}
			return setAside()
		}); err != nil {
			return err
		}
	}
	if err := b.removalDone(id); err != nil {
		return err
	}
	b.a.hub.Reset(id)
	if m.GetDeleteData() {
		if err := os.RemoveAll(dir); err != nil {
			return fmt.Errorf("borrar %s: %w", dir, err)
		}
		return nil
	}
	// Sin spec (reintento tras un corte entre apartar y olvidar): si <slug> sigue ahí, es el de este
	// servidor (el panel no deja crear otro con este slug en el nodo mientras la retirada esté pendiente).
	return setAside()
}

// forgetHeld reserva el servidor, espera a las escrituras de archivos en curso, ejecuta before (si
// hay) con la reserva tomada, olvida la spec (deja lápida) y libera la reserva, lo que para y borra
// su contenedor. Si algo falla antes de olvidar, libera sin más: el servidor sigue como estaba.
func (b *backupService) forgetHeld(id string, before func() error) error {
	ctx := b.a.life
	release, err := b.a.rec.Hold(id, holdMigration)
	if err != nil {
		return err
	}
	if err := b.waitFileWrites(id); err != nil {
		release(ctx)
		return err
	}
	if before != nil {
		if err := before(); err != nil {
			release(ctx)
			return err
		}
	}
	if err := b.a.rec.Forget(id); err != nil {
		release(ctx)
		return err
	}
	release(ctx) // con lápida: completa el borrado del contenedor (o lo deja al reintento de lápidas)
	return nil
}

// waitFileWrites espera, como mucho drainWait, a que terminen las escrituras de archivos que ya
// estaban en curso en el servidor al reservarlo (las nuevas ya responden busy). Ver fileWrites.
func (b *backupService) waitFileWrites(id string) error {
	select {
	case <-b.a.fileWrites.drained(id):
		return nil
	case <-b.clock.Until(b.clock.Now().Add(b.drainWait)):
		return fmt.Errorf("%w: hay operaciones de archivos en curso en el servidor; se reintentará", reconcile.Busy(holdMigration))
	case <-b.a.life.Done():
		return errClosing
	}
}

// removalDone falla con busy si el borrado del contenedor quedó pendiente (lápida): la pasada de
// lápidas lo reintenta y el panel repite la orden.
func (b *backupService) removalDone(id string) error {
	tomb, err := b.a.st.HasTombstone(id)
	if err != nil {
		return err
	}
	if tomb {
		return fmt.Errorf("%w: el contenedor del servidor aún no se ha podido borrar; se reintentará", reconcile.Busy(holdMigration))
	}
	return nil
}

// stopForRetire para el contenedor si sigue en marcha (el panel lo paró en el paso 1, pero alguien
// pudo arrancarlo a mano) y comprueba que se ha parado: nunca se apartan los datos de un servidor
// en marcha.
func (b *backupService) stopForRetire(id string) error {
	ctx := b.a.life
	running, err := b.isRunning(ctx, id)
	if err != nil || !running {
		return err
	}
	c, err := b.a.rec.Container(ctx, id)
	if err != nil {
		return errCheckContainer(err)
	}
	if c != nil {
		if err := b.a.eng.Stop(ctx, c.ID, reconcile.StopTimeout); err != nil && !errors.Is(err, docker.ErrNotFound) {
			return fmt.Errorf("parar el servidor en el origen: %w", err)
		}
	}
	if running, err := b.isRunning(ctx, id); err != nil {
		return err
	} else if running {
		return errors.New("el servidor sigue en marcha en el origen: no se retira")
	}
	return nil
}

  "Copia de seguridad previa (antes de migrar)",
  "Subir la copia al panel",
  "Enviar la copia al destino y restaurarla",
  "Crear el servidor en el destino",
  "Arrancar y comprobar en el destino",
  "Confirmar y retirar el origen",
] as const;

export function stepProgress(step: MigrationStep, fraction = 0): number {
  const [from, to] = MIGRATION_PROGRESS[step - 1]!;
  const f = Number.isFinite(fraction) ? Math.max(0, Math.min(1, fraction)) : 0;
  return Math.min(to - 1, Math.floor(from + (to - from) * f));
}

  let step = 1;
  for (let i = 0; i < MIGRATION_PROGRESS.length; i++) if (progress >= MIGRATION_PROGRESS[i]![0]) step = i + 1;
  return step as MigrationStep;
}

export function stepMessage(step: MigrationStep, detail = ""): string {
  return `Paso ${step}/7 · ${MIGRATION_STEPS[step - 1]}${detail ? `: ${detail}` : ""}`;

    wasRunning: r.was_running === 1, deleteSource: r.delete_source === 1, phase: r.phase,
    sourcePending: r.source_pending === 1, targetPending: r.target_pending === 1, error: r.error,
    createdAt: r.created_at, updatedAt: r.updated_at,
  };
}

export class MigrationsRepo {
  constructor(private db: Db) {}

  private one(sql: string, ...args: string[]): MigrationRow | null {
    return (this.db.prepare(sql).get(...args) as MigrationRow | undefined) ?? null;
  }

  insert(m: NewMigration): MigrationRow {
    const now = nowIso();
    this.db.prepare(`INSERT INTO migrations (id, server_id, source_node_id, target_node_id, source_slug, target_slug, source_version,
        target_version, target_port, target_spec, was_running, delete_source, phase, created_at, updated_at)
      VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 'running', ?, ?)`)
      .run(m.id, m.server_id, m.source_node_id, m.target_node_id, m.source_slug, m.target_slug, m.source_version,
        m.target_version, m.target_port, m.target_spec, m.was_running, m.delete_source, now, now);
    return this.get(m.id)!;
  }

  get(id: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE id = ?", id);
  }

  latestForServer(serverId: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE server_id = ? ORDER BY created_at DESC, id DESC LIMIT 1", serverId);
  }

  openForServer(serverId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${OPEN} ORDER BY created_at DESC LIMIT 1`, serverId);
  }

  listOpen(): MigrationRow[] {
    return this.db.prepare(`SELECT * FROM migrations WHERE phase IN ${OPEN} ORDER BY created_at, id`).all() as unknown as MigrationRow[];
  }

  update(id: string, patch: MigrationPatch): MigrationRow {
    const keys = PATCHABLE.filter((k) => patch[k] !== undefined);
    if (keys.length > 0) {
      this.db.prepare(`UPDATE migrations SET ${keys.map((k) => `${k} = ?`).join(", ")}, updated_at = ? WHERE id = ?`)
        .run(...keys.map((k) => patch[k] as string | number | null), nowIso(), id);
    }
    return this.get(id)!;
  }

  /** Bloquea las acciones del usuario sobre el servidor: pasos en curso o deshaciéndose. */
  blockingServer(serverId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${BLOCKING} ORDER BY created_at DESC LIMIT 1`, serverId);
  }

  /** Bloquea crear servidores en el nodo: destino sin confirmar, u origen con la retirada pendiente (su slug). */
  blockingNodeCreate(nodeId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE (target_node_id = ? AND phase IN ${BLOCKING}) OR (source_node_id = ? AND phase = 'committed')
      ORDER BY created_at LIMIT 1`, nodeId, nodeId);
  }

  /** Bloquea borrar el nodo mientras una migración que lo usa está en curso (deshaciéndose, sí se puede). */
  blockingNodeDelete(nodeId: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE phase = 'running' AND (source_node_id = ? OR target_node_id = ?) ORDER BY created_at LIMIT 1", nodeId, nodeId);
  }

  /** SyncSpecs no retira de `nodeId` un servidor con una migración abierta que pasa por ese nodo. */
  protects(nodeId: string, serverId: string): boolean {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${OPEN} AND (source_node_id = ? OR target_node_id = ?) LIMIT 1`,
      serverId, nodeId, nodeId) !== null;
  }

  /** Al arrancar el panel: lo que estaba en curso pasa a deshacerse, con lo pendiente según lo que llegó a hacer. */
  interruptRunning(message: string): MigrationRow[] {
    const rows = this.db.prepare("SELECT id FROM migrations WHERE phase = 'running' ORDER BY created_at").all() as unknown as { id: string }[];
    const now = nowIso();
    const stmt = this.db.prepare(`UPDATE migrations SET phase = 'rolling_back', target_pending = target_touched, source_pending = was_running,
      error = COALESCE(error, ?), updated_at = ? WHERE id = ? AND phase = 'running'`);
    for (const r of rows) stmt.run(message, now, r.id);
    return rows.map((r) => this.get(r.id)!);
  }

  /**
   * Confirma la migración en UNA transacción: la fila del servidor pasa al destino (nodo, slug, spec, versión, estado
   * deseado y último observado) solo si sigue en el origen con la versión del inicio, y la migración pasa a
   * `committed` con la retirada del origen pendiente. Devuelve false (sin cambiar nada) si la versión cambió o el
   * slug ya está ocupado en el destino.
   */
  commit(m: MigrationRow, desired: "running" | "stopped", observed: ObservedDto | null): boolean {
    const now = nowIso();
    // El Plan 6 (en paralelo) añade servers.imported_from: un servidor migrado ya no sigue a su contenedor original.
    const cols = this.db.prepare("PRAGMA table_info(servers)").all() as unknown as { name: string }[];
    const clearImport = cols.some((c) => c.name === "imported_from") ? ", imported_from = NULL" : "";
    this.db.exec("BEGIN IMMEDIATE");
    try {
      const moved = this.db.prepare(`UPDATE servers SET node_id = ?, slug = ?, spec = ?, spec_version = ?, desired_state = ?,
          observed = ?, observed_spec_version = ?, observed_at = ?, updated_at = ?${clearImport}
        WHERE id = ? AND node_id = ? AND spec_version = ?`)
        .run(m.target_node_id, m.target_slug, m.target_spec, m.target_version, desired,
          observed ? JSON.stringify(observed) : null, m.target_version, observed ? now : null, now,
          m.server_id, m.source_node_id, m.source_version);
      const done = this.db.prepare("UPDATE migrations SET phase = 'committed', source_pending = 1, error = NULL, updated_at = ? WHERE id = ? AND phase = 'running'")
        .run(now, m.id);
      if (Number(moved.changes) !== 1 || Number(done.changes) !== 1) {
        this.db.exec("ROLLBACK");
        return false;
      }
      this.db.exec("COMMIT");
      return true;
    } catch (e) {
      this.db.exec("ROLLBACK");
      if (e instanceof Error && /UNIQUE constraint failed/.test(e.message)) return false;
      throw e;
    }
  }
}

import fp from "fastify-plugin";
import type { FastifyInstance } from "fastify";
import { HttpError } from "../lib/http.js";
import { MigrationsRepo } from "./repo.js";

export type GuardSubject =
  | { kind: "server"; serverId: string }
  | { kind: "create"; nodeId: string }
  | { kind: "deleteNode"; nodeId: string }
  | null;

const READ = new Set(["GET", "HEAD", "OPTIONS"]);
const MIGRATION_ROUTE = "/api/servers/:id/migration";

/**
 * Qué protege la guarda en una petición. Decide por la ruta enrutada (`req.routeOptions.url`), como el guard de
 * sesión, nunca por la URL cruda. Pura.
 * - Cualquier método no GET bajo /api/servers/:id (salvo las rutas de la migración): el servidor.
 * - Crear servidores (POST /api/servers, /api/templates/:id/servers con `nodeId` en el cuerpo, y cualquier
 *   POST /api/nodes/:id/…, como la importación del Plan 6): el nodo.
 * - DELETE /api/nodes/:id: el nodo.
 */
export function guardSubject(method: string, route: string | undefined, params: unknown, body: unknown): GuardSubject {
  if (!route || READ.has(method)) return null;
  const rawId = (params as { id?: unknown } | null | undefined)?.id;
  const id = typeof rawId === "string" && rawId !== "" ? rawId : null;
  if (route === MIGRATION_ROUTE || route.startsWith(`${MIGRATION_ROUTE}/`)) return null;
  if (route === "/api/servers/:id" || route.startsWith("/api/servers/:id/")) return id ? { kind: "server", serverId: id } : null;
  if (route === "/api/servers" || route === "/api/templates/:id/servers") {
    const nodeId = (body as { nodeId?: unknown } | null | undefined)?.nodeId;
    return typeof nodeId === "string" && nodeId !== "" ? { kind: "create", nodeId } : null;
  }
  if (route === "/api/nodes/:id") return method === "DELETE" && id ? { kind: "deleteNode", nodeId: id } : null;
  if (route.startsWith("/api/nodes/:id/") && method === "POST") return id ? { kind: "create", nodeId: id } : null;
  return null;
}

function blockError(app: FastifyInstance, s: NonNullable<GuardSubject>): HttpError | null {
  if (s.kind === "server") {
    const m = app.migrations.blockingServer(s.serverId);
    if (!m) return null;
    const name = app.servers.get(s.serverId)?.name ?? "El servidor";
    return new HttpError(409, m.phase === "running"
      ? `«${name}» se está migrando a otro nodo: espera a que termine (pestaña Migrar)`
      : `Se está deshaciendo una migración fallida de «${name}»: espera a que termine (pestaña Migrar)`);
  }
  const m = s.kind === "create" ? app.migrations.blockingNodeCreate(s.nodeId) : app.migrations.blockingNodeDelete(s.nodeId);
  if (!m) return null;
  return new HttpError(409, `El nodo «${app.nodes.get(s.nodeId)?.name ?? s.nodeId}» participa en una migración en curso: espera a que termine (Jobs)`);
}

/**
 * Decora `app.migrations` y añade la guarda de migraciones: un hook `preHandler` raíz que responde 409 a lo que
 * cambiaría un servidor o un nodo con una migración abierta. Se registra ANTES de las rutas: Fastify fija los hooks
 * de cada contexto al registrarlo, así que un hook raíz añadido después no llegaría a ellas.
 */
export const migrationGuard = fp(async function migrationGuard(app: FastifyInstance) {
  app.decorate("migrations", new MigrationsRepo(app.db));
  app.addHook("preHandler", async (req) => {
    const s = guardSubject(req.method, req.routeOptions.url, req.params, req.body);
    if (!s) return;
    const err = blockError(app, s);
    if (err) throw err;
  });
}, { name: "migration-guard" });

declare module "fastify" {
  interface FastifyInstance { migrations: MigrationsRepo }
}

type Case = NonNullable<Envelope["body"]["case"]>;

/** Nodo de pruebas: alta real en el panel y un agente falso que responde a mano. No descarta mensajes. */
export class FakeNode {
  agent!: FakeAgent;
  private buffer: Envelope[] = [];

  private constructor(readonly url: string, readonly id: string, readonly token: string, readonly name: string) {}

  static async enroll(app: FastifyInstance, url: string, cookie: string, name: string): Promise<FakeNode> {

    const r = (await app.inject({ method: "POST", url: "/agent/enroll", payload: { enrollToken: t, nameHint: name, agentVersion: "fake" } })).json();
    return new FakeNode(url, r.nodeId, r.nodeToken, name);

  /** Conecta, confirma SyncSpecs y contesta al BackupList del Hello. Devuelve el SyncSpecs. */
  async connect(specVersions: Record<string, bigint> = {}): Promise<Envelope> {
    this.buffer = [];
    this.agent = new FakeAgent(this.url, this.token);
    await this.agent.connect({ specVersions });
    const sync = await this.agent.handshake();
    this.ack(await this.next("backupList"));
    return sync;

  async next(c: Case, timeoutMs = 5000): Promise<Envelope> {
    const i = this.buffer.findIndex((e) => e.body.case === c);
    if (i >= 0) return this.buffer.splice(i, 1)[0]!;
    const deadline = Date.now() + timeoutMs;
    for (;;) {
      const left = deadline - Date.now();
      if (left <= 0) throw new Error(`nodo ${this.name}: no llegó ${c}`);
      const e = await this.agent.next(left);
      if (e.body.case === c) return e;
      this.buffer.push(e);
    }
  }

  /** Falla si hay mensajes guardados o llega alguno en `ms`. */
  async nothingFor(ms: number): Promise<void> {
    if (this.buffer.length > 0) throw new Error(`nodo ${this.name}: pendientes ${this.buffer.map((e) => e.body.case).join(", ")}`);
    const e = await this.agent.next(ms).catch(() => null);
    if (e) throw new Error(`nodo ${this.name}: llegó ${e.body.case}`);
  }

  send(env: MessageInitShape<typeof EnvelopeSchema>): void { this.agent.send(env); }
  ack(env: Envelope): void { this.agent.ack(env.id); }
  fail(env: Envelope, code: string, message: string): void {
    this.agent.send({ id: env.id, body: { case: "error", value: { code, message } } });

  }

    this.agent.send({ body: { case: "serverObserved", value: {
      serverId, tsUnixMs: BigInt(Date.now()),
      observed: { state: o.state, health: o.health ?? "", exitCode: o.exitCode ?? 0, appliedVersion: o.appliedVersion ?? 0n, mc: { online: o.online ?? false } },
    } } });
  }

  /** PUT /agent/transfer/:id con el token del nodo. Devuelve el estado HTTP. */
  async put(transferId: string, body: Uint8Array): Promise<number> {
    const r = await fetch(`${this.url}/agent/transfer/${transferId}`, {
      method: "PUT", headers: { authorization: `Bearer ${this.token}`, "content-type": "application/octet-stream" }, body: new Uint8Array(body),
    });
    await r.arrayBuffer();
    return r.status;

  }

/** Margen mínimo libre tras escribir: el mismo que el agente (max(5 %, 256 MiB)). */
export const SPACE_MARGIN_MIN = 256 * 1024 * 1024;
export const requiredSpace = (n: number): number => n + Math.max(Math.floor(n * 0.05), SPACE_MARGIN_MIN);

export interface TargetServer { slug: string; spec: Spec }
export interface ProposalInput {
  slug: string; spec: Spec; targetServers: TargetServer[]; range: { from: number; to: number }; requestedPort?: number;
}
export type Proposal = { ok: true; slug: string; port: number; portChanged: boolean } | { ok: false; error: string };

/** Slug libre entre `taken`: el mismo o con sufijo -2, -3… (máx. 40 caracteres), como al crear un servidor. */
export function uniqueSlugAmong(base: string, taken: ReadonlySet<string>): string {
  if (!taken.has(base)) return base;
  for (let n = 2; ; n++) {
    const suffix = `-${n}`;
    const candidate = base.slice(0, 40 - suffix.length).replace(/-+$/g, "") + suffix;
    if (!taken.has(candidate)) return candidate;
  }
}

/**
 * Slug y puerto de juego del servidor en el destino (spec §7: «puerto nuevo si colisiona»). El puerto pedido se
 * respeta si está libre; si no se pide, el actual si está libre y, si no, el primero libre del rango del panel. Los
 * puertos extra no se cambian solos: si chocan, error. Pura.
 */
export function proposeTarget(i: ProposalInput): Proposal {
  const used = new Set<number>();
  for (const s of i.targetServers) {
    used.add(s.spec.ports.game);
    for (const e of s.spec.ports.extra) used.add(e.host);
  }
  const clash = i.spec.ports.extra.find((e) => used.has(e.host));
  if (clash) {
    return { ok: false, error: `El puerto extra ${clash.host} (${clash.label || clash.proto}) ya lo usa otro servidor del nodo destino: cámbialo antes de migrar` };
  }
  const extras = new Set(i.spec.ports.extra.map((e) => e.host));
  let port: number | undefined;
  if (i.requestedPort !== undefined) {
    if (used.has(i.requestedPort) || extras.has(i.requestedPort)) return { ok: false, error: `El puerto ${i.requestedPort} ya está en uso en el nodo destino` };
    port = i.requestedPort;
  } else if (!used.has(i.spec.ports.game)) {
    port = i.spec.ports.game;
  } else {
    for (let p = i.range.from; p <= i.range.to && port === undefined; p++) if (!used.has(p) && !extras.has(p)) port = p;
    if (port === undefined) return { ok: false, error: `No quedan puertos libres entre ${i.range.from} y ${i.range.to} en el nodo destino` };
  }
  const slug = uniqueSlugAmong(i.slug, new Set(i.targetServers.map((s) => s.slug)));
  return { ok: true, slug, port, portChanged: port !== i.spec.ports.game };
}

/** Nombre de la copia en el destino: el mismo con el slug del destino (el agente exige `<slug>-<ts>-<v>.tar.zst`). */
export function retargetFilename(filename: string, fromSlug: string, toSlug: string): string {
  if (!filename.startsWith(`${fromSlug}-`)) throw new Error(`La copia ${filename} no es del servidor ${fromSlug}`);
  return toSlug + filename.slice(fromSlug.length);
}

import type { FastifyInstance } from "fastify";
import type { Envelope } from "@mcsm/proto";
import { observedToDto } from "../agents/service.js";
import type { Timers } from "../files/stream.js";
import type { JobDto } from "../jobs/repo.js";
import { FINAL_STATES } from "../jobs/service.js";
import type { ObservedDto } from "../servers/repo.js";
import { StepError } from "./errors.js";

export interface Waiter<T> { promise: Promise<T>; cancel(): void }

/** Escucha los mensajes no solicitados de los agentes (los mismos que despacha AgentService). */
export function onAgentMessage(agents: EventEmitter, fn: (nodeId: string, env: Envelope) => void): () => void {
  agents.on("message", fn);
  return () => { agents.off("message", fn); };
}

/**
 * Espera a que el job termine (ok, failed o cancelled). `onProgress` recibe cada avance; sin avances durante `idleMs`
 * rechaza con `idleMessage`. Mira también el estado actual: si ya terminó, resuelve enseguida.
 */
export function waitJob(app: FastifyInstance, jobId: string, opts: { idleMs: number; timers: Timers; idleMessage: string; onProgress?: (j: JobDto) => void }): Waiter<JobDto> {
  let off = () => {};
  let disarm = () => {};
  const promise = new Promise<JobDto>((resolve, reject) => {
    const settle = (fn: () => void) => { off(); disarm(); fn(); };
    const arm = () => {
      disarm();
      disarm = opts.timers.set(() => settle(() => reject(new StepError(opts.idleMessage))), opts.idleMs);
    };
    const h = (j: JobDto) => {
      if (j.id !== jobId) return;
      if (FINAL_STATES.has(j.status)) settle(() => resolve(j));
      else {
        opts.onProgress?.(j);
        arm();
      }
    };
    app.events.on("job", h);
    off = () => { app.events.off("job", h); };
    arm();
    const now = app.jobs.get(jobId);
    if (now && FINAL_STATES.has(now.status)) settle(() => resolve(now));
  });
  promise.catch(() => {});
  return { promise, cancel: () => { off(); disarm(); } };
}

/**
 * Espera a que el servidor quede sano en el nodo: `running` con healthcheck `healthy` o ping SLP correcto. Un
 * `exited`/`dead` rechaza al instante; si vence `timeoutMs`, también. Hay que crearlo ANTES de ordenar el arranque.
 */
export function waitObserved(agents: EventEmitter, nodeId: string, serverId: string, opts: { timeoutMs: number; timers: Timers; onObserved?: (o: ObservedDto) => void }): Waiter<ObservedDto> {
  let off = () => {};
  let disarm = () => {};
  const promise = new Promise<ObservedDto>((resolve, reject) => {
    const settle = (fn: () => void) => { off(); disarm(); fn(); };
    off = onAgentMessage(agents, (from, env) => {
      if (from !== nodeId || env.body.case !== "serverObserved" || env.body.value.serverId !== serverId) return;
      const o = observedToDto(env.body.value.observed);
      opts.onObserved?.(o);
      if (o.state === "running" && (o.health === "healthy" || o.mc.online)) settle(() => resolve(o));
      else if (o.state === "exited" || o.state === "dead") {
        settle(() => reject(new StepError(`El servidor se paró en el destino (código de salida ${o.exitCode})${o.error ? `: ${o.error}` : ""}`)));
      }
    });
    const minutes = Math.round(opts.timeoutMs / 60_000);
    disarm = opts.timers.set(() => settle(() => reject(new StepError(`El servidor no quedó sano en el destino en ${minutes} min (healthcheck o ping)`))), opts.timeoutMs);
  });
  promise.catch(() => {});
  return { promise, cancel: () => { off(); disarm(); } };
}

import { stepMessage, stepProgress, type MigrationStep } from "@mcsm/shared";
import type { JobService } from "../jobs/service.js";

/** Cómo cuentan los pasos su avance. En producción, el job de la migración (JobReporter). */
export interface Reporter {
  /** Empieza el paso n: progreso al inicio de su tramo, mensaje y una línea en el log. */
  step(n: MigrationStep, detail: string): void;
  /** Avance dentro del paso (fracción 0-1). Solo escribe si cambia el porcentaje o el texto. */
  within(n: MigrationStep, fraction: number, detail: string): void;
  /** Cambia el mensaje sin tocar el progreso (p. ej. «deshaciendo»). */
  message(n: MigrationStep, detail: string): void;
  log(line: string): void;
}

/** Reporter sobre el job `migrate`: cada cambio emite el evento `job` (la web lo ve en vivo, topic `jobs`). */
export class JobReporter implements Reporter {
  private last = { progress: -1, message: "" };

  constructor(private jobs: JobService, private jobId: string) {}

  step(n: MigrationStep, detail: string): void {
    const progress = stepProgress(n);
    const message = stepMessage(n, detail);
    this.last = { progress, message };
    this.jobs.update(this.jobId, { progress, message, logChunk: `${message}\n` });
  }

  within(n: MigrationStep, fraction: number, detail: string): void {
    const progress = stepProgress(n, fraction);
    const message = stepMessage(n, detail);
    if (progress === this.last.progress && message === this.last.message) return;
    this.last = { progress, message };
    this.jobs.update(this.jobId, { progress, message });
  }

  message(n: MigrationStep, detail: string): void {
    const message = stepMessage(n, detail);
    this.last = { ...this.last, message };
    this.jobs.update(this.jobId, { message });
  }

  log(line: string): void {
    this.jobs.update(this.jobId, { logChunk: `${line}\n` });
  }
}

    if (job.status !== "ok") throw new StepError(`La copia previa falló: ${job.message}`);
    const got = made as BackupMade | null;
    if (!got) throw new StepError("La copia se hizo pero el panel no recibió su aviso (BackupCreated): vuelve a intentarlo");
    if (!got.sha256) throw new StepError("La copia no tiene sha256: no se migra sin poder comprobarla");
    d.report.log(`Copia ${got.filename}: ${fmtBytes(got.sizeBytes)}, sha256 ${got.sha256}`);
    return got;
  } finally {
    offCreated();
    wait.cancel();
  }
}

/**
 * Paso 3. El origen sube la copia (BackupPush → PUT /agent/transfer) al staging del panel. Se comprueba antes el
 * espacio del panel y, al llegar, el tamaño exacto y el sha256 (frente al BackupCreated y al BackupPushResult). Si algo
 * falla, no queda nada en el staging.
 */
export async function pushToPanel(d: StepDeps, m: MigrationRow, made: BackupMade): Promise<Pushed> {
  const { app } = d;
  const free = await d.timings.freeSpace(app.config.dataDir).catch(() => null);
  if (free !== null && free < requiredSpace(made.sizeBytes)) {
    throw new StepError(`No hay espacio en el panel para la copia: hacen falta ${fmtBytes(requiredSpace(made.sizeBytes))} y quedan ${fmtBytes(free)} libres`);
  }
  const conn = connOf(app, m.source_node_id);
  const t = app.transfers.inbound(m.source_node_id);
  const req = conn.request({ case: "backupPush", value: { serverId: m.server_id, filename: made.filename, transferId: t.id } }, NO_DEADLINE_MS);
  req.catch(() => {});
  let staged: StagedFile | null = null;
  try {
    const incoming = await Promise.race([
      t.incoming,
      req.then((): never => { throw new StepError("El nodo origen terminó sin enviar la copia"); }),
    ]);
    if (incoming.size !== null && incoming.size !== made.sizeBytes) {
      throw new StepError(`El nodo origen envía ${incoming.size} bytes y la copia mide ${made.sizeBytes}`);
    }
    const hash = createHash("sha256");
    let received = 0;
    const meter = new Transform({
      transform(chunk: Buffer, _enc, cb) {
        hash.update(chunk);
        received += chunk.length;
        d.report.within(3, received / Math.max(made.sizeBytes, 1), `subiendo (${fmtBytes(received)} de ${fmtBytes(made.sizeBytes)})`);
        cb(null, chunk);
      },
    });
    const guard = idleGuard(IDLE_TIMEOUT_MS, () => {
      t.cancel("el nodo origen dejó de enviar la copia");
      return new StepError("El nodo origen dejó de enviar la copia");
    }, d.timers);
    const src = pipeline(incoming.stream, guard, meter, () => { /* el resultado lo ve save */ });
    staged = await app.staging.save(stagingId(m.id), src, { maxBytes: made.sizeBytes });
    const res = await req;
    if (res.body.case !== "backupPushResult") throw new StepError("Respuesta inesperada del nodo origen");
    const digest = hash.digest("hex");
    if (staged.size !== made.sizeBytes || digest !== made.sha256 || res.body.value.sha256 !== made.sha256) {
      throw new StepError(`La copia llegó al panel dañada: sha256 ${digest}, esperado ${made.sha256}`);
    }
    d.report.log(`Copia en el panel: ${fmtBytes(staged.size)}, sha256 verificado`);
    return { staged, dataBytes: Number(res.body.value.dataBytes) };
  } catch (e) {
    t.cancel("migración fallida");
    if (staged) await app.staging.remove(staged).catch(() => {});
    throw e;
  }
}

/**
 * Paso 4. El destino recibe la copia desde el staging (MigrateReceive → GET /agent/transfer) y la restaura, como
 * sub-job `migrate_in`. `target_touched` se marca ANTES de pedirlo: a partir de aquí, deshacer exige MigrateAbort. Un
 * fallo del job (o una orden sin respuesta) se reintenta una vez tras limpiar el intento anterior; un rechazo
 * explícito del agente (exists, too_large…) no.
 */
export async function receiveOnTarget(d: StepDeps, m: MigrationRow, pushed: Pushed, made: BackupMade): Promise<void> {
  const { app } = d;
  app.migrations.update(m.id, { target_touched: 1 });
  const filename = retargetFilename(made.filename, m.source_slug, m.target_slug);
  let last = "";
  for (let attempt = 1; attempt <= d.timings.receiveAttempts; attempt++) {
    if (attempt > 1) {
      d.report.log(`Reintentando la recepción en el destino (intento ${attempt} de ${d.timings.receiveAttempts})`);
      await abortTarget(d, m).catch((e) => d.report.log(`No se pudo limpiar el intento anterior: ${errorText(e)}`));
    }
    const conn = connOf(app, m.target_node_id);
    const jobId = newId();
    app.jobs.create({
      id: jobId, type: "migrate_in", serverId: m.server_id, nodeId: m.target_node_id, status: "running",
      message: "Solicitando la recepción de la copia", payload: { migrationId: m.id },
    });
    const out = app.transfers.outbound(m.target_node_id, app.staging.source(pushed.staged, { removeAfter: false }));
    out.done.catch(() => {});
    const wait = waitJob(app, jobId, {
      idleMs: d.timings.jobIdleMs, timers: d.timers, idleMessage: "La recepción en el destino lleva demasiado tiempo sin avanzar",
      onProgress: (j) => d.report.within(4, j.progress / 100, j.message || "recibiendo"),
    });
    try {
      try {
        await conn.request({ case: "migrateReceive", value: {
          serverId: m.server_id, slug: m.target_slug, jobId, migrationId: m.id, transferId: out.id, filename,
          sizeBytes: BigInt(made.sizeBytes), sha256: made.sha256, dataBytes: BigInt(pushed.dataBytes),
        } }, 30_000);
      } catch (e) {
        app.jobs.finish(jobId, "failed", errorText(e));
        if (!isDoubtful(e)) throw new StepError(`El nodo destino rechazó la copia: ${errorText(e)}`);
        last = errorText(e);
        continue;
      }
      const job = await wait.promise;
      if (job.status === "ok") {
        d.report.log("Copia recibida, verificada (sha256) y restaurada en el destino");
        return;
      }
      last = job.message;
    } finally {
      out.cancel("recepción terminada"); // sin efecto si ya terminó
      wait.cancel();
    }
  }
  throw new StepError(`La recepción en el destino falló: ${last}`);
}

/** Paso 5. El destino guarda la spec (slug y puerto del destino, versión +1) con el servidor parado. */
export async function applyOnTarget(d: StepDeps, m: MigrationRow): Promise<void> {
  const row = d.app.servers.get(m.server_id);
  if (!row) throw new StepError("El servidor ya no existe en el panel");
  const conn = connOf(d.app, m.target_node_id);

  } catch (e) {
    throw new StepError(`El nodo destino no pudo crear el servidor: ${errorText(e)}`);
  }
  d.report.log(`Servidor creado en el destino (slug ${m.target_slug}, puerto ${m.target_port}, versión ${m.target_version})`);
}

/**
 * Paso 6. Arranca en el destino y espera a que quede sano (como mucho `verifyTimeoutMs`). `target_started` se marca
 * ANTES de la orden: si algo falla desde aquí, el origen no se rearranca hasta haber retirado la copia del destino.
 */
export async function startAndVerify(d: StepDeps, m: MigrationRow): Promise<ObservedDto> {
  d.app.migrations.update(m.id, { target_started: 1 });
  const conn = connOf(d.app, m.target_node_id);
  const w = waitObserved(d.app.agents, m.target_node_id, m.server_id, {
    timeoutMs: d.timings.verifyTimeoutMs, timers: d.timers,
    onObserved: (o) => d.report.within(6, 0.5, `estado ${o.state}${o.health ? `, healthcheck ${o.health}` : ""}`),
  });
  try {
    await conn.request({ case: "powerAction", value: { serverId: m.server_id, action: PowerActionType.START } }, 90_000);
  } catch (e) {
    w.cancel();
    throw new StepError(`El servidor no arrancó en el destino: ${errorText(e)}`);
  }
  d.report.within(6, 0.2, `esperando a que arranque y responda (máx. ${Math.round(d.timings.verifyTimeoutMs / 60_000)} min)`);
  const o = await w.promise;
  d.report.log(`El servidor responde en el destino (${o.health === "healthy" ? "healthcheck sano" : "ping correcto"})`);
  return o;
}

/** Paso 6 (si estaba parado). Lo vuelve a parar en el destino tras comprobarlo. */
export async function stopTarget(d: StepDeps, m: MigrationRow): Promise<void> {
  try {
    await connOf(d.app, m.target_node_id).request({ case: "powerAction", value: { serverId: m.server_id, action: PowerActionType.STOP } }, 90_000);
  } catch (e) {
    throw new StepError(`No se pudo volver a parar el servidor en el destino: ${errorText(e)}`);
  }
}

/** Paso 7 (tras el commit). Retira el servidor del origen: <slug>.migrated-<ts> o borrado con «borrar origen». */

  } }, LONG_MS);
}

/** Deshacer: borra del destino la spec, el contenedor y el directorio marcado de esta migración. */

/** Deshacer: vuelve a arrancar el servidor en el origen (estado deseado `running` en el agente y en la fila). */
export async function restartSource(d: StepDeps, m: MigrationRow): Promise<void> {
  await d.app.serversService.power(m.server_id, "start");
}

import type { FastifyInstance } from "fastify";
import type { Envelope } from "@mcsm/proto";
import {
  formatZodError, MIGRATION_STEPS, migrationProposalQuerySchema, migrationRequestSchema, specSchema, stepMessage,
  type MigrationDto, type MigrationProposalDto, type MigrationStep, type Spec,
} from "@mcsm/shared";
import { realTimers, type Timers } from "../files/stream.js";
import type { JobDto } from "../jobs/repo.js";
import { HttpError } from "../lib/http.js";
import type { ObservedDto, ServerRow } from "../servers/repo.js";
import type { StagedFile } from "../transfers/staging.js";
import { errorText, isKnownError, StepError } from "./errors.js";
import { proposeTarget, type TargetServer } from "./propose.js";
import { toMigrationDto, type MigrationRow } from "./repo.js";
import { JobReporter, type Reporter } from "./report.js";
import {
  abortTarget, applyOnTarget, backupSource, DEFAULT_TIMINGS, pushToPanel, receiveOnTarget, restartSource, retireSource,
  startAndVerify, stopSource, stopTarget, type MigrationTimings, type StepDeps,
} from "./steps.js";

/** Cada cuánto se reintenta lo pendiente (deshacer, retirar el origen), además de tras cada Hello. */
export const PENDING_EVERY_MS = 30_000;
export const INTERRUPTED = "interrumpido: el panel se reinició durante la migración";

interface Plan {
  target: { id: string; name: string }; slug: string; port: number; portChanged: boolean; currentPort: number; spec: Spec;
}

const silent = (log: (line: string) => void): Reporter => ({ step: () => {}, within: () => {}, message: () => {}, log });

/**
 * Migración entre nodos (spec §7 MigrationService): job `migrate` de 7 pasos, orquestado aquí, sobre la tabla
 * `migrations` (estado duradero: qué falta deshacer o retirar si el panel se reinicia o un nodo cae).
 */
export class MigrationService {
  /** Temporizadores de las esperas (los tests ponen ManualTimers). */
  timers: Timers = realTimers;
  timings: MigrationTimings = { ...DEFAULT_TIMINGS };
  /** Migraciones con trabajo en curso en este proceso (pasos o pendientes): nunca dos tareas a la vez sobre una. */
  private busy = new Set<string>();
  private tick: NodeJS.Timeout | undefined;

  constructor(private app: FastifyInstance) {}

  start(): void {
    // Tras el Hello de un nodo, lo pendiente con él (las peticiones esperan solas al Ack de SyncSpecs).
    this.app.agents.on("message", (nodeId: string, env: Envelope) => {
      if (env.body.case === "hello") void this.runPending(nodeId);
    });
  }

  /** Al arrancar el panel: lo que estaba en curso pasa a deshacerse; lo pendiente se reintenta cada 30 s. */
  async recover(): Promise<void> {
    const rows = this.app.migrations.interruptRunning(INTERRUPTED);
    if (rows.length > 0) this.app.log.warn({ count: rows.length }, "migraciones interrumpidas por el reinicio del panel: se deshacen");
    if (!this.tick) {
      this.tick = setInterval(() => void this.runPending(), PENDING_EVERY_MS);
      this.tick.unref();
    }
    await this.runPending();
  }

  close(): void {
    clearInterval(this.tick);
    this.tick = undefined;
  }

  latest(serverId: string): { migration: MigrationDto | null } {
    this.requireServer(serverId);
    const m = this.app.migrations.latestForServer(serverId);
    return { migration: m ? toMigrationDto(m) : null };
  }

  proposal(serverId: string, query: unknown): MigrationProposalDto {
    const q = migrationProposalQuerySchema.parse(query);
    const p = this.plan(this.requireServer(serverId), q.targetNodeId, q.port);
    return { targetNodeId: p.target.id, slug: p.slug, port: p.port, currentPort: p.currentPort, portChanged: p.portChanged };
  }

  /** Valida y lanza la migración. Devuelve el job (202); el avance va por el topic `jobs`. */
  begin(serverId: string, body: unknown): JobDto {
    const input = migrationRequestSchema.parse(body);
    const row = this.requireServer(serverId);
    const p = this.plan(row, input.targetNodeId, input.port);
    const sourceName = this.nodeName(row.node_id);
    if (!this.app.agents.get(row.node_id)) throw new HttpError(409, `El nodo origen «${sourceName}» está desconectado`);
    if (!this.app.agents.get(p.target.id)) throw new HttpError(409, `El nodo destino «${p.target.name}» está desconectado`);
    // Sin await entre las comprobaciones y el insert: dos peticiones a la vez no lanzan dos migraciones.
    const wasRunning = row.desired_state === "running";
    const job = this.app.jobs.create({
      type: "migrate", serverId, nodeId: row.node_id, status: "running", message: stepMessage(1, "preparando"),
      payload: { targetNodeId: p.target.id, targetNodeName: p.target.name, sourceNodeName: sourceName, slug: p.slug, port: p.port, deleteSource: input.deleteSource, wasRunning },
    });
    this.app.migrations.insert({
      id: job.id, server_id: serverId, source_node_id: row.node_id, target_node_id: p.target.id, source_slug: row.slug, target_slug: p.slug,
      source_version: row.spec_version, target_version: row.spec_version + 1, target_port: p.port, target_spec: JSON.stringify(p.spec),
      was_running: wasRunning ? 1 : 0, delete_source: input.deleteSource ? 1 : 0,
    });
    void this.run(job.id);
    return job;
  }

  /** Reintenta lo pendiente (de un nodo, o de todos): deshacer o retirar el origen. */
  async runPending(nodeId?: string): Promise<void> {
    for (const m of this.app.migrations.listOpen()) {
      if (m.phase === "running" || this.busy.has(m.id)) continue;
      if (nodeId && m.source_node_id !== nodeId && m.target_node_id !== nodeId) continue;
      this.busy.add(m.id);
      try {
        await this.settle(m.id, (line) => this.app.log.info({ migrationId: m.id, serverId: m.server_id }, line));
      } catch (e) {
        this.app.log.warn({ err: e, migrationId: m.id }, "fallo reintentando lo pendiente de una migración");
      } finally {
        this.busy.delete(m.id);
      }
    }
  }

  // Internos

  private requireServer(id: string): ServerRow {
    const row = this.app.servers.get(id);
    if (!row) throw new HttpError(404, "Servidor no encontrado");
    return row;
  }

  private nodeName(id: string): string {
    return this.app.nodes.get(id)?.name ?? "otro nodo";
  }

  private deps(report: Reporter): StepDeps {
    return { app: this.app, timers: this.timers, timings: this.timings, report };
  }

  /** Comprueba que se puede migrar y calcula slug, puerto y spec en el destino. Lanza HttpError. */
  private plan(row: ServerRow, targetNodeId: string, port?: number): Plan {
    if (targetNodeId === row.node_id) throw new HttpError(400, "El servidor ya está en ese nodo");
    const target = this.app.nodes.get(targetNodeId);
    if (!target) throw new HttpError(404, "Nodo destino no encontrado");
    const open = this.app.migrations.openForServer(row.id);
    if (open) throw new HttpError(409, this.openMessage(open));
    const spec = JSON.parse(row.spec) as Spec;
    // dataPath (Plan 6): los datos están fuera de DATA_ROOT y el agente no puede copiarlos ni restaurarlos.
    if ((spec as unknown as Record<string, unknown>).dataPath) {
      throw new HttpError(409, `Los datos de «${row.name}» están fuera de DATA_ROOT (dataPath, servidor importado) y el agente no puede copiarlos: muévelos a <DATA_ROOT>/${row.slug}/data del nodo y quita dataPath antes de migrarlo`);
    }
    const targetServers: TargetServer[] = this.app.servers.list(targetNodeId).map((r) => ({ slug: r.slug, spec: JSON.parse(r.spec) as Spec }));
    // Lo que ya reservan otras migraciones sin confirmar hacia ese nodo.
    for (const m of this.app.migrations.listOpen()) {
      if (m.target_node_id === targetNodeId && m.phase !== "committed" && m.server_id !== row.id) {
        targetServers.push({ slug: m.target_slug, spec: JSON.parse(m.target_spec) as Spec });
      }
    }
    const p = proposeTarget({ slug: row.slug, spec, targetServers, range: this.app.config.gamePortRange, requestedPort: port });
    if (!p.ok) throw new HttpError(409, p.error);
    const parsed = specSchema.safeParse({ ...spec, ports: { ...spec.ports, game: p.port } });
    if (!parsed.success) throw new HttpError(400, formatZodError(parsed.error));
    return { target: { id: target.id, name: target.name }, slug: p.slug, port: p.port, portChanged: p.portChanged, currentPort: spec.ports.game, spec: parsed.data };
  }

  private openMessage(m: MigrationRow): string {
    if (m.phase === "running") return "Ya hay una migración en curso de este servidor";
    if (m.phase === "rolling_back") {
      const parts = [m.target_pending ? `limpiar «${this.nodeName(m.target_node_id)}»` : "", m.source_pending ? `arrancar en «${this.nodeName(m.source_node_id)}»` : ""].filter(Boolean);
      return `Se está deshaciendo una migración anterior (pendiente: ${parts.join(" y ")}); espera a que vuelvan los nodos`;
    }
    return `La migración anterior aún tiene que retirar el servidor del nodo «${this.nodeName(m.source_node_id)}»; espera a que vuelva a conectar`;
  }

  private async run(id: string): Promise<void> {
    this.busy.add(id);
    const report = new JobReporter(this.app.jobs, id);
    const d = this.deps(report);
    let step: MigrationStep = 1;
    let staged: StagedFile | null = null;
    try {
      try {
        const m = this.app.migrations.get(id)!;
        report.step(1, m.was_running ? "parando el servidor" : "comprobando que está parado");
        await stopSource(d, m);
        step = 2;
        report.step(2, "pidiendo la copia al nodo origen");
        const made = await backupSource(d, m);
        step = 3;
        report.step(3, made.filename);
        const pushed = await pushToPanel(d, m, made);
        staged = pushed.staged;
        step = 4;
        report.step(4, `enviando la copia a «${this.nodeName(m.target_node_id)}»`);
        await receiveOnTarget(d, m, pushed, made);
        await this.app.staging.remove(pushed.staged);
        staged = null;
        step = 5;
        report.step(5, `slug ${m.target_slug}, puerto ${m.target_port}, versión ${m.target_version}`);
        await applyOnTarget(d, m);
        step = 6;
        report.step(6, "arrancando");
        let observed: ObservedDto | null = await startAndVerify(d, m);
        if (!m.was_running) {
          report.within(6, 0.9, "estaba parado: se vuelve a parar");
          await stopTarget(d, m);
          observed = null; // el próximo ServerObserved del destino lo rellena
        }
        step = 7;
        report.step(7, "confirmando el cambio de nodo");
        this.commit(id, observed);
      } catch (e) {
        if (staged) await this.app.staging.remove(staged).catch(() => {});
        await this.rollback(id, step, e, report);
        return;
      }
      await this.finishCommitted(id, report);
    } catch (e) {
      // Ni rollback ni finishCommitted deberían lanzar; si pasa, que no quede un rechazo sin manejar.
      this.app.log.error({ err: e, migrationId: id }, "fallo inesperado gestionando una migración");
    } finally {
      this.busy.delete(id);
    }
  }

  /** Commit: la fila pasa al destino en una transacción (si la versión no cambió). Después, inventario del destino. */
  private commit(id: string, observed: ObservedDto | null): void {
    const m = this.app.migrations.get(id)!;
    if (!this.app.migrations.commit(m, m.was_running ? "running" : "stopped", observed)) {
      throw new StepError("No se pudo confirmar: la configuración del servidor cambió durante la migración, o su slug o su puerto dejaron de estar libres en el destino");
    }
    if (observed) this.app.events.emit("observed", m.server_id, observed);
    // El destino da de alta la copia pre_migration recibida; las del origen se dan por borradas (ya no son gestionables).
    void this.app.backupsService.sync(m.target_node_id);
  }

  private async finishCommitted(id: string, report: Reporter): Promise<void> {
    report.within(7, 0.5, "retirando el servidor del nodo origen");
    const m = await this.settle(id, (line) => report.log(line));
    const name = this.app.servers.get(m.server_id)?.name ?? "El servidor";
    const where = `«${name}» está en «${this.nodeName(m.target_node_id)}», puerto ${m.target_port}`;
    const kept = m.delete_source ? "sus datos se borrarán" : `sus datos quedarán en ${m.source_slug}.migrated-…`;
    this.app.jobs.finish(id, "ok", m.phase === "done"
      ? `Migración completada: ${where}`
      : `Migración completada: ${where}. El nodo «${this.nodeName(m.source_node_id)}» no respondió: el servidor se retirará de allí (${kept}) cuando vuelva a conectar`);
  }

  private async rollback(id: string, step: MigrationStep, err: unknown, report: Reporter): Promise<void> {
    const msg = errorText(err);
    if (!isKnownError(err)) this.app.log.error({ err, migrationId: id }, "fallo inesperado en una migración");
    report.log(`ERROR en el paso ${step}: ${msg}`);
    report.message(step, "deshaciendo la migración");
    const cur = this.app.migrations.get(id)!;
    this.app.migrations.update(id, { phase: "rolling_back", error: `Paso ${step}: ${msg}`, target_pending: cur.target_touched, source_pending: cur.was_running });
    const m = await this.settle(id, (line) => report.log(line));
    this.app.jobs.finish(id, "failed", `Paso ${step}/7 (${MIGRATION_STEPS[step - 1]}): ${msg}. ${this.originText(m)}`);
  }

  private originText(m: MigrationRow): string {
    const src = this.nodeName(m.source_node_id);
    const dst = this.nodeName(m.target_node_id);
    if (m.phase === "failed") {
      return m.was_running ? `El servidor sigue en «${src}» con su mundo intacto y se ha vuelto a arrancar` : `El servidor sigue en «${src}» con su mundo intacto (parado, como estaba)`;
    }
    if (m.source_pending && m.target_pending && m.target_started) {
      return `El servidor sigue en «${src}» con su mundo intacto, pero parado: se arrancará cuando «${dst}» vuelva y se haya retirado la copia de allí (para no tener dos servidores vivos con el mismo mundo)`;
    }
    const parts: string[] = [];
    if (m.target_pending) parts.push(`la copia a medias de «${dst}» se borrará cuando vuelva a conectar`);
    if (m.source_pending) parts.push(`se volverá a arrancar cuando «${src}» vuelva a conectar`);
    return `El servidor sigue en «${src}» con su mundo intacto; ${parts.join("; ")}`;
  }

  /**
   * Intenta lo pendiente de una migración que se deshace o ya se confirmó y devuelve la fila resultante. Deshacer:
   * primero el destino (MigrateAbort) y después el origen; si el destino llegó a arrancarse y no se ha podido
   * limpiar, el origen NO se arranca (nunca dos servidores vivos con el mismo mundo). Confirmada: MigrateRetire.
   */
  private async settle(id: string, log: (line: string) => void): Promise<MigrationRow> {
    const repo = this.app.migrations;
    const d = this.deps(silent(log));
    let m = repo.get(id)!;
    if (m.phase === "rolling_back") {
      if (m.target_pending) {
        try {
          await abortTarget(d, m);
          m = repo.update(id, { target_pending: 0 });
          log(`Destino limpio: se borró lo que la migración dejó en «${this.nodeName(m.target_node_id)}»`);
        } catch (e) {
          log(`No se pudo limpiar el destino: ${errorText(e)} (se reintentará)`);
        }
      }
      if (m.source_pending && !(m.target_started && m.target_pending)) {
        try {
          await restartSource(d, m);
          m = repo.update(id, { source_pending: 0 });
          log(`Servidor arrancado de nuevo en «${this.nodeName(m.source_node_id)}»`);
        } catch (e) {
          log(`No se pudo volver a arrancar el servidor en el origen: ${errorText(e)} (se reintentará)`);
        }
      }
      if (!m.target_pending && !m.source_pending) m = repo.update(id, { phase: "failed" });
    } else if (m.phase === "committed") {
      try {
        await retireSource(d, m);

import { MIGRATION_STEPS, OPEN_PHASES, stepOfProgress, type MigrationDto, type MigrationProposalDto, type MigrationRequestInput } from "@mcsm/shared";
import type { JobDto, NodeDto } from "./api";
import { isActive } from "./jobs";

export const migrationKey = (serverId: string) => ["migration", serverId] as const;
export const proposalKey = (serverId: string, targetNodeId: string) => ["migration-proposal", serverId, targetNodeId] as const;

export interface TargetOption { id: string; label: string; disabled: boolean }

/** Nodos a los que se puede migrar: todos menos el actual; los desconectados aparecen deshabilitados. */
export function targetOptions(nodes: NodeDto[] | undefined, currentNodeId: string): TargetOption[] {
  return (nodes ?? []).filter((n) => n.id !== currentNodeId).map((n) => ({
    id: n.id, label: n.status === "online" ? n.name : `${n.name} (desconectado)`, disabled: n.status !== "online",
  }));
}

/** Job de migración en curso del servidor (la lista viene de los más nuevos a los más antiguos). */
export const activeMigrationJob = (jobs: JobDto[] | undefined): JobDto | undefined => jobs?.find((j) => j.type === "migrate" && isActive(j));
/** Último job de migración del servidor, terminado o no. */
export const lastMigrationJob = (jobs: JobDto[] | undefined): JobDto | undefined => jobs?.find((j) => j.type === "migrate");

/** "" = el puerto que propone el panel; un número 1-65535; null si no es un puerto. */
export function parsePortInput(s: string): number | undefined | null {
  const t = s.trim();
  if (t === "") return undefined;
  if (!/^\d{1,5}$/.test(t)) return null;
  const n = Number(t);
  return n >= 1 && n <= 65535 ? n : null;
}

export function migrationBody(targetNodeId: string, port: number | undefined, deleteSource: boolean): MigrationRequestInput {
  return port === undefined ? { targetNodeId, deleteSource } : { targetNodeId, port, deleteSource };
}

/** Texto bajo el campo del puerto. */
export function portHint(p: MigrationProposalDto | undefined, typed: number | undefined | null): string {
  if (typed === null) return "Escribe un puerto entre 1 y 65535, o déjalo vacío para usar el propuesto.";
  if (typed !== undefined) return `Se usará el puerto ${typed}.`;
  if (!p) return "Elige primero el nodo destino.";
  return p.portChanged
    ? `Propuesto: ${p.port} (el ${p.currentPort} está ocupado en el destino). Escribe otro para cambiarlo.`
    : `Propuesto: ${p.port}, el mismo que ahora. Escribe otro para cambiarlo.`;
}

/** Por qué no se puede migrar ahora (null = se puede). */
export function migrateBlockedReason(o: {
  sourceOnline: boolean | undefined; active: JobDto | undefined; migration: MigrationDto | null | undefined;
  target: TargetOption | undefined; portInvalid: boolean; proposalError: string | null;
}): string | null {
  if (o.active) return "Ya hay una migración en curso";
  if (o.migration && OPEN_PHASES.has(o.migration.phase)) return "La migración anterior aún tiene pasos pendientes";
  if (o.sourceOnline === false) return "El nodo actual está desconectado";
  if (!o.target) return "Elige el nodo destino";
  if (o.target.disabled) return "El nodo destino está desconectado";
  if (o.portInvalid) return "El puerto debe ser un número entre 1 y 65535";
  if (o.proposalError) return o.proposalError;
  return null;
}

export type StepState = "done" | "current" | "failed" | "pending";

/** Estado de cada uno de los 7 pasos según el job: el paso en curso sale de su progreso. */
export function stepStates(job: Pick<JobDto, "progress" | "status">): StepState[] {
  const cur = job.status === "ok" ? MIGRATION_STEPS.length + 1 : stepOfProgress(job.progress);
  const failed = job.status === "failed" || job.status === "cancelled";
  return MIGRATION_STEPS.map((_, i) => {
    const n = i + 1;
    if (n < cur) return "done";
    if (n === cur) return failed ? "failed" : "current";
    return "pending";
  });
}

/** Lo que queda pendiente de una migración abierta, o null si no hay nada que contar. */
export function pendingText(m: MigrationDto, nodeName: (id: string) => string): string | null {
  const src = nodeName(m.sourceNodeId);
  const dst = nodeName(m.targetNodeId);
  if (m.phase === "rolling_back") {
    const parts: string[] = [];
    if (m.targetPending) parts.push(`borrar la copia a medias en «${dst}» cuando vuelva a conectar`);
    if (m.sourcePending) parts.push(m.targetPending ? `después, volver a arrancar el servidor en «${src}»` : `volver a arrancar el servidor en «${src}» cuando vuelva a conectar`);
    return `La migración falló y se está deshaciendo: falta ${parts.join("; ")}.`;
  }
  if (m.phase === "committed") {
    return `Migrado a «${dst}». Falta retirar el servidor del nodo «${src}» (${m.deleteSource ? "borrando sus datos" : `sus datos quedarán en ${m.sourceSlug}.migrated-…`}) cuando vuelva a conectar.`;
  }
  return null;
}

/** Texto del diálogo de confirmación. */
export function confirmText(o: { serverName: string; slug: string; source: string; target: string; port: number; deleteSource: boolean; running: boolean }): string {
  return [
    o.running ? `«${o.serverName}» se parará en «${o.source}» durante la migración.` : `«${o.serverName}» está parado en «${o.source}».`,
    "Se hará una copia de seguridad previa, se enviará al destino (comprobando su sha256) y se restaurará allí.",
    `En «${o.target}» usará el puerto ${o.port} y se arrancará para comprobar que funciona${o.running ? "; después seguirá en marcha" : "; después se volverá a parar"}.`,
    o.deleteSource
      ? `Al terminar se BORRARÁN sus datos y sus copias en «${o.source}».`
      : `Al terminar, sus datos y copias en «${o.source}» se conservarán en ${o.slug}.migrated-… (bórralos a mano cuando ya no los necesites).`,
    `Si algo falla, el servidor sigue en «${o.source}» con su mundo intacto${o.running ? " y se vuelve a arrancar" : ""}.`,
  ].join(" ");
}

/** ¿Acaba de terminar la migración que estaba en curso (`prevActiveId`)? Sirve para refrescar el servidor. */
export function migrationFinished(prevActiveId: string | null, jobs: JobDto[] | undefined): boolean {
  if (!prevActiveId || !jobs) return false;
  const j = jobs.find((x) => x.id === prevActiveId);
  return !j || !isActive(j);
}

import { useEffect, useRef } from "react";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { OPEN_PHASES, type MigrationDto, type MigrationProposalDto, type MigrationRequestInput } from "@mcsm/shared";
import { api, apiPath, type JobDto } from "@/lib/api";
import { backupsKey } from "@/lib/jobs";
import { activeMigrationJob, migrationFinished, migrationKey, proposalKey } from "@/lib/migration";

/** Última migración del servidor (o null). Mientras está abierta se refresca cada 15 s (lo pendiente cambia sin job). */
export function useMigration(serverId: string) {
  return useQuery({
    queryKey: migrationKey(serverId),
    queryFn: async () => (await api.get<{ migration: MigrationDto | null }>(apiPath`/api/servers/${serverId}/migration`)).migration,
    refetchInterval: (q) => (q.state.data && OPEN_PHASES.has(q.state.data.phase) ? 15_000 : false),
  });
}

/** Slug y puerto que propone el panel para el destino elegido. */
export function useMigrationProposal(serverId: string, targetNodeId: string | null) {
  return useQuery({
    queryKey: proposalKey(serverId, targetNodeId ?? ""),
    queryFn: () => api.get<MigrationProposalDto>(`${apiPath`/api/servers/${serverId}/migration/proposal`}?${new URLSearchParams({ targetNodeId: targetNodeId ?? "" })}`),
    enabled: targetNodeId !== null,
    retry: false,
  });
}

export function startMigration(serverId: string, body: MigrationRequestInput): Promise<JobDto> {
  return api.post<JobDto>(apiPath`/api/servers/${serverId}/migration`, body);
}

/** Al terminar la migración en curso, refresca el servidor (quizá ya en otro nodo), la lista, la migración y sus copias. */
export function useMigrationSync(serverId: string, jobs: JobDto[] | undefined) {
  const qc = useQueryClient();
  const prev = useRef<string | null>(null);
  useEffect(() => {
    if (migrationFinished(prev.current, jobs)) {
      void qc.invalidateQueries({ queryKey: ["server", serverId] });
      void qc.invalidateQueries({ queryKey: ["servers"] });
      void qc.invalidateQueries({ queryKey: migrationKey(serverId) });
      void qc.invalidateQueries({ queryKey: backupsKey(serverId) });
    }
    prev.current = activeMigrationJob(jobs)?.id ?? null;
  }, [jobs, qc, serverId]);
}
