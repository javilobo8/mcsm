# MC Server Manager — Plan 2: Métricas

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El agente envía cada 10 s un `MetricBatch` con el uso del host (CPU, RAM, disco de `DATA_ROOT`) y de cada servidor en marcha (CPU, memoria, red, jugadores, ping y TPS en Paper/Purpur); el panel lo guarda 7 días en `metric_samples`, lo sirve agregado al vuelo (`GET /api/servers/:id/metrics`, `GET /api/nodes/:id/metrics`) y la web muestra gráficas 1 h / 24 h / 7 días en el Resumen del servidor y uso en vivo en las tarjetas de nodo.

**Architecture:** En el agente, un paquete nuevo `internal/stats` con un `Sampler` que en cada tick (segundo 5 de cada ventana de 10 s) lee `docker stats` one-shot de los contenedores en marcha, calcula el % de CPU contra la lectura anterior, hace el Server List Ping y, cada 30 s, pide `tps` por una sesión RCON persistente en Paper/Purpur; el host se lee con gopsutil. En el panel, `MetricsService` (ingesta transaccional idempotente por clave `(scope, scope_id, ts)`, purga horaria a 7 días, agregación por cubos de 10 s / 1 min / 5 min en la consulta) y un evento `node_metrics` que el WS del navegador reenvía en el topic `nodes`. En la web, uPlot para las gráficas.

**Tech Stack:** Go 1.27.2, `github.com/moby/moby/client` v0.6.2 (`ContainerStats` one-shot), `github.com/shirou/gopsutil/v4` v4.26.9 (ya en `go.mod`); Node 26, Fastify 5, `node:sqlite`, zod 4, `@bufbuild/protobuf` 2.16; React 19, TanStack Query 5, **uPlot 1.6.32**; buf 1.73.

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` — §4 `metric_samples`, §6.4, §7 (`MetricsService`, WS), §8 (gráficas del Resumen y tarjetas de nodo). Alcance y aceptación: `docs/superpowers/plans/README.md` (Plan 2). Reglas de fusión: `docs/superpowers/plans/COORDINATION.md`.

## Review Focus

1. **Tamaño de la tabla con reenvíos y purga** (reconexión del agente que repite una ventana, dos lotes en el mismo slot, purga que no llega a correr) → como máximo una fila por servidor y ventana de 10 s y nunca más de 60 480 + 360 filas por servidor/semana (aceptación: ≤ ~70k). Pruebas: Task 7 (clave primaria `(scope, scope_id, ts)` con `INSERT OR REPLACE`) y Task 8 (8 días simulados con duplicados y purga horaria).
2. **Reloj del nodo desfasado o tick retrasado** → un nodo con la hora mal no debe dejar sus puntos fuera de la gráfica ni colisionar ventanas: el agente muestrea a mitad de ventana (segundo 5) y redondea a 10 s; el panel usa su propia hora si el `ts` del agente difiere más de 30 s. Pruebas: Task 4 (`NextTick`/`RoundTS` con retrasos de hasta 3,6 s) y Task 8 (lote con +1 h y con `ts = 0`).
3. **Agregación al vuelo incorrecta o lenta** → `node:sqlite` enlaza números como REAL y `ts / 60` dejaría de agrupar; los cubos sin datos (servidor parado) deben ser `null`, no 0 ni una línea que una dos periodos; la consulta debe ir por la clave primaria. Pruebas: Task 7 (`ts` no múltiplo del cubo, relleno con `null`, `EXPLAIN QUERY PLAN` con `USING PRIMARY KEY`).
4. **Primera lectura y contadores reiniciados** (agente recién arrancado, contenedor reiniciado: la CPU acumulada vuelve a 0) → nunca un pico absurdo por desbordamiento de `uint64` ni un 0 falso: esa ventana se omite. Pruebas: Task 4 (`ContainerCPUPercent` con contadores que bajan) y Task 5 (`TestSampleSkipsStoppedUnlabeledAndResetCounters`).
5. **Coste del muestreo** (`docker stats` sin `one-shot` espera 1 s por contenedor; un servidor colgado que no responde al ping) → `docker stats` con `stream=false&one-shot=true` (< 1 s) y ping/TPS en paralelo con tope de 4 s por servidor: un servidor colgado no retrasa a los demás. Pruebas: Task 2 (integración: `Stats` en < 900 ms) y Task 5 (`TestHungServerDoesNotBlockOthers`).
6. **TPS por RCON solo en Paper/Purpur** → nunca se manda `tps` a Vanilla/Fabric/Forge (responden "Unknown command"); se pide cada 30 s por una **sesión RCON persistente** (cada conexión nueva escribe "Thread RCON Client … started/shutting down" en la consola), se cierra al parar el servidor o cambiar la contraseña, se reconecta tras un error y un valor de más de 45 s no se envía. Pruebas: Task 3 (una conexión para varios comandos, `ParseTPS` de Paper/Purpur con códigos §) y Task 5 (tres tests de TPS) y Task 13 (consola real).

## Decisiones (desviaciones conscientes de la spec)

- `metric_samples` no tiene `id` UUID (§4 dice que todas las tablas lo llevan): la clave primaria compuesta `(scope, scope_id, ts)` `WITHOUT ROWID` **es** el índice que pide la spec, hace idempotente la ingesta y ahorra ~40 bytes por fila en ~600k filas.
- Columna extra `disk_total_bytes` (solo nodo) para pintar "usado / total" sin tocar `nodes.host_info` ni el `Hello` del Plan 1.
- §5.3/§6.4 hablan de `MetricSample{...}` agrupado: el mensaje es `MetricBatch` (nombre de la hoja de ruta) con `HostMetricSample` y `ServerMetricSample`.
- §7 menciona el topic `node:<id>:metrics`: se usa el topic existente `nodes` con el tipo `node_metrics` (no amplía la regex de topics, que el Plan 4 también toca). Las gráficas del servidor se recargan por REST al ritmo de su cubo (10 s / 1 min / 5 min).
- El muestreador hace su propio Server List Ping (barato y no aparece en el log del servidor) en vez de reutilizar el del bucle de observación: así no toca `onObserved` ni el struct `App` del Plan 1.
- La primera lectura de cada contenedor y del host no se envía (no hay base para el % de CPU): el primer punto aparece 10–20 s después de arrancar.
- Red (`net_rx_bytes`/`net_tx_bytes`): contadores acumulados de Docker; se guardan y agregan (máximo del cubo) pero este plan no los dibuja.
- Por cubo: CPU, memoria, TPS y ping con media; jugadores con máximo (pico del cubo), límites con máximo.
- Si el panel no está conectado, el lote se descarta: el agente no acumula métricas.

```proto
// ── plan-2 ──

// MetricBatch agrupa las métricas de un ciclo de muestreo (cada 10 s, spec §6.4).
// Agente → panel, no solicitado (Envelope.id = 0). Solo lleva servidores cuyo
// contenedor está en marcha.
message MetricBatch {
  // Epoch en segundos, redondeado hacia abajo a múltiplo de 10.
  int64 ts_unix = 1;
  // Ausente mientras no haya dos lecturas de CPU del host.
  HostMetricSample host = 2;
  repeated ServerMetricSample servers = 3;
}

message HostMetricSample {
  // 0–100 sobre todas las CPU del host.
  double cpu_pct = 1;
  // Total menos disponible.
  uint64 mem_used_bytes = 2;
  uint64 mem_total_bytes = 3;
  // Sistema de ficheros que contiene DATA_ROOT.
  uint64 disk_used_bytes = 4;
  uint64 disk_total_bytes = 5;
}

message ServerMetricSample {
  string server_id = 1;
  // 100 = un núcleo completo (mismo criterio que `docker stats`).
  double cpu_pct = 2;
  // Uso sin la caché de páginas inactiva.
  uint64 mem_bytes = 3;
  uint64 mem_limit_bytes = 4;
  // Acumulados desde que arrancó el contenedor (todas las interfaces).
  uint64 net_rx_bytes = 5;
  uint64 net_tx_bytes = 6;
  // El Server List Ping respondió; si es false, players_* y ping_ms no significan nada.
  bool mc_online = 7;
  uint32 players_online = 8;
  uint32 players_max = 9;
  uint32 ping_ms = 10;
  // Solo PAPER/PURPUR: TPS del último minuto, medido en los últimos 45 s.
  optional double tps = 11;
}
```

import (
	"context"
	"encoding/json"
	"fmt"

	"github.com/moby/moby/api/types/container"
	"github.com/moby/moby/client"
)

// Stats pide una sola muestra (`stream=false&one-shot=true`): responde al instante,
// sin el segundo de espera que necesita Docker para rellenar precpu_stats.
func (m *Moby) Stats(ctx context.Context, id string) (Stats, error) {
	res, err := m.cli.ContainerStats(ctx, id, client.ContainerStatsOptions{Stream: false, IncludePreviousSample: false})
	if err != nil {
		return Stats{}, notFound(err)
	}
	defer res.Body.Close()
	var s container.StatsResponse
	if err := json.NewDecoder(res.Body).Decode(&s); err != nil {
		return Stats{}, fmt.Errorf("docker: decodificar stats: %w", err)
	}
	return statsFrom(&s), nil
}

// statsFrom reduce la respuesta de Docker a lo que usa el muestreador.
func statsFrom(s *container.StatsResponse) Stats {
	out := Stats{
		Read:        s.Read,
		CPUTotalNs:  s.CPUStats.CPUUsage.TotalUsage,
		SystemCPUNs: s.CPUStats.SystemUsage,
		OnlineCPUs:  s.CPUStats.OnlineCPUs,
		MemBytes:    memWithoutCache(s.MemoryStats),
		MemLimit:    s.MemoryStats.Limit,
	}
	if out.OnlineCPUs == 0 {
		out.OnlineCPUs = uint32(len(s.CPUStats.CPUUsage.PercpuUsage))
	}
	for _, n := range s.Networks {
		out.NetRxBytes += n.RxBytes
		out.NetTxBytes += n.TxBytes
	}
	return out
}

// memWithoutCache replica el cálculo de la CLI de Docker: uso menos la caché de
// páginas inactiva (cgroup v1: total_inactive_file; cgroup v2: inactive_file).
func memWithoutCache(m container.MemoryStats) uint64 {
	if v, ok := m.Stats["total_inactive_file"]; ok && v < m.Usage {
		return m.Usage - v
	}
	if v := m.Stats["inactive_file"]; v < m.Usage {
		return m.Usage - v
	}
	return m.Usage
}

package mc

import (
	"context"
	"errors"
	"fmt"
	"net"
	"strconv"
	"time"
)

// Tipos de paquete del protocolo Source RCON.
const (
	typeCommandResp = 0
	typeCommand     = 2
	typeAuthResp    = 2
	typeAuth        = 3
)

// RconConn es una sesión RCON autenticada que admite varios comandos seguidos sobre
// la misma conexión TCP. Sirve para sondeos periódicos (TPS) sin abrir una conexión
// por comando: cada conexión nueva escribe "Thread RCON Client … started/shutting
// down" en la consola del servidor.
//
// No es segura para uso concurrente. Tras cualquier error queda cerrada y hay que
// abrir otra con DialRcon.
type RconConn struct {
	conn   net.Conn
	nextID int32
	closed bool
}

// DialRcon abre una conexión RCON y se autentica.
func DialRcon(ctx context.Context, host string, port uint16, password string) (*RconConn, error) {
	d := net.Dialer{Timeout: rconTimeout}
	conn, err := d.DialContext(ctx, "tcp", net.JoinHostPort(host, strconv.Itoa(int(port))))
	if err != nil {
		return nil, fmt.Errorf("rcon: conectar: %w", err)
	}
	c := &RconConn{conn: conn, nextID: 1}
	if err := c.login(ctx, password); err != nil {
		c.Close()
		return nil, err
	}
	return c, nil
}

// arm fija el plazo de una operación (rconTimeout o el deadline de ctx si es antes) y
// cierra la conexión si ctx se cancela mientras tanto. Devuelve la función que desarma
// esa cancelación.
func (c *RconConn) arm(ctx context.Context) func() bool {
	deadline := time.Now().Add(rconTimeout)
	if dl, ok := ctx.Deadline(); ok && dl.Before(deadline) {
		deadline = dl
	}
	_ = c.conn.SetDeadline(deadline)
	return context.AfterFunc(ctx, func() { _ = c.conn.Close() })
}

func (c *RconConn) next() int32 {
	id := c.nextID
	c.nextID++
	if c.nextID <= 0 { // -1 significa "contraseña incorrecta": nunca lo usamos como id
		c.nextID = 1
	}
	return id
}

func (c *RconConn) login(ctx context.Context, password string) error {
	stop := c.arm(ctx)
	defer stop()
	if err := writePacket(c.conn, c.next(), typeAuth, password); err != nil {
		return fmt.Errorf("rcon: login: %w", err)
	}
	for { // el servidor puede enviar antes un paquete de respuesta vacío
		id, typ, _, err := readPacket(c.conn)
		if err != nil {
			return fmt.Errorf("rcon: login: %w", err)
		}
		if typ != typeAuthResp {
			continue
		}
		if id == -1 {
			return errors.New("rcon: login: contraseña incorrecta")
		}
		return nil
	}
}

// Command ejecuta un comando y devuelve su salida. Si falla, la sesión queda cerrada.
func (c *RconConn) Command(ctx context.Context, command string) (string, error) {
	if c.closed {
		return "", errors.New("rcon: sesión cerrada")
	}
	stop := c.arm(ctx)
	defer stop()
	id := c.next()
	if err := writePacket(c.conn, id, typeCommand, command); err != nil {
		c.Close()
		return "", fmt.Errorf("rcon: ejecutar: %w", err)
	}
	for {
		rid, typ, body, err := readPacket(c.conn)
		if err != nil {
			c.Close()
			return "", fmt.Errorf("rcon: ejecutar: %w", err)
		}
		if typ == typeCommandResp && rid == id {
			return body, nil
		}
	}
}

// Close cierra la conexión. Es idempotente.
func (c *RconConn) Close() error {
	if c.closed {
		return nil
	}
	c.closed = true
	return c.conn.Close()
}

package mc

import (
	"math"
	"regexp"
	"strconv"
	"strings"
)

var (
	// colorCode son los códigos de formato heredados (§a, §l, §x…) que Paper deja en la
	// salida de los comandos por RCON.
	colorCode = regexp.MustCompile(`§[0-9a-fk-orxA-FK-ORX]`)
	tpsLine   = regexp.MustCompile(`(?i)TPS from last ([^:\n]+):([^\n]*)`)
	number    = regexp.MustCompile(`^\*?\s*([0-9]+(?:\.[0-9]+)?)`)
)

// ParseTPS extrae el TPS del último minuto de la salida del comando `tps` de Paper
// ("TPS from last 1m, 5m, 15m: 20.0, 20.0, 20.0") o Purpur (añade "5s" delante).
// Admite códigos de color § y el prefijo * con el que Paper marca valores recortados.
func ParseTPS(out string) (float64, bool) {
	m := tpsLine.FindStringSubmatch(colorCode.ReplaceAllString(out, ""))
	if m == nil {
		return 0, false
	}
	labels := strings.Split(m[1], ",")
	values := strings.Split(m[2], ",")
	idx := 0
	for i, l := range labels {
		if strings.TrimSpace(l) == "1m" {
			idx = i
			break
		}
	}
	if idx >= len(values) {
		return 0, false
	}
	n := number.FindStringSubmatch(strings.TrimSpace(values[idx]))
	if n == nil {
		return 0, false
	}
	v, err := strconv.ParseFloat(n[1], 64)
	if err != nil || math.IsNaN(v) || math.IsInf(v, 0) {
		return 0, false
	}
	return v, true
}

// Package stats muestrea cada 10 s el uso del host y de los contenedores en marcha
// (spec §6.4) y lo envía al panel en un MetricBatch.
package stats

import (
	"math"
	"time"

	"mcsm/agent/internal/docker"
)

// Interval es el periodo de muestreo.
const Interval = 10 * time.Second

const intervalSec = int64(Interval / time.Second)

// RoundTS devuelve t en epoch segundos redondeado hacia abajo a múltiplo de 10.
func RoundTS(t time.Time) int64 {
	s := t.Unix()
	return s - s%intervalSec
}

// NextTick devuelve el próximo instante de muestreo: el segundo 5 de una ventana de
// 10 s (…:05, …:15). Muestrear a mitad de ventana hace que RoundTS dé ventanas
// consecutivas aunque el temporizador se retrase unos milisegundos.
func NextTick(now time.Time) time.Time {
	base := RoundTS(now)
	t := time.Unix(base+intervalSec/2, 0)
	if !t.After(now) {
		t = t.Add(Interval)
	}
	return t
}

// ContainerCPUPercent calcula el % de CPU entre dos lecturas como `docker stats`
// (100 = un núcleo completo). ok=false si no hay delta válido: contadores reiniciados
// (el contenedor se reinició) o el reloj de CPU del host no avanzó.
func ContainerCPUPercent(prev, cur docker.Stats) (float64, bool) {
	if cur.CPUTotalNs < prev.CPUTotalNs || cur.SystemCPUNs <= prev.SystemCPUNs {
		return 0, false
	}
	cpus := cur.OnlineCPUs
	if cpus == 0 {
		cpus = 1
	}
	cpu := float64(cur.CPUTotalNs - prev.CPUTotalNs)
	sys := float64(cur.SystemCPUNs - prev.SystemCPUNs)
	return cpu / sys * float64(cpus) * 100, true
}

// CPUTimes son los contadores acumulados de CPU del host, en segundos.
type CPUTimes struct{ Busy, Total float64 }

// HostCPUPercent calcula el % de CPU del host (0–100 sobre todas las CPU) entre dos
// lecturas. ok=false si el total no avanzó o los contadores retrocedieron.
func HostCPUPercent(prev, cur CPUTimes) (float64, bool) {
	dt := cur.Total - prev.Total
	if dt <= 0 || cur.Busy < prev.Busy {
		return 0, false
	}
	return math.Min(100, math.Max(0, (cur.Busy-prev.Busy)/dt*100)), true
}

// round1 redondea a un decimal (lo que se muestra en la UI).
func round1(v float64) float64 { return math.Round(v*10) / 10 }

package stats

import (
	"context"
	"errors"

	"github.com/shirou/gopsutil/v4/cpu"
	"github.com/shirou/gopsutil/v4/disk"
	"github.com/shirou/gopsutil/v4/mem"
)

// HostReader lee el uso del host.
type HostReader interface {
	CPUTimes(ctx context.Context) (CPUTimes, error)
	// Memory devuelve la RAM usada (total - disponible) y la total.
	Memory(ctx context.Context) (used, total uint64, err error)
	// Disk devuelve el uso del sistema de ficheros que contiene path.
	Disk(ctx context.Context, path string) (used, total uint64, err error)
}

// GopsutilHost implementa HostReader con gopsutil. gopsutil lee HOST_PROC, así que con
// /proc del host montado en /host/proc (spec §6.1) mide el host y no el contenedor.
type GopsutilHost struct{}

func (GopsutilHost) CPUTimes(ctx context.Context) (CPUTimes, error) {
	ts, err := cpu.TimesWithContext(ctx, false)
	if err != nil {
		return CPUTimes{}, err
	}
	if len(ts) == 0 {
		return CPUTimes{}, errors.New("stats: sin tiempos de CPU")
	}
	return cpuTimesFrom(ts[0]), nil
}

// cpuTimesFrom replica el cálculo de gopsutil: guest y guestNice ya están incluidos
// en user y nice, así que no se suman otra vez.
func cpuTimesFrom(t cpu.TimesStat) CPUTimes {
	total := t.User + t.System + t.Idle + t.Nice + t.Iowait + t.Irq + t.Softirq + t.Steal
	return CPUTimes{Busy: total - t.Idle - t.Iowait, Total: total}
}

func (GopsutilHost) Memory(ctx context.Context) (uint64, uint64, error) {
	vm, err := mem.VirtualMemoryWithContext(ctx)
	if err != nil {
		return 0, 0, err
	}
	used := vm.Total
	if vm.Available < vm.Total {
		used = vm.Total - vm.Available
	}
	return used, vm.Total, nil
}

func (GopsutilHost) Disk(ctx context.Context, path string) (uint64, uint64, error) {
	u, err := disk.UsageWithContext(ctx, path)
	if err != nil {
		return 0, 0, err
	}
	return u.Used, u.Total, nil
}

// fakeClock entrega los ticks que pide el test; After informa de la espera pedida.
type fakeClock struct {
	mu    sync.Mutex
	now   time.Time
	waits chan time.Duration
	fire  chan time.Time
}

func (c *fakeClock) Now() time.Time { c.mu.Lock(); defer c.mu.Unlock(); return c.now }
func (c *fakeClock) After(d time.Duration) <-chan time.Time {
	c.waits <- d
	return c.fire
}

// wait espera a que Run pida un temporizador y devuelve la espera pedida.
func (c *fakeClock) wait(t *testing.T) time.Duration {
	t.Helper()
	select {
	case d := <-c.waits:
		return d
	case <-time.After(3 * time.Second):
		t.Fatal("Run no pidió temporizador")
		return 0
	}
}

// advance mueve el reloj d y dispara el temporizador pendiente.
func (c *fakeClock) advance(d time.Duration) {
	c.mu.Lock()
	c.now = c.now.Add(d)
	now := c.now
	c.mu.Unlock()
	c.fire <- now
}

package stats

import (
	"context"
	"fmt"
	"log/slog"
	"strings"
	"sync"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"

	"mcsm/agent/internal/spec"
)

const (
	tpsEvery            = 30 * time.Second // spec §6.4
	tpsMaxAge           = 45 * time.Second // un TPS más antiguo no se envía
	statsTimeout        = 3 * time.Second
	defaultProbeTimeout = 4 * time.Second // SLP + TPS de un servidor
)

// Containers es lo que el muestreador usa de Docker (docker.Engine lo cumple).
type Containers interface {
	ListManaged(ctx context.Context) ([]docker.Container, error)
	Stats(ctx context.Context, id string) (docker.Stats, error)
}

// Rcon es una sesión RCON persistente (*mc.RconConn la cumple).
type Rcon interface {
	Command(ctx context.Context, command string) (string, error)
	Close() error
}

// DialRcon abre una sesión RCON autenticada.
type DialRcon func(ctx context.Context, host string, port uint16, password string) (Rcon, error)

// Clock abstrae el tiempo para probar Run sin esperas reales.
type Clock interface {
	Now() time.Time
	After(d time.Duration) <-chan time.Time
}

type realClock struct{}

func (realClock) Now() time.Time                         { return time.Now() }
func (realClock) After(d time.Duration) <-chan time.Time { return time.After(d) }

// RealClock es el reloj del sistema.
var RealClock Clock = realClock{}

// Options son las dependencias del muestreador.
type Options struct {
	Containers   Containers
	Host         HostReader
	DataRoot     string                                  // ruta cuyo sistema de ficheros se mide
	Status       mc.StatusFunc                           // Server List Ping
	Spec         func(serverID string) (spec.Spec, bool) // spec guardada: tipo y contraseña RCON
	Dial         DialRcon
	Send         func(*mcsmv1.Envelope) error
	Clock        Clock         // por defecto RealClock
	ProbeTimeout time.Duration // SLP + TPS por servidor; por defecto 4 s
	Log          *slog.Logger
}

// tpsProbe es el estado del sondeo de TPS de un servidor. Durante un Sample solo lo
// toca la goroutine que sondea ese servidor.
type tpsProbe struct {
	password string
	conn     Rcon
	tried    time.Time // último intento (cero: nunca)
	value    float64
	at       time.Time // cuándo se midió value (cero: nunca)
	err      error     // resultado del último intento, para registrarlo desde Sample
}

func (p *tpsProbe) close() {
	if p.conn != nil {
		_ = p.conn.Close()
		p.conn = nil
	}
}

// job es un servidor en marcha cuyo SLP y TPS se sondean en paralelo.
type job struct {
	m     *mcsmv1.ServerMetricSample
	host  string
	probe *tpsProbe // nil si su tipo no tiene `tps`
}

// Sampler reúne las métricas del host y de los servidores en marcha. No es seguro
// para uso concurrente: Run es el único que llama a Sample.
type Sampler struct {
	o        Options
	prevHost *CPUTimes
	prev     map[string]docker.Stats // última lectura por id de contenedor
	tps      map[string]*tpsProbe    // por server_id
	warned   map[string]string       // último error registrado por clave
}

// New crea un muestreador.
func New(o Options) *Sampler {
	if o.Clock == nil {
		o.Clock = RealClock
	}
	if o.ProbeTimeout <= 0 {
		o.ProbeTimeout = defaultProbeTimeout
	}
	if o.Log == nil {
		o.Log = slog.Default()
	}
	return &Sampler{o: o, prev: map[string]docker.Stats{}, tps: map[string]*tpsProbe{}, warned: map[string]string{}}
}

// Run muestrea en cada NextTick y envía el lote hasta que ctx termina. Si el panel no
// está conectado el lote se descarta: no se acumula nada en memoria.
func (s *Sampler) Run(ctx context.Context) {
	defer s.closeAll()
	for {
		now := s.o.Clock.Now()
		select {
		case <-ctx.Done():
			return
		case t := <-s.o.Clock.After(NextTick(now).Sub(now)):
			b := s.Sample(ctx, t)
			if b == nil {
				continue
			}
			if err := s.o.Send(&mcsmv1.Envelope{Body: &mcsmv1.Envelope_MetricBatch{MetricBatch: b}}); err != nil {
				s.o.Log.Debug("lote de métricas descartado", "err", err)
			}
		}
	}
}

// Sample toma una lectura en el instante now. Devuelve nil si no hay nada que enviar:
// la primera lectura de cada contenedor (y del host) solo fija la base de la CPU.
func (s *Sampler) Sample(ctx context.Context, now time.Time) *mcsmv1.MetricBatch {
	b := &mcsmv1.MetricBatch{TsUnix: RoundTS(now), Host: s.sampleHost(ctx)}
	list, err := s.o.Containers.ListManaged(ctx)
	s.report("listar contenedores", err)
	if err != nil {
		return nonEmpty(b) // fallo pasajero: no se toca el estado ni se cierran sesiones
	}
	var jobs []job
	seen, running := map[string]bool{}, map[string]bool{}
	for _, c := range list {
		id := c.Labels[spec.LabelServerID]
		if id == "" || c.State != "running" {
			continue
		}
		seen[c.ID], running[id] = true, true
		if m := s.readContainer(ctx, c.ID, id); m != nil {
			jobs = append(jobs, job{m: m, host: spec.ContainerName(c.Labels[spec.LabelSlug]), probe: s.probeFor(id)})
		}
	}
	var wg sync.WaitGroup
	for _, j := range jobs {
		wg.Go(func() { s.probe(ctx, now, j) })
	}
	wg.Wait()
	for _, j := range jobs {
		b.Servers = append(b.Servers, j.m)
		if j.probe != nil {
			s.report("tps de "+j.m.ServerId, j.probe.err)
		}
	}
	for cid := range s.prev {
		if !seen[cid] {
			delete(s.prev, cid)
		}
	}
	for id, p := range s.tps {
		if !running[id] {
			p.close()
			delete(s.tps, id)
		}
	}
	return nonEmpty(b)
}

// sampleHost lee el host. nil en la primera lectura o si falla la CPU; si fallan
// memoria o disco se envían a 0 y se registra el error.
func (s *Sampler) sampleHost(ctx context.Context) *mcsmv1.HostMetricSample {
	cur, err := s.o.Host.CPUTimes(ctx)
	s.report("cpu del host", err)
	if err != nil {
		return nil
	}
	prev := s.prevHost
	s.prevHost = &cur
	if prev == nil {
		return nil
	}
	pct, ok := HostCPUPercent(*prev, cur)
	if !ok {
		return nil
	}
	h := &mcsmv1.HostMetricSample{CpuPct: round1(pct)}
	var memErr, diskErr error
	h.MemUsedBytes, h.MemTotalBytes, memErr = s.o.Host.Memory(ctx)
	s.report("memoria del host", memErr)
	h.DiskUsedBytes, h.DiskTotalBytes, diskErr = s.o.Host.Disk(ctx, s.o.DataRoot)
	s.report("disco de DATA_ROOT", diskErr)
	return h
}

// readContainer lee docker stats y calcula la CPU respecto a la lectura anterior.
// nil en la primera lectura del contenedor o si sus contadores se reiniciaron.
func (s *Sampler) readContainer(ctx context.Context, containerID, serverID string) *mcsmv1.ServerMetricSample {
	cctx, cancel := context.WithTimeout(ctx, statsTimeout)
	cur, err := s.o.Containers.Stats(cctx, containerID)
	cancel()
	s.report("stats de "+serverID, err)
	if err != nil {
		return nil
	}
	prev, had := s.prev[containerID]
	s.prev[containerID] = cur
	if !had {
		return nil
	}
	pct, ok := ContainerCPUPercent(prev, cur)
	if !ok {
		return nil
	}
	return &mcsmv1.ServerMetricSample{
		ServerId: serverID, CpuPct: round1(pct), MemBytes: cur.MemBytes, MemLimitBytes: cur.MemLimit,
		NetRxBytes: cur.NetRxBytes, NetTxBytes: cur.NetTxBytes,
	}
}

// probeFor devuelve el sondeo de TPS si el tipo del servidor lo admite, cerrando la
// sesión RCON si la contraseña cambió. nil si no aplica.
func (s *Sampler) probeFor(serverID string) *tpsProbe {
	sp, ok := s.o.Spec(serverID)
	if !ok || !hasTPS(sp.Type) {
		if p := s.tps[serverID]; p != nil {
			p.close()
			delete(s.tps, serverID)
		}
		return nil
	}
	p := s.tps[serverID]
	if p == nil {
		p = &tpsProbe{}
		s.tps[serverID] = p
	}
	if p.password != sp.RconPassword {
		p.close()
		p.password = sp.RconPassword
	}
	return p
}

// hasTPS: solo Paper y Purpur tienen el comando `tps` (spec §6.4).
func hasTPS(serverType string) bool {
	return strings.EqualFold(serverType, "PAPER") || strings.EqualFold(serverType, "PURPUR")
}

// probe hace el Server List Ping y, cada 30 s, pide el TPS. Corre en paralelo con los
// demás servidores y solo toca j: un servidor colgado no retrasa más de ProbeTimeout.
func (s *Sampler) probe(ctx context.Context, now time.Time, j job) {
	ctx, cancel := context.WithTimeout(ctx, s.o.ProbeTimeout)
	defer cancel()
	st := s.o.Status(ctx, j.host, spec.GamePort)
	if st == nil || !st.Online {
		return
	}
	j.m.McOnline = true
	j.m.PlayersOnline, j.m.PlayersMax, j.m.PingMs = st.PlayersOnline, st.PlayersMax, st.LatencyMs
	p := j.probe
	if p == nil {
		return
	}
	if p.tried.IsZero() || now.Sub(p.tried) >= tpsEvery {
		p.tried = now
		p.err = s.measureTPS(ctx, now, p, j.host)
	}
	if !p.at.IsZero() && now.Sub(p.at) <= tpsMaxAge {
		v := p.value
		j.m.Tps = &v
	}
}

// measureTPS reutiliza la sesión RCON del servidor (o abre una) y ejecuta `tps`.
// Si la sesión falla se cierra y se reabre en el siguiente intento.
func (s *Sampler) measureTPS(ctx context.Context, now time.Time, p *tpsProbe, host string) error {
	if p.conn == nil {
		c, err := s.o.Dial(ctx, host, spec.RconPort, p.password)
		if err != nil {
			return err
		}
		p.conn = c
	}
	out, err := p.conn.Command(ctx, "tps")
	if err != nil {
		p.close()
		return err
	}
	v, ok := mc.ParseTPS(out)
	if !ok {
		return fmt.Errorf("salida de tps no reconocida: %.80q", out)
	}
	p.value, p.at = v, now
	return nil
}

func (s *Sampler) closeAll() {
	for id, p := range s.tps {
		p.close()
		delete(s.tps, id)
	}
}

// report registra err una sola vez mientras no cambie, para no repetirlo cada 10 s.
func (s *Sampler) report(key string, err error) {
	if err == nil {
		delete(s.warned, key)
		return
	}
	if s.warned[key] == err.Error() {
		return
	}
	s.warned[key] = err.Error()
	s.o.Log.Warn("métricas: fallo al leer "+key, "err", err)
}

func nonEmpty(b *mcsmv1.MetricBatch) *mcsmv1.MetricBatch {
	if b.Host == nil && len(b.Servers) == 0 {
		return nil
	}
	return b
}

import { z } from "zod";

/** Rangos de las gráficas y tamaño del cubo con que se agregan al vuelo (spec §4 `metric_samples`). */
export const METRIC_RANGES = {
  "1h": { seconds: 3_600, step: 10 },
  "24h": { seconds: 86_400, step: 60 },
  "7d": { seconds: 604_800, step: 300 },
} as const;

export type MetricRange = keyof typeof METRIC_RANGES;

export const metricRangeSchema = z.enum(["1h", "24h", "7d"], { message: "Rango inválido: usa 1h, 24h o 7d" });

/** Cubos de una consulta: `count` cubos de `step` segundos; el último contiene `nowSec`. */
export function metricBuckets(range: MetricRange, nowSec: number): { from: number; step: number; count: number } {
  const { seconds, step } = METRIC_RANGES[range];
  const count = seconds / step;
  const last = Math.floor(nowSec / step) * step;
  return { from: last - (count - 1) * step, step, count };
}

/** Columnas de una serie, alineadas con `t`. */
export const METRIC_COLUMNS = [
  "cpuPct", "memBytes", "memLimitBytes", "netRxBytes", "netTxBytes", "diskBytes", "diskTotalBytes",
  "playersOnline", "playersMax", "tps", "pingMs",
] as const;

export type MetricColumn = (typeof METRIC_COLUMNS)[number];

/**
 * Serie agregada para una gráfica: `t` son los inicios de cubo (epoch s) y cada columna tiene
 * un valor por cubo, `null` si no hubo muestras (servidor parado, nodo caído).
 * Servidores: cpuPct con 100 = un núcleo; players*, tps y pingMs solo si el ping respondió.
 * Nodos: cpuPct 0–100 del host, memLimitBytes = RAM total, diskBytes/diskTotalBytes de DATA_ROOT.
 */
export type MetricSeries = { range: MetricRange; step: number; t: number[] } & Record<MetricColumn, (number | null)[]>;

/** Última muestra de un nodo; la emite el WS del navegador como `{ type: "node_metrics", nodeId, sample }`. */
export interface NodeLiveSample {
  ts: number;
  cpuPct: number;
  memBytes: number;
  memTotalBytes: number;
  diskBytes: number;
  diskTotalBytes: number;
}

import type { StatementSync } from "node:sqlite";
import { METRIC_COLUMNS, metricBuckets, type MetricColumn, type MetricRange, type MetricSeries } from "@mcsm/shared";
import type { Db } from "../db/db.js";

export type MetricScope = "server" | "node";

/** Una fila de `metric_samples`. `ts` en epoch segundos, múltiplo de 10. */
export type MetricRow = { scope: MetricScope; scopeId: string; ts: number } & Record<MetricColumn, number | null>;

/** Columna SQL y agregación por cubo de cada columna de la serie. */
const AGG: Record<MetricColumn, string> = {
  cpuPct: "AVG(cpu_pct)",
  memBytes: "AVG(mem_bytes)",
  memLimitBytes: "MAX(mem_limit_bytes)",
  netRxBytes: "MAX(net_rx_bytes)", // contadores acumulados: el último del cubo
  netTxBytes: "MAX(net_tx_bytes)",
  diskBytes: "MAX(disk_bytes)",
  diskTotalBytes: "MAX(disk_total_bytes)",
  playersOnline: "MAX(players_online)", // pico del cubo: un jugador que entra y sale no desaparece
  playersMax: "MAX(players_max)",
  tps: "AVG(tps)", // AVG ignora los NULL (servidores sin TPS o sin medida)
  pingMs: "AVG(ping_ms)",
};

const SQL_COLUMN: Record<MetricColumn, string> = {
  cpuPct: "cpu_pct", memBytes: "mem_bytes", memLimitBytes: "mem_limit_bytes", netRxBytes: "net_rx_bytes",
  netTxBytes: "net_tx_bytes", diskBytes: "disk_bytes", diskTotalBytes: "disk_total_bytes",
  playersOnline: "players_online", playersMax: "players_max", tps: "tps", pingMs: "ping_ms",
};

/** Decimales con que se devuelve cada columna (los bytes y contadores, enteros). */
const DECIMALS: Partial<Record<MetricColumn, number>> = { cpuPct: 1, tps: 2, pingMs: 0 };

const round = (v: number, decimals: number) => {
  const f = 10 ** decimals;
  return Math.round(v * f) / f;
};

export class MetricsRepo {
  private insert: StatementSync;
  private aggregate: StatementSync;

  constructor(private db: Db) {
    const cols = METRIC_COLUMNS.map((c) => SQL_COLUMN[c]);
    this.insert = db.prepare(
      `INSERT OR REPLACE INTO metric_samples (scope, scope_id, ts, ${cols.join(", ")}) VALUES (?, ?, ?, ${cols.map(() => "?").join(", ")})`,
    );
    // node:sqlite enlaza los number de JS como REAL: sin CAST, ts / 10 sería una división real
    // y no habría cubos.
    this.aggregate = db.prepare(
      `SELECT (ts / CAST(? AS INTEGER)) * CAST(? AS INTEGER) AS t, ${METRIC_COLUMNS.map((c) => `${AGG[c]} AS ${c}`).join(", ")}
       FROM metric_samples
       WHERE scope = ? AND scope_id = ? AND ts >= ? AND ts < ?
       GROUP BY t ORDER BY t`,
    );
  }

  /** Inserta (o reemplaza, si ya existe esa ventana) todas las filas en una transacción. */
  insertMany(rows: MetricRow[]): void {
    if (rows.length === 0) return;
    this.db.exec("BEGIN");
    try {
      for (const r of rows) this.insert.run(r.scope, r.scopeId, r.ts, ...METRIC_COLUMNS.map((c) => r[c]));
      this.db.exec("COMMIT");
    } catch (e) {
      this.db.exec("ROLLBACK");
      throw e;
    }
  }

  /** Borra las filas con `ts` anterior a `beforeTs`. Devuelve cuántas borró. */
  deleteOlderThan(beforeTs: number): number {
    return Number(this.db.prepare("DELETE FROM metric_samples WHERE ts < ?").run(beforeTs).changes);
  }

  count(scope: MetricScope, scopeId: string): number {
    return (this.db.prepare("SELECT COUNT(*) AS n FROM metric_samples WHERE scope = ? AND scope_id = ?").get(scope, scopeId) as { n: number }).n;
  }

  /** Agrega al vuelo por cubos del rango y rellena con null los cubos sin muestras. */
  series(scope: MetricScope, scopeId: string, range: MetricRange, nowSec: number): MetricSeries {
    const { from, step, count } = metricBuckets(range, nowSec);
    const out = { range, step, t: Array.from({ length: count }, (_, i) => from + i * step) } as MetricSeries;
    for (const c of METRIC_COLUMNS) out[c] = new Array<number | null>(count).fill(null);
    const rows = this.aggregate.all(step, step, scope, scopeId, from, from + count * step) as unknown as ({ t: number } & Record<MetricColumn, number | null>)[];
    for (const row of rows) {
      const i = (row.t - from) / step;
      if (!Number.isInteger(i) || i < 0 || i >= count) continue;
      for (const c of METRIC_COLUMNS) {
        const v = row[c];
        out[c][i] = v === null ? null : round(v, DECIMALS[c] ?? 0);
      }
    }
    return out;
  }
}

import type { EventEmitter } from "node:events";
import type { MetricBatch } from "@mcsm/proto";
import type { MetricRange, MetricSeries, NodeLiveSample } from "@mcsm/shared";
import type { MetricRow, MetricScope, MetricsRepo } from "./repo.js";

/** Retención del histórico: 7 días (spec §4). */
export const RETENTION_SECONDS = 7 * 86_400;
/** Cada cuánto se purga lo que excede la retención. */
export const PURGE_EVERY_MS = 3_600_000;
/** Si el reloj del nodo difiere más que esto del panel, el lote se fecha con la hora del panel. */
export const MAX_SKEW_SECONDS = 30;

type Cancel = () => void;

export interface MetricsDeps {
  repo: MetricsRepo;
  /** Ids de los servidores del nodo: las muestras de servidores ajenos o borrados se descartan. */
  serverIdsOf: (nodeId: string) => Set<string>;
  /** Recibe `node_metrics` (nodeId, NodeLiveSample) en cada lote con datos del host. */
  events: EventEmitter;
  /** Reloj en ms (inyectable en tests). */
  now?: () => number;
  /** Repite `fn` cada `ms` y devuelve la función que lo cancela (inyectable en tests). */
  every?: (fn: () => void, ms: number) => Cancel;
  log?: { warn(obj: object, msg: string): void };
}

const defaultEvery = (fn: () => void, ms: number): Cancel => {
  const t = setInterval(fn, ms);
  t.unref();
  return () => clearInterval(t);
};

const finite = (v: number): number => (Number.isFinite(v) ? v : 0);

/** Ingesta por lotes, purga horaria y agregación en consulta (spec §7 `MetricsService`). */
export class MetricsService {
  private stopPurge: Cancel | null = null;
  private now: () => number;

  constructor(private deps: MetricsDeps) {
    this.now = deps.now ?? Date.now;
  }

  private nowSec(): number {
    return Math.floor(this.now() / 1000);
  }

  /** Ventana de 10 s del lote: la del agente si su reloj es razonable; si no, la del panel. */
  slotOf(agentTs: number): number {
    const now = this.nowSec();
    const ts = Number.isFinite(agentTs) && Math.abs(agentTs - now) <= MAX_SKEW_SECONDS ? agentTs : now;
    return ts - (ts % 10);
  }

  /** Guarda un MetricBatch del agente. Devuelve cuántas filas escribió. */
  ingest(nodeId: string, batch: MetricBatch): number {
    const ts = this.slotOf(Number(batch.tsUnix));
    const rows: MetricRow[] = [];
    const h = batch.host;
    if (h) {
      rows.push({
        scope: "node", scopeId: nodeId, ts, cpuPct: finite(h.cpuPct),
        memBytes: Number(h.memUsedBytes), memLimitBytes: Number(h.memTotalBytes), netRxBytes: null, netTxBytes: null,
        diskBytes: Number(h.diskUsedBytes), diskTotalBytes: Number(h.diskTotalBytes),
        playersOnline: null, playersMax: null, tps: null, pingMs: null,
      });
    }
    if (batch.servers.length > 0) {
      const mine = this.deps.serverIdsOf(nodeId);
      for (const s of batch.servers) {
        if (!mine.has(s.serverId)) continue;
        const online = s.mcOnline;
        rows.push({
          scope: "server", scopeId: s.serverId, ts, cpuPct: finite(s.cpuPct),
          memBytes: Number(s.memBytes), memLimitBytes: Number(s.memLimitBytes),
          netRxBytes: Number(s.netRxBytes), netTxBytes: Number(s.netTxBytes), diskBytes: null, diskTotalBytes: null,
          playersOnline: online ? s.playersOnline : null, playersMax: online ? s.playersMax : null,
          pingMs: online ? s.pingMs : null,
          tps: online && s.tps !== undefined && Number.isFinite(s.tps) ? s.tps : null,
        });
      }
    }
    this.deps.repo.insertMany(rows);
    if (h) {
      const sample: NodeLiveSample = {
        ts, cpuPct: finite(h.cpuPct), memBytes: Number(h.memUsedBytes), memTotalBytes: Number(h.memTotalBytes),
        diskBytes: Number(h.diskUsedBytes), diskTotalBytes: Number(h.diskTotalBytes),
      };
      this.deps.events.emit("node_metrics", nodeId, sample);
    }
    return rows.length;
  }

  /** Borra lo que excede la retención. Devuelve cuántas filas borró. */
  purge(): number {
    return this.deps.repo.deleteOlderThan(this.nowSec() - RETENTION_SECONDS);
  }

  /** Purga ahora y después cada hora. */
  start(): void {
    if (this.stopPurge) return;
    this.safePurge();
    this.stopPurge = (this.deps.every ?? defaultEvery)(() => this.safePurge(), PURGE_EVERY_MS);
  }

  stop(): void {
    this.stopPurge?.();
    this.stopPurge = null;
  }

  series(scope: MetricScope, scopeId: string, range: MetricRange): MetricSeries {
    return this.deps.repo.series(scope, scopeId, range, this.nowSec());
  }

  private safePurge() {
    try {
      this.purge();
    } catch (e) {
      this.deps.log?.warn({ err: e }, "fallo purgando métricas antiguas");
    }
  }
}

import WebSocket from "ws";

/** Cliente WS del navegador para tests: cola de mensajes JSON y espera con timeout. */
export function browserClient(url: string, cookie: string): Promise<{ ws: WebSocket; next: (timeoutMs?: number) => Promise<any> }> {
  return new Promise((resolve, reject) => {
    const ws = new WebSocket(url.replace(/^http/, "ws") + "/ws", { headers: { cookie } });
    const queue: any[] = [];
    const waiters: ((m: any) => void)[] = [];
    ws.on("message", (d) => {
      const m = JSON.parse(d.toString());
      const w = waiters.shift();
      if (w) w(m); else queue.push(m);
    });
    const next = (timeoutMs = 3000) => queue.length
      ? Promise.resolve(queue.shift())
      : new Promise<any>((res, rej) => {
        const t = setTimeout(() => rej(new Error("sin mensaje")), timeoutMs);
        waiters.push((m) => { clearTimeout(t); res(m); });
      });
    ws.on("open", () => resolve({ ws, next }));
    ws.on("unexpected-response", (_r, res) => reject(new Error(`HTTP ${res.statusCode}`)));
    ws.on("error", reject);
  });
}

import type { QueryClient } from "@tanstack/react-query";
import type { MetricColumn, MetricRange, MetricSeries, NodeLiveSample } from "@mcsm/shared";
import type { ServerMessage } from "./api";
import type { LiveSource } from "./live";
import { formatBytes } from "./format";

export const RANGE_OPTIONS: { value: MetricRange; label: string }[] = [
  { value: "1h", label: "1 h" },
  { value: "24h", label: "24 h" },
  { value: "7d", label: "7 días" },
];

/** Cada cuánto se recarga una gráfica: un cubo nuevo de 10 s, 1 min o 5 min. */
export const REFRESH_MS: Record<MetricRange, number> = { "1h": 10_000, "24h": 60_000, "7d": 300_000 };

/** Datos para uPlot: [t, serie1, serie2…] con `null` en los huecos. */
export type Aligned = [number[], ...(number | null)[][]];

export const aligned = (s: MetricSeries, cols: MetricColumn[]): Aligned => [s.t, ...cols.map((c) => s[c])];

export const hasData = (col: (number | null)[]): boolean => col.some((v) => v !== null);

/** Última muestra de una serie de nodo (pinta la tarjeta antes del primer evento en vivo). */
export function latestNodeSample(s: MetricSeries): NodeLiveSample | null {
  for (let i = s.t.length - 1; i >= 0; i--) {
    const cpu = s.cpuPct[i];
    if (cpu === null || cpu === undefined) continue;
    return {
      ts: s.t[i]!, cpuPct: cpu, memBytes: s.memBytes[i] ?? 0, memTotalBytes: s.memLimitBytes[i] ?? 0,
      diskBytes: s.diskBytes[i] ?? 0, diskTotalBytes: s.diskTotalBytes[i] ?? 0,
    };
  }
  return null;
}

/** El agente envía cada 10 s: una muestra con más de 60 s está caducada. */
export const isFresh = (s: NodeLiveSample | null | undefined, nowMs: number): s is NodeLiveSample =>
  !!s && nowMs / 1000 - s.ts <= 60;

export const percent = (used: number, total: number): number => (total > 0 ? Math.min(100, Math.max(0, (used / total) * 100)) : 0);

export const usageTone = (pct: number): "ok" | "warn" | "bad" => (pct >= 90 ? "bad" : pct >= 70 ? "warn" : "ok");

export const formatCpu = (v: number): string => `${Math.round(v)} %`;
export const formatCount = (v: number): string => String(Math.round(v));
export const formatTps = (v: number): string => v.toFixed(1);
export const formatMem = (v: number): string => formatBytes(v);

type NodeMetricsMsg = Extract<ServerMessage, { type: "node_metrics" }>;

/** Guarda la última muestra en vivo de un nodo; una más antigua que la que hay no la pisa. */
export function applyNodeMetricsEvent(qc: QueryClient, msg: NodeMetricsMsg): void {
  qc.setQueryData<NodeLiveSample | null>(["node-live", msg.nodeId], (old) => (old && old.ts > msg.sample.ts ? old : msg.sample));
}

/** Conecta `node_metrics` del WS con la caché. Devuelve la función de limpieza. */
export function bindNodeMetrics(qc: QueryClient, live: LiveSource): () => void {
  const offs = [
    live.subscribe("nodes", (m) => { if (m.type === "node_metrics") applyNodeMetricsEvent(qc, m); }),
    // Durante la desconexión se pierden muestras: se recarga la última por REST.
    live.onReconnect(() => { void qc.invalidateQueries({ queryKey: ["node-live"] }); }),
  ];
  return () => offs.forEach((off) => off());
}

          label: l.label, stroke: l.color, width: 1.5, dash: l.dash, fill: l.fill ? `${l.color}26` : undefined,
          value: (_u: uPlot, v: number | null) => (v == null ? "—" : format(v)),
        })),
      ],
    }, latest.current, el);
    plot.current = u;
    const ro = new ResizeObserver(() => u.setSize({ width: Math.max(el.clientWidth, MIN_WIDTH), height }));
    ro.observe(el);
    return () => { ro.disconnect(); u.destroy(); plot.current = null; };
  }, [lines, format, yRange, height]);

  useEffect(() => { plot.current?.setData(data); }, [data]);

  return (
    <figure className="min-w-0">
      <figcaption className="mb-1 text-xs uppercase tracking-wide text-muted-foreground">{title}</figcaption>
      <div ref={box} className="w-full" />

import { cn } from "@/lib/utils";
import { formatBytes } from "@/lib/format";
import { isFresh, percent, usageTone } from "@/lib/metrics";
import { useNodeLive } from "@/hooks/use-metrics";

const TONE = { ok: "bg-emerald-500", warn: "bg-amber-500", bad: "bg-red-500" } as const;

function UsageBar({ label, pct, text }: { label: string; pct: number; text: string }) {
  return (
    <div className="grid grid-cols-[3rem_1fr_auto] items-center gap-2 text-xs">
      <span className="text-muted-foreground">{label}</span>
      <div role="meter" aria-label={label} aria-valuemin={0} aria-valuemax={100} aria-valuenow={Math.round(pct)} className="h-1.5 overflow-hidden rounded bg-zinc-800">
        <div className={cn("h-full transition-[width]", TONE[usageTone(pct)])} style={{ width: `${pct}%` }} />
      </div>
      <span className="tabular-nums text-zinc-300">{text}</span>
    </div>
  );
}

/** CPU, RAM y disco de DATA_ROOT de un nodo, en vivo (spec §8: tarjetas de nodo). */
export function NodeUsage({ nodeId }: { nodeId: string }) {
  const q = useNodeLive(nodeId);
  const s = q.data;
  if (q.isPending) return <p className="text-xs text-muted-foreground">Cargando uso…</p>;
  if (!isFresh(s, Date.now())) return <p className="text-xs text-muted-foreground">Sin métricas recientes del nodo</p>;
  return (
    <div className="flex flex-col gap-1.5" aria-label="Uso del nodo">
      <UsageBar label="CPU" pct={s.cpuPct} text={`${Math.round(s.cpuPct)} %`} />
      <UsageBar label="RAM" pct={percent(s.memBytes, s.memTotalBytes)} text={`${formatBytes(s.memBytes)} / ${formatBytes(s.memTotalBytes)}`} />
      <UsageBar label="Disco" pct={percent(s.diskBytes, s.diskTotalBytes)} text={`${formatBytes(s.diskBytes)} / ${formatBytes(s.diskTotalBytes)}`} />
    </div>
  );
}
