# MC Server Manager — Plan 6: Import of existing servers

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the `itzg/minecraft-server` servers that already run on a node (e.g. those in the user's docker-compose) appear under Nodes → Import, get reviewed with the configuration form, and be adopted without stopping them; the first “Save and apply” recreates them as `mcsm-<slug>` with `mcsm.*` labels and the same data directory.

**Architecture:** The agent lists the foreign itzg containers (`ImportScan` → `ImportScanResult`, with the user's env without the image's ENV) and the panel derives the candidate spec with a pure function, without letting `RCON_PASSWORD` or `CF_API_KEY` reach the browser. When adopting (`ImportAdopt`), the agent checks that the container's `/data` is the spec's, connects it to the `mcsm` network with the alias `mcsm-<slug>` (RCON, ping and metrics look it up by that name) and saves an adoption record: the reconciler treats that container as the server's until the spec version exceeds the adoption's, and then replaces it. The spec the panel sends for an imported server carries `adopt` (like the CurseForge key: only in the message, never in `servers.spec`), so a lost adoption or a new agent store is rebuilt without creating a second container over the same world. `dataPath` (new, optional field, always outside `DATA_ROOT`) is set only by the import; with it there are no backups or file browser, because the agent only mounts `DATA_ROOT` (§6.1).

**Tech Stack:** Go 1.27.2 (agent: `reconcile`, `store` bbolt, `docker` over `github.com/moby/moby/client` v0.6.2, new package `importer`); protobuf with buf 1.73 (`pnpm gen`); Node 26, pnpm 12, Fastify 5, `node:sqlite`, zod 4; React 19, TanStack Router/Query, shadcn/ui (Radix), Vitest 4 on node (no jsdom).

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` (§4 `servers.imported_from`, §5.3 `ImportScan`/`ImportAdopt`, §6.7, §7 `ImportService`, §8 Nodes → import). Scope and acceptance: `docs/superpowers/plans/README.md` (Plan 6). Coordination: `docs/superpowers/plans/COORDINATION.md`.

## Decisions resolved with the real code

- **Adoption without recreating.** Docker does not allow adding labels to an existing container, so “adding the labels” (§6.7) means recreating. Until the first spec change, the agent follows the original container through an **adoption record** in bbolt (`store.Adoption{ContainerID, Slug, Version}`). `reconcile.find` returns first the managed container (label `mcsm.server_id`) and, if there is none, the adopted one (with `Adopted=true` and `mcsm.server_id`/`mcsm.slug` synthesized); this way logs, console, `Power`, backups (`Container`) and observation work without changes. `reconcileLocked` does not compare the hash for an adopted container: if `spec_version` > `Adoption.Version`, it stops and removes the original (the data is in the bind) and creates `mcsm-<slug>`; otherwise it only adjusts the desired state.
- **`adopt` in the message, not in the stored spec.** `toServerSpecMessage` adds `"adopt": {containerId, version}` to every spec of a server with `imported_from`. If the agent has no record (ImportAdopt lost, new store), `reconcileLocked` adopts again with the same checks; if the original no longer exists, it creates the managed one; if it exists but does not match (another `/data`, already managed…), it fails without creating anything. `adopt` does not enter `BuildContainer` nor the hash.
- **Network and names.** RCON, the status ping and the TPS use `mcsm-<slug>` on the `mcsm` network. When adopting, the agent connects the original container to that network with the alias `mcsm-<slug>` (`NetworkConnect` live, without restarting). Containers with network `host`, `none` or `container:` are not imported.
- **RCON of the adopted container.** The spec's password is the container's `RCON_PASSWORD` if it has ≥ 8 characters; if it does not set it (itzg generates a random one on each start), uses another `RCON_PORT` or has RCON disabled, the console, the TPS and the `save-off` of hot backups fail until the first recreation, and the candidate warns about it. Logs and players (ping) always work.
- **Metrics.** The Plan 2 sampler receives as `Containers` an adapter that lists managed + adopted (`Reconciler.ServerContainers`). The Docker events of the adopted container do not arrive (the filter is `mcsm.managed=true`): its state is refreshed with the 10 s observation tick.
- **`dataPath` and `DATA_ROOT`.** Bind `/data` = `<DATA_ROOT>/<slug>/data` with a valid slug → no `dataPath` and fixed slug (changing it would point to another folder). Bind outside `DATA_ROOT` → `dataPath`. Bind inside `DATA_ROOT` in another form, or one that contains `DATA_ROOT` → not importable (with the instruction to move it). This way no `dataPath` overlaps the data of managed servers.
- **Backups and files.** With `dataPath` the agent does not see the folder (it only mounts `DATA_ROOT`): `Files*`, `BackupNow` and `BackupRestore` answer `external_data` (409), scheduled backups do not validate, and deleting “with data” is rejected. Without `dataPath` (data already in `DATA_ROOT`), backups and files also work before the first recreation (RCON according to the previous point). The Plan 5 note (“use `dataPath` as the root of `serverFS`”) does not work: that folder is not mounted in the agent.
- **Review before adopting.** “Adopt without stopping” requires the deduced spec unchanged (and valid): the spec v1 describes the container that keeps running. With changes, “Adopt and apply” adopts and then immediately goes to v2 (the agent recreates).
- **Deleting an imported server** deletes its container (the original if it is still adopted), like any managed server; its data outside `DATA_ROOT` is never deleted from the panel.
- **Doubtful failures when adopting.** If the agent rejects `ImportAdopt` with one of its codes, the row is deleted. If the request drops due to `timeout` or `disconnected`, the row is **kept** (504 with an explanation): deleting it would make the next `SyncSpecs` retire the server and delete the original container if the agent did adopt it; with the row, `adopt` completes the adoption on reconnect.
- **Deviations from the spec:** `ImportCandidates` is called `ImportScanResult` (`*Result` convention of `isResponseCase`); `ImportAdopt` carries the full `ServerSpec` (includes `server_id` and `slug`) instead of `{container_id, server_id, slug}`; the container is not renamed: it is recreated.

```proto
// Import of existing containers (spec §6.7).

// Panel → agent. Lists the containers whose image is itzg/minecraft-server, without the
// mcsm.managed label and that this agent has not already adopted. Response: ImportScanResult, or Error.
message ImportScan {}

message ImportScanResult {
  repeated ImportCandidate candidates = 1;
  // The agent's DATA_ROOT: the panel uses it to decide whether a candidate's data is in
  // <DATA_ROOT>/<slug>/data or needs dataPath.
  string data_root = 2;
}

// Reduced Inspect of an importable container. `env` holds only what the user set (without the
// variables identical to the image's ENV) and INCLUDES secrets (RCON_PASSWORD, CF_API_KEY): the
// panel does not forward them to the browser nor log them.
message ImportCandidate {
  string container_id = 1; // full id
  string name = 2; // without the leading "/"
  string image = 3; // Config.Image as is (itzg/minecraft-server:java21)
  string state = 4; // created|running|restarting|exited|paused|dead
  map<string, string> env = 5;
  repeated ImportPort ports = 6; // configured publications (HostConfig.PortBindings)
  repeated ImportMount mounts = 7;
  string restart_policy = 8; // no|always|unless-stopped|on-failure ("" = no)
  int64 memory_limit_bytes = 9; // 0 = no limit
  int64 nano_cpus = 10; // 0 = no limit
  string network_mode = 11; // bridge|host|none|container:<id>|<user network>
  repeated string networks = 12;
  map<string, string> labels = 13; // only com.docker.compose.project and com.docker.compose.service
}

message ImportPort {
  uint32 container_port = 1;
  string proto = 2; // tcp|udp
  string host_ip = 3; // "" = all interfaces
  uint32 host_port = 4; // 0 = ephemeral
}

message ImportMount {
  string type = 1; // bind|volume|tmpfs…
  string source = 2; // host path (bind) or volume
  string destination = 3;
  bool read_write = 4;
  string name = 5; // volume name
}

// Panel → agent. Adopts a container without recreating it. server.spec_json carries "adopt":
// {"containerId", "version"} (added by the panel). The agent checks that the container exists,
// is not a MC Server Manager one, uses the itzg image and mounts the spec's folder on /data; it
// connects it to its network with the alias mcsm-<slug> and saves the spec and the adoption.
// Response: Ack, or Error with not_found (does not exist), exists (managed or adopted by another
// server), invalid_request (not itzg, host/none/container network or a different /data),
// invalid_spec or apply_failed (Docker).
message ImportAdopt {
  ServerSpec server = 1;
}
```

```go
package spec

import (
	"fmt"
	"path/filepath"
	"regexp"
	"strings"
)

// Import (plan-6, spec §6.7): data folder of an imported server and adoption.

// MaxDataPath is the maximum length of dataPath in bytes (DATA_PATH_MAX_BYTES in the panel).
const MaxDataPath = 1024

// dataPathSegRe: each segment of dataPath, ASCII only (letters, digits, space and . _ @ + -). No
// ":" (it would break the src:/data bind), "," nor "\". Same rule in zod (fixture data-path-cases.json).
var dataPathSegRe = regexp.MustCompile(`^[A-Za-z0-9._@+ -]+$`)

// DeniedDataPaths are system areas that are never mounted on /data: the agent runs as root and
// itzg's entrypoint does chown -R on /data. They are compared by segments (/etcetera is valid).
var DeniedDataPaths = []string{
	"/bin", "/boot", "/dev", "/etc", "/lib", "/lib32", "/lib64", "/libx32", "/proc", "/run",
	"/sbin", "/sys", "/usr", "/var/lib/docker", "/var/run",
}

// adoptIDRe: id of the container to adopt. The panel sends full ids (64 hex); any short
// alphanumeric id is accepted for the Docker fake in the tests.
var adoptIDRe = regexp.MustCompile(`^[0-9A-Za-z]{1,64}$`)

// Adopt is added by the panel to the spec it sends for an imported server; it is never stored in
// the panel's spec. ContainerID is the original container and Version the spec version it was
// adopted with: the agent does not recreate it while the spec does not exceed it.
type Adopt struct {
	ContainerID string `json:"containerId"`
	Version     uint64 `json:"version"`
}

// pathWithin reports whether child is parent or hangs from it (clean absolute paths).
func pathWithin(child, parent string) bool {
	if parent == "/" {
		return strings.HasPrefix(child, "/")
	}
	return child == parent || strings.HasPrefix(child, parent+"/")
}

// ValidateDataPath validates dataPath without knowing DATA_ROOT ("" = no dataPath). The relation
// with DATA_ROOT is checked by BuildContainer.
func ValidateDataPath(p string) error {
	if p == "" {
		return nil
	}
	if len(p) > MaxDataPath {
		return fmt.Errorf("spec: dataPath too long (max %d bytes)", MaxDataPath)
	}
	if !strings.HasPrefix(p, "/") {
		return fmt.Errorf("spec: dataPath must be an absolute path: %q", p)
	}
	segs := strings.Split(p[1:], "/")
	if len(segs) < 2 {
		return fmt.Errorf("spec: dataPath %q is too general: use at least two levels", p)
	}
	for _, s := range segs {
		if s == "" || s == "." || s == ".." {
			return fmt.Errorf("spec: dataPath %q is not normalized (no //, «.» or «..», no trailing /)", p)
		}
		if !dataPathSegRe.MatchString(s) {
			return fmt.Errorf("spec: dataPath %q has unsupported characters (ASCII letters and digits, space and . _ @ + -)", p)
		}
	}
	for _, d := range DeniedDataPaths {
		if pathWithin(p, d) {
			return fmt.Errorf("spec: dataPath %q is in a system area (%s): it is not mounted", p, d)
		}
	}
	return nil
}

// IsItzgImage reports whether ref is itzg/minecraft-server (with or without docker.io/, with tag or digest).
func IsItzgImage(ref string) bool {
	rest, ok := strings.CutPrefix(strings.TrimPrefix(ref, "docker.io/"), Image)
	return ok && (rest == "" || rest[0] == ':' || rest[0] == '@')
}

// validateImport validates dataPath and adopt. With dataPath there are no scheduled backups: the
// agent does not see that folder (it only mounts DATA_ROOT). Same criteria as dataPathCheck in the panel.
func (s Spec) validateImport() error {
	if err := ValidateDataPath(s.DataPath); err != nil {
		return err
	}
	if s.DataPath != "" && s.Backups != nil && s.Backups.Enabled {
		return fmt.Errorf("spec: scheduled backups are not available with dataPath: the agent cannot see that folder (it only mounts DATA_ROOT)")
	}
	if a := s.Adopt; a != nil {
		if !adoptIDRe.MatchString(a.ContainerID) {
			return fmt.Errorf("spec: invalid adopt.containerId %q", a.ContainerID)
		}
		if a.Version == 0 {
			return fmt.Errorf("spec: adopt.version must be at least 1")
		}
	}
	return nil
}

// dataDir is the host folder mounted on /data: dataPath if there is one (outside DATA_ROOT and
// without containing it: it never overlaps the data of managed servers) or <dataRoot>/<slug>/data.
func (s Spec) dataDir(slug, dataRoot string) (string, error) {
	if s.DataPath == "" {
		return filepath.Join(dataRoot, slug, "data"), nil
	}
	root := filepath.Clean(dataRoot)
	if pathWithin(s.DataPath, root) || pathWithin(root, s.DataPath) {
		return "", fmt.Errorf("spec: dataPath %q cannot be inside DATA_ROOT (%s) nor contain it", s.DataPath, root)
	}
	return s.DataPath, nil
}
```

```go
import "sort"

// ImportInfo is the reduced inspect of a container that can be imported (spec §6.7).
type ImportInfo struct {
	ID          string
	Name        string
	Image       string // Config.Image as the user wrote it
	ImageID     string // image it runs with (sha256:… in Docker)
	State       string
	Env         []string
	Labels      map[string]string

	Mounts      []Mount
	Restart     string
	Memory      int64 // memory limit; 0 = no limit
	NanoCPUs    int64

}

// PortPublish is a port publication. HostIP "" = all interfaces; HostPort 0 = ephemeral.
type PortPublish struct {
	ContainerPort int
	Proto         string
	HostIP        string

	Source      string

func sortPorts(ps []PortPublish) {
	sort.Slice(ps, func(i, j int) bool {
		a, b := ps[i], ps[j]
		if a.ContainerPort != b.ContainerPort {
			return a.ContainerPort < b.ContainerPort
		}
		if a.Proto != b.Proto {
			return a.Proto < b.Proto
		}
		if a.HostPort != b.HostPort {
			return a.HostPort < b.HostPort
		}
		return a.HostIP < b.HostIP
	})
}
```

```go
package store

import (
	"encoding/json"
	"errors"

	"go.etcd.io/bbolt"
	"google.golang.org/protobuf/proto"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
)

// bAdoptions stores the adoptions (plan-6, spec §6.7): imported server → original container that
// the agent keeps without recreating until the first spec change. It survives DeleteSpec and
// ForgetWithTombstone on purpose: the pending deletion of an imported server needs to know which
// container to stop. Whoever deletes or replaces that container removes it (DeleteAdoption). The
// bucket is created on first use (it does not touch the bucket list of Open).
var bAdoptions = []byte("adoptions")

// Adoption is an adopted container: its id, the server's slug (network alias and synthesized
// labels) and the spec version it was adopted with (a higher one recreates it).
type Adoption struct {
	ContainerID string `json:"containerId"`
	Slug        string `json:"slug"`
	Version     uint64 `json:"version"`
}

func putAdoption(tx *bbolt.Tx, serverID string, a Adoption) error {
	raw, err := json.Marshal(a)
	if err != nil {
		return err
	}
	b, err := tx.CreateBucketIfNotExists(bAdoptions)
	if err != nil {
		return err
	}
	return b.Put([]byte(serverID), raw)
}

// PutAdoption saves (or replaces) the adoption of serverID.
func (s *Store) PutAdoption(serverID string, a Adoption) error {
	if serverID == "" || a.ContainerID == "" {
		return errors.New("store: adoption without server or container")
	}
	return s.db.Update(func(tx *bbolt.Tx) error { return putAdoption(tx, serverID, a) })
}

// AdoptWithSpec saves the spec (cancelling its tombstone, like PutSpec) and the adoption in one
// transaction: an adoption never exists without the spec that asked for it.
func (s *Store) AdoptWithSpec(sp *mcsmv1.ServerSpec, a Adoption) error {
	if sp.GetServerId() == "" || a.ContainerID == "" {
		return errors.New("store: adoption without server or container")
	}
	raw, err := proto.Marshal(sp)
	if err != nil {
		return err
	}
	return s.db.Update(func(tx *bbolt.Tx) error {
		if err := tx.Bucket(bSpecs).Put([]byte(sp.ServerId), raw); err != nil {
			return err
		}
		if err := deleteTombstone(tx, sp.ServerId); err != nil {
			return err
		}
		return putAdoption(tx, sp.ServerId, a)
	})
}

// Adoption returns the adoption of serverID, or nil if there is none.
func (s *Store) Adoption(serverID string) (*Adoption, error) {
	var out *Adoption
	err := s.db.View(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bAdoptions)
		if b == nil {
			return nil
		}
		raw := b.Get([]byte(serverID))
		if raw == nil {
			return nil
		}
		var a Adoption
		if err := json.Unmarshal(raw, &a); err != nil {
			return err
		}
		out = &a
		return nil
	})
	return out, err
}

// Adoptions returns all the adoptions by server_id.
func (s *Store) Adoptions() (map[string]Adoption, error) {
	out := map[string]Adoption{}
	err := s.db.View(func(tx *bbolt.Tx) error {
		b := tx.Bucket(bAdoptions)
		if b == nil {
			return nil
		}
		return b.ForEach(func(k, v []byte) error {
			var a Adoption
			if err := json.Unmarshal(v, &a); err != nil {
				return err
			}
			out[string(k)] = a
			return nil
		})
	})
	return out, err
}

// AdoptedBy returns the server that adopted containerID, or "" if none.
func (s *Store) AdoptedBy(containerID string) (string, error) {
	all, err := s.Adoptions()
	if err != nil {
		return "", err
	}
	for id, a := range all {
		if a.ContainerID == containerID {
			return id, nil
		}
	}
	return "", nil
}

// DeleteAdoption removes the adoption of serverID (idempotent).
func (s *Store) DeleteAdoption(serverID string) error {
	return s.db.Update(func(tx *bbolt.Tx) error {
		if b := tx.Bucket(bAdoptions); b != nil {
			return b.Delete([]byte(serverID))
		}
		return nil
	})
}
```

```go
package reconcile

import (
	"context"
	"errors"
	"fmt"
	"path/filepath"
	"sort"
	"strings"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/docker"
	"mcsm/agent/internal/spec"
	"mcsm/agent/internal/store"
)

// Hot adoption of imported containers (plan-6, spec §6.7).
//
// An imported server stays in its original container (without mcsm.* labels) until the first spec
// change. The store's adoption record says which container it is and with which spec version it
// was adopted. find returns it as the server's container (Adopted, with synthesized mcsm.server_id
// and mcsm.slug), so logs, console, power, backups and observation work the same. reconcileLocked
// does not recreate it while the spec version does not exceed the adoption's; with a higher one it
// stops it, removes it (the data is in the bind) and creates mcsm-<slug> with the same data folder.
//
// The spec of an imported server carries "adopt" (the panel adds it): if the record is missing
// (ImportAdopt lost, new store), reconcileLocked adopts again with the same checks; if the original
// no longer exists it creates the managed one; if it exists but does not match, it fails without
// creating anything.
//
// Lock order: per-server lock → adoptMu → r.mu.

var (
	ErrAdoptNotFound = errors.New("the container to adopt does not exist")
	ErrAdoptConflict = errors.New("the container is already managed")
	ErrAdoptMismatch = errors.New("the container does not match the spec")
	ErrAdoptSpec     = errors.New("invalid adoption spec")
)

// Adopt sets up the adoption the panel asks for (ImportAdopt): checks the container, connects it to
// the agent's network with the alias mcsm-<slug>, saves spec and adoption in one transaction and
// reconciles. It is idempotent. Once the adoption is saved it does not return an error because of
// the reconciliation (it is left in Observed): the panel must not retire the server, or the next
// SyncSpecs would delete the original.
func (r *Reconciler) Adopt(ctx context.Context, sp *mcsmv1.ServerSpec) error {
	unlock := r.lock(sp.ServerId)
	defer unlock()
	parsed, err := spec.Parse(sp.SpecJson)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrAdoptSpec, err)
	}
	if parsed.Adopt == nil {
		return fmt.Errorf("%w: missing adopt", ErrAdoptSpec)
	}
	build, err := spec.BuildContainer(spec.Meta{ServerID: sp.ServerId, Slug: sp.Slug, Version: sp.Version}, parsed, r.dataRoot, r.network)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrAdoptSpec, err)
	}
	// adoptMu is released before reconciling: reconcileLocked may call readopt, which takes it.
	if err := r.recordAdoption(ctx, sp, parsed.Adopt, build.DataDir); err != nil {
		return err
	}
	if err := r.reconcileLocked(ctx, sp.ServerId); err != nil {
		r.log.Warn("reconcile after adopting", "server", sp.Slug, "err", err)
	}
	return nil
}

// recordAdoption checks the container and saves spec and adoption, under adoptMu (requires the
// server's lock). If this server has already adopted it (panel retry with the Ack lost), it only
// saves the spec if it is not older.
func (r *Reconciler) recordAdoption(ctx context.Context, sp *mcsmv1.ServerSpec, a *spec.Adopt, dataDir string) error {
	r.adoptMu.Lock()
	defer r.adoptMu.Unlock()
	cur, err := r.st.Adoption(sp.ServerId)
	if err != nil {
		return err
	}
	if cur != nil && cur.ContainerID == a.ContainerID {
		stored, err := r.st.GetSpec(sp.ServerId)
		if err != nil {
			return err
		}
		if stored == nil || sp.Version >= stored.Version {
			return r.st.PutSpec(sp)
		}
		return nil
	}
	managed, err := r.findManaged(ctx, sp.ServerId)
	if err != nil {
		return err
	}
	if managed != nil {
		return fmt.Errorf("%w: the server already has the container %s", ErrAdoptConflict, managed.Name)
	}
	info, err := r.verifyAdoptable(ctx, sp.ServerId, a.ContainerID, dataDir)
	if err != nil {
		return err
	}
	if err := r.connectAlias(ctx, info, sp.Slug); err != nil {
		return err
	}
	return r.st.AdoptWithSpec(sp, store.Adoption{ContainerID: info.ID, Slug: sp.Slug, Version: a.Version})

// readopt adopts an imported server again when it has no record (its spec carries adopt). Requires
// the server's lock. It returns the adopted container, or nil if the original no longer exists (the
// managed one will be created). Any other failure stops the reconciliation: a second container is
// never created over the data of one that could not be checked.
func (r *Reconciler) readopt(ctx context.Context, sp *mcsmv1.ServerSpec, a *spec.Adopt, dataDir string) (*docker.Container, error) {
	r.adoptMu.Lock()
	defer r.adoptMu.Unlock()
	info, err := r.verifyAdoptable(ctx, sp.ServerId, a.ContainerID, dataDir)
	if errors.Is(err, ErrAdoptNotFound) {
		r.log.Info("the original container of an imported server no longer exists: the managed one is created", "server", sp.Slug)
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	if err := r.connectAlias(ctx, info, sp.Slug); err != nil {
		return nil, err
	}
	if err := r.st.PutAdoption(sp.ServerId, store.Adoption{ContainerID: info.ID, Slug: sp.Slug, Version: a.Version}); err != nil {
		return nil, err
	}
	r.log.Info("imported server re-adopted from its spec", "server", sp.Slug, "container", info.Name)
	return adoptedContainer(sp.ServerId, sp.Slug, info.ID, info.Name, info.State), nil
}

// verifyAdoptable checks that the container exists, is neither an MC Server Manager one nor another
// server's, uses the itzg image, has its own network and mounts exactly dataDir on /data. Requires adoptMu.
func (r *Reconciler) verifyAdoptable(ctx context.Context, serverID, containerID, dataDir string) (*docker.ImportInfo, error) {
	info, err := r.eng.InspectImport(ctx, containerID)
	if errors.Is(err, docker.ErrNotFound) {
		return nil, fmt.Errorf("%w: %s", ErrAdoptNotFound, containerID)
	}
	if err != nil {
		return nil, fmt.Errorf("inspect the container to adopt: %w", err)
	}
	if info.Labels[spec.LabelManaged] == "true" {
		return nil, fmt.Errorf("%w: %s is already an MC Server Manager container", ErrAdoptConflict, info.Name)
	}
	if other, err := r.st.AdoptedBy(info.ID); err != nil {
		return nil, err
	} else if other != "" && other != serverID {
		return nil, fmt.Errorf("%w: %s was already adopted by another server", ErrAdoptConflict, info.Name)
	}
	if !spec.IsItzgImage(info.Image) {
		return nil, fmt.Errorf("%w: %s does not use the image %s (%s)", ErrAdoptMismatch, info.Name, spec.Image, info.Image)
	}
	if m := info.NetworkMode; m == "host" || m == "none" || strings.HasPrefix(m, "container:") {
		return nil, fmt.Errorf("%w: %s uses network %q; only containers with their own network are adopted", ErrAdoptMismatch, info.Name, m)
	}
	src := ""
	for _, m := range info.Mounts {
		if m.Destination == "/data" && m.Type == "bind" {
			src = filepath.Clean(m.Source)
		}
	}
	if src != filepath.Clean(dataDir) {
		return nil, fmt.Errorf("%w: the /data of %s is %q and the spec expects %q", ErrAdoptMismatch, info.Name, src, dataDir)
	}
	return info, nil
}

// connectAlias connects the container to the agent's network with the alias mcsm-<slug> (RCON, ping
// and metrics look it up by that name). If it is already on the network, it does nothing.
func (r *Reconciler) connectAlias(ctx context.Context, info *docker.ImportInfo, slug string) error {
	for _, n := range info.Networks {
		if n == r.network {
			return nil
		}
	}
	if err := r.eng.ConnectNetwork(ctx, r.network, info.ID, []string{spec.ContainerName(slug)}); err != nil {
		return fmt.Errorf("connect %s to network %s: %w", info.Name, r.network, err)
	}
	return nil
}

func adoptedContainer(serverID, slug, id, name, state string) *docker.Container {
	return &docker.Container{ID: id, Name: name, State: state, Adopted: true,
		Labels: map[string]string{spec.LabelServerID: serverID, spec.LabelSlug: slug}}
}

// findAdopted returns the server's adopted container, or nil if there is no adoption or its container
// no longer exists (reconcileLocked then cleans up the record).
func (r *Reconciler) findAdopted(ctx context.Context, serverID string) (*docker.Container, error) {
	ad, err := r.st.Adoption(serverID)
	if err != nil || ad == nil {
		return nil, err
	}
	ins, err := r.eng.Inspect(ctx, ad.ContainerID)
	if errors.Is(err, docker.ErrNotFound) {
		return nil, nil
	}
	if err != nil {
		return nil, fmt.Errorf("inspect the adopted container: %w", err)
	}
	return adoptedContainer(serverID, ad.Slug, ins.ID, ins.Name, ins.State), nil
}

// ServerContainers returns the containers of the node's servers: the managed ones and the adopted
// ones not yet recreated (Adopted, with synthesized labels). The metrics sampler uses it. An adopted
// container that no longer exists is skipped.
func (r *Reconciler) ServerContainers(ctx context.Context) ([]docker.Container, error) {
	list, err := r.eng.ListManaged(ctx)
	if err != nil {
		return nil, err
	}
	ads, err := r.st.Adoptions()
	if err != nil {
		return nil, err
	}
	have := map[string]bool{}
	for _, c := range list {
		have[c.Labels[spec.LabelServerID]] = true
	}
	ids := make([]string, 0, len(ads))
	for id := range ads {
		ids = append(ids, id)
	}
	sort.Strings(ids)
	for _, id := range ids {
		if have[id] {
			continue
		}
		ad := ads[id]
		ins, err := r.eng.Inspect(ctx, ad.ContainerID)
		if errors.Is(err, docker.ErrNotFound) {
			continue
		}
		if err != nil {
			return nil, err
		}
		list = append(list, *adoptedContainer(id, ad.Slug, ins.ID, ins.Name, ins.State))
	}
	return list, nil
}
```

```go
// Engine is what the import uses from Docker (docker.Engine satisfies it).
type Engine interface {
	ListAll(ctx context.Context) ([]docker.Container, error)
	InspectImport(ctx context.Context, id string) (*docker.ImportInfo, error)
	ImageEnv(ctx context.Context, image string) ([]string, error)
}

var _ Engine = docker.Engine(nil)

// composeLabels are the only labels that travel to the panel (it warns that Compose would recreate it).
var composeLabels = []string{"com.docker.compose.project", "com.docker.compose.service"}

// Scan returns the candidates to import, sorted by name: containers with the itzg/minecraft-server
// image, without the mcsm.managed label and not discarded by skip (the already adopted ones). If the
// image's ENV cannot be read, the env is sent in full. It never logs the env (it carries secrets).
func Scan(ctx context.Context, eng Engine, skip func(containerID string) bool) ([]*mcsmv1.ImportCandidate, error) {
	list, err := eng.ListAll(ctx)
	if err != nil {
		return nil, fmt.Errorf("list containers: %w", err)
	}
	sort.Slice(list, func(i, j int) bool { return list[i].Name < list[j].Name })
	var out []*mcsmv1.ImportCandidate
	for _, c := range list {
		if c.Labels[spec.LabelManaged] == "true" || skip(c.ID) {
			continue
		}
		info, err := eng.InspectImport(ctx, c.ID)
		if errors.Is(err, docker.ErrNotFound) {
			continue // removed between the list and the inspect
		}
		if err != nil {
			return nil, fmt.Errorf("inspect %s: %w", c.Name, err)
		}
		if !spec.IsItzgImage(info.Image) || info.Labels[spec.LabelManaged] == "true" {
			continue
		}
		imageEnv, err := eng.ImageEnv(ctx, info.ImageID)
		if err != nil {
			imageEnv = nil
		}
		out = append(out, candidate(info, UserEnv(info.Env, imageEnv)))
	}
	return out, nil
}

// UserEnv returns the container's env without the entries identical to the image's ENV: what the
// user set. An image variable with a different value does belong to the user.
func UserEnv(containerEnv, imageEnv []string) map[string]string {
	defaults := make(map[string]bool, len(imageEnv))
	for _, e := range imageEnv {
		defaults[e] = true
	}
	out := map[string]string{}
	for _, e := range containerEnv {
		if defaults[e] {
			continue
		}
		k, v, ok := strings.Cut(e, "=")
		if !ok || k == "" {
			continue
		}
		out[k] = v
	}
	return out
}

// valid sanitizes container text: proto3 rejects strings with invalid UTF-8 and the whole message would be lost.
func valid(s string) string { return strings.ToValidUTF8(s, "�") }

func candidate(info *docker.ImportInfo, env map[string]string) *mcsmv1.ImportCandidate {
	c := &mcsmv1.ImportCandidate{
		ContainerId: info.ID, Name: valid(info.Name), Image: valid(info.Image), State: info.State,
		Env: make(map[string]string, len(env)), RestartPolicy: info.Restart, MemoryLimitBytes: info.Memory,
		NanoCpus: info.NanoCPUs, NetworkMode: valid(info.NetworkMode), Labels: map[string]string{},
	}
	for k, v := range env {
		c.Env[valid(k)] = valid(v)
	}
	for _, k := range composeLabels {
		if v, ok := info.Labels[k]; ok {
			c.Labels[k] = valid(v)
		}
	}
	for _, n := range info.Networks {
		c.Networks = append(c.Networks, valid(n))
	}
	for _, p := range info.Ports {
		c.Ports = append(c.Ports, &mcsmv1.ImportPort{ContainerPort: uint32(p.ContainerPort), Proto: p.Proto, HostIp: p.HostIP, HostPort: uint32(p.HostPort)})
	}
	for _, m := range info.Mounts {
		c.Mounts = append(c.Mounts, &mcsmv1.ImportMount{Type: m.Type, Source: valid(m.Source), Destination: valid(m.Destination), ReadWrite: m.RW, Name: valid(m.Name)})
	}
	return c
}
```

```go
// handleImportAdopt adopts a container (it touches Docker and the store: the agent's life context).
func (a *App) handleImportAdopt(id uint64, m *mcsmv1.ImportAdopt, send func(*mcsmv1.Envelope) error) {

	}

		return
	}

}

// adoptErrCode translates a failure of Reconciler.Adopt to the protocol's Error.code.
func adoptErrCode(err error) string {
	switch {
	case errors.Is(err, reconcile.ErrAdoptNotFound):
		return errcode.NotFound
	case errors.Is(err, reconcile.ErrAdoptConflict):
		return errcode.Exists
	case errors.Is(err, reconcile.ErrAdoptMismatch):
		return errcode.InvalidRequest
	case errors.Is(err, reconcile.ErrAdoptSpec):
		return errcode.InvalidSpec
	case errors.Is(err, reconcile.ErrBusy):
		return errcode.Busy
	default:
		return errcode.ApplyFailed
	}
}
```

```ts
import { z } from "zod";

/**
 * `dataPath` (plan-6, spec §6.7): host folder mounted on /data of an imported server when it is not
 * <DATA_ROOT>/<slug>/data. Same rules as agent/internal/spec/adopt.go (ValidateDataPath); the cases in
 * proto/fixtures/data-path-cases.json are tested on both sides. The agent runs as root and itzg's
 * entrypoint does chown on /data: no system areas.
 */
export const DATA_PATH_MAX_BYTES = 1024;
const SEGMENT_RE = /^[A-Za-z0-9._@+ -]+$/;
export const DENIED_DATA_PATHS = [
  "/bin", "/boot", "/dev", "/etc", "/lib", "/lib32", "/lib64", "/libx32", "/proc", "/run",
  "/sbin", "/sys", "/usr", "/var/lib/docker", "/var/run",
] as const;

/** Is `child` `parent` or hangs from it? Clean absolute paths; compared by segments. */
export function pathWithin(child: string, parent: string): boolean {
  if (parent === "/") return child.startsWith("/");
  return child === parent || child.startsWith(`${parent}/`);
}

export const dataPathsOverlap = (a: string, b: string): boolean => pathWithin(a, b) || pathWithin(b, a);

const encoder = new TextEncoder();

/** Why `p` is not valid as a dataPath, or null. It does not know DATA_ROOT (the agent and the import check that). */
export function dataPathError(p: string): string | null {
  if (encoder.encode(p).length > DATA_PATH_MAX_BYTES) return `Path too long (max ${DATA_PATH_MAX_BYTES} bytes)`;
  if (!p.startsWith("/")) return "Must be an absolute path";
  const segs = p.slice(1).split("/");
  if (segs.length < 2) return "Path too general: use at least two levels";
  for (const s of segs) {
    if (s === "" || s === "." || s === "..") return "Path not normalized: no //, «.» or «..», and no trailing /";
    if (!SEGMENT_RE.test(s)) return "Unsupported characters: ASCII letters and digits, space and . _ @ + -";
  }
  const denied = DENIED_DATA_PATHS.find((d) => pathWithin(p, d));
  return denied ? `It is in a system area (${denied}): it is not mounted` : null;
}

export const dataPathSchema = z.string().superRefine((p, ctx) => {
  const e = dataPathError(p);
  if (e) ctx.addIssue({ code: "custom", message: `Data folder: ${e}` });
});

/** dataPath and scheduled backups do not coexist: the agent cannot see that folder (it only mounts DATA_ROOT). Same as validateImport in Go. */
export function dataPathCheck(s: { dataPath?: string | undefined; backups?: { enabled: boolean } | undefined }, ctx: z.RefinementCtx) {
  if (s.dataPath && s.backups?.enabled) {
    ctx.addIssue({ code: "custom", path: ["backups", "enabled"], message: "Scheduled backups are not available: this server's data is outside DATA_ROOT" });
  }
}

/**
 * Spec PATCH: only the import sets dataPath (it is the real folder of the adopted container). The PATCH
 * may resend it unchanged or remove it with null (it goes back to <DATA_ROOT>/<slug>/data). 400 message or null.
 */
export function dataPathPatchError(patch: Record<string, unknown>, previous: { dataPath?: string | undefined }): string | null {
  if (!Object.hasOwn(patch, "dataPath")) return null;
  const v = patch.dataPath;
  if (v === null || v === previous.dataPath) return null;
  return "The data folder (dataPath) is only set by importing a server: it cannot be changed here";
}
```

```ts
  if (!v || typeof v !== "object") return v;
```

```ts
import type { ImportCandidate } from "@mcsm/proto";
import {
  CURSEFORGE_API_KEY_RE, DIGITS_RE, ENTRY_RE, ENV_KEY_RE, IMAGE_TAG_RE, MAX_STRING_BYTES, MEMORY_RE, PLAYER_RE, PROPERTY_KEY_RE,
  RESERVED_ENV, RESERVED_PROPS, URL_RE, dataPathError, formatZodError, memoryToBytes, pathWithin, slugify, specInputSchema, utf8Bytes,
  type ImportCandidateDto, type SpecInput,
} from "@mcsm/shared";

/**
 * Agent candidate → proposed spec (spec §6.7). Pure: the list and the adoption use it (the adoption
 * scans again and recalculates, so as not to trust the browser). Rules table: “Mapping container →
 * candidate spec” in Plan 6. The secrets (RCON_PASSWORD, CF_API_KEY) only leave in rconPassword and
 * curseforgeApiKey, which never go to the browser (toCandidateDto), and no warning repeats values.
 */
export interface ProposeContext {
  /** The agent's DATA_ROOT (ImportScanResult.dataRoot). */
  dataRoot: string;
  /** Slugs already used on the node. */
  takenSlugs: ReadonlySet<string>;
  /** A CurseForge API key is set in Settings. */
  curseforgeConfigured: boolean;
}

export interface ImportProposal {
  name: string;
  slug: string;
  slugLocked: boolean;
  desiredState: "running" | "stopped";
  spec: SpecInput;
  specError: string | null;
  dataPath: string | null;
  rconPassword: string | null;
  curseforgeApiKey: string | null;
  blockers: string[];
  warnings: string[];
  hiddenEnv: string[];
}

const GAME_PORT = 25565;
const RCON_PORT = 25575;
const PLUGIN_TYPES = new Set(["PAPER", "PURPUR", "SPIGOT", "FOLIA", "BUKKIT", "PUFFERFISH", "LEAF"]);
const PLATFORMS = new Set(["MODRINTH", "AUTO_CURSEFORGE", "FTBA"]);
const RESTART = new Set(["no", "always", "unless-stopped", "on-failure"]);
const SECRET_ENV = ["RCON_PASSWORD", "CF_API_KEY"] as const;
export const COMPOSE_PROJECT = "com.docker.compose.project";
export const COMPOSE_SERVICE = "com.docker.compose.service";
const SLUG_DATA_RE = /^\/([a-z0-9][a-z0-9-]{0,39})\/data$/;

const truthy = (v: string | undefined) => v !== undefined && /^(true|1|yes|on)$/i.test(v.trim());
const falsy = (v: string | undefined) => v !== undefined && /^(false|0|no|off)$/i.test(v.trim());
/** itzg list: separated by commas or line breaks. */
const splitList = (v: string) => v.split(/[,\n]/).map((s) => s.trim()).filter(Boolean);

function uniqueSlug(base: string, taken: ReadonlySet<string>): string {
  if (!taken.has(base)) return base;
  for (let n = 2; ; n++) {
    const suffix = `-${n}`;
    const candidate = base.slice(0, 40 - suffix.length).replace(/-+$/g, "") + suffix;
    if (!taken.has(candidate)) return candidate;
  }
}

function imageTag(ref: string, warn: (m: string) => void): string {
  const rest = ref.replace(/^docker\.io\//, "").slice("itzg/minecraft-server".length);
  if (rest.startsWith("@")) {
    warn("The image is pinned by digest: on recreation the latest tag will be used (check the Java version in “Version and mods”)");
    return "latest";
  }
  if (rest.startsWith(":")) {
    const tag = rest.slice(1).split("@")[0] ?? "";
    if (IMAGE_TAG_RE.test(tag)) return tag;
    warn(`The image tag “${tag}” is not valid for the panel: on recreation latest will be used`);
  }
  return "latest";
}

function memLimitText(bytes: bigint): string {
  const MiB = 1024n * 1024n;
  const GiB = 1024n * MiB;
  return bytes % GiB === 0n ? `${bytes / GiB}G` : `${(bytes + MiB - 1n) / MiB}M`;
}

export function proposeImport(c: ImportCandidate, ctx: ProposeContext): ImportProposal {
  const blockers: string[] = [];
  const warnings: string[] = [];
  const warn = (m: string) => { if (!warnings.includes(m)) warnings.push(m); };
  const env: Record<string, string> = { ...c.env };
  const take = (k: string): string | undefined => { const v = env[k]; delete env[k]; return v; };
  const hiddenEnv = SECRET_ENV.filter((k) => k in env);
  const root = ctx.dataRoot.replace(/\/+$/, "") || "/";

  // Network.
  const mode = c.networkMode;
  if (mode === "host" || mode === "none" || mode.startsWith("container:")) {
    blockers.push(`Uses network “${mode}”: only containers with their own network (bridge or a user network) can be imported`);
  }

  // /data.
  let slugLocked = false;
  let lockedSlug = "";
  let dataPath: string | null = null;
  const data = c.mounts.find((m) => m.destination === "/data");
  if (!data) blockers.push("It does not mount /data: the world lives inside the container and would be lost on recreation. Mount a host folder on /data and search again");
  else if (data.type !== "bind") blockers.push(`Its /data is a Docker volume (“${data.name || data.source}”): only host folders mounted on /data can be imported`);
  else if (!data.readWrite) blockers.push("Its /data is read-only");
  else {
    const src = data.source;
    const m = pathWithin(src, root) ? SLUG_DATA_RE.exec(src.slice(root === "/" ? 0 : root.length)) : null;
    if (m) {
      slugLocked = true;
      lockedSlug = m[1]!;
    } else if (pathWithin(src, root) || pathWithin(root, src)) {
      blockers.push(`The data is in ${src}, which ${pathWithin(src, root) ? "is inside" : "contains"} DATA_ROOT (${root}) without being ${root}/<slug>/data: move it to ${root}/<slug>/data or outside DATA_ROOT and search again`);
    } else {
      const err = dataPathError(src);
      if (err) blockers.push(`Cannot use ${src} as a data folder: ${err}`);
      else {
        dataPath = src;
        warn(`The data stays outside DATA_ROOT (${src}): this server will not have backups nor a file browser. To have them, stop the container and move the folder to ${root}/<slug>/data before importing`);
      }
    }
  }
  for (const m of c.mounts) if (m.destination !== "/data") warn(`The mount ${m.source || m.name} → ${m.destination} is not kept when the container is recreated`);

  // Ports.
  let game: number | undefined;
  const extra: { host: number; container: number; proto: "tcp" | "udp"; label: string }[] = [];
  const seen = new Set<string>();
  for (const p of c.ports) {
    if (p.containerPort === GAME_PORT && p.proto === "tcp") {
      if (p.hostPort === 0) continue;
      game ??= p.hostPort;
      if (p.hostIp) warn(`Port ${p.hostPort} only listens on ${p.hostIp}: on recreation it will be published on all interfaces`);
      continue;
    }
    if (p.containerPort === RCON_PORT) {
      warn("Publishes RCON (25575) on the host: on recreation it will stop being published (the panel uses RCON over the internal network)");
      continue;
    }
    if (p.hostPort === 0 || (p.proto !== "tcp" && p.proto !== "udp")) continue;
    const key = `${p.hostPort}/${p.containerPort}/${p.proto}`;
    if (seen.has(key)) continue;
    seen.add(key);
    extra.push({ host: p.hostPort, container: p.containerPort, proto: p.proto as "tcp" | "udp", label: "" });
  }
  if (game === undefined) blockers.push("It does not publish port 25565/tcp on a fixed host port (ports: \"<port>:25565\"): the panel manages the game port this way");
  const serverPort = take("SERVER_PORT");
  if (serverPort !== undefined && serverPort.trim() !== String(GAME_PORT)) {
    blockers.push(`The server listens on SERVER_PORT=${serverPort} inside the container; the panel only manages 25565`);
  }

  // RCON and secrets.
  take("EULA");
  const rconEnv = take("RCON_PASSWORD");
  const rconOk = rconEnv !== undefined && rconEnv.length >= 8 && utf8Bytes(rconEnv) <= MAX_STRING_BYTES;
  const rconOff = falsy(take("ENABLE_RCON"));
  const rconPort = take("RCON_PORT");
  const rconPortOk = rconPort === undefined || rconPort.trim() === String(RCON_PORT);
  if (!rconOk || rconOff || !rconPortOk) {
    const why = rconOff ? "the container has RCON disabled" : !rconPortOk ? `it uses RCON_PORT=${rconPort}` : "it does not set RCON_PASSWORD (or it has fewer than 8 characters)";
    warn(`The command console (RCON) will not work until the first “Save and apply”: ${why}. On recreation the panel enables RCON with ${rconOk ? "the same password" : "a new password"}`);
  }
  const cfKey = take("CF_API_KEY");
  let curseforgeApiKey: string | null = null;
  if (cfKey !== undefined) {
    if (ctx.curseforgeConfigured) warn("The container has its own CF_API_KEY: on recreation the CurseForge API key from Settings will be used");
    else if (CURSEFORGE_API_KEY_RE.test(cfKey)) {
      curseforgeApiKey = cfKey;
      warn("The container's CF_API_KEY will be saved in Settings when importing it if the server uses CurseForge (none is configured)");
    } else warn("The container's CF_API_KEY is not valid and is discarded");
  }

  // Type, version and memory.
  let type = (take("TYPE") ?? "").trim().toUpperCase();
  const platform = env.MODPACK_PLATFORM?.trim().toUpperCase();
  if (platform && PLATFORMS.has(platform) && (type === "" || type === "VANILLA")) {
    type = platform;
    delete env.MODPACK_PLATFORM;
  }
  if (!type) type = "VANILLA";
  const version = (take("VERSION") ?? "").trim() || "LATEST";
  const memRaw = take("MEMORY")?.trim();
  let memory = "1G";
  if (memRaw) {
    if (MEMORY_RE.test(memRaw)) memory = memRaw;
    else warn(`MEMORY=${memRaw} does not have the panel's format (4G, 512M): 1G is proposed; check it in “Resources”`);
  }

  // Modpack.
  let modpack: SpecInput["modpack"];
  if (type === "MODRINTH" && env.MODRINTH_MODPACK !== undefined) {
    modpack = {
      platform: "MODRINTH", slugOrUrl: take("MODRINTH_MODPACK")!.trim(), versionId: take("MODRINTH_VERSION")?.trim() ?? "",
      loader: (take("MODRINTH_LOADER")?.trim().toLowerCase() ?? "") as NonNullable<SpecInput["modpack"]>["loader"],
    };
  } else if (type === "AUTO_CURSEFORGE" && (env.CF_SLUG !== undefined || env.CF_PAGE_URL !== undefined)) {
    const slug = take("CF_SLUG");
    const page = slug === undefined ? take("CF_PAGE_URL") : undefined;
    modpack = { platform: "AUTO_CURSEFORGE", slugOrUrl: (slug ?? page ?? "").trim(), versionId: take("CF_FILE_ID")?.trim() ?? "", loader: "" };
  } else if (type === "FTBA" && env.FTB_MODPACK_ID !== undefined) {
    modpack = { platform: "FTBA", slugOrUrl: take("FTB_MODPACK_ID")!.trim(), versionId: take("FTB_MODPACK_VERSION_ID")?.trim() ?? "", loader: "" };
  }

  // Mods and plugins: only if all the entries are valid (otherwise the variable stays in env as is).
  const moveList = (key: string, re: RegExp): string[] | undefined => {
    const v = env[key];
    if (v === undefined) return undefined;
    const items = splitList(v);
    if (!items.every((i) => re.test(i))) return undefined;
    delete env[key];
    return items;
  };
  const pluginsKind = PLUGIN_TYPES.has(type);
  const modrinth = moveList("MODRINTH_PROJECTS", ENTRY_RE);
  const cfFiles = moveList("CURSEFORGE_FILES", ENTRY_RE);
  const modUrls = moveList("MODS", URL_RE);
  const pluginUrls = moveList("PLUGINS", URL_RE);
  const spiget = moveList("SPIGET_RESOURCES", DIGITS_RE);
  let mods: SpecInput["mods"];
  let plugins: SpecInput["plugins"];
  if ((modrinth && !pluginsKind) || cfFiles || modUrls) {
    mods = { modrinthProjects: !pluginsKind ? (modrinth ?? []) : [], curseforgeFiles: cfFiles ?? [], urls: modUrls ?? [] };
  }
  if ((modrinth && pluginsKind) || pluginUrls || spiget) {
    plugins = { modrinthProjects: pluginsKind ? (modrinth ?? []) : [], spigetResources: spiget ?? [], urls: pluginUrls ?? [] };
  }

  // Properties.
  const properties: Record<string, string> = {};
  const custom = take("CUSTOM_SERVER_PROPERTIES");
  if (custom !== undefined) {
    const dropped: string[] = [];
    for (const raw of custom.split("\n")) {
      const line = raw.replace(/\r$/, "").trim();
      if (!line || line.startsWith("#")) continue;
      const i = line.indexOf("=");
      const k = i > 0 ? line.slice(0, i).trim() : "";
      if (!k || !PROPERTY_KEY_RE.test(k) || RESERVED_PROPS.has(k)) {
        dropped.push(k && PROPERTY_KEY_RE.test(k) ? k : "(line without a valid key=value)"); // never the value: it may be rcon.password
        continue;
      }
      properties[k] = line.slice(i + 1).trim();
    }
    if (dropped.length) warn(`From CUSTOM_SERVER_PROPERTIES these are discarded: ${dropped.join(", ")}`);
  }

  // Players: sections only if the container already synchronizes the file (otherwise they would delete what was added from the game).
  let whitelist: SpecInput["whitelist"];
  let ops: string[] | undefined;
  if (env.EXISTING_WHITELIST_FILE?.trim().toUpperCase() === "SYNCHRONIZE" && env.WHITELIST_FILE === undefined
    && (env.WHITELIST !== undefined || env.ENABLE_WHITELIST !== undefined)
    && !("white-list" in properties) && !("enforce-whitelist" in properties)) {
    const players = env.WHITELIST !== undefined ? splitList(env.WHITELIST) : [];
    const en = env.ENABLE_WHITELIST;
    const enabled = truthy(en) || (en === undefined && players.length > 0);
    const coherent = en === undefined || truthy(en) || (falsy(en) && players.length === 0);
    if (coherent && players.every((p) => PLAYER_RE.test(p))) {
      whitelist = { enabled, players };
      delete env.WHITELIST;
      delete env.ENABLE_WHITELIST;
      delete env.EXISTING_WHITELIST_FILE;
    }
  }
  if (env.EXISTING_OPS_FILE?.trim().toUpperCase() === "SYNCHRONIZE" && env.OPS_FILE === undefined && env.OPS !== undefined) {
    const list = splitList(env.OPS);
    if (list.every((p) => PLAYER_RE.test(p))) {
      ops = list;
      delete env.OPS;
      delete env.EXISTING_OPS_FILE;
    }
  }
  if (env.WHITELIST !== undefined || env.OPS !== undefined) {
    warn("The whitelist and operators stay as environment variables (Advanced) because the container does not synchronize those files: this way what was added from the game is not lost");
  }

  // Rest of the env.
  const passEnv: Record<string, string> = {};
  for (const [k, v] of Object.entries(env)) {
    if (!ENV_KEY_RE.test(k) || RESERVED_ENV.has(k)) {
      warn(`The variable ${k} cannot be kept and is discarded`);
      continue;
    }
    passEnv[k] = v;
  }

  // Restart and resources.
  let restartPolicy = c.restartPolicy || "no";
  if (!RESTART.has(restartPolicy)) {
    warn(`Unknown restart policy “${restartPolicy}”: unless-stopped is proposed`);
    restartPolicy = "unless-stopped";
  }
  const cpus = Math.round(Number(c.nanoCpus) / 1e7) / 100;
  let memLimit = "";
  if (c.memoryLimitBytes > 0n) {
    memLimit = memLimitText(c.memoryLimitBytes);
    if (memoryToBytes(memLimit) < memoryToBytes(memory)) {
      warn(`Docker's memory limit (${memLimit}) is lower than MEMORY (${memory}): it is removed (the agent sets memory + 1G)`);
      memLimit = "";
    }
  } else {
    warn("Docker does not limit its memory: on recreation it will be limited to MEMORY + 1G");
  }

  // Name, slug and state.
  const project = c.labels[COMPOSE_PROJECT] ?? "";
  const service = c.labels[COMPOSE_SERVICE] ?? "";
  if (project) {
    warn(`Docker Compose created it (project “${project}”, service “${service}”): before the first “Save and apply”, remove that service from the compose file (or do not run “docker compose up” again), or Compose will recreate the original container next to the panel's`);
  }
  const name = (c.name || service || "Imported server").slice(0, 60);
  let slug: string;
  if (slugLocked) {
    slug = lockedSlug;
    if (ctx.takenSlugs.has(slug)) blockers.push(`There is already a server “${slug}” on this node and this container's data is in ${root}/${slug}/data`);
  } else {
    slug = uniqueSlug(slugify(c.name || service), ctx.takenSlugs);
  }
  const desiredState = c.state === "running" || c.state === "restarting" ? "running" : "stopped";

  const raw = {
    imageTag: imageTag(c.image, warn), type, version, memory, properties, env: passEnv,
    resources: { cpus, memLimit }, restartPolicy, ports: { ...(game !== undefined ? { game } : {}), extra },
    ...(modpack ? { modpack } : {}), ...(mods ? { mods } : {}), ...(plugins ? { plugins } : {}),
    ...(whitelist ? { whitelist } : {}), ...(ops ? { ops } : {}),
  };
  const parsed = specInputSchema.safeParse(raw);
  return {
    name, slug, slugLocked, desiredState,
    spec: parsed.success ? parsed.data : (raw as unknown as SpecInput),
    specError: parsed.success ? null : formatZodError(parsed.error),
    dataPath, rconPassword: rconOk ? rconEnv! : null, curseforgeApiKey, blockers, warnings, hiddenEnv,
  };
}

/** DTO for the browser: without rconPassword nor curseforgeApiKey. */
export function toCandidateDto(c: ImportCandidate, p: ImportProposal): ImportCandidateDto {

    proposal: { name: p.name, slug: p.slug, slugLocked: p.slugLocked, desiredState: p.desiredState, spec: p.spec, specError: p.specError, dataPath: p.dataPath },
  };
}
```

```ts
import type { FastifyInstance } from "fastify";
import type { ImportCandidate } from "@mcsm/proto";
import {
  dataPathsOverlap, formatZodError, sameSpecInput, specInputSchema, specSchema, specSizeError, usesCurseForge,
  type ImportAdoptInput, type ImportCandidateDto, type ImportedFrom, type Spec,
} from "@mcsm/shared";
import { AgentError, type AgentConn } from "../agents/hub.js";
import { AgentErrorCode } from "../agents/error-codes.js";
import { HttpError, agentErrorToHttp } from "../lib/http.js";
import { nowIso } from "../lib/time.js";
import { randomToken } from "../lib/tokens.js";
import { parseImportedFrom, toServerDto, toServerSpecMessage, type ServerDto } from "../servers/repo.js";
import { COMPOSE_PROJECT, COMPOSE_SERVICE, proposeImport, toCandidateDto, type ImportProposal } from "./propose.js";

const SCAN_TIMEOUT_MS = 30_000;
const ADOPT_TIMEOUT_MS = 60_000;

interface Scanned { candidate: ImportCandidate; proposal: ImportProposal }

/** Import of existing servers (spec §6.7, §7 ImportService). */
export class ImportService {
  constructor(private app: FastifyInstance) {}

  private conn(nodeId: string): AgentConn {
    if (!this.app.nodes.get(nodeId)) throw new HttpError(404, "Node not found");
    const conn = this.app.agents.get(nodeId);
    if (!conn) throw new HttpError(409, "The node is offline");
    return conn;
  }

  /** ImportScan + proposal for each candidate. Containers already imported on this node are left out. */
  private async scan(nodeId: string, conn: AgentConn): Promise<Scanned[]> {
    let res;
    try {
      res = await conn.request({ case: "importScan", value: {} }, SCAN_TIMEOUT_MS);
    } catch (e) {
      throw agentErrorToHttp(e, "The agent could not list the containers");
    }
    if (res.body.case !== "importScanResult") throw new HttpError(502, "Unexpected response from the agent");
    const { candidates, dataRoot } = res.body.value;
    const rows = this.app.servers.list(nodeId);
    const imported = new Set(rows.map((r) => parseImportedFrom(r)?.containerId).filter((id): id is string => !!id));
    const ctx = { dataRoot, takenSlugs: new Set(rows.map((r) => r.slug)), curseforgeConfigured: this.app.curseforge.get() !== null };
    return candidates.filter((c) => !imported.has(c.containerId)).map((c) => ({ candidate: c, proposal: proposeImport(c, ctx) }));
  }

  async candidates(nodeId: string): Promise<ImportCandidateDto[]> {
    const conn = this.conn(nodeId);
    return (await this.scan(nodeId, conn)).map(({ candidate, proposal }) => toCandidateDto(candidate, proposal));
  }

  /**
   * Adopts a candidate. It scans again (it does not trust what the browser sent): dataPath, the RCON
   * password and the CurseForge key come from the container. Without applyNow it requires the proposal
   * unchanged (spec v1 describes the container that keeps running); with applyNow it goes up to v2 after the Ack.
   */
  async adopt(nodeId: string, input: ImportAdoptInput): Promise<ServerDto> {
    const conn = this.conn(nodeId);
    const found = (await this.scan(nodeId, conn)).find((s) => s.candidate.containerId === input.containerId);
    if (!found) throw new HttpError(404, "That container can no longer be imported: it does not exist, the panel already manages it or it was already imported");
    const { candidate: c, proposal: p } = found;
    if (p.blockers.length > 0) throw new HttpError(409, p.blockers[0]!);

    const { dataPath: _fromBrowser, ...edited } = input.spec; // dataPath comes from the container, never from the browser
    const parsed = specInputSchema.safeParse(edited);
    if (!parsed.success) throw new HttpError(400, formatZodError(parsed.error));
    if (!input.applyNow && (p.specError !== null || !sameSpecInput(p.spec, parsed.data))) {
      throw new HttpError(409, "The configuration is not the container's: adopting it without stopping requires the proposal unchanged. Use “Adopt and apply” (recreates the container) or undo the changes");
    }

    const slug = input.slug ?? p.slug;
    if (p.slugLocked && slug !== p.slug) throw new HttpError(400, `The slug must be “${p.slug}”: the data is already in DATA_ROOT/${p.slug}/data`);
    if (this.app.servers.getBySlug(nodeId, slug)) throw new HttpError(409, `A server with slug "${slug}" already exists on this node`);
    if (p.dataPath) {
      for (const r of this.app.servers.list(nodeId)) {
        const other = (JSON.parse(r.spec) as Spec).dataPath;
        if (other && dataPathsOverlap(other, p.dataPath)) throw new HttpError(409, `Server “${r.name}” already uses that data folder (${other})`);
      }
    }
    const full = specSchema.safeParse({
      ...parsed.data,
      ports: { game: parsed.data.ports.game ?? p.spec.ports.game, extra: parsed.data.ports.extra },
      rconPassword: p.rconPassword ?? randomToken(),
      ...(p.dataPath ? { dataPath: p.dataPath } : {}),
    });
    if (!full.success) throw new HttpError(400, formatZodError(full.error));
    const tooBig = specSizeError(full.data);
    if (tooBig) throw new HttpError(400, tooBig);
    this.app.serversService.checkPorts(nodeId, full.data);

    // The container's CurseForge key goes to Settings if there was none. Not reapplied to the other
    // servers (recreating them because of an import would be a surprise): they will receive it on their next change.
    if (p.curseforgeApiKey && usesCurseForge(full.data) && this.app.curseforge.get() === null) {
      this.app.curseforge.set(p.curseforgeApiKey);
    }

    const created = this.app.servers.create({ nodeId, name: input.name, slug, spec: full.data, desiredState: p.desiredState });
    const from: ImportedFrom = {
      containerId: c.containerId, containerName: c.name, specVersion: created.spec_version, importedAt: nowIso(),
      composeProject: c.labels[COMPOSE_PROJECT] ?? "", composeService: c.labels[COMPOSE_SERVICE] ?? "",
    };
    let row = this.app.servers.setImportedFrom(created.id, from);
    try {
      await conn.request({ case: "importAdopt", value: { server: toServerSpecMessage(row, this.app.curseforge.get()) } }, ADOPT_TIMEOUT_MS);
    } catch (e) {
      if (e instanceof AgentError && (e.code === AgentErrorCode.Timeout || e.code === AgentErrorCode.Disconnected)) {
        // The agent may have adopted it: deleting the row would make the next SyncSpecs retire the server
        // and delete the original container. It is kept: on reconnect, its spec (with adopt) completes the adoption.
        this.app.log.warn({ nodeId, serverId: row.id, code: e.code }, "ImportAdopt not confirmed; the imported server is kept");
        throw new HttpError(504, "The agent did not confirm the adoption in time. The server stays imported and the adoption will complete when the node responds: check its status in a few seconds");
      }
      this.app.servers.delete(row.id);
      throw agentErrorToHttp(e, "The agent could not adopt the container");
    }
    if (input.applyNow) {
      row = this.app.servers.bumpVersion(row.id);
      void this.app.serversService.push(row);
    }
    return toServerDto(row, { includeSecrets: true });
  }
}
```

```ts
import { sameSpecInput, type ImportCandidateDto } from "@mcsm/shared";
import type { ServerDto } from "./api";
import type { EditableSpec } from "./spec-edit";

/** What the user reviews before adopting a container (Nodes → Import). */
export interface ReviewState { name: string; slug: string; spec: EditableSpec }

export function initialReview(c: ImportCandidateDto): ReviewState {
  return { name: c.proposal.name, slug: c.proposal.slug, spec: c.proposal.spec };
}

/** Is the reviewed spec the one deduced from the container, and is this one valid? Only then is it adopted without stopping. */
export function isPristine(c: ImportCandidateDto, spec: EditableSpec): boolean {
  return c.proposal.specError === null && sameSpecInput(c.proposal.spec, spec);
}

const SLUG_RE = /^[a-z0-9][a-z0-9-]{0,39}$/;

/**
 * Why it cannot be adopted (null = it can). `applyNow`: “Adopt and apply” (recreates right away);
 * otherwise “Adopt without stopping”, which requires the proposal unchanged. `specError`: validateSpec of the review.
 */
export function adoptBlock(
  c: ImportCandidateDto, r: ReviewState,
  o: { fieldErrors: Readonly<Record<string, string>>; specError: string | null; applyNow: boolean },
): string | null {
  if (c.blockers.length > 0) return c.blockers[0]!;
  if (!r.name.trim()) return "Enter a name";
  if (!SLUG_RE.test(r.slug)) return "Invalid slug: lowercase letters, numbers and hyphens (max. 40)";
  const n = Object.keys(o.fieldErrors).length;
  if (n > 0) return `Fix ${n} ${n === 1 ? "field with an error" : "fields with errors"}`;
  if (o.specError) return o.specError;
  if (!o.applyNow && !isPristine(c, r.spec)) {
    return c.proposal.specError
      ? "The container's configuration is not valid as it is: correct it and use “Adopt and apply”"
      : "You have changed the configuration: use “Adopt and apply” (recreates the container) or undo the changes";
  }
  return null;
}

/** Body of POST /api/nodes/:id/import. dataPath is not sent (the panel takes it from the container), nor the slug when it is fixed. */
export function adoptRequest(c: ImportCandidateDto, r: ReviewState, applyNow: boolean) {
  const { dataPath: _fromContainer, ...spec } = r.spec;
  return { containerId: c.containerId, name: r.name.trim(), ...(c.proposal.slugLocked ? {} : { slug: r.slug }), spec, applyNow };
}

/** The server still runs in the original container it was imported from (not yet recreated). */
export function isAdopted(s: Pick<ServerDto, "importedFrom" | "observed">): boolean {
  return !!s.importedFrom && !!s.observed && s.observed.containerId === s.importedFrom.containerId;
}

/** Notices for the header of the server page. */
export function importNotices(s: Pick<ServerDto, "importedFrom" | "observed" | "slug" | "spec">): string[] {
  const out: string[] = [];
  const from = s.importedFrom;
  if (from && isAdopted(s)) {
    out.push(`Imported from “${from.containerName}”: it stays in its original container until the first “Save and apply”, which will recreate it as mcsm-${s.slug} (brief stop; the world is not touched) and delete the original container.`);
    if (from.composeProject) {
      out.push(`It comes from Docker Compose (project “${from.composeProject}”, service “${from.composeService}”): remove that service from the compose file before applying changes, or Compose will recreate it.`);
    }
  }
  if (s.spec.dataPath) {
    out.push(`The data is in ${s.spec.dataPath}, outside DATA_ROOT: this server has no backups nor a file browser.`);
  }
  return out;
}

const STATES: Record<string, string> = {
  running: "Running", exited: "Stopped", created: "Created", restarting: "Restarting", paused: "Paused", dead: "Dead",
};
export const candidateStateLabel = (state: string): string => STATES[state] ?? state;
```
