# MC Server Manager — Plan 5: Files and transfers

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** *Files* tab of the server: browse `/data`, edit text with CodeMirror 6, upload, download, rename, delete and create folders, with the agent confined to the data directory and a generic mechanism of HTTP streaming transfers (`/agent/transfer/:id`) that backups and migration will reuse in wave B.

**Architecture:** The agent adds the package `internal/files` (lexical validation + `filepath.EvalSymlinks` with prefix + I/O through `os.Root`, atomic writes) and handles the `Files*` messages of the WebSocket; large files travel over the agent's outbound HTTP with its token (`conn.TransferClient`). The panel creates single-use transfers bound to the node (`TransferService`), serves them at `GET/PUT /agent/transfer/:id` and links in streaming the browser body with the agent's one, without loading anything in memory or passing through disk; the staging (`<DATA_DIR>/staging`) is ready for wave B. The web adds the tab with a file browser and a CodeMirror editor loaded on demand.

**Tech Stack:** Go 1.27.2 (`os.Root`, `net/http`), protobuf with buf 1.73; Node 26, Fastify 5 (`application/octet-stream` parser as a stream), `node:stream`, zod 4; React 19, TanStack Query, CodeMirror 6 (`codemirror` 6.0.2, `@codemirror/state` 6.7, `@codemirror/view` 6.43, `@codemirror/language` 6.13, `@codemirror/lang-json` 6.0, `@codemirror/legacy-modes` 6.5, `@codemirror/theme-one-dark` 6.1; versions checked with `npm view` on 2026-10-12).

**Spec:** `docs/superpowers/specs/2026-10-12-mc-server-manager-design.md` (§5.1 HTTP transfers and staging, §5.3 `Files*`, §6.6 files, §8 Files tab, §9 security, §10 errors). Roadmap: `docs/superpowers/plans/README.md` (Plan 5). Wave A coordination: `docs/superpowers/plans/COORDINATION.md`.

## Review Focus

1. **Paths that leave `/data`** — `../../etc/passwd` → 400 in the panel (zod) and `invalid_path` in the agent; a link created inside `/data` by a plugin (absolute, relative, or toward the sibling folder `data2` that shares the prefix) → `path_outside`, also when the final component does not exist; a link changed between the check and the use (TOCTOU) does not escape thanks to `os.Root`. Tests: Task 2 (`TestTraversalRejected`, `TestSymlinksOutsideAreRejected`, `TestTOCTOUSwapToSymlinkIsRefused`), Task 3 (`TestWriteErrors`, `TestRename`, `TestDelete`), Task 6, Task 9 (400 with the node disconnected), Task 13.
2. **Writes that leave the file half-written or with another owner** — a save or upload cut off does not touch the original nor leave temporaries; permissions and uid/gid are kept so that itzg (uid 1000) can rewrite `server.properties`. Tests: Task 3 (`TestWriteFailureKeepsOriginal`, `TestWriteTruncatedTransferKeepsOriginal`, `TestWriteReplacesAtomicallyKeepingMode`), Task 5 (`TestFilesUploadTruncatedDoesNotReplace`), Task 13 (`stat` of the uploaded file).
3. **Inline limit of 2 MiB** — reading or saving more than 2 MiB gives 413 with a message that tells you to download; a FIFO inside `/data` does not block the agent. Tests: Task 2 (`TestReadLimits`), Task 3, Task 9 (413 without reaching the agent), Task 11 (`canEdit`).
4. **50 MB upload without loading it in memory** — the panel does not accumulate the body (the agent receives data before the browser finishes sending), the agent writes with constant memory and an agent cut returns its error to the browser as JSON, not as a network cut. Tests: Task 3 (`TestWriteFromStreamsWithoutBuffering`), Task 5 (`TestFilesUploadStreamsFromPanel`), Task 10 (50 MiB upload with a gate and an agent cut), Task 13 (panel RSS).
5. **Reused, foreign or abandoned `transferId`** — second use → 404; the token of another node → 404 without burning it; not claimed within 60 s → it expires and the browser upload gets 504; `HEAD` does not consume it; the staging is emptied at startup and swept. Tests: Task 7, Task 8 and Task 10 (upload with the agent that never makes the GET).
6. **Download names and content type** — `mundo ñ.dat`, quotes or `\r\n` in the name do not break nor inject headers; an uploaded `.html` is never rendered in the panel's origin (`octet-stream` + `nosniff`). Tests: Task 10 (`contentDisposition`, download headers).

```proto
// ── plan-5 ──
// Files of a server (spec §5.3, §6.6). The paths are relative to the server's /data,
// with "/" as separator ("/" is the root); the agent rejects ".." and control
// characters. Responses: the *Result messages, Ack or Error{code, message} with
// code ∈ invalid_path|path_outside|unknown_server|not_found|exists|is_dir|not_dir|
// too_large|root|transfer_failed|io_error.

message FileEntry {
  string name = 1;
  bool dir = 2;
  bool symlink = 3;
  uint64 size = 4;
  int64 mod_time_unix_ms = 5;
  uint32 mode = 6; // permission bits (0o755…)
}

message FilesList {
  string server_id = 1;
  string path = 2;
}

message FilesListResult {
  repeated FileEntry entries = 1; // folders first, then by name
  bool truncated = 2; // the folder has more entries than those returned
}

message FilesStat {
  string server_id = 1;
  string path = 2;
}

message FilesStatResult {
  FileEntry entry = 1;
}

// Inline read: at most 2 MiB (or max_bytes if smaller); otherwise too_large.
message FilesRead {
  string server_id = 1;
  string path = 2;
  uint32 max_bytes = 3;
}

message FilesReadResult {
  bytes content = 1;
  uint64 size = 2;
}

// Atomic inline write (temporary + rename), at most 2 MiB. Response: Ack.
message FilesWrite {
  string server_id = 1;
  string path = 2;
  bytes content = 3;
}

message FilesMkdir {
  string server_id = 1;
  string path = 2;
}

// Does not overwrite: if `to` exists it responds exists.
message FilesRename {
  string server_id = 1;
  string from = 2;
  string to = 3;
}

// A folder is deleted with all its contents; a link deletes itself.
message FilesDelete {
  string server_id = 1;
  string path = 2;
}

// The agent uploads the file with PUT /agent/transfer/{transfer_id} and responds Ack
// when the panel has received it entirely.
message FilesDownload {
  string server_id = 1;
  string path = 2;
  string transfer_id = 3;
}

// The agent downloads the content with GET /agent/transfer/{transfer_id}, writes it
// atomically and responds Ack. size = -1 if the panel does not know the size.
message FilesUpload {
  string server_id = 1;
  string path = 2;
  string transfer_id = 3;
  int64 size = 4;
}
```

```go
// layout creates <tmp>/srv/alpha/data (the root), a secret outside it and a sibling
// folder data2 whose name shares the prefix with the root.
func layout(t *testing.T) (fsys *FS, root, outside string) {
	t.Helper()
	base := t.TempDir()
	root = filepath.Join(base, "srv", "alpha", "data")
	outside = filepath.Join(base, "outside")
	for _, d := range []string{root, outside, filepath.Join(root, "mods"), filepath.Join(root, "config"), filepath.Join(base, "srv", "alpha", "data2")} {
		if err := os.MkdirAll(d, 0o755); err != nil {
			t.Fatal(err)
		}
	}
	write(t, filepath.Join(outside, "secret.txt"), "SECRETO")
	write(t, filepath.Join(base, "srv", "alpha", "data2", "secret.txt"), "SECRETO2")
	write(t, filepath.Join(root, "server.properties"), "motd=hola\n")
	write(t, filepath.Join(root, "config", "a.yml"), "a: 1\n")
	return New(root), root, outside
}

func write(t *testing.T, p, s string) {
	t.Helper()
	if err := os.WriteFile(p, []byte(s), 0o644); err != nil {
		t.Fatal(err)
	}
}

func TestClean(t *testing.T) {
	ok := map[string]string{"": ".", "/": ".", ".": ".", "mods": "mods", "/mods/a.jar": "mods/a.jar", "mods//a.jar/": "mods/a.jar", "./config/./a.yml": "config/a.yml", "con espacios/ñ.txt": "con espacios/ñ.txt"}
	for in, want := range ok {
		got, err := Clean(in)
		if err != nil || got != want {
			t.Errorf("Clean(%q) = %q, %v; want %q", in, got, err, want)
		}
	}
	for _, in := range []string{"../../etc/passwd", "/..", "mods/../../x", "a/../b", "a\x00b", "a\nb", "a\rb", string(make([]byte, 5000))} {
		if _, err := Clean(in); !errors.Is(err, ErrInvalidPath) {
			t.Errorf("Clean(%q) = %v; want ErrInvalidPath", in, err)
		}
	}
}

func TestTraversalRejected(t *testing.T) {
	fsys, _, _ := layout(t)

	}

func TestSymlinksOutsideAreRejected(t *testing.T) {
	fsys, root, outside := layout(t)
	must(t, os.Symlink(outside, filepath.Join(root, "abs")))                       // absolute, outside
	must(t, os.Symlink("../../../outside/secret.txt", filepath.Join(root, "rel"))) // relative, outside
	must(t, os.Symlink("../data2", filepath.Join(root, "sibling")))                // sibling with a common prefix
	cases := []string{"abs/secret.txt", "rel", "sibling/secret.txt", "abs/no-existe"}
	for _, p := range cases {
		if _, _, err := fsys.Read(p, 0); !errors.Is(err, ErrOutside) {
			t.Errorf("Read(%q) = %v; want ErrOutside", p, err)
		}
		if _, err := fsys.Stat(p); !errors.Is(err, ErrOutside) {
			t.Errorf("Stat(%q) = %v; want ErrOutside", p, err)
		}
		if f, _, err := fsys.Open(p); !errors.Is(err, ErrOutside) {
			if f != nil {
				f.Close()
			}
			t.Errorf("Open(%q) = %v; want ErrOutside", p, err)
		}
	}
	if _, _, err := fsys.List("abs"); !errors.Is(err, ErrOutside) {
		t.Errorf("List(abs) = %v", err)
	}
}
```

```go
// Package files implements the operations on a server's files, confined to its data
// directory (spec §6.6).
//
// Every path goes through three barriers:
//  1. Clean: lexical validation; ".." and control characters are rejected, never "fixed".
//  2. resolve: filepath.EvalSymlinks + prefix check with a separator over the real root.
//  3. The I/O is done with os.Root (openat without following links that leave the root): if a
//     link is changed between the check and the use (TOCTOU), the operation fails instead of escaping.
package files

import (
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"
	"syscall"
	"time"

	"mcsm/agent/internal/spec"
)

// InlineMax is the maximum inline read/write over the WebSocket (spec §6.6).
const InlineMax = 2 << 20

// maxEntries limits a listing; the rest is marked as truncated. A variable for the tests.
var maxEntries = 5000

// tmpPrefix marks the temporaries of the atomic writes (they are hidden in the listings).
const tmpPrefix = ".mcsm-tmp-"

var (
	ErrInvalidPath   = errors.New("invalid path")
	ErrOutside       = errors.New("the path leaves the server directory")
	ErrUnknownServer = errors.New("unknown server on this node")
	ErrNotFound      = errors.New("does not exist")
	ErrExists        = errors.New("already exists")
	ErrIsDir         = errors.New("is a directory")
	ErrNotDir        = errors.New("not a directory")
	ErrTooLarge      = errors.New("too large to open inline (max. 2 MiB): download it")
	ErrRoot          = errors.New("the server's root folder cannot be modified")
	ErrTransfer      = errors.New("transfer failed")
)

// Code translates an error to its protocol code (Error.code).
func Code(err error) string {
	switch {
	case errors.Is(err, ErrInvalidPath):
		return "invalid_path"
	case errors.Is(err, ErrOutside):
		return "path_outside"
	case errors.Is(err, ErrUnknownServer):
		return "unknown_server"
	case errors.Is(err, ErrNotFound):
		return "not_found"
	case errors.Is(err, ErrExists):
		return "exists"
	case errors.Is(err, ErrIsDir):
		return "is_dir"
	case errors.Is(err, ErrNotDir):
		return "not_dir"
	case errors.Is(err, ErrTooLarge):
		return "too_large"
	case errors.Is(err, ErrRoot):
		return "root"
	case errors.Is(err, ErrTransfer):
		return "transfer_failed"
	default:
		return "io_error"
	}
}

// Entry describes a file or folder.
type Entry struct {
	Name    string
	Dir     bool
	Symlink bool
	Size    int64
	ModTime time.Time
	Mode    fs.FileMode // permission bits only
}

// Root returns the data directory of a server: <dataRoot>/<slug>/data.
func Root(dataRoot, slug string) (string, error) {
	if !spec.ValidSlug(slug) {
		return "", fmt.Errorf("%w: slug %q", ErrInvalidPath, slug)
	}
	return filepath.Join(filepath.Clean(dataRoot), slug, "data"), nil
}

// FS operates inside a root.
type FS struct {
	root string
	// afterCheck is invoked between the check of a path and its use. Tests only (TOCTOU).
	afterCheck func()
}

// New creates an FS confined to root (normally the result of Root).
func New(root string) *FS { return &FS{root: filepath.Clean(root)} }

// Clean validates a panel path ("/", "mods/a.jar", "/config/x.yml") and returns it relative
// to the root, with "/" as separator ("." is the root).
func Clean(p string) (string, error) {
	if len(p) > 4096 {
		return "", fmt.Errorf("%w: too long", ErrInvalidPath)
	}
	parts := make([]string, 0, 8)
	for _, seg := range strings.Split(p, "/") {
		switch seg {
		case "", ".":
			continue
		case "..":
			return "", fmt.Errorf("%w: “..” is not allowed", ErrInvalidPath)
		}
		for _, r := range seg {
			if r < 0x20 || r == 0x7f {
				return "", fmt.Errorf("%w: contains control characters", ErrInvalidPath)
			}
		}
		parts = append(parts, seg)
	}
	if len(parts) == 0 {
		return ".", nil
	}
	return strings.Join(parts, "/"), nil
}

// display is the path as the user sees it ("/" + relative).
func display(rel string) string {
	if rel == "." {
		return "/"
	}
	return "/" + rel
}

// within checks that p is root or hangs from root. The separator prevents /x/data2
// from counting as "inside" /x/data.
func within(root, p string) bool {
	return p == root || strings.HasPrefix(p, root+string(filepath.Separator))
}

// realRoot resolves the links of the root itself (DATA_ROOT may be a link).
func (f *FS) realRoot() (string, error) {
	r, err := filepath.EvalSymlinks(f.root)
	if errors.Is(err, fs.ErrNotExist) {
		return "", fmt.Errorf("%w: the server data folder does not exist yet (start it once)", ErrNotFound)
	}
	if err != nil {
		return "", fmt.Errorf("I/O error in the data folder: %v", errors.Unwrap(err))
	}
	return r, nil
}

// resolve applies spec §6.6 to a clean path: EvalSymlinks and prefix. It returns the real path
// relative to the real root (following the links that stay inside it).
func (f *FS) resolve(rel string) (string, error) {
	root, err := f.realRoot()
	if err != nil {
		return "", err
	}
	real, err := filepath.EvalSymlinks(filepath.Join(root, filepath.FromSlash(rel)))
	if err != nil {
		if errors.Is(err, fs.ErrNotExist) || errors.Is(err, syscall.ENOTDIR) {
			// If an intermediate component leaves the root it is reported as such, not as
			// "does not exist": what lies outside is not revealed.
			if rel != "." {
				if _, perr := f.resolve(path.Dir(rel)); errors.Is(perr, ErrOutside) {
					return "", perr
				}
			}
			return "", fmt.Errorf("%w: %s", ErrNotFound, display(rel))
		}
		return "", fmt.Errorf("%w: %s", ErrInvalidPath, display(rel))
	}
	if !within(root, real) {
		return "", fmt.Errorf("%w: %s", ErrOutside, display(rel))
	}
	out, err := filepath.Rel(root, real)
	if err != nil {
		return "", fmt.Errorf("%w: %s", ErrOutside, display(rel))
	}
	return filepath.ToSlash(out), nil
}

// resolveEntry resolves the parent folder (following links) and keeps the last component
// without following it: deleting or renaming a link acts on the link, never on its target.
func (f *FS) resolveEntry(rel string) (string, error) {
	if rel == "." {
		return "", ErrRoot
	}
	parent, err := f.resolve(path.Dir(rel))
	if err != nil {
		return "", err
	}
	return path.Join(parent, path.Base(rel)), nil
}

// open opens the real root as an os.Root. It is opened on every operation: a backup restore
// renames the folder and a saved descriptor would point to the old one.
func (f *FS) open() (*os.Root, error) {
	if f.afterCheck != nil {
		f.afterCheck()
	}
	root, err := f.realRoot()
	if err != nil {
		return nil, err
	}
	r, err := os.OpenRoot(root)
	if err != nil {
		return nil, fmt.Errorf("I/O error in the data folder: %v", errors.Unwrap(err))
	}
	return r, nil
}

// isEscape detects the os.Root error when a path leaves the root.
func isEscape(err error) bool {
	var pe *fs.PathError
	if errors.As(err, &pe) && pe.Err != nil && pe.Err.Error() == "path escapes from parent" {
		return true
	}
	var le *os.LinkError
	return errors.As(err, &le) && le.Err != nil && le.Err.Error() == "path escapes from parent"
}

// mapErr translates os.Root errors to the package's errors, without absolute host paths.
func mapErr(err error, rel string) error {
	if err == nil {
		return nil
	}
	d := display(rel)
	switch {
	case isEscape(err):
		return fmt.Errorf("%w: %s", ErrOutside, d)
	case errors.Is(err, fs.ErrNotExist):
		return fmt.Errorf("%w: %s", ErrNotFound, d)
	case errors.Is(err, fs.ErrExist):
		return fmt.Errorf("%w: %s", ErrExists, d)
	case errors.Is(err, syscall.ENOTDIR):
		return fmt.Errorf("%w: %s", ErrNotDir, d)
	case errors.Is(err, syscall.EISDIR):
		return fmt.Errorf("%w: %s", ErrIsDir, d)
	case errors.Is(err, syscall.EINVAL):
		return fmt.Errorf("%w: %s", ErrInvalidPath, d)
	}
	cause := err
	var pe *fs.PathError
	var le *os.LinkError
	if errors.As(err, &pe) {
		cause = pe.Err
	} else if errors.As(err, &le) {
		cause = le.Err
	}
	return fmt.Errorf("I/O error on %s: %v", d, cause)
}

func entryOf(name string, info fs.FileInfo) Entry {
	return Entry{
		Name: name, Dir: info.IsDir(), Symlink: info.Mode()&fs.ModeSymlink != 0,
		Size: info.Size(), ModTime: info.ModTime(), Mode: info.Mode().Perm(),
	}
}

// List returns the content of a folder: folders first, then by name. Links that point inside the
// root are described by their target; those that leave it, as links.
func (f *FS) List(p string) ([]Entry, bool, error) {
	rel, err := Clean(p)
	if err != nil {
		return nil, false, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, false, err
	}
	r, err := f.open()
	if err != nil {
		return nil, false, err
	}
	defer r.Close()
	d, err := r.Open(real)
	if err != nil {
		return nil, false, mapErr(err, rel)
	}
	defer d.Close()
	st, err := d.Stat()
	if err != nil {
		return nil, false, mapErr(err, rel)
	}
	if !st.IsDir() {
		return nil, false, fmt.Errorf("%w: %s", ErrNotDir, display(rel))
	}
	des, err := d.ReadDir(maxEntries + 1)
	if err != nil && !errors.Is(err, io.EOF) {
		return nil, false, mapErr(err, rel)
	}
	truncated := len(des) > maxEntries
	if truncated {
		des = des[:maxEntries]
	}
	out := make([]Entry, 0, len(des))
	for _, de := range des {
		if strings.HasPrefix(de.Name(), tmpPrefix) {
			continue
		}
		info, err := de.Info()
		if err != nil {
			continue // deleted between ReadDir and Info
		}
		e := entryOf(de.Name(), info)
		if e.Symlink {
			if target, err := r.Stat(path.Join(real, de.Name())); err == nil {
				e.Dir, e.Size, e.ModTime = target.IsDir(), target.Size(), target.ModTime()
			}
		}
		out = append(out, e)
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].Dir != out[j].Dir {
			return out[i].Dir
		}
		return strings.ToLower(out[i].Name) < strings.ToLower(out[j].Name)
	})
	return out, truncated, nil
}

// Stat describes a path, following the links that stay inside the root.
func (f *FS) Stat(p string) (Entry, error) {
	rel, err := Clean(p)
	if err != nil {
		return Entry{}, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return Entry{}, err
	}
	r, err := f.open()
	if err != nil {
		return Entry{}, err
	}
	defer r.Close()
	info, err := r.Stat(real)
	if err != nil {
		return Entry{}, mapErr(err, rel)
	}
	return entryOf(path.Base(display(rel)), info), nil
}

// openRegular opens only regular files. O_NONBLOCK avoids blocking when opening a FIFO that
// someone created inside /data; on a regular file it has no effect.
func openRegular(r *os.Root, real, rel string) (*os.File, fs.FileInfo, error) {
	fh, err := r.OpenFile(real, os.O_RDONLY|syscall.O_NONBLOCK, 0)
	if err != nil {
		return nil, nil, mapErr(err, rel)
	}
	info, err := fh.Stat()
	if err != nil {
		fh.Close()
		return nil, nil, mapErr(err, rel)
	}
	if info.IsDir() {
		fh.Close()
		return nil, nil, fmt.Errorf("%w: %s", ErrIsDir, display(rel))
	}
	if !info.Mode().IsRegular() {
		fh.Close()
		return nil, nil, fmt.Errorf("%w: %s is not a regular file", ErrInvalidPath, display(rel))
	}
	return fh, info, nil
}

// Read reads a whole file if it does not exceed max (or InlineMax if max <= 0 or greater).
func (f *FS) Read(p string, max int64) ([]byte, int64, error) {
	if max <= 0 || max > InlineMax {
		max = InlineMax
	}
	rel, err := Clean(p)
	if err != nil {
		return nil, 0, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, 0, err
	}
	r, err := f.open()
	if err != nil {
		return nil, 0, err
	}
	defer r.Close()
	fh, info, err := openRegular(r, real, rel)
	if err != nil {
		return nil, 0, err
	}
	defer fh.Close()
	if info.Size() > max {
		return nil, info.Size(), fmt.Errorf("%w: %s takes %d bytes", ErrTooLarge, display(rel), info.Size())
	}
	data, err := io.ReadAll(io.LimitReader(fh, max+1))
	if err != nil {
		return nil, 0, mapErr(err, rel)
	}
	if int64(len(data)) > max { // it grew while being read
		return nil, int64(len(data)), fmt.Errorf("%w: %s", ErrTooLarge, display(rel))
	}
	return data, info.Size(), nil
}

// Open opens a regular file to download it in streaming. The caller closes it.
func (f *FS) Open(p string) (*os.File, Entry, error) {
	rel, err := Clean(p)
	if err != nil {
		return nil, Entry{}, err
	}
	real, err := f.resolve(rel)
	if err != nil {
		return nil, Entry{}, err
	}
	r, err := f.open()
	if err != nil {
		return nil, Entry{}, err
	}
	defer r.Close() // the open file remains valid after closing the root
	fh, info, err := openRegular(r, real, rel)
	if err != nil {
		return nil, Entry{}, err
	}
	return fh, entryOf(path.Base(rel), info), nil
}
```

```go
// patternBlock is a 251-byte cycle repeated; pattern copies it without allocating memory.
var patternBlock = func() []byte {
	b := make([]byte, 64<<10+251)
	for i := range b {
		b[i] = byte(i % 251)
	}
	return b
}()

func (p *pattern) Read(b []byte) (int, error) {
	n := copy(b, patternBlock[p.off%251:])
	p.off += n
	return n, nil
}
```

```go
// writeTarget is the already validated target of a write.
type writeTarget struct {
	real  string      // real path relative to the root
	mode  fs.FileMode // permissions to keep (0o644 if new)
	owner fs.FileInfo // whose uid/gid to copy: the replaced file or its folder
}

// prepareWrite validates the target of a write: the folder exists and is inside, the target is not
// a folder and, if it is a link that stays inside, it is written to its real target.
func (f *FS) prepareWrite(r *os.Root, rel string) (writeTarget, error) {
	target, err := f.resolveEntry(rel)
	if err != nil {
		return writeTarget{}, err
	}
	li, err := r.Lstat(target)
	switch {
	case err == nil:
		if li.Mode()&fs.ModeSymlink != 0 {
			if target, err = f.resolve(target); err != nil {
				return writeTarget{}, err
			}
			if li, err = r.Stat(target); err != nil {
				return writeTarget{}, mapErr(err, rel)
			}
		}
		if li.IsDir() {
			return writeTarget{}, fmt.Errorf("%w: %s", ErrIsDir, display(rel))
		}
		if !li.Mode().IsRegular() {
			return writeTarget{}, fmt.Errorf("%w: %s is not a regular file", ErrInvalidPath, display(rel))
		}
		return writeTarget{real: target, mode: li.Mode().Perm(), owner: li}, nil
	case errors.Is(err, fs.ErrNotExist):
		pi, err := r.Stat(path.Dir(target))
		if err != nil {
			return writeTarget{}, mapErr(err, path.Dir(rel))
		}
		if !pi.IsDir() {
			return writeTarget{}, fmt.Errorf("%w: %s", ErrNotDir, display(path.Dir(rel)))
		}
		return writeTarget{real: target, mode: 0o644, owner: pi}, nil
	default:
		return writeTarget{}, mapErr(err, rel)
	}
}

// CheckWrite validates that p can be written without touching anything. It is used to fail before
// starting a transfer; WriteFrom validates again when writing.
func (f *FS) CheckWrite(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	_, err = f.prepareWrite(r, rel)
	return err
}

// readErr marks the errors that come from the source (the transfer), not from the disk.
type readErr struct{ error }

func (e readErr) Unwrap() error { return e.error }

type tagReader struct{ r io.Reader }

func (t tagReader) Read(p []byte) (int, error) {
	n, err := t.r.Read(p)
	if err != nil && err != io.EOF {
		err = readErr{err}
	}
	return n, err
}

func randHex() string {
	b := make([]byte, 8)
	_, _ = rand.Read(b)
	return hex.EncodeToString(b)
}

// WriteFrom writes src to p atomically: temporary in the same folder, fsync and rename.
// If anything fails, the previous file stays intact and the temporary is removed. expected >= 0
// requires that exact number of bytes (a truncated transfer never replaces the file). It keeps the
// permissions and owner of the replaced file; a new one inherits the owner of its folder, so that
// the server (uid 1000 in itzg) can keep rewriting it even though the agent is root.
// Streaming copy: the memory used does not depend on the size.
func (f *FS) WriteFrom(p string, src io.Reader, expected int64) (int64, error) {
	rel, err := Clean(p)
	if err != nil {
		return 0, err
	}
	r, err := f.open()
	if err != nil {
		return 0, err
	}
	defer r.Close()
	wt, err := f.prepareWrite(r, rel)
	if err != nil {
		return 0, err
	}
	tmp := path.Join(path.Dir(wt.real), tmpPrefix+randHex())
	fh, err := r.OpenFile(tmp, os.O_WRONLY|os.O_CREATE|os.O_EXCL, wt.mode)
	if err != nil {
		return 0, mapErr(err, rel)
	}
	closed, renamed := false, false
	defer func() {
		if !closed {
			fh.Close()
		}
		if !renamed {
			_ = r.Remove(tmp)
		}
	}()
	n, err := io.Copy(fh, tagReader{src})
	if err != nil {
		var re readErr
		if errors.As(err, &re) {
			return n, fmt.Errorf("%w: %v", ErrTransfer, re.error)
		}
		return n, mapErr(err, rel)
	}
	if expected >= 0 && n != expected {
		return n, fmt.Errorf("%w: received %d of %d bytes", ErrTransfer, n, expected)
	}
	if err := fh.Chmod(wt.mode); err != nil { // the umask may have trimmed the permissions on creation
		return n, mapErr(err, rel)
	}
	chownLike(fh, wt.owner)
	if err := fh.Sync(); err != nil {
		return n, mapErr(err, rel)
	}
	closed = true
	if err := fh.Close(); err != nil {
		return n, mapErr(err, rel)
	}
	if err := r.Rename(tmp, wt.real); err != nil {
		return n, mapErr(err, rel)
	}
	renamed = true
	if d, err := r.Open(path.Dir(wt.real)); err == nil { // so that the rename survives a power cut
		_ = d.Sync()
		d.Close()
	}
	return n, nil
}

// Write is the inline write (editor): at most InlineMax bytes.
func (f *FS) Write(p string, data []byte) error {
	if len(data) > InlineMax {
		return fmt.Errorf("%w: %d bytes", ErrTooLarge, len(data))
	}
	_, err := f.WriteFrom(p, bytes.NewReader(data), int64(len(data)))
	return err
}

// chownLike copies the uid/gid of ref. Without privileges it fails with EPERM and is ignored: the
// file stays owned by the agent's user, which in that case is the same as the folder's.
func chownLike(fh *os.File, ref fs.FileInfo) {
	if st, ok := ref.Sys().(*syscall.Stat_t); ok {
		_ = fh.Chown(int(st.Uid), int(st.Gid))
	}
}

// Mkdir creates a folder (its parent must exist), owned like the parent folder.
func (f *FS) Mkdir(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	target, err := f.resolveEntry(rel)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	pi, err := r.Stat(path.Dir(target))
	if err != nil {
		return mapErr(err, path.Dir(rel))
	}
	if err := r.Mkdir(target, 0o755); err != nil {
		return mapErr(err, rel)
	}
	if st, ok := pi.Sys().(*syscall.Stat_t); ok {
		_ = r.Lchown(target, int(st.Uid), int(st.Gid))
	}
	return nil
}

// Rename moves or renames without overwriting: if the target exists it returns ErrExists.
// Renaming a link moves the link, not its target.
func (f *FS) Rename(from, to string) error {
	src, err := Clean(from)
	if err != nil {
		return err
	}
	dst, err := Clean(to)
	if err != nil {
		return err
	}
	s, err := f.resolveEntry(src)
	if err != nil {
		return err
	}
	d, err := f.resolveEntry(dst)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	if _, err := r.Lstat(s); err != nil {
		return mapErr(err, src)
	}
	if _, err := r.Lstat(d); err == nil {
		return fmt.Errorf("%w: %s", ErrExists, display(dst))
	} else if !errors.Is(err, fs.ErrNotExist) {
		return mapErr(err, dst)
	}
	if err := r.Rename(s, d); err != nil {
		return mapErr(err, dst)
	}
	return nil
}

// Delete deletes a file, a link (not its target) or a folder with all its contents.
func (f *FS) Delete(p string) error {
	rel, err := Clean(p)
	if err != nil {
		return err
	}
	target, err := f.resolveEntry(rel)
	if err != nil {
		return err
	}
	r, err := f.open()
	if err != nil {
		return err
	}
	defer r.Close()
	li, err := r.Lstat(target)
	if err != nil {
		return mapErr(err, rel)
	}
	if li.IsDir() {
		return mapErr(r.RemoveAll(target), rel)
	}
	return mapErr(r.Remove(target), rel)
}
```

```go
var transferIDRe = regexp.MustCompile(`^[A-Za-z0-9_-]{43}$`)

// transferHTTP is shared to reuse connections. No global Timeout: the bodies are streamed and the
// context cuts them; only the handshake and the wait for headers are bounded.
var transferHTTP = &http.Client{Transport: &http.Transport{
	Proxy:                 http.ProxyFromEnvironment,
	DialContext:           (&net.Dialer{Timeout: dialTimeout, KeepAlive: 30 * time.Second}).DialContext,
	ResponseHeaderTimeout: 60 * time.Second,
	IdleConnTimeout:       90 * time.Second,
	MaxIdleConnsPerHost:   4,
}}

// TransferClient makes the agent's outbound HTTP transfers (spec §5.1):
// GET and PUT /agent/transfer/{id} with the node token.
type TransferClient struct {
	base  string
	token string
	http  *http.Client
}

// NewTransferClient creates a client for the panel at panelURL with the node token.
func NewTransferClient(panelURL, token string) *TransferClient {
	return &TransferClient{base: strings.TrimRight(panelURL, "/"), token: token, http: transferHTTP}
}

func (c *TransferClient) newRequest(ctx context.Context, method, id string, body io.Reader) (*http.Request, error) {
	if !transferIDRe.MatchString(id) {
		return nil, fmt.Errorf("invalid transfer_id %q", id)
	}
	req, err := http.NewRequestWithContext(ctx, method, c.base+"/agent/transfer/"+id, body)
	if err != nil {
		return nil, err
	}
	req.Header.Set("Authorization", "Bearer "+c.token)
	return req, nil
}

func statusErr(resp *http.Response) error {
	if resp.StatusCode >= 200 && resp.StatusCode < 300 {
		return nil
	}
	if resp.StatusCode == http.StatusNotFound {
		return ErrTransferNotFound
	}
	msg, _ := io.ReadAll(io.LimitReader(resp.Body, 4096))
	return fmt.Errorf("the panel responded %d: %s", resp.StatusCode, strings.TrimSpace(string(msg)))
}

// Get opens a panel → agent transfer. It returns the streaming body (the caller closes it) and its
// size, or -1 if the panel did not indicate it.
func (c *TransferClient) Get(ctx context.Context, id string) (io.ReadCloser, int64, error) {
	req, err := c.newRequest(ctx, http.MethodGet, id, nil)
	if err != nil {
		return nil, 0, err
	}
	resp, err := c.http.Do(req)
	if err != nil {
		return nil, 0, err
	}
	if err := statusErr(resp); err != nil {
		resp.Body.Close()
		return nil, 0, err
	}
	return resp.Body, resp.ContentLength, nil
}

// Put sends body in an agent → panel transfer. size >= 0 sets Content-Length (if the body has a
// different size the request fails); -1 uses chunked. It finishes when the panel has received and
// forwarded everything (it answers 204).
func (c *TransferClient) Put(ctx context.Context, id string, body io.Reader, size int64) error {
	if size == 0 {
		body = http.NoBody // with ContentLength 0 and a non-nil body Go would use chunked
	}
	req, err := c.newRequest(ctx, http.MethodPut, id, body)
	if err != nil {
		return err
	}
	req.ContentLength = size
	req.Header.Set("Content-Type", "application/octet-stream")
	resp, err := c.http.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()
	if err := statusErr(resp); err != nil {
		return err
	}
	_, _ = io.Copy(io.Discard, io.LimitReader(resp.Body, 4096))
	return nil
}
```

```go
// patternBlock is a 251-byte cycle repeated; pattern copies it without allocating memory.
var patternBlock = func() []byte {
	b := make([]byte, 64<<10+251)
	for i := range b {
		b[i] = byte(i % 251)
	}
	return b
}()

// pattern generates deterministic bytes (up to 64 KiB per read) without allocating memory.
type pattern struct{ off int }

func (p *pattern) Read(b []byte) (int, error) {
	n := copy(b, patternBlock[p.off%251:])
	p.off += n
	return n, nil
```
```go
}

func entryToProto(e files.Entry) *mcsmv1.FileEntry {
	return &mcsmv1.FileEntry{
		Name: e.Name, Dir: e.Dir, Symlink: e.Symlink, Size: uint64(max(e.Size, 0)),

// handleFiles serves the panel's Files* messages (spec §5.3, §6.6) and replies with the same id:
// a *Result, an Ack or an Error with the files.Code code.
func (a *App) handleFiles(ctx context.Context, env *mcsmv1.Envelope, send func(*mcsmv1.Envelope) error) {

	if err != nil {
		_ = send(errMsg(env.Id, files.Code(err), err))
		return

func (a *App) filesOp(ctx context.Context, env *mcsmv1.Envelope) (*mcsmv1.Envelope, error) {
	req := filesRequest(env)
	if req == nil {
		return nil, fmt.Errorf("files message not supported: %T", env.Body)
	}
	fsys, err := a.serverFS(req.GetServerId())
	if err != nil {
		return nil, err
	}
	switch b := env.Body.(type) {
	case *mcsmv1.Envelope_FilesList:
		entries, truncated, err := fsys.List(b.FilesList.Path)
		if err != nil {
			return nil, err
		}
		out := make([]*mcsmv1.FileEntry, 0, len(entries))
		for _, e := range entries {
			out = append(out, entryToProto(e))
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesListResult{FilesListResult: &mcsmv1.FilesListResult{Entries: out, Truncated: truncated}}}, nil

	case *mcsmv1.Envelope_FilesStat:
		e, err := fsys.Stat(b.FilesStat.Path)
		if err != nil {
			return nil, err
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesStatResult{FilesStatResult: &mcsmv1.FilesStatResult{Entry: entryToProto(e)}}}, nil

	case *mcsmv1.Envelope_FilesRead:
		data, size, err := fsys.Read(b.FilesRead.Path, int64(b.FilesRead.MaxBytes))
		if err != nil {
			return nil, err
		}
		return &mcsmv1.Envelope{Body: &mcsmv1.Envelope_FilesReadResult{FilesReadResult: &mcsmv1.FilesReadResult{Content: data, Size: uint64(size)}}}, nil

	case *mcsmv1.Envelope_FilesWrite:
		err = fsys.Write(b.FilesWrite.Path, b.FilesWrite.Content)
	case *mcsmv1.Envelope_FilesMkdir:
		err = fsys.Mkdir(b.FilesMkdir.Path)
	case *mcsmv1.Envelope_FilesRename:
		err = fsys.Rename(b.FilesRename.From, b.FilesRename.To)
	case *mcsmv1.Envelope_FilesDelete:
		err = fsys.Delete(b.FilesDelete.Path)
	case *mcsmv1.Envelope_FilesDownload:
		err = a.filesDownload(ctx, fsys, b.FilesDownload)
	case *mcsmv1.Envelope_FilesUpload:
		err = a.filesUpload(ctx, fsys, b.FilesUpload)
	default:
		return nil, fmt.Errorf("files message not supported: %T", env.Body)

		return nil, err
	}

// filesDownload uploads the file to the panel with PUT /agent/transfer/{id} and confirms when done.
func (a *App) filesDownload(ctx context.Context, fsys *files.FS, m *mcsmv1.FilesDownload) error {
	f, e, err := fsys.Open(m.Path)
	if err != nil {
		return err
	}
	defer f.Close()
	xfer, err := a.transfers()
	if err != nil {
		return err
	}
	// LimitReader: if the file grows while it is being sent, only what it measured when opened is sent.
	if err := xfer.Put(ctx, m.TransferId, io.LimitReader(f, e.Size), e.Size); err != nil {
		return fmt.Errorf("%w: %v", files.ErrTransfer, err)
	}
	return nil
}

// filesUpload validates the target, downloads from the panel with GET /agent/transfer/{id} and
// writes atomically in streaming. A truncated body never replaces the file.
func (a *App) filesUpload(ctx context.Context, fsys *files.FS, m *mcsmv1.FilesUpload) error {
	if err := fsys.CheckWrite(m.Path); err != nil { // fail before consuming the transfer
		return err
	}
	xfer, err := a.transfers()
	if err != nil {
		return err
	}
	body, size, err := xfer.Get(ctx, m.TransferId)
	if err != nil {
		return fmt.Errorf("%w: %v", files.ErrTransfer, err)
	}
	defer body.Close()
	expected := m.Size
	if expected < 0 {
		expected = size
	}
	if size >= 0 && expected != size {
		return fmt.Errorf("%w: the panel announces %d bytes and sends %d", files.ErrTransfer, m.Size, size)
	}
	_, err = fsys.WriteFrom(m.Path, body, expected)
	return err
}
```

```ts
 * Normalizes a path inside the server's /data ("mods//a.jar/" → "/mods/a.jar", "" → "/").

  const parts: string[] = [];

    if (seg === "" || seg === ".") continue;
    if (seg === "..") return null;
```

```ts
import type { Readable } from "node:stream";
import { randomToken } from "../lib/tokens.js";

/** Body of a transfer: stream and size (null if unknown). */
export interface TransferPayload { stream: Readable; size: number | null }
/** Lazy source of a panel → agent transfer: it is invoked when the agent does GET. */
export type TransferSource = () => Promise<TransferPayload>;

export type TransferErrorCode = "expired" | "cancelled" | "aborted";

export class TransferError extends Error {
  constructor(public code: TransferErrorCode, message: string) { super(message); this.name = "TransferError"; }
}

/** Panel → agent: the agent does GET /agent/transfer/:id. */
export interface OutboundTransfer {
  id: string;
  /** Resolved when the agent has received the whole body; rejected if it expires, is cancelled or is cut. */
  done: Promise<void>;
  cancel(reason?: string): void;
}

/** Agent → panel: the agent does PUT /agent/transfer/:id. */
export interface InboundTransfer {
  id: string;
  /** Resolved when the agent's PUT arrives, with its streaming body. */
  incoming: Promise<TransferPayload>;
  cancel(reason?: string): void;
}

/** What the HTTP route gets when it claims a transferId. */
export type ClaimedTransfer =
  | { kind: "outbound"; source: TransferSource; complete(): void; fail(err: Error): void }
  | { kind: "inbound"; deliver(payload: TransferPayload): void };

interface Deferred<T> { promise: Promise<T>; resolve(v: T): void; reject(e: Error): void }

function deferred<T>(): Deferred<T> {
  let resolve!: (v: T) => void;
  let reject!: (e: Error) => void;
  const promise = new Promise<T>((res, rej) => { resolve = res; reject = rej; });
  promise.catch(() => {}); // whoever does not await it does not cause an unhandledRejection
  return { promise, resolve, reject };
}

type Entry =
  | { kind: "outbound"; nodeId: string; createdAt: number; source: TransferSource; done: Deferred<void> }
  | { kind: "inbound"; nodeId: string; createdAt: number; incoming: Deferred<TransferPayload> };

export interface TransferServiceOptions {
  /** Injectable clock (ms). */
  now?: () => number;
  /** Time the agent has to claim the transfer. */
  claimTtlMs?: number;
}

/**
 * HTTP transfers between the panel and the agents (spec §5.1). Each transferId is random
 * (32 bytes), single use, bound to the node that must claim it, and it expires if nobody
 * claims it in time. The body is never loaded into memory: streams are passed along.
 */
export class TransferService {
  private pending = new Map<string, Entry>();
  private now: () => number;
  private ttl: number;

  constructor(opts: TransferServiceOptions = {}) {
    this.now = opts.now ?? (() => Date.now()); // read when called: tests can fake Date
    this.ttl = opts.claimTtlMs ?? 60_000;
  }

  /** Transfers not yet claimed. */
  get pendingCount(): number { return this.pending.size; }

  outbound(nodeId: string, source: TransferSource): OutboundTransfer {
    const id = randomToken();
    const done = deferred<void>();
    this.pending.set(id, { kind: "outbound", nodeId, createdAt: this.now(), source, done });
    return { id, done: done.promise, cancel: (reason = "cancelled") => this.cancel(id, reason) };
  }

  inbound(nodeId: string): InboundTransfer {
    const id = randomToken();
    const incoming = deferred<TransferPayload>();
    this.pending.set(id, { kind: "inbound", nodeId, createdAt: this.now(), incoming });
    return { id, incoming: incoming.promise, cancel: (reason = "cancelled") => this.cancel(id, reason) };
  }

  /**
   * Claims a transferId (single use). It returns null without consuming it if it belongs to another
   * node or to the other direction (a node cannot burn foreign transfers), and null consuming it if
   * it has expired.
   */
  claim(id: string, nodeId: string, method: "GET" | "PUT"): ClaimedTransfer | null {
    const e = this.pending.get(id);
    if (!e || e.nodeId !== nodeId) return null;
    if ((method === "GET") !== (e.kind === "outbound")) return null;
    this.pending.delete(id);
    if (this.now() - e.createdAt > this.ttl) {
      this.reject(e, new TransferError("expired", "The agent did not start the transfer in time"));
      return null;
    }
    if (e.kind === "outbound") {
      return { kind: "outbound", source: e.source, complete: () => e.done.resolve(), fail: (err) => e.done.reject(err) };
    }
    return { kind: "inbound", deliver: (p) => e.incoming.resolve(p) };
  }

  /** Expires the transfers not claimed in time. Returns how many. */
  sweep(): number {
    let n = 0;
    for (const [id, e] of this.pending) {
      if (this.now() - e.createdAt <= this.ttl) continue;
      this.pending.delete(id);
      this.reject(e, new TransferError("expired", "The agent did not start the transfer in time"));
      n++;
    }
    return n;
  }

  /** Cancels everything pending (panel shutdown). */
  closeAll(): void {
    for (const id of [...this.pending.keys()]) this.cancel(id, "the panel is shutting down");
  }

  private cancel(id: string, reason: string) {
    const e = this.pending.get(id);
    if (!e) return; // already claimed: its HTTP route handles the cut
    this.pending.delete(id);
    this.reject(e, new TransferError("cancelled", `Transfer cancelled: ${reason}`));
  }

  private reject(e: Entry, err: TransferError) {
    if (e.kind === "outbound") e.done.reject(err);
    else e.incoming.reject(err);
  }
}
```

```ts
  private removing = new Set<Promise<void>>();

  constructor(readonly dir: string, private now: () => number = Date.now) {}

  /** Deletes the leftovers of a previous run. Does not create the directory. */
  async init(): Promise<number> {
    let names: string[];
    try {
      names = await readdir(this.dir);
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code === "ENOENT") return 0;
      throw e;
    }
    await Promise.all(names.map((n) => rm(join(this.dir, n), { recursive: true, force: true })));
    return names.length;
  }

  /** Saves a stream (writes `<id>.part` and renames it to `<id>.bin` when done). */
  async save(id: string, stream: Readable): Promise<StagedFile> {
    if (!ID_RE.test(id)) throw new Error("Invalid staging identifier");
    await mkdir(this.dir, { recursive: true });
    const part = join(this.dir, `${id}.part`);
    const path = join(this.dir, `${id}.bin`);
    try {
      await pipeline(stream, createWriteStream(part, { flags: "wx" }));
      await rename(part, path);
    } catch (e) {
      await rm(part, { force: true });
      throw e;
    }
    return { id, path, size: (await stat(path)).size };
  }

  /** Source for TransferService.outbound; by default it deletes the file when the stream closes. */
  source(file: StagedFile, opts: { removeAfter?: boolean } = {}): TransferSource {
    const removeAfter = opts.removeAfter ?? true;
    return async () => {
      const stream = createReadStream(file.path);
      if (removeAfter) stream.once("close", () => { this.track(rm(file.path, { force: true })); });
      return { stream, size: file.size };
    };
  }

  async remove(file: StagedFile): Promise<void> {
    await rm(file.path, { force: true });
  }

  /** Waits for the deletions launched when the sources close to finish (panel shutdown, tests). */
  async settled(): Promise<void> {
    await Promise.all([...this.removing]);
  }

  private track(p: Promise<void>) {
    const t = p.catch(() => {}).finally(() => this.removing.delete(t));
    this.removing.add(t);
  }

  /** Deletes what has not been modified for more than maxAgeMs. Returns how many files. */
  async sweep(maxAgeMs: number): Promise<number> {
    let names: string[];
    try {
      names = await readdir(this.dir);
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code === "ENOENT") return 0;
      throw e;
    }
    let n = 0;
    for (const name of names) {
      const p = join(this.dir, name);
      const st = await stat(p).catch(() => null);
      if (st && this.now() - st.mtimeMs > maxAgeMs) {
        await rm(p, { recursive: true, force: true });
        n++;
      }
    }
    return n;
  }
}
```

```ts
import type { Readable } from "node:stream";
import { finished } from "node:stream/promises";
import type { FastifyInstance, FastifyRequest } from "fastify";
import { hashToken } from "../lib/tokens.js";
import { TransferError, type TransferPayload } from "./service.js";

/** Node that owns the Bearer token, or null. Same criterion as /agent/ws. */
function nodeFromAuth(app: FastifyInstance, req: FastifyRequest) {
  const header = req.headers.authorization ?? "";
  const token = header.startsWith("Bearer ") ? header.slice(7) : "";
  return token ? app.nodes.findByTokenHash(hashToken(token)) : null;
}

const NOT_FOUND = { error: "Unknown, expired or already used transfer" };

/** Content-Length of the request, or null if it is absent (chunked body). */
export function contentLength(req: FastifyRequest): number | null {
  const v = req.headers["content-length"];
  return v !== undefined && /^\d+$/.test(v) ? Number(v) : null;
}

/**
 * HTTP transfers of the agents (spec §5.1), outside the session guard and with the node token.
 * The body is never loaded into memory: the stream is passed as it is.
 */
export async function transferRoutes(app: FastifyInstance) {
  // The body arrives as a stream (req.body) with no size limit and no parsing.
  app.addContentTypeParser("application/octet-stream", (_req, payload, done) => done(null, payload));

  // Panel → agent. No automatic HEAD route: a HEAD would consume the transfer.
  app.get<{ Params: { id: string } }>("/agent/transfer/:id", { exposeHeadRoute: false }, async (req, reply) => {
    const node = nodeFromAuth(app, req);
    if (!node) return reply.code(401).send({ error: "invalid token" });
    const claimed = app.transfers.claim(req.params.id, node.id, "GET");
    if (claimed?.kind !== "outbound") return reply.code(404).send(NOT_FOUND);
    let payload: TransferPayload;
    try {
      payload = await claimed.source();
    } catch (e) {
      claimed.fail(e instanceof Error ? e : new Error(String(e)));
      req.log.warn({ err: e }, "transfer source not available");
      return reply.code(500).send({ error: "Internal error" });
    }
    reply.raw.once("close", () => {
      if (reply.raw.writableFinished) claimed.complete();
      else claimed.fail(new TransferError("aborted", "The transfer was cut off before finishing"));
    });
    reply.header("content-type", "application/octet-stream");
    if (payload.size !== null) reply.header("content-length", String(payload.size));
    return reply.send(payload.stream);
  });

  // Agent → panel: the body is delivered to whoever is waiting and the reply is sent once it has been read in full.
  app.put<{ Params: { id: string } }>("/agent/transfer/:id", async (req, reply) => {
    const node = nodeFromAuth(app, req);
    if (!node) return reply.code(401).send({ error: "invalid token" });
    const claimed = app.transfers.claim(req.params.id, node.id, "PUT");
    if (claimed?.kind !== "inbound") return reply.code(404).send(NOT_FOUND);
    const body = req.body as Readable | undefined;
    if (!body || typeof body.pipe !== "function") return reply.code(415).send({ error: "Send the body as application/octet-stream" });
    claimed.deliver({ stream: body, size: contentLength(req) });
    try {
      await finished(body);
    } catch {
      return reply.code(400).send({ error: "The transfer was cut off before finishing" });
    }
    return reply.code(204).send();
  });
}
```

```ts
import { join } from "node:path";
import fp from "fastify-plugin";
import type { FastifyInstance } from "fastify";
import { TransferService } from "./service.js";
import { Staging } from "./staging.js";
import { transferRoutes } from "./routes.js";

const SWEEP_EVERY_MS = 10_000;
const STAGING_SWEEP_EVERY_MS = 3600_000;
const STAGING_MAX_AGE_MS = 24 * 3600_000;

/**
 * Transfers and staging (spec §5.1). Decorates `app.transfers` and `app.staging` at the root
 * (fastify-plugin) and registers the agent routes in their own context.
 */
export const transfersPlugin = fp(async function transfersPlugin(app: FastifyInstance) {
  app.decorate("transfers", new TransferService());
  app.decorate("staging", new Staging(join(app.config.dataDir, "staging")));
  await app.register(transferRoutes);

  const transferSweep = setInterval(() => app.transfers.sweep(), SWEEP_EVERY_MS);
  transferSweep.unref();
  const stagingSweep = setInterval(() => {
    app.staging.sweep(STAGING_MAX_AGE_MS).catch((e) => app.log.warn({ err: e }, "staging cleanup failed"));
  }, STAGING_SWEEP_EVERY_MS);
  stagingSweep.unref();

  app.addHook("onReady", async () => {
    const n = await app.staging.init();
    if (n) app.log.info({ n }, "staging: deleted leftovers of a previous run");
  });
  app.addHook("onClose", async () => {
    clearInterval(transferSweep);
    clearInterval(stagingSweep);
    app.transfers.closeAll();
    await app.staging.settled();
  });
}, { name: "transfers" });

declare module "fastify" {
  interface FastifyInstance { transfers: TransferService; staging: Staging }
```

```ts
import type { FastifyInstance } from "fastify";
import type { FileEntry } from "@mcsm/proto";
import { INLINE_MAX_BYTES, type FileEntryDto } from "@mcsm/shared";
import { AgentError, type Body } from "../agents/hub.js";
import { HttpError } from "../servers/service.js";
import { TransferError } from "../transfers/service.js";

/** Agent error code (files.Code in Go) → HTTP status. */
const STATUS_BY_CODE: Record<string, number> = {
  invalid_path: 400, path_outside: 400, root: 400, is_dir: 400, not_dir: 400,
  unknown_server: 404, not_found: 404,
  exists: 409, disconnected: 409,
  too_large: 413,
  timeout: 504,
};

/** Translates an agent or transfer failure to HttpError, keeping the agent's text (spec §10). */
export function toHttpError(e: unknown, fallback: string): HttpError {
  if (e instanceof HttpError) return e;
  if (e instanceof AgentError) return new HttpError(STATUS_BY_CODE[e.code] ?? 502, e.message);
  if (e instanceof TransferError) return new HttpError(e.code === "expired" ? 504 : 502, e.message);
  return new HttpError(502, fallback);
}

export const toEntryDto = (e: FileEntry): FileEntryDto => ({
  name: e.name, dir: e.dir, symlink: e.symlink, size: Number(e.size), modifiedAt: Number(e.modTimeUnixMs), mode: e.mode,
});

const REQUEST_TIMEOUT_MS = 30_000;

export class FilesService {
  constructor(protected app: FastifyInstance) {}

  /** Server and connection of its node: 404/409 before bothering the agent. */
  protected target(serverId: string) {
    const row = this.app.servers.get(serverId);
    if (!row) throw new HttpError(404, "Server not found");
    const conn = this.app.agents.get(row.node_id);
    if (!conn) throw new HttpError(409, "The node is disconnected");
    return { row, conn };
  }

  private async call(serverId: string, body: Body, fallback: string) {
    const { conn } = this.target(serverId);
    try {
      return await conn.request(body, REQUEST_TIMEOUT_MS);
    } catch (e) {
      throw toHttpError(e, fallback);
    }
  }

  async list(serverId: string, path: string): Promise<{ path: string; entries: FileEntryDto[]; truncated: boolean }> {
    const res = await this.call(serverId, { case: "filesList", value: { serverId, path } }, "Could not list the folder");
    if (res.body.case !== "filesListResult") throw new HttpError(502, "Unexpected response from the agent");
    return { path, entries: res.body.value.entries.map(toEntryDto), truncated: res.body.value.truncated };
  }

  async stat(serverId: string, path: string): Promise<FileEntryDto> {
    const res = await this.call(serverId, { case: "filesStat", value: { serverId, path } }, "Could not read the file info");
    if (res.body.case !== "filesStatResult" || !res.body.value.entry) throw new HttpError(502, "Unexpected response from the agent");
    return toEntryDto(res.body.value.entry);
  }

  async read(serverId: string, path: string): Promise<{ path: string; content: string; size: number }> {
    const res = await this.call(serverId, { case: "filesRead", value: { serverId, path, maxBytes: INLINE_MAX_BYTES } }, "Could not read the file");
    if (res.body.case !== "filesReadResult") throw new HttpError(502, "Unexpected response from the agent");
    let content: string;
    try {
      content = new TextDecoder("utf-8", { fatal: true }).decode(res.body.value.content);
    } catch {
      throw new HttpError(415, "The file is not UTF-8 text: download it to open it");
    }
    if (content.includes("\u0000")) throw new HttpError(415, "The file looks binary: download it to open it");
    return { path, content, size: Number(res.body.value.size) };
  }

  async write(serverId: string, path: string, content: string): Promise<void> {
    const bytes = new TextEncoder().encode(content);
    if (bytes.byteLength > INLINE_MAX_BYTES) throw new HttpError(413, "The content exceeds 2 MiB: upload it as a file");
    await this.call(serverId, { case: "filesWrite", value: { serverId, path, content: bytes } }, "Could not save the file");
  }

  async mkdir(serverId: string, path: string): Promise<void> {
    await this.call(serverId, { case: "filesMkdir", value: { serverId, path } }, "Could not create the folder");
  }

  async rename(serverId: string, from: string, to: string): Promise<void> {
    if (from === "/" || to === "/") throw new HttpError(400, "The root folder cannot be renamed");
    await this.call(serverId, { case: "filesRename", value: { serverId, from, to } }, "Could not rename");
  }

  async remove(serverId: string, path: string): Promise<void> {
    if (path === "/") throw new HttpError(400, "The root folder cannot be deleted");
    await this.call(serverId, { case: "filesDelete", value: { serverId, path } }, "Could not delete");
  }
}
```

```ts
/** Decorates the service at the root and registers the encapsulated routes with their own errorHandler. */
export const fileRoutes = fp(async function fileRoutes(root: FastifyInstance) {
  root.decorate("filesService", new FilesService(root));
  await root.register(fileRoutesInner);

async function fileRoutesInner(app: FastifyInstance) {
  const svc = app.filesService;

  app.setErrorHandler((err: FastifyError | Error, _req, reply) => {
    if (err instanceof HttpError) return reply.code(err.status).send({ error: err.message });
    if (err instanceof z.ZodError) return reply.code(400).send({ error: err.issues[0]?.message ?? "Invalid data" });
    const fe = err as FastifyError;
    if (fe.code === "FST_ERR_CTP_INVALID_MEDIA_TYPE") return reply.code(415).send({ error: "Content type not supported" });
    if (fe.code === "FST_ERR_CTP_BODY_TOO_LARGE") return reply.code(413).send({ error: "Request too large" });
    if (fe.statusCode === undefined || fe.statusCode >= 500) {
      app.log.error(err);
      return reply.code(500).send({ error: "Internal error" });
    }
    return reply.code(fe.statusCode).send({ error: err.message });
  });

  type P = { Params: { id: string } };

  app.get<P>("/api/servers/:id/files", async (req) => svc.list(req.params.id, pathQuery.parse(req.query).path));

  app.get<P>("/api/servers/:id/files/stat", async (req) => svc.stat(req.params.id, pathQuery.parse(req.query).path));

    return reply.code(204).send();
  });
```

```ts
/**
 * Content-Disposition header to download `filename` (RFC 6266 + RFC 5987): a quoted ASCII fallback
 * name and the real name in percent-encoded UTF-8. Quotes, backslashes, % and control characters
 * never arrive raw in the header.
 */
export function contentDisposition(filename: string): string {
  const name = filename || "download";
  const fallback = name.replace(/[^\x20-\x7e]|["\\%]/g, "_");
  const encoded = encodeURIComponent(name).replace(/['()*]/g, (c) => "%" + c.charCodeAt(0).toString(16).toUpperCase());
  return `attachment; filename="${fallback}"; filename*=UTF-8''${encoded}`;
}
```

```ts
import { PassThrough, type Readable } from "node:stream";
import { finished } from "node:stream/promises";

/**
 * Wraps the body of a browser upload to hand it to the agent. If the agent cuts, the original body
 * is not destroyed (it is detached and keeps being read), so that the browser finishes sending and
 * receives the error response instead of a network cut. If it is the browser that cuts, the copy is
 * destroyed and the agent sees the transfer truncated.
 */
export function detachable(src: Readable): Readable {
  const out = new PassThrough();
  src.on("error", (e) => out.destroy(e));
  src.on("close", () => { if (!src.readableEnded) out.destroy(new Error("The upload was interrupted")); });
  out.on("close", () => {
    if (!src.readableEnded) {
      src.unpipe(out);
      src.resume();
    }
  });
  src.pipe(out);
  return out;
}

/** Reads and discards what remains of a body so that a clean error can be answered. */
export async function drain(body: Readable): Promise<void> {
  if (body.readableEnded || body.destroyed) return;
  body.resume();
  await finished(body).catch(() => {});
}
```

```ts
  invalid_path: 400, path_outside: 400, root: 400, is_dir: 400, not_dir: 400,
  unknown_server: 404, not_found: 404,
  exists: 409, disconnected: 409,

export function toHttpError(e: unknown, fallback: string): HttpError {

  if (e instanceof AgentError) return new HttpError(STATUS_BY_CODE[e.code] ?? 502, e.message);

export class FilesService {
  constructor(protected app: FastifyInstance) {}

  /** Server and connection of its node: 404/409 before bothering the agent. */
  protected target(serverId: string) {
    const row = this.app.servers.get(serverId);
    if (!row) throw new HttpError(404, "Server not found");
    const conn = this.app.agents.get(row.node_id);
    if (!conn) throw new HttpError(409, "The node is disconnected");
    return { row, conn };
  }

  private async call(serverId: string, body: Body, fallback: string) {
    const { conn } = this.target(serverId);
    try {
      return await conn.request(body, REQUEST_TIMEOUT_MS);
    } catch (e) {
      throw toHttpError(e, fallback);
    }
  }

  async list(serverId: string, path: string): Promise<{ path: string; entries: FileEntryDto[]; truncated: boolean }> {
    const res = await this.call(serverId, { case: "filesList", value: { serverId, path } }, "Could not list the folder");
    if (res.body.case !== "filesListResult") throw new HttpError(502, "Unexpected response from the agent");
    return { path, entries: res.body.value.entries.map(toEntryDto), truncated: res.body.value.truncated };
  }

  async stat(serverId: string, path: string): Promise<FileEntryDto> {
    const res = await this.call(serverId, { case: "filesStat", value: { serverId, path } }, "Could not read the file info");
    if (res.body.case !== "filesStatResult" || !res.body.value.entry) throw new HttpError(502, "Unexpected response from the agent");
    return toEntryDto(res.body.value.entry);
  }

  async read(serverId: string, path: string): Promise<{ path: string; content: string; size: number }> {
    const res = await this.call(serverId, { case: "filesRead", value: { serverId, path, maxBytes: INLINE_MAX_BYTES } }, "Could not read the file");
    if (res.body.case !== "filesReadResult") throw new HttpError(502, "Unexpected response from the agent");
    let content: string;
    try {
      content = new TextDecoder("utf-8", { fatal: true }).decode(res.body.value.content);
    } catch {
      throw new HttpError(415, "The file is not UTF-8 text: download it to open it");
    }
    if (content.includes("\u0000")) throw new HttpError(415, "The file looks binary: download it to open it");
    return { path, content, size: Number(res.body.value.size) };
  }

  async write(serverId: string, path: string, content: string): Promise<void> {
    const bytes = new TextEncoder().encode(content);
    if (bytes.byteLength > INLINE_MAX_BYTES) throw new HttpError(413, "The content exceeds 2 MiB: upload it as a file");
    await this.call(serverId, { case: "filesWrite", value: { serverId, path, content: bytes } }, "Could not save the file");
  }

  async mkdir(serverId: string, path: string): Promise<void> {
    await this.call(serverId, { case: "filesMkdir", value: { serverId, path } }, "Could not create the folder");
  }

  async rename(serverId: string, from: string, to: string): Promise<void> {
    if (from === "/" || to === "/") throw new HttpError(400, "The root folder cannot be renamed");
    await this.call(serverId, { case: "filesRename", value: { serverId, from, to } }, "Could not rename");
  }

  async remove(serverId: string, path: string): Promise<void> {
    if (path === "/") throw new HttpError(400, "The root folder cannot be deleted");
    await this.call(serverId, { case: "filesDelete", value: { serverId, path } }, "Could not delete");
  }

  /**
   * Download: the agent uploads the file with PUT /agent/transfer/:id and the stream is forwarded
   * as it is to the browser. `done` is the agent's final result (only to log it).
   */
  async download(serverId: string, path: string): Promise<{ stream: Readable; size: number | null; done: Promise<void> }> {
    const { row, conn } = this.target(serverId);
    const t = this.app.transfers.inbound(row.node_id);
    const req = conn.request({ case: "filesDownload", value: { serverId, path, transferId: t.id } }, TRANSFER_TIMEOUT_MS);
    const done = req.then(() => undefined);
    done.catch(() => {});
    try {
      const incoming = await Promise.race([
        t.incoming,
        req.then((): never => { throw new HttpError(502, "The agent finished without sending the file"); }),
      ]);
      return { stream: incoming.stream, size: incoming.size, done };
    } catch (e) {
      t.cancel("download failed");
      throw toHttpError(e, "Could not download the file");
    }
  }

  /**
   * Upload: the agent downloads the browser's body with GET /agent/transfer/:id, without going
   * through disk. If it fails, what remains of the body is drained so that the agent's error can be
   * answered.
   */
  async upload(serverId: string, path: string, body: Readable, size: number | null): Promise<void> {
    let t: OutboundTransfer | undefined;
    try {
      const { row, conn } = this.target(serverId);
      t = this.app.transfers.outbound(row.node_id, async () => ({ stream: detachable(body), size }));
      const req = conn.request({ case: "filesUpload", value: { serverId, path, transferId: t.id, size: BigInt(size ?? -1) } }, TRANSFER_TIMEOUT_MS);
      await Promise.race([req, failOnExpiry(t.done)]);
    } catch (e) {
      t?.cancel("upload failed");
      await drain(body);
      throw toHttpError(e, "Could not upload the file");
    }
  }
}
```

```ts
 * application/octet-stream and the panel forwards it to the agent in streaming.
 */
export function uploadFile(serverId: string, path: string, file: Blob, onProgress?: (sent: number, total: number) => void, signal?: AbortSignal): Promise<void> {
  const url = `${base(serverId)}/upload?${q(path)}`;
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open("PUT", url);
    xhr.setRequestHeader("content-type", "application/octet-stream");
    xhr.upload.onprogress = (e) => onProgress?.(e.loaded, e.lengthComputable ? e.total : file.size);
    xhr.onload = () => {
      if (xhr.status >= 200 && xhr.status < 300) return resolve();
      reportStatus(xhr.status, url);
      let data: unknown = null;
      try { data = JSON.parse(xhr.responseText); } catch { /* body is not JSON */ }
      reject(new ApiError(xhr.status, errorMessage(xhr.status, xhr.statusText, data)));
    };
    xhr.onerror = () => reject(new ApiError(0, "Network error: the upload was cut off"));
    xhr.onabort = () => reject(new ApiError(0, "Upload cancelled"));
    signal?.addEventListener("abort", () => xhr.abort(), { once: true });
    xhr.send(file);
  });
}

/** Breadcrumbs of a path: the root is called "data" as in the container. */
export function breadcrumbs(path: string): { name: string; path: string }[] {
  const out = [{ name: "data", path: "/" }];
  let acc = "";
  for (const seg of path.split("/").filter(Boolean)) {
    acc += `/${seg}`;
    out.push({ name: seg, path: acc });
  }
  return out;
}

/** Opens in the editor if it is known text and fits the inline limit. */
export function canEdit(e: Pick<FileEntryDto, "name" | "dir" | "size">): boolean {
  return !e.dir && editorLanguage(e.name) !== null && e.size <= INLINE_MAX_BYTES;
}

/** Validates a new name (folder or rename): error message or null. */
export function validateNewName(name: string, existing: readonly string[], current?: string): string | null {
  const parsed = fileNameSchema.safeParse(name);
  if (!parsed.success) return parsed.error.issues[0]?.message ?? "Invalid name";
  if (parsed.data !== current && existing.includes(parsed.data)) return `«${parsed.data}» already exists in this folder`;
  return null;
}

/** Integer percentage of an upload (0 if the total is 0). */
export const progressPct = (sent: number, total: number): number => (total > 0 ? Math.min(100, Math.floor((sent / total) * 100)) : 0);
```

```tsx
  switch (lang) {
    case "json": return json();
    case "yaml": return StreamLanguage.define(yaml);
    case "toml": return StreamLanguage.define(toml);
    case "properties": return StreamLanguage.define(properties);
    case "text": return [];
  }
}

interface Props {
  initial: string;
  language: EditorLanguage;
  /** Receives the view on mount (and null on unmount) to read the document when saving. */
  onView(view: EditorView | null): void;
  onDirty(): void;
  onSave(): void;
}

/** CodeMirror 6 without React dependencies: it is created on mount and destroyed on unmount. */
export function CodeEditor({ initial, language, onView, onDirty, onSave }: Props) {
  const host = useRef<HTMLDivElement>(null);
  const cb = useRef({ onView, onDirty, onSave });
  cb.current = { onView, onDirty, onSave };

  useEffect(() => {
    const view = new EditorView({
      parent: host.current!,
      state: EditorState.create({
        doc: initial,
        extensions: [
          basicSetup,
          oneDark,
          languageExtension(language),
          Prec.highest(keymap.of([{ key: "Mod-s", preventDefault: true, run: () => { cb.current.onSave(); return true; } }])),
          EditorView.updateListener.of((u) => { if (u.docChanged) cb.current.onDirty(); }),
          EditorView.theme({ "&": { height: "65vh", fontSize: "12px" }, ".cm-scroller": { fontFamily: "ui-monospace, SFMono-Regular, monospace" } }),
        ],
      }),
    });
    cb.current.onView(view);
    return () => { cb.current.onView(null); view.destroy(); };
  }, [initial, language]);

  return <div ref={host} className="overflow-hidden rounded-md border border-border" />;
}
```

```tsx
const errText = (e: unknown) => (e instanceof ApiError ? e.message : "Unexpected error");

export function FileBrowser({ serverId, nodeOnline }: { serverId: string; nodeOnline?: boolean }) {
  const [path, setPath] = useState("/");
  const [editing, setEditing] = useState<string | null>(null);
  const [uploads, setUploads] = useState<UploadItem[]>([]);
  const [nameAction, setNameAction] = useState<NameAction>(null);
  const fileInput = useRef<HTMLInputElement>(null);
  const qc = useQueryClient();
  const offline = nodeOnline === false;

  const list = useQuery({
    queryKey: ["files", serverId, path],
    queryFn: () => filesApi.list(serverId, path),
    enabled: !offline,
  });
  const refresh = () => qc.invalidateQueries({ queryKey: ["files", serverId] });
  const names = list.data?.entries.map((e) => e.name) ?? [];

    mutationFn: async (name: string) => {
      if (nameAction?.kind === "mkdir") return filesApi.mkdir(serverId, joinPath(path, name));
      if (nameAction?.kind === "rename") return filesApi.rename(serverId, joinPath(path, nameAction.entry.name), joinPath(path, name));
    },
    onSuccess: () => { setNameAction(null); void refresh(); },
  });
  const del = useMutation({
    mutationFn: (e: FileEntryDto) => filesApi.remove(serverId, joinPath(path, e.name)),
    onSettled: () => void refresh(),
  });

  const upload = async (picked: FileList | null) => {
    if (!picked?.length) return;
    const files = [...picked];
    const clash = files.filter((f) => names.includes(f.name)).map((f) => f.name);
    if (clash.length && !confirm(`${clash.join(", ")} already exists in this folder. Replace?`)) return;

        await uploadFile(serverId, joinPath(path, f.name), f, (sent, total) => update({ sent, total }));
        update({ sent: f.size });
      } catch (e) {
        update({ error: errText(e) });
      }
    }
    void refresh();
    setUploads((u) => u.filter((x) => x.error)); // the successful ones disappear; the errors stay in view
  };

  const open = (e: FileEntryDto) => {
    if (e.dir) return setPath(joinPath(path, e.name));

            </span>
          ))}
        </nav>
        <div className="flex items-center gap-2">
          <input ref={fileInput} type="file" multiple hidden onChange={(e) => { void upload(e.target.files); e.target.value = ""; }} />
          <Button size="sm" variant="secondary" disabled={offline} onClick={() => fileInput.current?.click()}><Upload /> Upload</Button>
          <Button size="sm" variant="secondary" disabled={offline} onClick={() => { nameMut.reset(); setNameAction({ kind: "mkdir" }); }}><FolderPlus /> New folder</Button>
          <Button size="icon-sm" variant="ghost" aria-label="Refresh" disabled={offline} onClick={() => void refresh()}><RefreshCw /></Button>
        </div>
      </div>

      {offline && <p className="text-sm text-amber-400">The node is disconnected: the files are not available.</p>}
      {uploads.map((u) => (
        <div key={u.name} className="flex items-center gap-3 text-sm">

          {u.error ? <span role="alert" className="text-red-400">{u.error}</span> : (

              <span className="text-muted-foreground">{progressPct(u.sent, u.total)} % of {formatBytes(u.total)}</span>

          )}
        </div>
      ))}
      {del.error && <p role="alert" className="text-sm text-red-400">{errText(del.error)}</p>}
      {list.isError && <p role="alert" className="text-sm text-red-400">{errText(list.error)}</p>}

        <TableHeader>
          <TableRow><TableHead>Name</TableHead><TableHead className="w-28 text-right">Size</TableHead><TableHead className="w-44">Modified</TableHead><TableHead className="w-32" /></TableRow>

          {list.data?.entries.map((e) => {

            const clickable = e.dir || canEdit(e);
```
