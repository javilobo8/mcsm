# MC Server Manager — Plan 7: Migration between nodes

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move a server (world, spec and identity) from one node to another from the web, with a job of 7 visible steps: if something fails, the source stays intact and, if it was running, it is started again; if it succeeds, the server lives on the target with the spec at version +1 (and another port if its own clashes) and the source is retired (`<slug>.migrated-<ts>` or deleted).

**Architecture:** The panel orchestrates (`MigrationService`) and the agents execute idempotent steps. Source: `PowerAction stop` → `BackupNow{PRE_MIGRATION}` → `BackupPush` (uploads the `.tar.zst` to the panel's staging via `PUT /agent/transfer`). Target: `MigrateReceive` (agent job: downloads from staging with `GET /agent/transfer`, checks size and sha256, restores into a `<DATA_ROOT>/<slug>` that it creates exclusively with a marker) → `ApplySpec` (version +1, stopped) → `PowerAction start` and waits for `healthy`/ping (5 min). The commit is an SQLite transaction that changes `servers.node_id/slug/spec/spec_version` only if the version did not change; afterwards `MigrateRetire` retires the source. While the migration is open (`migrations` table), `SyncSpecs` does not retire the server from either node and a panel hook rejects (409) the user's actions on it. A failure before the commit is rolled back: `MigrateAbort` on the target (deletes only what carries this migration's marker) and, if the source was running, it is restarted, but never before having removed a copy on the target that got to be started.

**Tech Stack:** Go 1.27.2 (agent: `backup`, `app`, `reconcile`, `jobs`, `conn.TransferClient`); protobuf with buf 1.73 (`pnpm gen`); Node 26, pnpm 12, Fastify 5, `node:sqlite`, zod 4; React 19, TanStack Query, shadcn/ui (Radix), Vitest 4 on node (no jsdom); E2E with real Docker and Docker-in-Docker for the second node.

## Decisions resolved with the real code

- **The same identity on both nodes, with the panel as arbiter.** The server keeps its `id` (URL, metrics, history). Between step 4 and the commit, the target stores a “ghost” spec with that `id`; the `servers` row stays on the source. The `migrations` table records each migration and `AgentService.handshake` does not put in `removed_ids` a server with an open migration that goes through that node (`app.migrations.protects`): neither the target's ghost nor the source pending retirement disappears because of a Hello. The change of node is **one** transaction (`MigrationsRepo.commit`) that is only applied if the row is still on the source with the `spec_version` from the start; otherwise the migration is undone.
- **Staging on the panel, not direct streaming.** The spec (§7) asks for `BackupPush` and `BackupPull` in parallel; Plan 5 left `Staging.source({removeAfter:false})` + `remove()` precisely so that the migration can **retry** the send to the target without repeating the copy on the source. The panel saves the copy in `staging/mig-<id>.bin`, verifying size and sha256 (against the source's `BackupCreated` and the `BackupPushResult`), and serves it to the target; it is deleted when step 4 ends or when it fails.
- **Restore before creating the spec on the target** (steps 4 and 5 of the spec, inverted). `MigrateReceive` creates `<DATA_ROOT>/<slug>` with `os.Mkdir` (exclusive) and a `.mcsm-migration` marker with the migration's id, downloads the copy to `<slug>/backups/` and restores it with `backup.Restore` into a `data` that does not exist yet (without `pre-restore`). That way the reconciler never creates an empty `data`, a foreign directory is never overwritten (`exists`) and `MigrateAbort` only deletes what carries its marker.
- **Message names.** `BackupPush{server_id, filename, transfer_id}` answers `BackupPushResult{size_bytes, sha256, data_bytes}` (`*Result` convention of `isResponseCase`). Instead of `BackupPull`, `MigrateReceive` (download + verification + extraction, as job `migrate_in`). Also `MigrateAbort` (undo on the target) and `MigrateRetire` (retire the source).
- **Visible steps** (`MIGRATION_STEPS` in shared; the job's progress falls in the span of its step): 1 stop on the source (0–5 %), 2 `pre_migration` copy (5–30), 3 copy to the panel (30–50), 4 copy to the target and restore (50–80), 5 create the server on the target (80–83), 6 start and check (83–95), 7 confirm and retire the source (95–100).
- **Verification.** It always starts on the target and waits for `state=running` with `health=healthy` or a correct SLP ping, at most 5 min; `exited`/`dead` fails immediately. If the server was stopped, it is stopped again before the commit. The final desired state is the previous one (`was_running`).
- **Never two live servers.** Step 1 uses `serversService.power(id,"stop")`, which persists `stopped` in the agent **and** in the row: a `SyncSpecs` from the source in the middle does not start it again. When undoing, if the target got to receive `start` (`target_started`), the source is only started again after `MigrateAbort` has deleted that container; if the target does not answer, the source stays stopped and the migration in `rolling_back` until it does.
- **Retirement of the source** (`MigrateRetire`, idempotent): reserves, waits for `fileWrites`, stops the container if someone started it, sets the whole server directory aside, `<DATA_ROOT>/<slug>` → `<DATA_ROOT>/<slug>.migrated-<ts>` (or, with “delete source”, deletes it once the container no longer exists), `Forget` and releases the reservation (which deletes the container through its tombstone). **Deviation from the spec** (§7 says `data.migrated-<ts>`): the whole `<slug>` is set aside and not just `data`, so that the slug is free on the source (migrating the server back to that node, or creating another with that slug, does not trip over a directory the web does not let you delete) and the source's copies stay next to their data. The source's copies are no longer managed from the panel; after the commit the panel asks the target for the inventory, which registers the received `pre_migration` copy (same server, new node) and marks as deleted those of the source (negative path of the inventory, `request_id`).
- **User actions blocked while it lasts.** A root `preHandler` hook (registered **before** the routes, because Fastify fixes each context's hooks when they are registered) rejects with 409: any non-GET method under `/api/servers/:id…` (except `/migration`) if the migration is `running` or `rolling_back`; creating servers on a target node without confirming or on a source with the retirement pending (`POST /api/servers`, `/api/templates/:id/servers`, `POST /api/nodes/:id/…` such as the Plan 6 import); deleting a node with a `running` migration. Escape hatch: if the target node is not going to come back, it can be deleted (the `migrations` rows cascade and the server is free, stopped on the source).
- **Plan 6 in parallel.** A server with `dataPath` is rejected (409) by reading `spec.dataPath` generically (the field does not exist yet on this branch); the commit sets `imported_from = NULL` if the column exists (`PRAGMA table_info`) and the spec the target receives is built with a row without `imported_from` (without `adopt`).
- **Panel restart.** `JobService.interruptStale` fails the `migrate` job (“interrupted”); `MigrationService.recover` (in `onReady`) moves the `running` migrations to `rolling_back` with what is pending according to `target_touched`/`was_running`. What is pending (`rolling_back` and `committed`) is retried every 30 s and after each Hello of the nodes involved. The agents' sub-jobs (`backup` pre_migration and `migrate_in`) follow their course: `migrate_in` enters `AGENT_JOB_TYPES`.
- **E2E with Docker-in-Docker.** Two agents on the **same** Docker would see each other's containers (the reconciler looks for the `mcsm.server_id` label, which is the same on source and target): the target's would recreate the source's. The second node runs inside `mcsm-test-nodeb` (`docker:<version>-dind`, privileged) with its own Docker; its `DATA_ROOT` is a host directory mounted with the same path (mirror) in the dind container and in the agent.

```proto
// Migration between nodes (spec §7 MigrationService). The panel orchestrates it; the agent runs
// idempotent steps on its disk and its Docker. Source: BackupPush and MigrateRetire. Target:
// MigrateReceive and MigrateAbort.

// Panel → agent (source). Uploads a .tar.zst copy from <slug>/backups/ to the panel with
// PUT /agent/transfer/{transfer_id}. Response: BackupPushResult once the panel has received it
// whole, or Error (unknown_server | invalid_request | not_found | busy | transfer_failed |
// backup_failed: the copy has no sha256 in its .json).
message BackupPush {
  string server_id = 1;
  string filename = 2;
  string transfer_id = 3;
}

// Metadata of the sent copy, from its .json: the panel compares size and sha256 with what it has
// received and with the job's BackupCreated.
message BackupPushResult {
  uint64 size_bytes = 1;
  string sha256 = 2;
  uint64 data_bytes = 3; // uncompressed content; 0 if the copy did not record it
}

// Panel → agent (target). Job (type "migrate_in"): downloads the copy with
// GET /agent/transfer/{transfer_id} to <DATA_ROOT>/<slug>/backups/<filename>, checks that exactly
// size_bytes bytes arrive with that sha256 and restores it as <DATA_ROOT>/<slug>/data.
// <DATA_ROOT>/<slug> must not exist: it creates it with the .mcsm-migration marker (contains
// migration_id) and, if anything fails, deletes it entirely. The server must not be on this node.
// Response: Ack (accepted; progress arrives via JobProgress) or Error (invalid_request | exists |
// busy | too_large: it does not fit with the margin). A repeated job_id re-sends its state.
message MigrateReceive {
  string server_id = 1;
  string slug = 2; // slug on the target
  string job_id = 3;
  string migration_id = 4;
  string transfer_id = 5;
  string filename = 6; // <slug>-<ts>-<version>.tar.zst, with the target's slug
  uint64 size_bytes = 7;
  string sha256 = 8;
  uint64 data_bytes = 9; // 0 = unknown (the compressed size is reserved)
}

// Panel → agent (target). Undoes what an unconfirmed migration left on this node: forgets the
// server's spec (if it has one) and deletes its container, and deletes <DATA_ROOT>/<slug> only if
// it carries the marker of migration_id. Idempotent. Response: Ack or Error (busy: a receive is in
// progress or the container could not be deleted yet; the panel retries).
message MigrateAbort {
  string server_id = 1;
  string slug = 2;
  string migration_id = 3;
}

// Panel → agent (source), after confirming the migration. Stops the container if it is still
// running, sets <DATA_ROOT>/<slug> (data and copies) aside as <DATA_ROOT>/<slug>.migrated-<ts> (with
// delete_data, deletes it once the container is deleted), forgets the spec and deletes the container.
// Idempotent.
// Response: Ack or Error (invalid_request: the server has another slug here; busy: retry).
message MigrateRetire {
  string server_id = 1;
  string slug = 2;
  string migration_id = 3;
  bool delete_data = 4;
}
```

```go
package backup

import (
	"context"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"regexp"
	"time"
)

// migratedInfix: <slug>.migrated-<ts> is the directory of a server that the source node keeps
// after a confirmed migration (spec §7, step 7).
const migratedInfix = ".migrated-"

var sha256Re = regexp.MustCompile(`^[0-9a-f]{64}$`)

// MigratedName is the name under which the directory of a server is set aside on the source node,
// next to it, when a migration is confirmed: e.g. survival.migrated-20261012T040000.000Z. It keeps
// the data and its copies and frees <slug> (the server can come back, or another one can be
// created with that slug).
func MigratedName(serverDir string, t time.Time) string {
	return filepath.Base(serverDir) + migratedInfix + t.UTC().Format(tsLayout)
}

// CheckSpace fails, wrapping ErrNoSpace, if need bytes plus the margin max(5 %, 256 MiB) — with
// which the node's servers can keep saving — do not fit in dir. If the free space cannot be queried
// it does not fail: the writes watch it afterwards. free nil uses statfs.
func CheckSpace(dir string, need int64, what string, free func(dir string) (uint64, error)) error {
	if free == nil {
		free = freeSpace
	}
	got, err := free(dir)
	if err != nil {
		return nil
	}
	n := uint64(max(need, 0))
	if req := requiredSpace(need); got < req {
		return fmt.Errorf("%w for %s: %s needed (%s plus a margin of %s so the node's servers can keep saving) and only %s free in %s; %s missing",
			ErrNoSpace, what, humanBytes(req), humanBytes(n), humanBytes(req-n), humanBytes(got), dir, humanBytes(req-got))
	}
	return nil
}

// ReceiveRequest describes a copy that arrives from another node (migration, spec §7).
type ReceiveRequest struct {
	BackupsDir string
	ServerID   string
	Slug       string
	Filename   string    // <slug>-<ts>-<version>.tar.zst (ValidName with Slug)
	Body       io.Reader // the copy; at most Size+1 bytes are read
	Size       int64     // exact bytes that must arrive
	SHA256     string    // lowercase hex of the whole file
	// ExtractBytes is what it will occupy when extracted (0 = unknown: Size is used). While it
	// arrives, it must keep fitting with the margin: the restore comes right after.
	ExtractBytes int64
	Now          func() time.Time
	FreeSpace    func(dir string) (uint64, error) // nil: statfs
	Progress     func(done, total int64)
}

// Receive writes the copy as <Filename>.partial in BackupsDir computing its sha256 and, only if
// exactly Size bytes arrive with that sha256, writes its .json (trigger pre_migration) and renames
// it to its final name: Restore verifies it again with that .json. If anything fails, is cancelled
// or space runs out, it leaves nothing (neither partial nor .json) and never overwrites an existing copy.
func Receive(ctx context.Context, req ReceiveRequest) (meta Meta, err error) {
	if req.Now == nil {
		req.Now = time.Now
	}
	if req.FreeSpace == nil {
		req.FreeSpace = freeSpace
	}
	if req.Progress == nil {
		req.Progress = func(int64, int64) {}
	}
	if !ValidName(req.Slug, req.Filename) {
		return Meta{}, fmt.Errorf("invalid copy name %q", req.Filename)
	}
	if req.Size <= 0 || !sha256Re.MatchString(req.SHA256) {
		return Meta{}, errors.New("invalid copy size or sha256")
	}
	started, version, _ := parseName(req.Slug, req.Filename)
	if err := os.MkdirAll(req.BackupsDir, 0o750); err != nil {
		return Meta{}, fmt.Errorf("create the copies directory: %w", err)
	}
	final := filepath.Join(req.BackupsDir, req.Filename)
	if _, serr := os.Lstat(final); serr == nil {
		return Meta{}, fmt.Errorf("the copy %s already exists", req.Filename)
	}
	extract := req.ExtractBytes
	if extract <= 0 {
		extract = req.Size
	}
	partial := final + partialExt
	f, err := os.OpenFile(partial, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0o640)
	if err != nil {
		return Meta{}, fmt.Errorf("create the copy: %w", err)
	}
	closed := false
	defer func() {
		if err != nil {
			if !closed {
				_ = f.Close()
			}
			_ = os.Remove(partial)
		}
	}()
	h := sha256.New()
	// What must stay free while it arrives: the extraction that comes afterwards, with its margin.
	guard := &spaceGuard{w: f, free: req.FreeSpace, dir: req.BackupsDir, margin: requiredSpace(extract), since: -1}
	src := &progressReader{r: ctxReader{ctx: ctx, r: io.LimitReader(req.Body, req.Size+1)}, total: req.Size, fn: req.Progress}
	var n int64
	n, err = io.Copy(io.MultiWriter(guard, h), src)
	if err != nil {
		if cerr := ctx.Err(); cerr != nil {
			return Meta{}, fmt.Errorf("reception cancelled: %w", cerr)
		}
		return Meta{}, fmt.Errorf("receive the copy: %w", err)
	}
	if n < req.Size {
		return Meta{}, fmt.Errorf("the copy arrived incomplete: %d bytes of %d", n, req.Size)
	}
	if n > req.Size {
		return Meta{}, fmt.Errorf("the copy arrived with extra bytes: %d were expected", req.Size)
	}
	sum := hex.EncodeToString(h.Sum(nil))
	if sum != req.SHA256 {
		return Meta{}, fmt.Errorf("the copy arrived corrupt: sha256 %s, expected %s", sum, req.SHA256)
	}
	if err = f.Sync(); err != nil {
		return Meta{}, fmt.Errorf("save the copy to disk: %w", err)
	}
	closed = true
	if err = f.Close(); err != nil {
		return Meta{}, fmt.Errorf("save the copy to disk: %w", err)
	}
	meta = Meta{
		Filename: req.Filename, ServerID: req.ServerID, Slug: req.Slug, SpecVersion: version, Trigger: TriggerPreMigration,
		SizeBytes: req.Size, SHA256: sum, StartedAt: started.UTC(), FinishedAt: req.Now().UTC(), DataBytes: req.ExtractBytes,
	}
	if err = WriteMeta(req.BackupsDir, meta); err != nil {
		return Meta{}, fmt.Errorf("save the copy's metadata: %w", err)
	}
	if err = rename(partial, final); err != nil {
		_ = os.Remove(final + MetaExt)
		return Meta{}, fmt.Errorf("save the copy: %w", err)
	}
	_ = syncDir(req.BackupsDir)
	return meta, nil
}
```
Note: `progressReader` and `ctxReader` are those of `restore.go`; `spaceGuard`, `requiredSpace` and `freeSpace` are those of `create.go`/`restore.go`. The “cancelled” case of the test fails on the first read (`ctxReader`) and the `defer` deletes the partial.

```go
package app

import (
	"context"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"

	mcsmv1 "mcsm/agent/gen/mcsm/v1"
	"mcsm/agent/internal/backup"
	"mcsm/agent/internal/errcode"
	"mcsm/agent/internal/files"
	"mcsm/agent/internal/reconcile"
)

// Migration between nodes (Plan 7, spec §7). The panel orchestrates; the agent runs idempotent
// steps. Source: BackupPush (uploads the pre_migration copy to the panel) and MigrateRetire (retires
// it when the migration is confirmed). Target: MigrateReceive (receives and restores) and MigrateAbort (undoes).

// errMigrateExists: the target already has the server or its directory; nothing is overwritten.
var errMigrateExists = errors.New("already exists")

// migrateErrCode translates a failure of the migration messages to the protocol's Error.code.
func migrateErrCode(err error) string {
	switch {
	case errors.Is(err, reconcile.ErrBusy), errors.Is(err, errTransfersBusy), errors.Is(err, errClosing), errors.Is(err, errFilesClosing):
		return errcode.Busy
	case errors.Is(err, errUnknownServer):
		return errcode.UnknownServer
	case errors.Is(err, errBadRequest):
		return errcode.InvalidRequest
	case errors.Is(err, errMigrateExists):
		return errcode.Exists
	case errors.Is(err, backup.ErrNoSpace):
		return errcode.TooLarge
	case errors.Is(err, files.ErrTransfer):
		return errcode.TransferFailed
	case errors.Is(err, fs.ErrNotExist):
		return errcode.NotFound
	default:
		return errcode.BackupFailed
	}
}

// handleBackupPush uploads a copy to the panel (PUT /agent/transfer/{id}) and replies with its
// metadata when the panel has received it whole. It counts as an ongoing Files* for the shutdown
// (xfer.enter) and takes one of the node's transfer slots. ctx: the agent's life context.
func (a *App) handleBackupPush(ctx context.Context, id uint64, m *mcsmv1.BackupPush, send func(*mcsmv1.Envelope) error) {
	if !a.xfer.enter() {
		_ = send(errMsg(id, errcode.Busy, errFilesClosing))
		return
	}
	defer a.xfer.leave()
	res, err := a.backupPush(ctx, m)
	if err != nil {

func (a *App) backupPush(ctx context.Context, m *mcsmv1.BackupPush) (*mcsmv1.BackupPushResult, error) {
	t, err := a.bk.target(m.GetServerId())
	if err != nil {
		return nil, err
	}
	if !backup.ValidName(t.slug, m.GetFilename()) {
		return nil, fmt.Errorf("%w: invalid copy name %q", errBadRequest, m.GetFilename())
	}
	meta, err := backup.ReadMeta(t.backupsDir, m.GetFilename())
	if err != nil || meta.SHA256 == "" {
		return nil, fmt.Errorf("the copy %s has no sha256 in its .json: it is not sent without being able to verify it", m.GetFilename())
	}
	// Opened before claiming the transfer: a copy that no longer exists does not consume it. The
	// descriptor stays valid even if pruning deletes the file while it is being sent.
	f, err := os.Open(filepath.Join(t.backupsDir, m.GetFilename()))
	if err != nil {
		return nil, fmt.Errorf("open the copy: %w", err)
	}
	defer f.Close()
	fi, err := f.Stat()
	if err != nil {
		return nil, err
	}
	if !fi.Mode().IsRegular() {
		return nil, fmt.Errorf("%w: the copy is not a regular file", errBadRequest)
	}
	xfer, err := a.transfers()
	if err != nil {
		return nil, err
	}
	release, err := a.xfer.acquire()
	if err != nil {
		return nil, err
	}
	defer release()
	size := fi.Size()
	err = a.withIdleGuard(ctx, func(ctx context.Context, track func(io.Reader) io.Reader) error {
		// LimitReader: what it measured when opened is sent; if it shrinks, Put fails on Content-Length.
		if err := xfer.Put(ctx, m.GetTransferId(), track(io.LimitReader(f, size)), size); err != nil {
			return fmt.Errorf("%w: %v", files.ErrTransfer, err)
		}
		return nil
	})
	if err != nil {
		return nil, err
	}
	return &mcsmv1.BackupPushResult{SizeBytes: uint64(size), Sha256: meta.SHA256, DataBytes: uint64(max(meta.DataBytes, 0))}, nil
}
```

```go
const (
	// jobTypeMigrateIn is the job type of the reception (JobProgress.type, inventory).
	jobTypeMigrateIn = "migrate_in"
	// holdMigration is the reason for the reservation during a migration's steps.
	holdMigration = "migration"
	// migrationMarker is created in <DATA_ROOT>/<slug> when a migration is received and contains its
	// id: MigrateAbort only deletes a directory with the marker of that same migration.
	migrationMarker = ".mcsm-migration"
	// maxMigrateBytes bounds size_bytes and data_bytes (an absurd value would overflow the sums).
	maxMigrateBytes = 1 << 50
)

var migrateSHA256 = regexp.MustCompile(`^[0-9a-f]{64}$`)

func (b *backupService) handleMigrateReceive(id uint64, m *mcsmv1.MigrateReceive, send func(*mcsmv1.Envelope) error) {
	if err := b.startReceive(m); err != nil {
		_ = send(errMsg(id, migrateErrCode(err), err))
		return
	}
	_ = send(ack(id))
}

// startReceive validates, registers the job (an already known job_id re-sends its state, §5.4),
// checks that neither the server nor its directory exist on this node and that the copy plus its
// extraction fit with the margin, reserves the server and starts the reception in the background.
func (b *backupService) startReceive(m *mcsmv1.MigrateReceive) error {
	if m.GetJobId() == "" || m.GetServerId() == "" || m.GetMigrationId() == "" {
		return fmt.Errorf("%w: missing job_id, server_id or migration_id", errBadRequest)
	}
	if !spec.ValidSlug(m.GetSlug()) || !backup.ValidName(m.GetSlug(), m.GetFilename()) {
		return fmt.Errorf("%w: invalid slug or copy name", errBadRequest)
	}
	if m.GetSizeBytes() == 0 || m.GetSizeBytes() > maxMigrateBytes || m.GetDataBytes() > maxMigrateBytes || !migrateSHA256.MatchString(m.GetSha256()) {
		return fmt.Errorf("%w: invalid copy size or sha256", errBadRequest)
	}
	j, existing, err := b.jobs.Begin(m.GetJobId(), m.GetServerId(), jobTypeMigrateIn)
	if err != nil {
		return err
	}
	if existing != nil {
		b.jobs.Replay(existing)
		return nil
	}
	fail := func(err error) error {
		b.finish(j, err, "")
		return err
	}
	sp, err := b.a.st.GetSpec(m.GetServerId())
	if err != nil {
		return fail(err)
	}
	if sp != nil {
		return fail(fmt.Errorf("%w: the server is already on this node", errMigrateExists))
	}
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	if _, err := os.Lstat(dir); err == nil {
		return fail(fmt.Errorf("%w: %s already exists on the target node; move or delete it before migrating here", errMigrateExists, dir))
	} else if !errors.Is(err, fs.ErrNotExist) {
		return fail(err)
	}
	size, extract := int64(m.GetSizeBytes()), int64(m.GetDataBytes())
	if extract <= 0 {
		extract = size
	}
	if err := backup.CheckSpace(b.a.cfg.DataRoot, size+extract, "receive the migration", b.freeSpace); err != nil {
		return fail(err)
	}
	// Reservation without spec: an ApplySpec that arrives during the reception is only saved; it is
	// applied (and creates the container) on release, once the data is restored. No Files* can write
	// to this server (serverFS answers unknown_server before fileWrites.enter): there are no writes to wait for.
	release, err := b.a.rec.Hold(m.GetServerId(), holdMigration)
	if err != nil {
		return fail(err)
	}
	if !b.spawn(func() { b.runReceive(m, dir, j, release) }) {
		release(b.a.life)
		return fail(errClosing)
	}
	return nil
}

func (b *backupService) runReceive(m *mcsmv1.MigrateReceive, dir string, j *jobs.Job, release func(context.Context)) {
	ctx := b.a.life
	err := b.withSlot(ctx, j, func() error { return b.receive(ctx, m, dir, j) })
	err = interrupted(ctx, err)
	release(b.a.life) // normally without spec: there is nothing to reconcile
	b.finish(j, err, "Copy received, verified and restored in "+filepath.Join(dir, "data"))
}

// receive creates <DATA_ROOT>/<slug> (exclusively) with the migration's marker, downloads the copy
// to its backups/ checking size and sha256, and restores it as data/ with backup.Restore (which
// verifies it again, checks the space and bounds the extraction). If anything fails, it deletes the
// whole directory: this reception created it.
func (b *backupService) receive(ctx context.Context, m *mcsmv1.MigrateReceive, dir string, j *jobs.Job) (err error) {
	if err := os.Mkdir(dir, 0o755); err != nil {
		if errors.Is(err, fs.ErrExist) {
			return fmt.Errorf("%w: %s already exists on the target node", errMigrateExists, dir)
		}
		return fmt.Errorf("create %s: %w", dir, err)
	}
	defer func() {
		if err == nil {
			return
		}
		if rerr := os.RemoveAll(dir); rerr != nil {
			j.Log("warning: could not delete " + dir + " (delete it by hand): " + rerr.Error())
		}
	}()
	if err := os.WriteFile(filepath.Join(dir, migrationMarker), []byte(m.GetMigrationId()+"\n"), 0o644); err != nil {
		return fmt.Errorf("mark the migration directory: %w", err)
	}
	xfer, err := b.a.transfers()
	if err != nil {
		return err
	}
	releaseSlot, err := b.a.xfer.acquire()
	if err != nil {
		return err
	}
	backupsDir := backup.Dir(b.a.cfg.DataRoot, m.GetSlug())
	size := int64(m.GetSizeBytes())
	j.Progress(1, "Receiving the copy from the panel")
	err = b.a.withIdleGuard(ctx, func(ctx context.Context, track func(io.Reader) io.Reader) error {
		body, got, err := xfer.Get(ctx, m.GetTransferId())
		if err != nil {
			return fmt.Errorf("%w: %v", files.ErrTransfer, err)
		}
		defer body.Close()
		if got >= 0 && got != size {
			return fmt.Errorf("%w: the panel announces %d bytes and the copy measures %d", files.ErrTransfer, got, size)
		}
		_, err = backup.Receive(ctx, backup.ReceiveRequest{
			BackupsDir: backupsDir, ServerID: m.GetServerId(), Slug: m.GetSlug(), Filename: m.GetFilename(),
			Body: track(body), Size: size, SHA256: m.GetSha256(), ExtractBytes: int64(m.GetDataBytes()),
			Now: b.clock.Now, FreeSpace: b.freeSpace,
			Progress: func(done, total int64) {
				j.Progress(1+uint32(done*49/max(total, 1)), "Receiving the copy from the panel")
			},
		})
		return err
	})
	releaseSlot()
	if err != nil {
		return err
	}
	j.Log("copy received and verified (sha256 " + m.GetSha256() + ")")
	_, err = b.restore(ctx, backup.RestoreRequest{
		ServerID: m.GetServerId(), Slug: m.GetSlug(), Filename: m.GetFilename(),
		DataDir: filepath.Join(dir, "data"), BackupsDir: backupsDir, Now: b.clock.Now,
		Progress: func(pct uint32, msg string) { j.Progress(50+pct/2, msg) }, Log: j.Log,
	})
	return err
}
```

```go
func (b *backupService) handleMigrateAbort(id uint64, m *mcsmv1.MigrateAbort, send func(*mcsmv1.Envelope) error) {
	b.respondAsync(id, send, func() error { return b.abortMigration(m) })
}

func (b *backupService) handleMigrateRetire(id uint64, m *mcsmv1.MigrateRetire, send func(*mcsmv1.Envelope) error) {
	b.respondAsync(id, send, func() error { return b.retireMigration(m) })
}

// respondAsync runs fn in the background, counted in wg like the copies (shutdown waits for it), and
// replies Ack or Error when it finishes. If the agent is shutting down, busy.
func (b *backupService) respondAsync(id uint64, send func(*mcsmv1.Envelope) error, fn func() error) {
	if !b.spawn(func() {
		if err := fn(); err != nil {
			_ = send(errMsg(id, migrateErrCode(err), err))
			return
		}
		_ = send(ack(id))
	}) {
		_ = send(errMsg(id, errcode.Busy, errClosing))
	}
}

func checkMigrationMsg(serverID, slug, migrationID string) error {
	if serverID == "" || migrationID == "" || !spec.ValidSlug(slug) {
		return fmt.Errorf("%w: missing server_id or migration_id, or the slug is not valid", errBadRequest)
	}
	return nil
}

// abortMigration undoes on the target what an unconfirmed migration left: the spec and the container
// (Forget and releasing the reservation, which stops it and deletes it through its tombstone) and the
// directory, only if it carries this migration's marker. Repeating it does nothing.
func (b *backupService) abortMigration(m *mcsmv1.MigrateAbort) error {
	if err := checkMigrationMsg(m.GetServerId(), m.GetSlug(), m.GetMigrationId()); err != nil {
		return err
	}
	id := m.GetServerId()
	sp, err := b.a.st.GetSpec(id)
	if err != nil {
		return err
	}
	switch {
	case sp != nil && sp.Slug != m.GetSlug():
		return fmt.Errorf("%w: the server has another slug on this node (%s)", errBadRequest, sp.Slug)
	case sp != nil:
		if err := b.forgetHeld(id, nil); err != nil {
			return err
		}
	default:
		if reason := b.a.rec.HeldReason(id); reason != "" {
			return fmt.Errorf("%w: it will be retried when finished", reconcile.Busy(reason))
		}
	}
	if err := b.removalDone(id); err != nil {
		return err
	}
	b.a.hub.Reset(id)
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	mark, err := os.ReadFile(filepath.Join(dir, migrationMarker))
	switch {
	case errors.Is(err, fs.ErrNotExist):
		return nil // nothing from this migration on disk (or already deleted)
	case err != nil:
		return err
	case strings.TrimSpace(string(mark)) != m.GetMigrationId():
		b.a.log.Warn("undo migration: the directory belongs to another migration; it is not touched", "dir", dir)
		return nil
	}
	if err := os.RemoveAll(dir); err != nil {
		return fmt.Errorf("delete %s: %w", dir, err)
	}
	return nil
}

// retireMigration retires the server from the source after the migration is confirmed: with the
// reservation taken, it stops the container if someone started it, sets <DATA_ROOT>/<slug> (data and
// copies) aside as <DATA_ROOT>/<slug>.migrated-<ts> (without delete_data), forgets the spec and
// releases the reservation (which deletes the container). With delete_data it deletes
// <DATA_ROOT>/<slug> once the container no longer exists. Repeating it (after a cut or a lost
// response) does nothing more.
func (b *backupService) retireMigration(m *mcsmv1.MigrateRetire) error {
	if err := checkMigrationMsg(m.GetServerId(), m.GetSlug(), m.GetMigrationId()); err != nil {
		return err
	}
	id := m.GetServerId()
	sp, err := b.a.st.GetSpec(id)
	if err != nil {
		return err
	}
	if sp != nil && sp.Slug != m.GetSlug() {
		return fmt.Errorf("%w: the server has another slug on this node (%s)", errBadRequest, sp.Slug)
	}
	dir := filepath.Join(b.a.cfg.DataRoot, m.GetSlug())
	setAside := func() error {
		if m.GetDeleteData() {
			return nil // deleted whole at the end, once the container is gone
		}
		if _, err := os.Lstat(dir); errors.Is(err, fs.ErrNotExist) {
			return nil
		} else if err != nil {
			return err
		}
		to := filepath.Join(b.a.cfg.DataRoot, backup.MigratedName(dir, b.clock.Now()))
		if err := os.Rename(dir, to); err != nil {
			return fmt.Errorf("set aside %s: %w", dir, err)
		}
		b.a.log.Info("migration confirmed: the source's data is kept", "server", id, "in", to)
		return nil
	}
	if sp != nil {
		if err := b.forgetHeld(id, func() error {
			if err := b.stopForRetire(id); err != nil {
				return err
			}
			return setAside()
		}); err != nil {
			return err
		}
	}
	if err := b.removalDone(id); err != nil {
		return err
	}
	b.a.hub.Reset(id)
	if m.GetDeleteData() {
		if err := os.RemoveAll(dir); err != nil {
			return fmt.Errorf("delete %s: %w", dir, err)
		}
		return nil
	}
	// Without spec (retry after a cut between setting aside and forgetting): if <slug> is still there,
	// it belongs to this server (the panel does not let another with this slug be created on the node
	// while the retirement is pending).
	return setAside()
}

// forgetHeld reserves the server, waits for the file writes in progress, runs before (if any) with the
// reservation taken, forgets the spec (leaves a tombstone) and releases the reservation, which stops
// and deletes its container. If something fails before forgetting, it just releases: the server stays
// as it was.
func (b *backupService) forgetHeld(id string, before func() error) error {
	ctx := b.a.life
	release, err := b.a.rec.Hold(id, holdMigration)
	if err != nil {
		return err
	}
	if err := b.waitFileWrites(id); err != nil {
		release(ctx)
		return err
	}
	if before != nil {
		if err := before(); err != nil {
			release(ctx)
			return err
		}
	}
	if err := b.a.rec.Forget(id); err != nil {
		release(ctx)
		return err
	}
	release(ctx) // with tombstone: completes the container deletion (or leaves it to the tombstone retry)
	return nil
}

// waitFileWrites waits, at most drainWait, for the file writes that were already in progress on the
// server when it was reserved to finish (new ones already answer busy). See fileWrites.
func (b *backupService) waitFileWrites(id string) error {
	select {
	case <-b.a.fileWrites.drained(id):
		return nil
	case <-b.clock.Until(b.clock.Now().Add(b.drainWait)):
		return fmt.Errorf("%w: there are file operations in progress on the server; it will be retried", reconcile.Busy(holdMigration))
	case <-b.a.life.Done():
		return errClosing
	}
}

// removalDone fails with busy if the container's deletion is pending (tombstone): the tombstone pass
// retries it and the panel repeats the order.
func (b *backupService) removalDone(id string) error {
	tomb, err := b.a.st.HasTombstone(id)
	if err != nil {
		return err
	}
	if tomb {
		return fmt.Errorf("%w: the server's container could not be deleted yet; it will be retried", reconcile.Busy(holdMigration))
	}
	return nil
}

// stopForRetire stops the container if it is still running (the panel stopped it in step 1, but someone
// may have started it by hand) and checks that it has stopped: the data of a running server is never set aside.
func (b *backupService) stopForRetire(id string) error {
	ctx := b.a.life
	running, err := b.isRunning(ctx, id)
	if err != nil || !running {
		return err
	}
	c, err := b.a.rec.Container(ctx, id)
	if err != nil {
		return errCheckContainer(err)
	}
	if c != nil {
		if err := b.a.eng.Stop(ctx, c.ID, reconcile.StopTimeout); err != nil && !errors.Is(err, docker.ErrNotFound) {
			return fmt.Errorf("stop the server on the source: %w", err)
		}
	}
	if running, err := b.isRunning(ctx, id); err != nil {
		return err
	} else if running {
		return errors.New("the server is still running on the source: it is not retired")
	}
	return nil
}
```

```ts
import { z } from "zod";

/** Body of POST /api/servers/:id/migration. */
export const migrationRequestSchema = z.object({
  targetNodeId: z.string().min(1, "Choose the target node"),
  /** Game port on the target. Without it, the panel proposes one: the current one if it is free there. */
  port: z.number().int().min(1).max(65535).optional(),
  /** When finished, delete <DATA_ROOT>/<slug> on the source. Otherwise it is kept as <DATA_ROOT>/<slug>.migrated-<ts>. */
  deleteSource: z.boolean().default(false),
});
export type MigrationRequest = z.infer<typeof migrationRequestSchema>;
export type MigrationRequestInput = z.input<typeof migrationRequestSchema>;

/** Query of GET /api/servers/:id/migration/proposal. */
export const migrationProposalQuerySchema = z.object({
  targetNodeId: z.string().min(1, "Choose the target node"),
  port: z.coerce.number().int().min(1).max(65535).optional(),
});

/**
 * running: steps in progress. rolling_back: it failed and something is left to undo (the target or
 * starting the source). committed: the server is already on the target and the source still has to be
 * retired. done and failed: closed.
 */
export type MigrationPhase = "running" | "rolling_back" | "committed" | "done" | "failed";
/** Phases with pending work: the server has an open migration. */
export const OPEN_PHASES: ReadonlySet<MigrationPhase> = new Set<MigrationPhase>(["running", "rolling_back", "committed"]);

export interface MigrationDto {
  id: string; serverId: string; sourceNodeId: string; targetNodeId: string; sourceSlug: string; targetSlug: string;
  targetPort: number; targetVersion: number; wasRunning: boolean; deleteSource: boolean; phase: MigrationPhase;
  sourcePending: boolean; targetPending: boolean; error: string | null; createdAt: string; updatedAt: string;
}

export interface MigrationProposalDto { targetNodeId: string; slug: string; port: number; currentPort: number; portChanged: boolean }

/** The 7 visible steps of the migration job (spec §7), in order. */
export const MIGRATION_STEPS = [
  "Stop the server on the source",
  "Pre-migration backup",
  "Upload the backup to the panel",
  "Send the backup to the target and restore it",
  "Create the server on the target",
  "Start and check on the target",
  "Confirm and remove the source",
] as const;
export type MigrationStep = 1 | 2 | 3 | 4 | 5 | 6 | 7;

/** Progress span [from, to) of each step: the job advances within its step's span. */
export const MIGRATION_PROGRESS: readonly (readonly [number, number])[] = [[0, 5], [5, 30], [30, 50], [50, 80], [80, 83], [83, 95], [95, 100]];

/** Job progress with step `step` done at `fraction` (0-1). Integer and always below the next step. */
export function stepProgress(step: MigrationStep, fraction = 0): number {
  const [from, to] = MIGRATION_PROGRESS[step - 1]!;
  const f = Number.isFinite(fraction) ? Math.max(0, Math.min(1, fraction)) : 0;
  return Math.min(to - 1, Math.floor(from + (to - from) * f));
}

/** Step a migration job is in, according to its progress. */
export function stepOfProgress(progress: number): MigrationStep {
  let step = 1;
  for (let i = 0; i < MIGRATION_PROGRESS.length; i++) if (progress >= MIGRATION_PROGRESS[i]![0]) step = i + 1;
  return step as MigrationStep;
}

/** Job message: “Step 3/7 · Upload the backup to the panel: detail”. */
export function stepMessage(step: MigrationStep, detail = ""): string {
  return `Step ${step}/7 · ${MIGRATION_STEPS[step - 1]}${detail ? `: ${detail}` : ""}`;
}
```

```ts
import type { MigrationDto, MigrationPhase } from "@mcsm/shared";
import type { Db } from "../db/db.js";
import { nowIso } from "../lib/time.js";
import type { ObservedDto } from "../servers/repo.js";

export interface MigrationRow {
  id: string; server_id: string; source_node_id: string; target_node_id: string; source_slug: string; target_slug: string;
  source_version: number; target_version: number; target_port: number; target_spec: string;
  was_running: number; delete_source: number; phase: MigrationPhase;
  /** The target may already hold something of this migration (MigrateReceive was sent): undoing requires MigrateAbort. */
  target_touched: number;
  /** The target received the order to start: the source does not start again until the target is clean. */
  target_started: number;
  /** rolling_back: starting the source is pending. committed: retiring it is pending. */
  source_pending: number;
  /** rolling_back: MigrateAbort on the target is pending. */
  target_pending: number;
  error: string | null; created_at: string; updated_at: string;
}

export type NewMigration = Pick<MigrationRow,
  "id" | "server_id" | "source_node_id" | "target_node_id" | "source_slug" | "target_slug" | "source_version" | "target_version" |
  "target_port" | "target_spec" | "was_running" | "delete_source">;
export type MigrationPatch = Partial<Pick<MigrationRow, "phase" | "target_touched" | "target_started" | "source_pending" | "target_pending" | "error">>;

const OPEN = "('running', 'rolling_back', 'committed')";
const BLOCKING = "('running', 'rolling_back')";
const PATCHABLE = ["phase", "target_touched", "target_started", "source_pending", "target_pending", "error"] as const;

export function toMigrationDto(r: MigrationRow): MigrationDto {
  return {
    id: r.id, serverId: r.server_id, sourceNodeId: r.source_node_id, targetNodeId: r.target_node_id,
    sourceSlug: r.source_slug, targetSlug: r.target_slug, targetPort: r.target_port, targetVersion: r.target_version,
    wasRunning: r.was_running === 1, deleteSource: r.delete_source === 1, phase: r.phase,
    sourcePending: r.source_pending === 1, targetPending: r.target_pending === 1, error: r.error,
    createdAt: r.created_at, updatedAt: r.updated_at,
  };
}

export class MigrationsRepo {
  constructor(private db: Db) {}

  private one(sql: string, ...args: string[]): MigrationRow | null {
    return (this.db.prepare(sql).get(...args) as MigrationRow | undefined) ?? null;
  }

  insert(m: NewMigration): MigrationRow {
    const now = nowIso();
    this.db.prepare(`INSERT INTO migrations (id, server_id, source_node_id, target_node_id, source_slug, target_slug, source_version,
        target_version, target_port, target_spec, was_running, delete_source, phase, created_at, updated_at)
      VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 'running', ?, ?)`)
      .run(m.id, m.server_id, m.source_node_id, m.target_node_id, m.source_slug, m.target_slug, m.source_version,
        m.target_version, m.target_port, m.target_spec, m.was_running, m.delete_source, now, now);
    return this.get(m.id)!;
  }

  get(id: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE id = ?", id);
  }

  latestForServer(serverId: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE server_id = ? ORDER BY created_at DESC, id DESC LIMIT 1", serverId);
  }

  openForServer(serverId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${OPEN} ORDER BY created_at DESC LIMIT 1`, serverId);
  }

  listOpen(): MigrationRow[] {
    return this.db.prepare(`SELECT * FROM migrations WHERE phase IN ${OPEN} ORDER BY created_at, id`).all() as unknown as MigrationRow[];
  }

  update(id: string, patch: MigrationPatch): MigrationRow {
    const keys = PATCHABLE.filter((k) => patch[k] !== undefined);
    if (keys.length > 0) {
      this.db.prepare(`UPDATE migrations SET ${keys.map((k) => `${k} = ?`).join(", ")}, updated_at = ? WHERE id = ?`)
        .run(...keys.map((k) => patch[k] as string | number | null), nowIso(), id);
    }
    return this.get(id)!;
  }

  /** Blocks the user's actions on the server: steps in progress or undoing. */
  blockingServer(serverId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${BLOCKING} ORDER BY created_at DESC LIMIT 1`, serverId);
  }

  /** Blocks creating servers on the node: unconfirmed target, or source with the retirement pending (its slug). */
  blockingNodeCreate(nodeId: string): MigrationRow | null {
    return this.one(`SELECT * FROM migrations WHERE (target_node_id = ? AND phase IN ${BLOCKING}) OR (source_node_id = ? AND phase = 'committed')
      ORDER BY created_at LIMIT 1`, nodeId, nodeId);
  }

  /** Blocks deleting the node while a migration that uses it is in progress (undoing: it can be deleted). */
  blockingNodeDelete(nodeId: string): MigrationRow | null {
    return this.one("SELECT * FROM migrations WHERE phase = 'running' AND (source_node_id = ? OR target_node_id = ?) ORDER BY created_at LIMIT 1", nodeId, nodeId);
  }

  /** SyncSpecs does not retire from `nodeId` a server with an open migration that goes through that node. */
  protects(nodeId: string, serverId: string): boolean {
    return this.one(`SELECT * FROM migrations WHERE server_id = ? AND phase IN ${OPEN} AND (source_node_id = ? OR target_node_id = ?) LIMIT 1`,
      serverId, nodeId, nodeId) !== null;
  }

  /** When the panel starts: what was in progress goes to undoing, with what is pending according to what it got to do. */
  interruptRunning(message: string): MigrationRow[] {
    const rows = this.db.prepare("SELECT id FROM migrations WHERE phase = 'running' ORDER BY created_at").all() as unknown as { id: string }[];
    const now = nowIso();
    const stmt = this.db.prepare(`UPDATE migrations SET phase = 'rolling_back', target_pending = target_touched, source_pending = was_running,
      error = COALESCE(error, ?), updated_at = ? WHERE id = ? AND phase = 'running'`);
    for (const r of rows) stmt.run(message, now, r.id);
    return rows.map((r) => this.get(r.id)!);
  }

  /**
   * Confirms the migration in ONE transaction: the server's row moves to the target (node, slug, spec, version,
   * desired state and last observed) only if it is still on the source with the version from the start, and the
   * migration becomes `committed` with the retirement of the source pending. Returns false (without changing
   * anything) if the version changed or the slug is already taken on the target.
   */
  commit(m: MigrationRow, desired: "running" | "stopped", observed: ObservedDto | null): boolean {
    const now = nowIso();
    // Plan 6 (in parallel) adds servers.imported_from: a migrated server no longer follows its original container.
    const cols = this.db.prepare("PRAGMA table_info(servers)").all() as unknown as { name: string }[];
    const clearImport = cols.some((c) => c.name === "imported_from") ? ", imported_from = NULL" : "";
    this.db.exec("BEGIN IMMEDIATE");
    try {
      const moved = this.db.prepare(`UPDATE servers SET node_id = ?, slug = ?, spec = ?, spec_version = ?, desired_state = ?,
          observed = ?, observed_spec_version = ?, observed_at = ?, updated_at = ?${clearImport}
        WHERE id = ? AND node_id = ? AND spec_version = ?`)
        .run(m.target_node_id, m.target_slug, m.target_spec, m.target_version, desired,
          observed ? JSON.stringify(observed) : null, m.target_version, observed ? now : null, now,
          m.server_id, m.source_node_id, m.source_version);
      const done = this.db.prepare("UPDATE migrations SET phase = 'committed', source_pending = 1, error = NULL, updated_at = ? WHERE id = ? AND phase = 'running'")
        .run(now, m.id);
      if (Number(moved.changes) !== 1 || Number(done.changes) !== 1) {
        this.db.exec("ROLLBACK");
        return false;
      }
      this.db.exec("COMMIT");
      return true;
    } catch (e) {
      this.db.exec("ROLLBACK");
      if (e instanceof Error && /UNIQUE constraint failed/.test(e.message)) return false;
      throw e;
    }
  }
}
```

```ts
import fp from "fastify-plugin";
import type { FastifyInstance } from "fastify";
import { HttpError } from "../lib/http.js";

export type GuardSubject =
  | { kind: "server"; serverId: string }
  | { kind: "create"; nodeId: string }
  | { kind: "deleteNode"; nodeId: string }
  | null;

const READ = new Set(["GET", "HEAD", "OPTIONS"]);
const MIGRATION_ROUTE = "/api/servers/:id/migration";

/**
 * What the guard protects in a request. It decides by the routed path (`req.routeOptions.url`), like the
 * session guard, never by the raw URL. Pure.
 * - Any non-GET method under /api/servers/:id (except the migration routes): the server.
 * - Creating servers (POST /api/servers, /api/templates/:id/servers with `nodeId` in the body, and any
 *   POST /api/nodes/:id/…, such as the Plan 6 import): the node.
 * - DELETE /api/nodes/:id: the node.
 */
export function guardSubject(method: string, route: string | undefined, params: unknown, body: unknown): GuardSubject {
  if (!route || READ.has(method)) return null;
  const rawId = (params as { id?: unknown } | null | undefined)?.id;
  const id = typeof rawId === "string" && rawId !== "" ? rawId : null;
  if (route === MIGRATION_ROUTE || route.startsWith(`${MIGRATION_ROUTE}/`)) return null;
  if (route === "/api/servers/:id" || route.startsWith("/api/servers/:id/")) return id ? { kind: "server", serverId: id } : null;
  if (route === "/api/servers" || route === "/api/templates/:id/servers") {
    const nodeId = (body as { nodeId?: unknown } | null | undefined)?.nodeId;
    return typeof nodeId === "string" && nodeId !== "" ? { kind: "create", nodeId } : null;
  }
  if (route === "/api/nodes/:id") return method === "DELETE" && id ? { kind: "deleteNode", nodeId: id } : null;
  if (route.startsWith("/api/nodes/:id/") && method === "POST") return id ? { kind: "create", nodeId: id } : null;
  return null;
}

function blockError(app: FastifyInstance, s: NonNullable<GuardSubject>): HttpError | null {
  if (s.kind === "server") {
    const m = app.migrations.blockingServer(s.serverId);
    if (!m) return null;
    const name = app.servers.get(s.serverId)?.name ?? "The server";
    return new HttpError(409, m.phase === "running"
      ? `“${name}” is being migrated to another node: wait until it finishes (Migrate tab)`
      : `“${name}” is undoing a failed migration: wait until it finishes (Migrate tab)`);
  }
  const m = s.kind === "create" ? app.migrations.blockingNodeCreate(s.nodeId) : app.migrations.blockingNodeDelete(s.nodeId);
  if (!m) return null;
  return new HttpError(409, `The node “${app.nodes.get(s.nodeId)?.name ?? s.nodeId}” takes part in a migration in progress: wait until it finishes (Jobs)`);
}

  app.addHook("preHandler", async (req) => {
    const s = guardSubject(req.method, req.routeOptions.url, req.params, req.body);
    if (!s) return;
    const err = blockError(app, s);
    if (err) throw err;
  });
```

```ts
  private constructor(readonly url: string, readonly id: string, readonly token: string, readonly name: string) {}

    const r = (await app.inject({ method: "POST", url: "/agent/enroll", payload: { enrollToken: t, nameHint: name, agentVersion: "fake" } })).json();
    return new FakeNode(url, r.nodeId, r.nodeToken, name);

  /** Connects, confirms SyncSpecs and answers the BackupList of the Hello. Returns the SyncSpecs. */
  async connect(specVersions: Record<string, bigint> = {}): Promise<Envelope> {
    this.buffer = [];
    this.agent = new FakeAgent(this.url, this.token);
    await this.agent.connect({ specVersions });
    const sync = await this.agent.handshake();
    this.ack(await this.next("backupList"));
    return sync;

    const i = this.buffer.findIndex((e) => e.body.case === c);
    if (i >= 0) return this.buffer.splice(i, 1)[0]!;
    const deadline = Date.now() + timeoutMs;
    for (;;) {
      const left = deadline - Date.now();
      if (left <= 0) throw new Error(`node ${this.name}: ${c} did not arrive`);
      const e = await this.agent.next(left);
      if (e.body.case === c) return e;
      this.buffer.push(e);
    }
  }

    if (this.buffer.length > 0) throw new Error(`node ${this.name}: pending ${this.buffer.map((e) => e.body.case).join(", ")}`);
    const e = await this.agent.next(ms).catch(() => null);
    if (e) throw new Error(`node ${this.name}: arrived ${e.body.case}`);
  }

  ack(env: Envelope): void { this.agent.ack(env.id); }
```

```ts
export interface TargetServer { slug: string; spec: Spec }
export interface ProposalInput {
  slug: string; spec: Spec; targetServers: TargetServer[]; range: { from: number; to: number }; requestedPort?: number;
}
export type Proposal = { ok: true; slug: string; port: number; portChanged: boolean } | { ok: false; error: string };

/** Free slug among `taken`: the same one or with suffix -2, -3… (max. 40 characters), as when creating a server. */
export function uniqueSlugAmong(base: string, taken: ReadonlySet<string>): string {
  if (!taken.has(base)) return base;
  for (let n = 2; ; n++) {
    const suffix = `-${n}`;
    const candidate = base.slice(0, 40 - suffix.length).replace(/-+$/g, "") + suffix;
    if (!taken.has(candidate)) return candidate;
  }
}

/**
 * Slug and game port of the server on the target (spec §7: “new port if it clashes”). The requested port is
 * respected if it is free; if none is requested, the current one if it is free and, otherwise, the first free
 * one in the panel's range. Extra ports are not changed on their own: if they clash, error. Pure.
 */
export function proposeTarget(i: ProposalInput): Proposal {
  const used = new Set<number>();
  for (const s of i.targetServers) {
    used.add(s.spec.ports.game);
    for (const e of s.spec.ports.extra) used.add(e.host);
  }
  const clash = i.spec.ports.extra.find((e) => used.has(e.host));
  if (clash) {
    return { ok: false, error: `The extra port ${clash.host} (${clash.label || clash.proto}) is already used by another server on the target node: change it before migrating` };
  }
  const extras = new Set(i.spec.ports.extra.map((e) => e.host));
  let port: number | undefined;
  if (i.requestedPort !== undefined) {
    if (used.has(i.requestedPort) || extras.has(i.requestedPort)) return { ok: false, error: `Port ${i.requestedPort} is already in use on the target node` };
    port = i.requestedPort;
  } else if (!used.has(i.spec.ports.game)) {
    port = i.spec.ports.game;
  } else {
    for (let p = i.range.from; p <= i.range.to && port === undefined; p++) if (!used.has(p) && !extras.has(p)) port = p;
    if (port === undefined) return { ok: false, error: `There are no free ports between ${i.range.from} and ${i.range.to} on the target node` };
  }
  const slug = uniqueSlugAmong(i.slug, new Set(i.targetServers.map((s) => s.slug)));
  return { ok: true, slug, port, portChanged: port !== i.spec.ports.game };
}

/** Name of the copy on the target: the same one with the target's slug (the agent requires `<slug>-<ts>-<v>.tar.zst`). */
export function retargetFilename(filename: string, fromSlug: string, toSlug: string): string {
  if (!filename.startsWith(`${fromSlug}-`)) throw new Error(`The copy ${filename} does not belong to server ${fromSlug}`);
  return toSlug + filename.slice(fromSlug.length);
}
```

```ts
import type { FastifyInstance } from "fastify";
import type { Envelope } from "@mcsm/proto";
import { observedToDto } from "../agents/service.js";
import type { Timers } from "../files/stream.js";
import type { JobDto } from "../jobs/repo.js";
import { FINAL_STATES } from "../jobs/service.js";
import type { ObservedDto } from "../servers/repo.js";
import { StepError } from "./errors.js";

export interface Waiter<T> { promise: Promise<T>; cancel(): void }

/** Listens to the unsolicited messages from the agents (the same ones AgentService dispatches). */
export function onAgentMessage(agents: EventEmitter, fn: (nodeId: string, env: Envelope) => void): () => void {
  agents.on("message", fn);
  return () => { agents.off("message", fn); };
}

/**
 * Waits for the job to finish (ok, failed or cancelled). `onProgress` receives each advance; without advances
 * during `idleMs` it rejects with `idleMessage`. It also checks the current state: if it has already finished,
 * it resolves at once.
 */
export function waitJob(app: FastifyInstance, jobId: string, opts: { idleMs: number; timers: Timers; idleMessage: string; onProgress?: (j: JobDto) => void }): Waiter<JobDto> {
  let off = () => {};
  let disarm = () => {};
  const promise = new Promise<JobDto>((resolve, reject) => {
    const settle = (fn: () => void) => { off(); disarm(); fn(); };
    const arm = () => {
      disarm();
      disarm = opts.timers.set(() => settle(() => reject(new StepError(opts.idleMessage))), opts.idleMs);
    };
    const h = (j: JobDto) => {
      if (j.id !== jobId) return;
      if (FINAL_STATES.has(j.status)) settle(() => resolve(j));
      else {
        opts.onProgress?.(j);
        arm();
      }
    };
    app.events.on("job", h);
    off = () => { app.events.off("job", h); };
    arm();
    const now = app.jobs.get(jobId);
    if (now && FINAL_STATES.has(now.status)) settle(() => resolve(now));
  });
  promise.catch(() => {});
  return { promise, cancel: () => { off(); disarm(); } };
}

/**
 * Waits for the server to be healthy on the node: `running` with healthcheck `healthy` or a correct SLP ping. An
 * `exited`/`dead` rejects at once; if `timeoutMs` expires, so does it. It must be created BEFORE ordering the start.
 */
export function waitObserved(agents: EventEmitter, nodeId: string, serverId: string, opts: { timeoutMs: number; timers: Timers; onObserved?: (o: ObservedDto) => void }): Waiter<ObservedDto> {
  let off = () => {};
  let disarm = () => {};
  const promise = new Promise<ObservedDto>((resolve, reject) => {
    const settle = (fn: () => void) => { off(); disarm(); fn(); };
    off = onAgentMessage(agents, (from, env) => {
      if (from !== nodeId || env.body.case !== "serverObserved" || env.body.value.serverId !== serverId) return;
      const o = observedToDto(env.body.value.observed);
      opts.onObserved?.(o);
      if (o.state === "running" && (o.health === "healthy" || o.mc.online)) settle(() => resolve(o));
      else if (o.state === "exited" || o.state === "dead") {
        settle(() => reject(new StepError(`The server stopped on the target (exit code ${o.exitCode})${o.error ? `: ${o.error}` : ""}`)));
      }
    });
    const minutes = Math.round(opts.timeoutMs / 60_000);
    disarm = opts.timers.set(() => settle(() => reject(new StepError(`The server did not become healthy on the target within ${minutes} min (healthcheck or ping)`))), opts.timeoutMs);
  });
  promise.catch(() => {});
  return { promise, cancel: () => { off(); disarm(); } };
}
```

```ts
import { stepMessage, stepProgress, type MigrationStep } from "@mcsm/shared";
import type { JobService } from "../jobs/service.js";

/** How the steps report their progress. In production, the migration job (JobReporter). */
export interface Reporter {
  /** Starts step n: progress at the start of its span, message and a line in the log. */
  step(n: MigrationStep, detail: string): void;
  /** Progress within the step (fraction 0-1). It only writes if the percentage or the text changes. */
  within(n: MigrationStep, fraction: number, detail: string): void;
  /** Changes the message without touching the progress (e.g. “undoing”). */
  message(n: MigrationStep, detail: string): void;
  log(line: string): void;
}

/** Reporter on the `migrate` job: each change emits the `job` event (the web sees it live, topic `jobs`). */
export class JobReporter implements Reporter {
  private last = { progress: -1, message: "" };

  constructor(private jobs: JobService, private jobId: string) {}

  step(n: MigrationStep, detail: string): void {
    const progress = stepProgress(n);
    const message = stepMessage(n, detail);
    this.last = { progress, message };
    this.jobs.update(this.jobId, { progress, message, logChunk: `${message}\n` });
  }

  within(n: MigrationStep, fraction: number, detail: string): void {
    const progress = stepProgress(n, fraction);
    const message = stepMessage(n, detail);
    if (progress === this.last.progress && message === this.last.message) return;
    this.last = { progress, message };
    this.jobs.update(this.jobId, { progress, message });
  }

  message(n: MigrationStep, detail: string): void {
    const message = stepMessage(n, detail);
    this.last = { ...this.last, message };
    this.jobs.update(this.jobId, { message });
  }

  log(line: string): void {
    this.jobs.update(this.jobId, { logChunk: `${line}\n` });
  }
}
```

```ts
import { createHash } from "node:crypto";

import { pipeline, Transform } from "node:stream";
import type { FastifyInstance } from "fastify";
import { BackupTrigger, PowerActionType } from "@mcsm/proto";
import { AgentError, type AgentConn } from "../agents/hub.js";
import { AgentErrorCode } from "../agents/error-codes.js";
import { IDLE_TIMEOUT_MS, idleGuard, type Timers } from "../files/stream.js";
import { newId } from "../lib/ids.js";
import { toServerSpecMessage, type ObservedDto, type ServerRow } from "../servers/repo.js";
import type { StagedFile } from "../transfers/staging.js";
import { errorText, StepError } from "./errors.js";
import { requiredSpace, retargetFilename } from "./propose.js";
import type { MigrationRow } from "./repo.js";
import type { Reporter } from "./report.js";
import { onAgentMessage, waitJob, waitObserved } from "./wait.js";

export interface MigrationTimings {
  /** How long to wait for the server to become healthy on the target (spec §7: 5 min). */
  verifyTimeoutMs: number;
  /** Without progress from an agent sub-job (copy, reception) for this long, it is considered dead. */
  jobIdleMs: number;
  /** Reception attempts on the target (the copy stays in the staging between attempts). */
  receiveAttempts: number;
  /** Free space in bytes of dir's filesystem. */
  freeSpace: (dir: string) => Promise<number>;
}

export const DEFAULT_TIMINGS: MigrationTimings = {
  verifyTimeoutMs: 5 * 60_000,
  jobIdleMs: 30 * 60_000,
  receiveAttempts: 2,
  freeSpace: async (dir) => {
    const s = await statfs(dir);
    return Number(s.bavail) * Number(s.bsize);
  },
};

export interface StepDeps { app: FastifyInstance; timers: Timers; timings: MigrationTimings; report: Reporter }
export interface BackupMade { filename: string; sizeBytes: number; sha256: string }
export interface Pushed { staged: StagedFile; dataBytes: number }

/** No total deadline (setTimeout maximum): a transfer that is making progress lasts as long as it needs to (as in Files). */
const NO_DEADLINE_MS = 2 ** 31 - 1;
/** Retiring or undoing can delete a whole world on a slow disk. */
const LONG_MS = 5 * 60_000;

export const stagingId = (migrationId: string): string => `mig-${migrationId}`;

const isDoubtful = (e: unknown): boolean =>
  e instanceof AgentError && (e.code === AgentErrorCode.Disconnected || e.code === AgentErrorCode.Timeout);

function fmtBytes(n: number): string {
  return n >= 1024 ** 3 ? `${(n / 1024 ** 3).toFixed(1)} GiB` : `${Math.ceil(n / 1024 ** 2)} MiB`;
}

function connOf(app: FastifyInstance, nodeId: string): AgentConn {
  const conn = app.agents.get(nodeId);
  if (!conn) throw new StepError(`The node “${app.nodes.get(nodeId)?.name ?? nodeId}” is offline`);
  return conn;
}

/**
 * The row as it will be on the target, for `toServerSpecMessage`: another node, slug, spec and version, and without
 * `imported_from` (Plan 6): a migrated server no longer follows any original container (without `adopt`).
 */
export function targetRow(row: ServerRow, m: MigrationRow, desired: "running" | "stopped"): ServerRow {
  const out = { ...row, node_id: m.target_node_id, slug: m.target_slug, spec: m.target_spec, spec_version: m.target_version, desired_state: desired } as ServerRow & { imported_from?: unknown };
  if ("imported_from" in out) out.imported_from = null;
  return out;
}

/** Step 1. Stops the server on the source and leaves `stopped` as the desired state in the agent and in the row. */
export async function stopSource(d: StepDeps, m: MigrationRow): Promise<void> {
  try {
    await d.app.serversService.power(m.server_id, "stop");
  } catch (e) {
    throw new StepError(`Could not stop the server on the source: ${errorText(e)}`);
  }
  d.report.log(m.was_running ? "Server stopped on the source" : "The server was already stopped on the source");
}

/**
 * Step 2. `pre_migration` copy on the source (BackupNow) as a `backup` sub-job; its progress is reflected in the job.
 * The file, its size and its sha256 come from the BackupCreated with the same job_id, which the agent queues before
 * the end of the job (same FIFO queue): when the job finishes well, the notice has already arrived.
 */
export async function backupSource(d: StepDeps, m: MigrationRow): Promise<BackupMade> {
  const { app } = d;
  const conn = connOf(app, m.source_node_id);
  const jobId = newId();
  app.jobs.create({
    id: jobId, type: "backup", serverId: m.server_id, nodeId: m.source_node_id, status: "running",
    message: "Requesting the pre-migration copy", payload: { trigger: "pre_migration", migrationId: m.id },
  });
  let made: BackupMade | null = null;
  const offCreated = onAgentMessage(app.agents, (nodeId, env) => {
    if (nodeId !== m.source_node_id || env.body.case !== "backupCreated" || env.body.value.jobId !== jobId) return;
    const b = env.body.value.backup;
    if (b && b.serverId === m.server_id) made = { filename: b.filename, sizeBytes: Number(b.sizeBytes), sha256: b.sha256 };
  });
  const wait = waitJob(app, jobId, {
    idleMs: d.timings.jobIdleMs, timers: d.timers, idleMessage: "The pre-migration copy has been without progress for too long",
    onProgress: (j) => d.report.within(2, j.progress / 100, j.message || "copying"),
  });
  try {
    try {
      await conn.request({ case: "backupNow", value: { serverId: m.server_id, jobId, trigger: BackupTrigger.PRE_MIGRATION } }, 30_000);
    } catch (e) {
      if (!isDoubtful(e)) {
        app.jobs.finish(jobId, "failed", errorText(e));
        throw new StepError(`The source node could not make the copy: ${errorText(e)}`);
      }
      d.report.log("The source node has not confirmed the copy yet; waiting for it to report");
    }
    const job = await wait.promise;
    if (job.status !== "ok") throw new StepError(`The pre-migration copy failed: ${job.message}`);
    const got = made as BackupMade | null;
    if (!got) throw new StepError("The copy was made but the panel did not receive its notice (BackupCreated): try again");
    if (!got.sha256) throw new StepError("The copy has no sha256: it is not migrated without being able to verify it");
    d.report.log(`Copy ${got.filename}: ${fmtBytes(got.sizeBytes)}, sha256 ${got.sha256}`);
    return got;
  } finally {
    offCreated();
    wait.cancel();
  }
}

/**
 * Step 3. The source uploads the copy (BackupPush → PUT /agent/transfer) to the panel's staging. First the panel's
 * space is checked and, on arrival, the exact size and the sha256 (against the BackupCreated and the
 * BackupPushResult). If anything fails, nothing is left in the staging.
 */
export async function pushToPanel(d: StepDeps, m: MigrationRow, made: BackupMade): Promise<Pushed> {
  const { app } = d;
  const free = await d.timings.freeSpace(app.config.dataDir).catch(() => null);
  if (free !== null && free < requiredSpace(made.sizeBytes)) {
    throw new StepError(`There is no space on the panel for the copy: ${fmtBytes(requiredSpace(made.sizeBytes))} needed and ${fmtBytes(free)} free`);
  }
  const conn = connOf(app, m.source_node_id);
  const t = app.transfers.inbound(m.source_node_id);
  const req = conn.request({ case: "backupPush", value: { serverId: m.server_id, filename: made.filename, transferId: t.id } }, NO_DEADLINE_MS);
  req.catch(() => {});
  let staged: StagedFile | null = null;
  try {
    const incoming = await Promise.race([
      t.incoming,
      req.then((): never => { throw new StepError("The source node finished without sending the copy"); }),
    ]);
    if (incoming.size !== null && incoming.size !== made.sizeBytes) {
      throw new StepError(`The source node sends ${incoming.size} bytes and the copy measures ${made.sizeBytes}`);
    }
    const hash = createHash("sha256");
    let received = 0;
    const meter = new Transform({
      transform(chunk: Buffer, _enc, cb) {
        hash.update(chunk);
        received += chunk.length;
        d.report.within(3, received / Math.max(made.sizeBytes, 1), `uploading (${fmtBytes(received)} of ${fmtBytes(made.sizeBytes)})`);
        cb(null, chunk);
      },
    });
    const guard = idleGuard(IDLE_TIMEOUT_MS, () => {
      t.cancel("the source node stopped sending the copy");
      return new StepError("The source node stopped sending the copy");
    }, d.timers);
    const src = pipeline(incoming.stream, guard, meter, () => { /* save sees the result */ });
    staged = await app.staging.save(stagingId(m.id), src, { maxBytes: made.sizeBytes });
    const res = await req;
    if (res.body.case !== "backupPushResult") throw new StepError("Unexpected response from the source node");
    const digest = hash.digest("hex");
    if (staged.size !== made.sizeBytes || digest !== made.sha256 || res.body.value.sha256 !== made.sha256) {
      throw new StepError(`The copy arrived at the panel corrupt: sha256 ${digest}, expected ${made.sha256}`);
    }
    d.report.log(`Copy on the panel: ${fmtBytes(staged.size)}, sha256 verified`);
    return { staged, dataBytes: Number(res.body.value.dataBytes) };
  } catch (e) {
    t.cancel("migration failed");
    if (staged) await app.staging.remove(staged).catch(() => {});
    throw e;
  }
}

/**
 * Step 4. The target receives the copy from the staging (MigrateReceive → GET /agent/transfer) and restores it, as a
 * `migrate_in` sub-job. `target_touched` is set BEFORE requesting it: from here on, undoing requires MigrateAbort. A
 * failure of the job (or an order without response) is retried once after cleaning up the previous attempt; an
 * explicit refusal from the agent (exists, too_large…) is not.
 */
export async function receiveOnTarget(d: StepDeps, m: MigrationRow, pushed: Pushed, made: BackupMade): Promise<void> {
  const { app } = d;
  app.migrations.update(m.id, { target_touched: 1 });
  const filename = retargetFilename(made.filename, m.source_slug, m.target_slug);
  let last = "";
  for (let attempt = 1; attempt <= d.timings.receiveAttempts; attempt++) {
    if (attempt > 1) {
      d.report.log(`Retrying the reception on the target (attempt ${attempt} of ${d.timings.receiveAttempts})`);
      await abortTarget(d, m).catch((e) => d.report.log(`Could not clean up the previous attempt: ${errorText(e)}`));
    }
    const conn = connOf(app, m.target_node_id);
    const jobId = newId();
    app.jobs.create({
      id: jobId, type: "migrate_in", serverId: m.server_id, nodeId: m.target_node_id, status: "running",
      message: "Requesting the copy's reception", payload: { migrationId: m.id },
    });
    const out = app.transfers.outbound(m.target_node_id, app.staging.source(pushed.staged, { removeAfter: false }));
    out.done.catch(() => {});
    const wait = waitJob(app, jobId, {
      idleMs: d.timings.jobIdleMs, timers: d.timers, idleMessage: "The reception on the target has been without progress for too long",
      onProgress: (j) => d.report.within(4, j.progress / 100, j.message || "receiving"),
    });
    try {
      try {
        await conn.request({ case: "migrateReceive", value: {
          serverId: m.server_id, slug: m.target_slug, jobId, migrationId: m.id, transferId: out.id, filename,
          sizeBytes: BigInt(made.sizeBytes), sha256: made.sha256, dataBytes: BigInt(pushed.dataBytes),
        } }, 30_000);
      } catch (e) {
        app.jobs.finish(jobId, "failed", errorText(e));
        if (!isDoubtful(e)) throw new StepError(`The target node rejected the copy: ${errorText(e)}`);
        last = errorText(e);
        continue;
      }
      const job = await wait.promise;
      if (job.status === "ok") {
        d.report.log("Copy received, verified (sha256) and restored on the target");
        return;
      }
      last = job.message;
    } finally {
      out.cancel("reception finished"); // no effect if it has already finished
      wait.cancel();
    }
  }
  throw new StepError(`The reception on the target failed: ${last}`);
}

/** Step 5. The target saves the spec (target slug and port, version +1) with the server stopped. */
export async function applyOnTarget(d: StepDeps, m: MigrationRow): Promise<void> {

  if (!row) throw new StepError("The server no longer exists in the panel");
  const conn = connOf(d.app, m.target_node_id);
  try {
    await conn.request({ case: "applySpec", value: { server: toServerSpecMessage(targetRow(row, m, "stopped"), d.app.curseforge.get()) } }, 120_000);
  } catch (e) {
    throw new StepError(`The target node could not create the server: ${errorText(e)}`);
  }
  d.report.log(`Server created on the target (slug ${m.target_slug}, port ${m.target_port}, version ${m.target_version})`);
}

/**
 * Step 6. Starts on the target and waits for it to become healthy (at most `verifyTimeoutMs`). `target_started` is set
 * BEFORE the order: if anything fails from here on, the source is not started again until the copy on the target has been retired.
 */
export async function startAndVerify(d: StepDeps, m: MigrationRow): Promise<ObservedDto> {
  d.app.migrations.update(m.id, { target_started: 1 });
  const conn = connOf(d.app, m.target_node_id);
  const w = waitObserved(d.app.agents, m.target_node_id, m.server_id, {
    timeoutMs: d.timings.verifyTimeoutMs, timers: d.timers,
    onObserved: (o) => d.report.within(6, 0.5, `state ${o.state}${o.health ? `, healthcheck ${o.health}` : ""}`),
  });
  try {
    await conn.request({ case: "powerAction", value: { serverId: m.server_id, action: PowerActionType.START } }, 90_000);
  } catch (e) {
    w.cancel();
    throw new StepError(`The server did not start on the target: ${errorText(e)}`);
  }
  d.report.within(6, 0.2, `waiting for it to start and respond (max. ${Math.round(d.timings.verifyTimeoutMs / 60_000)} min)`);
  const o = await w.promise;
  d.report.log(`The server responds on the target (${o.health === "healthy" ? "healthcheck healthy" : "correct ping"})`);
  return o;
}

  } catch (e) {
    throw new StepError(`Could not stop the server on the target again: ${errorText(e)}`);
  }
}
```

```ts
export const PENDING_EVERY_MS = 30_000;
export const INTERRUPTED = "interrupted: the panel restarted during the migration";

interface Plan {
  target: { id: string; name: string }; slug: string; port: number; portChanged: boolean; currentPort: number; spec: Spec;
}

const silent = (log: (line: string) => void): Reporter => ({ step: () => {}, within: () => {}, message: () => {}, log });

/**
 * Migration between nodes (spec §7 MigrationService): 7-step `migrate` job, orchestrated here, over the `migrations`
 * table (durable state: what is left to undo or retire if the panel restarts or a node goes down).
 */
export class MigrationService {
  /** Timers of the waits (the tests use ManualTimers). */
  timers: Timers = realTimers;
  timings: MigrationTimings = { ...DEFAULT_TIMINGS };
  /** Migrations with work in progress in this process (steps or pending items): never two tasks at once on the same one. */
  private busy = new Set<string>();
  private tick: NodeJS.Timeout | undefined;

  constructor(private app: FastifyInstance) {}

  start(): void {
    // After a node's Hello, its pending items (the requests wait on their own for the SyncSpecs Ack).
    this.app.agents.on("message", (nodeId: string, env: Envelope) => {
      if (env.body.case === "hello") void this.runPending(nodeId);
    });
  }

  /** When the panel starts: what was in progress goes to undoing; the pending items are retried every 30 s. */
  async recover(): Promise<void> {
    const rows = this.app.migrations.interruptRunning(INTERRUPTED);
    if (rows.length > 0) this.app.log.warn({ count: rows.length }, "migrations interrupted by the panel restart: they are undone");
    if (!this.tick) {
      this.tick = setInterval(() => void this.runPending(), PENDING_EVERY_MS);
      this.tick.unref();
    }
    await this.runPending();
  }

  close(): void {
    clearInterval(this.tick);
    this.tick = undefined;
  }

    this.requireServer(serverId);
    const m = this.app.migrations.latestForServer(serverId);
    return { migration: m ? toMigrationDto(m) : null };
  }

  proposal(serverId: string, query: unknown): MigrationProposalDto {
    const q = migrationProposalQuerySchema.parse(query);
    const p = this.plan(this.requireServer(serverId), q.targetNodeId, q.port);
    return { targetNodeId: p.target.id, slug: p.slug, port: p.port, currentPort: p.currentPort, portChanged: p.portChanged };
  }

  /** Validates and starts the migration. Returns the job (202); progress goes through the `jobs` topic. */
  begin(serverId: string, body: unknown): JobDto {
    const input = migrationRequestSchema.parse(body);
    const row = this.requireServer(serverId);
    const p = this.plan(row, input.targetNodeId, input.port);
    const sourceName = this.nodeName(row.node_id);
    if (!this.app.agents.get(row.node_id)) throw new HttpError(409, `The source node “${sourceName}” is offline`);
    if (!this.app.agents.get(p.target.id)) throw new HttpError(409, `The target node “${p.target.name}” is offline`);
    // No await between the checks and the insert: two simultaneous requests do not start two migrations.
    const wasRunning = row.desired_state === "running";
    const job = this.app.jobs.create({
      type: "migrate", serverId, nodeId: row.node_id, status: "running", message: stepMessage(1, "preparing"),
      payload: { targetNodeId: p.target.id, targetNodeName: p.target.name, sourceNodeName: sourceName, slug: p.slug, port: p.port, deleteSource: input.deleteSource, wasRunning },
    });
    this.app.migrations.insert({
      id: job.id, server_id: serverId, source_node_id: row.node_id, target_node_id: p.target.id, source_slug: row.slug, target_slug: p.slug,
      source_version: row.spec_version, target_version: row.spec_version + 1, target_port: p.port, target_spec: JSON.stringify(p.spec),
      was_running: wasRunning ? 1 : 0, delete_source: input.deleteSource ? 1 : 0,
    });
    void this.run(job.id);
    return job;
  }

  /** Retries the pending items (of one node, or of all): undoing or retiring the source. */
  async runPending(nodeId?: string): Promise<void> {
    for (const m of this.app.migrations.listOpen()) {
      if (m.phase === "running" || this.busy.has(m.id)) continue;
      if (nodeId && m.source_node_id !== nodeId && m.target_node_id !== nodeId) continue;
      this.busy.add(m.id);
      try {
        await this.settle(m.id, (line) => this.app.log.info({ migrationId: m.id, serverId: m.server_id }, line));
      } catch (e) {
        this.app.log.warn({ err: e, migrationId: m.id }, "failure retrying a migration's pending items");
      } finally {
        this.busy.delete(m.id);
      }
    }
  }

  // Internals

  private requireServer(id: string): ServerRow {
    const row = this.app.servers.get(id);
    if (!row) throw new HttpError(404, "Server not found");
    return row;
  }

  private nodeName(id: string): string {
    return this.app.nodes.get(id)?.name ?? "another node";
  }

  private deps(report: Reporter): StepDeps {
    return { app: this.app, timers: this.timers, timings: this.timings, report };
  }

  /** Checks that it can be migrated and computes the slug, port and spec on the target. Throws HttpError. */
  private plan(row: ServerRow, targetNodeId: string, port?: number): Plan {
    if (targetNodeId === row.node_id) throw new HttpError(400, "The server is already on that node");
    const target = this.app.nodes.get(targetNodeId);
    if (!target) throw new HttpError(404, "Target node not found");
    const open = this.app.migrations.openForServer(row.id);
    if (open) throw new HttpError(409, this.openMessage(open));
    const spec = JSON.parse(row.spec) as Spec;
    // dataPath (Plan 6): the data is outside DATA_ROOT and the agent cannot copy or restore it.
    if ((spec as unknown as Record<string, unknown>).dataPath) {
      throw new HttpError(409, `The data of “${row.name}” is outside DATA_ROOT (dataPath, imported server) and the agent cannot copy it: move it to <DATA_ROOT>/${row.slug}/data on the node and remove dataPath before migrating it`);
    }
    const targetServers: TargetServer[] = this.app.servers.list(targetNodeId).map((r) => ({ slug: r.slug, spec: JSON.parse(r.spec) as Spec }));
    // What other unconfirmed migrations already reserve toward that node.
    for (const m of this.app.migrations.listOpen()) {
      if (m.target_node_id === targetNodeId && m.phase !== "committed" && m.server_id !== row.id) {
        targetServers.push({ slug: m.target_slug, spec: JSON.parse(m.target_spec) as Spec });
      }
    }
    const p = proposeTarget({ slug: row.slug, spec, targetServers, range: this.app.config.gamePortRange, requestedPort: port });
    if (!p.ok) throw new HttpError(409, p.error);
    const parsed = specSchema.safeParse({ ...spec, ports: { ...spec.ports, game: p.port } });
    if (!parsed.success) throw new HttpError(400, formatZodError(parsed.error));
    return { target: { id: target.id, name: target.name }, slug: p.slug, port: p.port, portChanged: p.portChanged, currentPort: spec.ports.game, spec: parsed.data };
  }

  private openMessage(m: MigrationRow): string {
    if (m.phase === "running") return "This server already has a migration in progress";
    if (m.phase === "rolling_back") {
      const parts = [m.target_pending ? `clean up “${this.nodeName(m.target_node_id)}”` : "", m.source_pending ? `start on “${this.nodeName(m.source_node_id)}”` : ""].filter(Boolean);
      return `A previous migration is being undone (pending: ${parts.join(" and ")}); wait for the nodes to come back`;
    }
    return `The previous migration still has to retire the server from node “${this.nodeName(m.source_node_id)}”; wait for it to reconnect`;
  }

  private async run(id: string): Promise<void> {
    this.busy.add(id);
    const report = new JobReporter(this.app.jobs, id);
    const d = this.deps(report);
    let step: MigrationStep = 1;
    let staged: StagedFile | null = null;
    try {
      try {
        const m = this.app.migrations.get(id)!;
        report.step(1, m.was_running ? "stopping the server" : "checking that it is stopped");
        await stopSource(d, m);
        step = 2;
        report.step(2, "requesting the copy from the source node");
        const made = await backupSource(d, m);
        step = 3;
        report.step(3, made.filename);
        const pushed = await pushToPanel(d, m, made);
        staged = pushed.staged;
        step = 4;
        report.step(4, `sending the copy to “${this.nodeName(m.target_node_id)}”`);
        await receiveOnTarget(d, m, pushed, made);
        await this.app.staging.remove(pushed.staged);
        staged = null;
        step = 5;
        report.step(5, `slug ${m.target_slug}, port ${m.target_port}, version ${m.target_version}`);
        await applyOnTarget(d, m);
        step = 6;
        report.step(6, "starting");
        let observed: ObservedDto | null = await startAndVerify(d, m);
        if (!m.was_running) {
          report.within(6, 0.9, "it was stopped: it is stopped again");
          await stopTarget(d, m);
          observed = null; // the target's next ServerObserved fills it in
        }
        step = 7;
        report.step(7, "confirming the node change");
        this.commit(id, observed);
      } catch (e) {
        if (staged) await this.app.staging.remove(staged).catch(() => {});
        await this.rollback(id, step, e, report);
        return;
      }
      await this.finishCommitted(id, report);
    } catch (e) {
      // Neither rollback nor finishCommitted should throw; if they do, do not leave an unhandled rejection.
      this.app.log.error({ err: e, migrationId: id }, "unexpected failure handling a migration");
    } finally {
      this.busy.delete(id);
    }
  }

  /** Commit: the row moves to the target in one transaction (if the version did not change). Afterwards, the target's inventory. */
  private commit(id: string, observed: ObservedDto | null): void {
    const m = this.app.migrations.get(id)!;
    if (!this.app.migrations.commit(m, m.was_running ? "running" : "stopped", observed)) {
      throw new StepError("Could not confirm: the server's configuration changed during the migration, or its slug or port stopped being free on the target");
    }
    if (observed) this.app.events.emit("observed", m.server_id, observed);
    // The target registers the pre_migration copy it received; the source's ones are considered deleted (they are no longer manageable).
    void this.app.backupsService.sync(m.target_node_id);
  }

  private async finishCommitted(id: string, report: Reporter): Promise<void> {
    report.within(7, 0.5, "retiring the server from the source node");
    const m = await this.settle(id, (line) => report.log(line));
    const name = this.app.servers.get(m.server_id)?.name ?? "The server";
    const where = `“${name}” is on “${this.nodeName(m.target_node_id)}”, port ${m.target_port}`;
    const kept = m.delete_source ? "its data will be deleted" : `its data will stay in ${m.source_slug}.migrated-…`;
    this.app.jobs.finish(id, "ok", m.phase === "done"
      ? `Migration completed: ${where}`
      : `Migration completed: ${where}. The node “${this.nodeName(m.source_node_id)}” did not answer: the server will be retired from there (${kept}) when it reconnects`);
  }

  private async rollback(id: string, step: MigrationStep, err: unknown, report: Reporter): Promise<void> {
    const msg = errorText(err);
    if (!isKnownError(err)) this.app.log.error({ err, migrationId: id }, "unexpected failure in a migration");
    report.log(`ERROR in step ${step}: ${msg}`);
    report.message(step, "undoing the migration");
    const cur = this.app.migrations.get(id)!;
    this.app.migrations.update(id, { phase: "rolling_back", error: `Step ${step}: ${msg}`, target_pending: cur.target_touched, source_pending: cur.was_running });
    const m = await this.settle(id, (line) => report.log(line));
    this.app.jobs.finish(id, "failed", `Step ${step}/7 (${MIGRATION_STEPS[step - 1]}): ${msg}. ${this.originText(m)}`);
  }

  private originText(m: MigrationRow): string {
    const src = this.nodeName(m.source_node_id);
    const dst = this.nodeName(m.target_node_id);
    if (m.phase === "failed") {
      return m.was_running ? `The server is still on “${src}”: its world is intact and the server has been started again` : `The server is still on “${src}”: its world is intact (stopped, as it was)`;
    }
    if (m.source_pending && m.target_pending && m.target_started) {
      return `The server is still on “${src}”: its world is intact but stopped: it will be started when “${dst}” comes back and the copy has been removed from there (so that there are never two live servers with the same world)`;
    }
    const parts: string[] = [];
    if (m.target_pending) parts.push(`the partial copy on “${dst}” will be deleted when it reconnects`);
    if (m.source_pending) parts.push(`it will be started again when “${src}” reconnects`);
    return `The server is still on “${src}” with its world intact; ${parts.join("; ")}`;
  }

  /**
   * Tries the pending items of a migration that is undoing or already confirmed, and returns the resulting row. Undoing:
   * first the target (MigrateAbort) and then the source; if the target got to be started and could not be cleaned up,
   * the source is NOT started (never two live servers with the same world). Confirmed: MigrateRetire.
   */
  private async settle(id: string, log: (line: string) => void): Promise<MigrationRow> {
    const repo = this.app.migrations;
    const d = this.deps(silent(log));
    let m = repo.get(id)!;
    if (m.phase === "rolling_back") {
      if (m.target_pending) {
        try {
          await abortTarget(d, m);
          m = repo.update(id, { target_pending: 0 });
          log(`Target clean: what the migration left on “${this.nodeName(m.target_node_id)}” was deleted`);
        } catch (e) {
          log(`Could not clean up the target: ${errorText(e)} (it will be retried)`);
        }
      }
      if (m.source_pending && !(m.target_started && m.target_pending)) {
        try {
          await restartSource(d, m);
          m = repo.update(id, { source_pending: 0 });
          log(`Server started again on “${this.nodeName(m.source_node_id)}”`);
        } catch (e) {
          log(`Could not start the server on the source again: ${errorText(e)} (it will be retried)`);
        }
      }
      if (!m.target_pending && !m.source_pending) m = repo.update(id, { phase: "failed" });
    } else if (m.phase === "committed") {
      try {
        await retireSource(d, m);
        m = repo.update(id, { source_pending: 0, phase: "done" });
        log(`Server retired from “${this.nodeName(m.source_node_id)}” (${m.delete_source ? "data deleted" : `data in ${m.source_slug}.migrated-…`})`);
      } catch (e) {
        log(`Could not retire the server from the source: ${errorText(e)} (it will be retried)`);
      }
    }
    return m;
  }
}
```

```ts
import type { JobDto, NodeDto } from "./api";
import { isActive } from "./jobs";

export const migrationKey = (serverId: string) => ["migration", serverId] as const;
export const proposalKey = (serverId: string, targetNodeId: string) => ["migration-proposal", serverId, targetNodeId] as const;

export interface TargetOption { id: string; label: string; disabled: boolean }

/** Nodes to migrate to: all except the current one; offline ones appear disabled. */
export function targetOptions(nodes: NodeDto[] | undefined, currentNodeId: string): TargetOption[] {
  return (nodes ?? []).filter((n) => n.id !== currentNodeId).map((n) => ({
    id: n.id, label: n.status === "online" ? n.name : `${n.name} (offline)`, disabled: n.status !== "online",
  }));
}

/** The server's migration job in progress (the list comes from newest to oldest). */
export const activeMigrationJob = (jobs: JobDto[] | undefined): JobDto | undefined => jobs?.find((j) => j.type === "migrate" && isActive(j));
/** The server's last migration job, finished or not. */
export const lastMigrationJob = (jobs: JobDto[] | undefined): JobDto | undefined => jobs?.find((j) => j.type === "migrate");

/** "" = the port the panel proposes; a number 1-65535; null if it is not a port. */
export function parsePortInput(s: string): number | undefined | null {
  const t = s.trim();
  if (t === "") return undefined;
  if (!/^\d{1,5}$/.test(t)) return null;
  const n = Number(t);
  return n >= 1 && n <= 65535 ? n : null;
}

export function migrationBody(targetNodeId: string, port: number | undefined, deleteSource: boolean): MigrationRequestInput {
  return port === undefined ? { targetNodeId, deleteSource } : { targetNodeId, port, deleteSource };
}

/** Text under the port field. */
export function portHint(p: MigrationProposalDto | undefined, typed: number | undefined | null): string {
  if (typed === null) return "Type a port between 1 and 65535, or leave it empty to use the proposed one.";
  if (typed !== undefined) return `Port ${typed} will be used.`;
  if (!p) return "Choose the target node first.";
  return p.portChanged
    ? `Proposed: ${p.port} (${p.currentPort} is taken on the target). Type another to change it.`
    : `Proposed: ${p.port}, the same as now. Type another to change it.`;
}

/** Why it cannot be migrated now (null = it can). */
export function migrateBlockedReason(o: {
  sourceOnline: boolean | undefined; active: JobDto | undefined; migration: MigrationDto | null | undefined;
  target: TargetOption | undefined; portInvalid: boolean; proposalError: string | null;
}): string | null {
  if (o.active) return "A migration is already in progress";
  if (o.migration && OPEN_PHASES.has(o.migration.phase)) return "The previous migration still has pending steps";
  if (o.sourceOnline === false) return "The current node is offline";
  if (!o.target) return "Choose the target node";
  if (o.target.disabled) return "The target node is offline";
  if (o.portInvalid) return "The port must be a number between 1 and 65535";
  if (o.proposalError) return o.proposalError;
  return null;
}

export type StepState = "done" | "current" | "failed" | "pending";

/** State of each of the 7 steps according to the job: the step in progress comes from its progress. */
export function stepStates(job: Pick<JobDto, "progress" | "status">): StepState[] {
  const cur = job.status === "ok" ? MIGRATION_STEPS.length + 1 : stepOfProgress(job.progress);
  const failed = job.status === "failed" || job.status === "cancelled";
  return MIGRATION_STEPS.map((_, i) => {
    const n = i + 1;
    if (n < cur) return "done";
    if (n === cur) return failed ? "failed" : "current";
    return "pending";
  });
}

/** What remains pending of an open migration, or null if there is nothing to report. */
export function pendingText(m: MigrationDto, nodeName: (id: string) => string): string | null {
  const src = nodeName(m.sourceNodeId);
  const dst = nodeName(m.targetNodeId);
  if (m.phase === "rolling_back") {
    const parts: string[] = [];
    if (m.targetPending) parts.push(`delete the partial copy on “${dst}” when it reconnects`);
    if (m.sourcePending) parts.push(m.targetPending ? `then start the server on “${src}” again` : `start the server on “${src}” again when it reconnects`);
    return `The migration failed and is being undone: pending: ${parts.join("; ")}.`;
  }
  if (m.phase === "committed") {
    return `Migrated to “${dst}”. The server still has to be retired from node “${src}” (${m.deleteSource ? "deleting its data" : `its data will stay in ${m.sourceSlug}.migrated-…`}) when it reconnects.`;
  }
  return null;
}

/** Text of the confirmation dialog. */
export function confirmText(o: { serverName: string; slug: string; source: string; target: string; port: number; deleteSource: boolean; running: boolean }): string {
  return [
    o.running ? `“${o.serverName}” will be stopped on “${o.source}” during the migration.` : `“${o.serverName}” is stopped on “${o.source}”.`,
    "A pre-migration backup is made, it is sent to the target (checking its sha256) and restored there.",
    `On “${o.target}” it will use port ${o.port} and will be started to check that it works${o.running ? "; afterwards it will keep running" : "; afterwards it will be stopped again"}.`,
    o.deleteSource
      ? `When finished, its data and copies on “${o.source}” WILL BE DELETED.`
      : `When finished, its data and copies on “${o.source}” will be kept in ${o.slug}.migrated-… (delete them by hand when you no longer need them).`,
    `If something fails, the server stays on “${o.source}” with its world intact${o.running ? " and it is started again" : ""}.`,
  ].join(" ");
}

/** Has the migration that was in progress (`prevActiveId`) just finished? It is used to refresh the server. */
export function migrationFinished(prevActiveId: string | null, jobs: JobDto[] | undefined): boolean {
  if (!prevActiveId || !jobs) return false;
  const j = jobs.find((x) => x.id === prevActiveId);
  return !j || !isActive(j);
}
```

```ts
import { useEffect, useRef } from "react";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { OPEN_PHASES, type MigrationDto, type MigrationProposalDto, type MigrationRequestInput } from "@mcsm/shared";
import { api, apiPath, type JobDto } from "@/lib/api";
import { backupsKey } from "@/lib/jobs";
import { activeMigrationJob, migrationFinished, migrationKey, proposalKey } from "@/lib/migration";

/** The server's last migration (or null). While it is open it refreshes every 15 s (the pending items change without a job). */
export function useMigration(serverId: string) {
  return useQuery({
    queryKey: migrationKey(serverId),
    queryFn: async () => (await api.get<{ migration: MigrationDto | null }>(apiPath`/api/servers/${serverId}/migration`)).migration,
    refetchInterval: (q) => (q.state.data && OPEN_PHASES.has(q.state.data.phase) ? 15_000 : false),
  });
}

/** Slug and port the panel proposes for the chosen target. */
export function useMigrationProposal(serverId: string, targetNodeId: string | null) {
  return useQuery({
    queryKey: proposalKey(serverId, targetNodeId ?? ""),
    queryFn: () => api.get<MigrationProposalDto>(`${apiPath`/api/servers/${serverId}/migration/proposal`}?${new URLSearchParams({ targetNodeId: targetNodeId ?? "" })}`),
    enabled: targetNodeId !== null,
    retry: false,
  });
}

export function startMigration(serverId: string, body: MigrationRequestInput): Promise<JobDto> {
  return api.post<JobDto>(apiPath`/api/servers/${serverId}/migration`, body);
}

/** When the migration in progress finishes, refreshes the server (possibly already on another node), the list, the migration and its backups. */
export function useMigrationSync(serverId: string, jobs: JobDto[] | undefined) {
  const qc = useQueryClient();
  const prev = useRef<string | null>(null);
  useEffect(() => {
    if (migrationFinished(prev.current, jobs)) {
      void qc.invalidateQueries({ queryKey: ["server", serverId] });
      void qc.invalidateQueries({ queryKey: ["servers"] });
      void qc.invalidateQueries({ queryKey: migrationKey(serverId) });
      void qc.invalidateQueries({ queryKey: backupsKey(serverId) });
    }
    prev.current = activeMigrationJob(jobs)?.id ?? null;
  }, [jobs, qc, serverId]);
}
```
